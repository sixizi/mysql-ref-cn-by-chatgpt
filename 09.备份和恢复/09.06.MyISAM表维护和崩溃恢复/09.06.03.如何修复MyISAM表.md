# 9.6.3 如何修复 MyISAM 表

建议按阶段处理：

1. 检查所有表：`myisamchk *.MYI`。
2. 对报错表先尝试快速修复：`myisamchk -r -q tbl_name`。
3. 若失败，先备份数据文件，再用恢复模式：`myisamchk -r tbl_name`。
4. 仍失败时使用更慢但更保守的方法：`myisamchk --safe-recover tbl_name`。

如果索引文件头部损坏或索引文件丢失，需要通过表定义文件重新创建索引，再回到快速修复阶段。服务器端也可使用：

```sql
REPAIR TABLE tbl_name;
```
