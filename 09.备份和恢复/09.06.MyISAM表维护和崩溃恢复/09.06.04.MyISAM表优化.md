# 9.6.4 MyISAM 表优化

`myisamchk -r` 可合并碎片行并回收删除或更新留下的空间：

```terminal
myisamchk -r tbl_name
```

也可以使用服务器语句：

```sql
OPTIMIZE TABLE tbl_name;
```

`OPTIMIZE TABLE` 会执行表修复、键分析和索引树排序，由服务器完成操作，避免 `myisamchk` 与服务器直接访问文件产生冲突。

其他有用选项包括 `--analyze`、`--sort-index` 和 `--sort-records=index_num`，分别用于分析键分布、排序索引块和按指定索引排序数据行。
