# 9.6.5 设置 MyISAM 表维护计划

应定期检查表，而不是等到问题发生后再处理。可用 `CHECK TABLE` 和 `REPAIR TABLE`，也可安排 `myisamchk -s`。

可配置服务器通过 `myisam_recover_options` 在启动或访问前自动检查 MyISAM 表。也可以用 cron 定期检查最近更新的表：

```cron
35 0 * * 0 /path/to/myisamchk --fast --silent /path/to/datadir/*/*.MYI
```

对于有大量更新或删除的动态行 MyISAM 表，可定期使用 `OPTIMIZE TABLE` 或在服务器停止时运行 `myisamchk -r --sort-index`。
