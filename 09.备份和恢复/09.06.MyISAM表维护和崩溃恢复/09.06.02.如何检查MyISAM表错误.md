# 9.6.2 如何检查 MyISAM 表错误

普通检查：

```terminal
myisamchk tbl_name.MYI
```

扩展检查更彻底，适合怀疑损坏时使用：

```terminal
myisamchk -e tbl_name.MYI
```

使用 `-s` 或 `--silent` 可只显示错误信息。若需要更多统计信息，可添加 `-i`。

服务器运行时，也可以直接使用：

```sql
CHECK TABLE tbl_name;
```

不要在服务器正在写入同一表时用 `myisamchk` 检查，否则可能得到误报。
