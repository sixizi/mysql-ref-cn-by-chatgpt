# 9.3.2 使用备份进行恢复

如果服务器必须从备份恢复，基本步骤是：

1. 停止服务器或阻止应用写入。
2. 从最近的全量备份恢复数据。
3. 使用 `mysqlbinlog` 将备份完成后至目标时间点的二进制日志转换为 SQL 并重放。
4. 验证数据一致性和应用状态。
5. 恢复服务，并记录事故原因和恢复位置。

对于 `mysqldump` 生成的 SQL 备份，可以用 `mysql` 客户端重新加载。对于物理备份，应使用对应备份工具的恢复命令或恢复文件副本。
