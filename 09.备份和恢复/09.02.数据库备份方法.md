# 9.2 数据库备份方法

常见备份方法包括：

- **MySQL Enterprise Backup**：执行物理备份，支持热备份 InnoDB 表，适合大型生产系统。
- **mysqldump**：生成 SQL 语句或分隔文本的逻辑备份，适用于中小规模数据库和跨版本迁移。
- **`SELECT ... INTO OUTFILE`**：将查询结果写为服务器端文本文件，适合导出部分数据。
- **二进制日志**：记录数据更改，是实现时间点恢复的基础。
- **复制**：提供实时冗余副本，但不能替代备份，因为误操作会同步到副本。
- **文件系统快照**：可在存储层快速创建一致性快照，但要求 MySQL 数据文件处于一致状态。
- **NDB Cluster 备份**：使用 NDB Cluster 管理服务器启动备份，并用 `ndb_restore` 恢复。

选择方法时应考虑数据量、恢复时间目标、备份窗口、存储位置和是否允许服务器停机。生产环境通常组合使用全量备份、增量备份和二进制日志。
