# 9.4.4 重新加载分隔文本格式的备份

先执行表定义文件，再导入数据文件：

```terminal
mysql db1 < t1.sql
mysqlimport db1 t1.txt
```

也可使用 `LOAD DATA`：

```sql
USE db1;
LOAD DATA INFILE 't1.txt' INTO TABLE t1;
```

如果导出时使用了 `--fields-terminated-by`、`--fields-enclosed-by` 或 `--lines-terminated-by`，导入时必须使用完全相同的选项。
