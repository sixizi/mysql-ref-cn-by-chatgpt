# 9.4.1 使用 mysqldump 以 SQL 格式转储数据

导出单个数据库：

```terminal
mysqldump db1 > dump.sql
```

导出多个数据库：

```terminal
mysqldump --databases db1 db2 > dump.sql
```

导出所有数据库：

```terminal
mysqldump --all-databases > dump.sql
```

默认输出包含 `CREATE TABLE` 和 `INSERT` 语句。使用 `--databases` 时，输出还会包含 `CREATE DATABASE` 和 `USE` 语句，因此重新加载时无需显式创建数据库。
