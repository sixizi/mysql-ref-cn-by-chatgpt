# 9.4.3 使用 mysqldump 以分隔文本格式转储数据

`--tab=dir_name` 让 `mysqldump` 为每个表生成两个文件：一个是包含 `CREATE TABLE` 语句的 SQL 文件，另一个是服务器直接写出的制表符分隔数据文件。

```terminal
mysqldump --tab=/tmp db1
```

可在导出时指定字段和行格式：

```terminal
mysqldump --tab=/tmp \
  --fields-terminated-by=',' \
  --fields-enclosed-by='"' \
  --lines-terminated-by='\n' db1
```

分隔文本格式适合导入电子表格、数据管道或其他数据库，但不适合包含复杂类型和字符编码的数据，除非格式选项被完整记录并在导入时使用相同配置。
