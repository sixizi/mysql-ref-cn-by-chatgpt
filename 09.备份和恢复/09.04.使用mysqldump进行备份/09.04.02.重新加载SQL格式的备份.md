# 9.4.2 重新加载 SQL 格式的备份

重新加载不包含 `CREATE DATABASE` 和 `USE` 的转储文件：

```terminal
mysqladmin create db1
mysql db1 < dump.sql
```

重新加载包含这些语句的转储文件：

```terminal
mysql < dump.sql
```

也可以在 `mysql` 客户端中执行 `source` 命令：

```sql
source /path/to/dump.sql
```

重新加载前应确认目标服务器字符集和 SQL 模式是否与导出环境兼容；大型转储文件建议在维护窗口或从副本服务器执行。
