# 9.4.5.2 将数据库从一个服务器复制到另一个服务器

在源服务器导出：

```terminal
mysqldump --databases db1 > dump.sql
```

将 `dump.sql` 复制到目标服务器后重新加载：

```terminal
mysql < dump.sql
```

使用 `--databases` 时，转储文件包含 `CREATE DATABASE` 和 `USE`，目标服务器会自动创建并选择该数据库。

如果希望导入到不同名称的数据库，可省略 `--databases`：

```terminal
mysqldump db1 > dump.sql
mysqladmin create db2
mysql db2 < dump.sql
```
