# 9.4.5.5 使用 mysqldump 测试升级不兼容性

升级前可在生产服务器导出所有数据库对象定义：

```terminal
mysqldump --all-databases --no-data --routines --events > dump-defs.sql
```

在目标版本服务器重新加载：

```terminal
mysql < dump-defs.sql
```

由于该文件不包含表数据，加载速度快，适合快速发现语法、保留字、字符集或对象定义方面的不兼容。确认定义兼容后，再导出数据并测试加载和查询。
