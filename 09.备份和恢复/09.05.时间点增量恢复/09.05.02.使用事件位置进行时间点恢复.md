# 9.5.2 使用事件位置进行时间点恢复

当需要精确停止在某个事件之前时，可使用二进制日志位置。流程如下：

1. 用 `mysqlbinlog` 查看相关日志内容，找到目标事件的位置和时间。
2. 恢复全量备份。
3. 使用 `--start-position` 和 `--stop-position` 选择要重放的日志范围。
4. 将输出传给 `mysql` 执行。

示例：

```terminal
mysqlbinlog --start-position=154 --stop-position=1042 \
  binlog.000003 | mysql -u root -p
```

`--stop-position` 指定的事件不会被重放。恢复前应先在测试环境验证位置选择，避免跳过或重复执行破坏性事务。
