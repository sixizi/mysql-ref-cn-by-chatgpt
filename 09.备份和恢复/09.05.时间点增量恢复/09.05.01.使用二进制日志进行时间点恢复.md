# 9.5.1 使用二进制日志进行时间点恢复

MySQL 8.0 默认启用二进制日志。要查看日志文件：

```sql
SHOW BINARY LOGS;
SHOW MASTER STATUS;
```

`mysqlbinlog` 将二进制事件转换为文本，并可按时间或位置选择部分日志。应用日志即重放其中的数据修改：

```terminal
mysqlbinlog binlog_files | mysql -u root -p
```

多个日志文件应在同一连接中按顺序处理：

```terminal
mysqlbinlog binlog.000001 binlog.000002 | mysql -u root -p
```

如果日志包含 NUL 字节，`mysql` 应使用 `--binary-mode`。若二进制日志已加密，`mysqlbinlog` 需要通过 `--read-from-remote-server` 从服务器读取。
