### 15.7.6.2 SET CHARACTER SET 语句

```
SET {CHARACTER SET | CHARSET}
    {'charset_name' | DEFAULT}
```

该语句将服务器和当前客户端之间发送的所有字符串映射到给定的字符集。SET CHARACTER SET 设置三个会话系统变量：character_set_client 和 character_set_results 被设置为给定的字符集，character_set_connection 被设置为 character_set_database 的值。参见第 12.4 节"连接字符集和排序规则"。

charset_name 可以带引号或不带引号。

可以使用 DEFAULT 值来恢复默认字符集映射。默认值取决于服务器配置。

某些字符集不能用作客户端字符集。尝试使用 SET CHARACTER SET 使用它们会产生错误。参见不允许的客户端字符集。
