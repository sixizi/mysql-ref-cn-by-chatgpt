# 可加载函数的 DROP FUNCTION 语句

此语句删除名为 function_name 的可加载函数。 （DROP FUNCTION 也用于删除存储的函数；请参见第 15.1.29 节，“DROP PROCEDURE 和 DROP FUNCTION 语句”。）DROP FUNCTION 是 CREATE FUNCTION 的补充。

官方英文版参见 [DROP FUNCTION Statement for Loadable Functions](https://dev.mysql.com/doc/refman/8.0/en/drop-function-loadable.html)。
