### 15.7.4.5 UNINSTALL COMPONENT 语句

```
UNINSTALL COMPONENT component_name [, component_name ] ...
```

此语句停用并卸载一个或多个组件。组件为服务器和其他组件提供服务；参见第 7.5 节"MySQL 组件"。UNINSTALL COMPONENT 是 INSTALL COMPONENT 的补充。它需要对 mysql.component 系统表的 DELETE 权限，因为它会删除该表中注册组件的行。UNINSTALL COMPONENT 不会撤销持久化变量，包括使用 INSTALL COMPONENT ... SET PERSIST 持久化的变量。

示例：

```
UNINSTALL COMPONENT 'file://component1', 'file://component2';
```

有关组件命名的信息，参见第 15.7.4.3 节"INSTALL COMPONENT 语句"。

如果发生任何错误，该语句将失败且无任何效果。例如，当组件名称错误、指定的组件未安装或因其他已安装的组件依赖它而无法卸载时，就会发生这种情况。

加载程序服务处理组件卸载，包括从用作注册表的 mysql.component 系统表中删除已卸载的组件。因此，卸载的组件在后续服务器重启的启动序列中不会被加载。

注意

此语句对密钥环组件无效，密钥环组件使用清单文件加载，无法卸载。参见第 8.4.5.2 节"密钥环组件安装"。
