### 15.7.4.3 INSTALL COMPONENT 语句

```
INSTALL COMPONENT component_name [, component_name ...
     [SET variable = expr [, variable = expr] ...]

    variable: {
      {GLOBAL | @@GLOBAL.} [component_prefix.]system_var_name
    | {PERSIST | @@PERSIST.} [component_prefix.]system_var_name
}
```

该语句安装一个或多个组件，这些组件立即变为活跃状态。组件提供可供服务器和其他组件使用的服务；参见第 7.5 节"MySQL 组件"。INSTALL COMPONENT 需要对 mysql.component 系统表的 INSERT 权限，因为它向该表添加一行以注册组件。

示例：
```
INSTALL COMPONENT 'file://component1', 'file://component2';
```

组件使用以 file:// 开头的 URN 命名，该 URN 指示实现该组件的库文件的基本名称，该文件位于 plugin_dir 系统变量指定的目录中。组件名称不包括任何平台相关的文件名后缀，如 .so 或 .dll。（这些命名细节可能会改变，因为组件名称解释本身由服务执行，组件基础设施使得可以用替代实现替换默认服务实现。）

INSTALL COMPONENT 允许在安装一个或多个组件时设置组件系统变量的值。SET 子句使您能够在需要时精确指定变量值，而无需与其他形式的赋值相关的不便或限制。具体来说，您还可以使用以下替代方法设置组件变量：

- 在服务器启动时使用命令行或选项文件中的选项，但这涉及服务器重启。这些值在您安装组件之前不会生效。您可以在命令行上为组件指定无效的变量名而不会触发错误。

- 在服务器运行时通过 SET 语句动态设置，这使您能够修改服务器操作而无需停止和重启它。不允许设置只读变量。

可选的 SET 子句仅将值应用于 INSTALL COMPONENT 语句中指定的组件，而不是应用于该组件的所有后续安装。SET GLOBAL|PERSIST 适用于所有类型的变量，包括只读变量，无需重启服务器。使用 INSTALL COMPONENT 设置的组件系统变量优先于来自命令行或选项文件的任何冲突值。

示例：
```
INSTALL COMPONENT 'file://component1', 'file://component2'
    SET GLOBAL component1.var1 = 12 + 3, PERSIST component2.var2 = 'strings';
```

省略 PERSIST 或 GLOBAL 等同于指定 GLOBAL。

在 SET 中为任何变量指定 PERSIST 会在 INSTALL COMPONENT 加载组件后但在更新 mysql.component 表之前立即静默执行 SET PERSIST_ONLY。如果 SET PERSIST_ONLY 失败，则服务器会卸载所有先前加载的新组件，而不会向 mysql.component 持久化任何内容。

SET 子句仅接受被安装组件的有效变量名，并为所有无效名称发出错误消息。子查询、存储函数和聚合函数不允许作为值表达式的一部分。如果您安装单个组件，则无需在变量名前加上组件名称前缀。

注意

虽然使用 SET 子句指定变量值类似于命令行方式——它在变量注册时立即可用——但 SET 子句处理布尔变量的无效数值方式存在明显差异。例如，如果您将布尔变量设置为 11（component1.boolvar = 11），您会看到以下行为：

- SET 子句产生 true

- 命令行产生 false（11 既不是 ON 也不是 1）

如果发生任何错误，该语句失败且无效。例如，这会在组件名称错误、命名的组件不存在或已安装、或组件初始化失败时发生。

加载程序服务处理组件加载，包括将已安装的组件添加到作为注册表的 mysql.component 系统表。对于后续的服务器重启，mysql.component 中列出的任何组件都会由加载程序服务在启动序列期间加载。即使服务器以 --skip-grant-tables 选项启动，也会发生这种情况。

如果组件依赖于注册表中不存在的服务，并且您尝试安装该组件而不同时安装提供其所依赖服务的组件或组件，则会发生错误：
```
ERROR 3527 (HY000): Cannot satisfy dependency for service 'component_a'
required by component 'component_b'.
```

为避免此问题，请在同一语句中安装所有组件，或在安装其所依赖的任何组件后安装依赖组件。

注意

对于密钥环组件，不要使用 INSTALL COMPONENT。而是使用清单文件配置密钥环组件加载。参见第 8.4.5.2 节"密钥环组件安装"。
