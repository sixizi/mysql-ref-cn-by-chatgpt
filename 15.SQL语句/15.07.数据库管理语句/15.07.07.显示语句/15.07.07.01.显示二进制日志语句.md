### 15.7.7.1 SHOW BINARY LOG STATUS 语句

SHOW BINARY LOG STATUS

此语句提供源服务器上二进制日志文件的状态信息，需要 REPLICATION CLIENT 权限（或已弃用的 SUPER 权限）。

示例：

```
mysql> SHOW BINARY LOG STATUS\G
*************************** 1. row ***************************
                 File: source-bin.000002
             Position: 1307
         Binlog_Do_DB: test
     Binlog_Ignore_DB: manual, mysql
    Executed_Gtid_Set: 3E11FA47-71CA-11E1-9E33-C80AA9429562:1-5
```

SHOW 语句

```
1 row in set (0.00 sec)
```

当使用全局事务 ID 时，Executed_Gtid_Set 显示已在源上执行的事务的 GTID 集合。这与此服务器上 gtid_executed 系统变量的值相同，也与此服务器上 SHOW REPLICA STATUS 输出中 Executed_Gtid_Set 的值相同。
