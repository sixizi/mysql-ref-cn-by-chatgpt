### 15.7.7.6 SHOW COLUMNS 语句

```
SHOW [EXTENDED] [FULL] {COLUMNS | FIELDS}
    {FROM | IN} tbl_name
    [{FROM | IN} db_name]
    [LIKE 'pattern' | WHERE expr]
```

SHOW COLUMNS 显示给定表中列的信息。它也适用于视图。SHOW COLUMNS 仅显示你有某些权限的列的信息。

```
mysql> SHOW COLUMNS FROM City;
+-------------+----------+------+-----+---------+----------------+
| Field       | Type     | Null | Key | Default | Extra          |
+-------------+----------+------+-----+---------+----------------+
| ID          | int(11) | NO    | PRI | NULL    | auto_increment |
| Name        | char(35) | NO   |     |         |                |
| CountryCode | char(3) | NO    | MUL |         |                |
| District    | char(20) | NO   |     |         |                |
| Population | int(11) | NO     |     | 0       |                |
+-------------+----------+------+-----+---------+----------------+
```

`tbl_name FROM db_name` 语法的替代方案是 `db_name.tbl_name`。这两个语句是等价的：

```
SHOW COLUMNS FROM mytable FROM mydb;
SHOW COLUMNS FROM mydb.mytable;
```

可选的 EXTENDED 关键字使输出包含有关 MySQL 内部使用且用户无法访问的隐藏列的信息。

可选的 FULL 关键字使输出包含列排序规则和注释，以及你对每列的权限。

LIKE 子句（如果存在）指示要匹配的列名。可以给出 WHERE 子句以使用更一般的条件选择行，如第 28.8 节"SHOW 语句的扩展"中所述。

数据类型可能与你根据 CREATE TABLE 语句期望的不同，因为 MySQL 有时在创建或更改表时会更改数据类型。发生这种情况的条件在第 15.1.25.7 节"静默列规范更改"中描述。

SHOW COLUMNS 为每个表列显示以下值：

- Field

  列的名称。

- Type

  列数据类型。

- Collation

  非二进制字符串列的排序规则，或其他列的 NULL。仅当使用 FULL 关键字时才显示此值。

- Null

  列的可空性。如果列可以存储 NULL 值，则值为 YES；否则为 NO。

- Key

  列是否被索引：

  - 如果 Key 为空，则列要么未被索引，要么仅作为多列非唯一索引中的辅助列被索引。

  - 如果 Key 为 PRI，则列是 PRIMARY KEY 或是多列 PRIMARY KEY 中的列之一。

  - 如果 Key 为 UNI，则列是 UNIQUE 索引的第一列。（UNIQUE 索引允许多个 NULL 值，但你可以通过检查 Null 字段来判断列是否允许 NULL。）

  - 如果 Key 为 MUL，则列是非唯一索引的第一列，其中允许给定值在列中出现多次。

  如果表的给定列适用多个 Key 值，Key 显示优先级最高的值，顺序为 PRI、UNI、MUL。

  如果 UNIQUE 索引不能包含 NULL 值且表中没有 PRIMARY KEY，则 UNIQUE 索引可能显示为 PRI。如果多列形成复合 UNIQUE 索引，UNIQUE 索引可能显示为 MUL；虽然列的组合是唯一的，但每列仍然可以保存给定值的多个出现。

- Default

  列的默认值。如果列具有显式的 NULL 默认值，或列定义不包含 DEFAULT 子句，则为 NULL。

- Extra

  关于给定列的任何其他可用信息。在以下情况下值非空：

  - 对于具有 AUTO_INCREMENT 属性的列为 auto_increment。

  - 对于具有 ON UPDATE CURRENT_TIMESTAMP 属性的 TIMESTAMP 或 DATETIME 列为 on update CURRENT_TIMESTAMP。

  - 对于生成列为 VIRTUAL GENERATED 或 STORED GENERATED。

  - 对于具有表达式默认值的列为 DEFAULT_GENERATED。

- Privileges

  你对列的权限。仅当使用 FULL 关键字时才显示此值。

- Comment

  列定义中包含的任何注释。仅当使用 FULL 关键字时才显示此值。

表列信息也可从 INFORMATION_SCHEMA COLUMNS 表获得。参见第 28.3.8 节"INFORMATION_SCHEMA COLUMNS 表"。有关隐藏列的扩展信息仅可使用 SHOW EXTENDED COLUMNS 获得；无法从 COLUMNS 表获得。

你可以使用 `mysqlshow db_name tbl_name` 命令列出表的列。

DESCRIBE 语句提供类似于 SHOW COLUMNS 的信息。参见第 15.8.1 节"DESCRIBE 语句"。

SHOW CREATE TABLE、SHOW TABLE STATUS 和 SHOW INDEX 语句也提供有关表的信息。参见第 15.7.7 节"SHOW 语句"。

SHOW COLUMNS 默认包括表的生成的不可见主键（如果有的话）。你可以通过设置 `show_gipk_in_create_table_and_information_schema = OFF` 来在语句的输出中抑制此信息。有关更多信息，参见第 15.1.25.11 节"生成的不可见主键"。
