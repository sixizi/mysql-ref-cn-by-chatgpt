### 15.7.7.10 SHOW CREATE LIBRARY 语句

```
SHOW CREATE LIBRARY [database_name.]library_name
```

返回可用于在指定数据库中重新创建命名的 JavaScript 或 WebAssembly 库的文本；如果未指定数据库，则默认为当前数据库。有关更多信息，请参见第 15.1.19 节"CREATE LIBRARY 语句"。

对于创建库的账户以外的账户，对例程属性的访问取决于授予该账户的权限，如下所述：

- 使用 SHOW_ROUTINE 权限或全局 SELECT 权限，该账户可以查看所有库属性，包括其定义。这意味着 SHOW CREATE LIBRARY 打印库的源代码，并且信息模式库表中的所有库对该账户都可见。

- 使用在包含库的范围内授予的 CREATE ROUTINE、ALTER ROUTINE 或 EXECUTE 权限，该账户可以查看除其定义外的所有例程属性。这意味着 INFORMATION_SCHEMA.LIBRARIES 中的关联行可见，但 SHOW CREATE LIBRARY 不打印库的源代码。

库代码可能包含 SQL 语句（称为 JavaScript SQL 调用）。这些语句受到使用该库的存储程序的 INVOKER 和 DEFINER 安全上下文的限制。此类 SQL 语句遵循适用于存储函数和存储过程的常规限制（请参见第 27.10 节"存储程序的限制"）。

```
mysql> SHOW CREATE LIBRARY jslib.lib1\G
*************************** 1. row ***************************
        Library: lib1
       sql_mode: ONLY_FULL_GROUP_BY,STRICT_TRANS_TABLES,NO_ZERO_IN_DATE,
NO_ZERO_DATE,ERROR_FOR_DIVISION_BY_ZERO,NO_ENGINE_SUBSTITUTION
Create Library: CREATE LIBRARY `lib1`
    LANGUAGE JAVASCRIPT COMMENT "This is lib1"
AS $$
       export function f(n) {
         return n
       }
    $$
1 row in set (0.00 sec)

mysql> SHOW CREATE LIBRARY jslib.lib2\G
*************************** 1. row ***************************

       sql_mode: ONLY_FULL_GROUP_BY,STRICT_TRANS_TABLES,NO_ZERO_IN_DATE,
NO_ZERO_DATE,ERROR_FOR_DIVISION_BY_ZERO,NO_ENGINE_SUBSTITUTION
Create Library: CREATE LIBRARY `lib2`
    LANGUAGE JAVASCRIPT COMMENT "This is lib2"
AS $$
       export function g(n) {
         return n * 2
       }
    $$
1 row in set (0.00 sec)

mysql> SHOW CREATE LIBRARY wasmlib.lib1\G

    LANGUAGE WASM
AS $$AGFzbQEAAAABJwdgA39/fwF/YAAAYAF/AX9gAX8AYAN/fn8BfmAAAX9gBH9/f38BfwJGAhZ3YXNpX3NuYXBzaG90X3ByZXZpZXcxCX
1 row in set (0.0002 sec)

mysql> SHOW CREATE LIBRARY wasmlib.lib2\G

      sql_mode: ONLY_FULL_GROUP_BY,STRICT_TRANS_TABLES,
NO_ZERO_IN_DATE,NO_ZERO_DATE,ERROR_FOR_DIVISION_BY_ZERO,NO_ENGINE_SUBSTITUTION

```
