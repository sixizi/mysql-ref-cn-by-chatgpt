### 15.6.4.2 本地变量作用域和解析

本地变量的作用域是声明它的 BEGIN ... END 块。该变量可以在声明块内嵌套的块中引用，但声明了同名变量的块除外。

由于本地变量仅在存储程序执行期间在作用域内，不允许在存储程序内创建的预处理语句中引用它们。预处理语句的作用域是当前会话，而不是存储程序，因此该语句可能在程序结束后执行，此时变量将不再在作用域内。例如，SELECT ... INTO local_var 不能用作预处理语句。此限制也适用于存储过程和函数参数。参见第 15.5.1 节"PREPARE 语句"。

流程控制语句

本地变量不应与表列同名。如果 SQL 语句（如 SELECT ... INTO 语句）包含对列的引用和同名的已声明本地变量，MySQL 当前将该引用解释为变量名。考虑以下过程定义：

```
CREATE PROCEDURE sp1 (x VARCHAR(5))
BEGIN
  DECLARE xname VARCHAR(5) DEFAULT 'bob';
  DECLARE newname VARCHAR(5);
  DECLARE xid INT;

  SELECT xname, id INTO newname, xid
     FROM table1 WHERE xname = xname;
  SELECT newname;
END;
```

MySQL 将 SELECT 语句中的 xname 解释为对 xname 变量的引用，而不是 xname 列。因此，当调用过程 sp1() 时，newname 变量返回值 'bob'，无论 table1.xname 列的值如何。

类似地，以下过程中的游标定义包含引用 xname 的 SELECT 语句。MySQL 将其解释为对该名称变量的引用，而不是列引用。

```
CREATE PROCEDURE sp2 (x VARCHAR(5))
BEGIN
  DECLARE xname VARCHAR(5) DEFAULT 'bob';
  DECLARE newname VARCHAR(5);
  DECLARE xid INT;
  DECLARE done TINYINT DEFAULT 0;
  DECLARE cur1 CURSOR FOR SELECT xname, id FROM table1;
  DECLARE CONTINUE HANDLER FOR NOT FOUND SET done = 1;

  OPEN cur1;
  read_loop: LOOP
     FETCH FROM cur1 INTO newname, xid;
     IF done THEN LEAVE read_loop; END IF;
     SELECT newname;
  END LOOP;
  CLOSE cur1;
END;
```
