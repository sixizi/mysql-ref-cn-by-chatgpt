### 15.6.4.1 本地变量 DECLARE 语句

```
DECLARE var_name [, var_name] ... type [DEFAULT value]
```

此语句在存储程序中声明本地变量。要为变量提供默认值，请包含 DEFAULT 子句。该值可以指定为表达式；不需要是常量。如果缺少 DEFAULT 子句，初始值为 NULL。

本地变量在数据类型和溢出检查方面的处理方式与存储例程参数相同。请参见第 15.1.22 节"CREATE PROCEDURE and CREATE FUNCTION Statements"。

变量声明必须出现在游标或处理程序声明之前。

本地变量名称不区分大小写。允许的字符和引用规则与其他标识符相同，如第 11.2 节"Schema Object Names"中所述。

本地变量的作用域是声明它的 BEGIN ... END 块。该变量可以在声明块内的嵌套块中引用，但声明同名变量的块除外。

有关变量声明的示例，请参见第 15.6.4.2 节"Local Variable Scope and Resolution"。
