### 15.6.7.2 DECLARE ... HANDLER 语句

```
DECLARE handler_action HANDLER
    FOR condition_value [, condition_value] ...
    statement

handler_action: {
    CONTINUE
  | EXIT
  | UNDO
}

condition_value: {
    mysql_error_code
  | SQLSTATE [VALUE] sqlstate_value
  | condition_name
  | SQLWARNING
  | NOT FOUND
  | SQLEXCEPTION
}
```

DECLARE ... HANDLER 语句指定一个处理程序来处理一个或多个条件。如果这些条件之一发生，指定的语句将执行。statement 可以是简单语句（如 SET var_name = value），或使用 BEGIN 和 END 编写的复合语句（参见第 15.6.1 节"BEGIN ... END 复合语句"）。

处理程序声明必须出现在变量或条件声明之后。

handler_action 值指示处理程序在执行处理程序语句后采取的操作：

- CONTINUE：继续执行当前程序。

- EXIT：终止声明处理程序的 BEGIN ... END 复合语句的执行。即使条件发生在内部块中，这也是成立的。

- UNDO：不支持。

DECLARE ... HANDLER 的 condition_value 指示激活处理程序的特定条件或条件类。它可以采用以下形式：

- mysql_error_code：表示 MySQL 错误代码的整数字面量，例如 1051 指定"未知表"：

```
DECLARE CONTINUE HANDLER FOR 1051
  BEGIN
    -- 处理程序体
  END;
```

不要使用 MySQL 错误代码 0，因为它表示成功而不是错误条件。有关 MySQL 错误代码列表，请参见服务器错误消息参考。

- SQLSTATE [VALUE] sqlstate_value：表示 SQLSTATE 值的 5 字符字符串字面量，例如 '42S01' 指定"未知表"：

```
DECLARE CONTINUE HANDLER FOR SQLSTATE '42S02'
  BEGIN
    -- 处理程序体
  END;
```

不要使用以 '00' 开头的 SQLSTATE 值，因为这些值表示成功而不是错误条件。有关 SQLSTATE 值列表，请参见服务器错误消息参考。

- condition_name：之前使用 DECLARE ... CONDITION 指定的条件名称。条件名称可以与 MySQL 错误代码或 SQLSTATE 值相关联。参见第 15.6.7.1 节"DECLARE ... CONDITION 语句"。

- SQLWARNING：SQLSTATE 值以 '01' 开头的类的简写。

```
DECLARE CONTINUE HANDLER FOR SQLWARNING
  BEGIN
    -- 处理程序体
  END;
```

- NOT FOUND：SQLSTATE 值以 '02' 开头的类的简写。这在游标的上下文中相关，用于控制当游标到达数据集末尾时发生的情况。如果没有更多行可用，将发生 No Data 条件，SQLSTATE 值为 '02000'。要检测此条件，可以为其或 NOT FOUND 条件设置处理程序。

```
DECLARE CONTINUE HANDLER FOR NOT FOUND
  BEGIN
    -- 处理程序体
  END;
```

有关另一个示例，请参见第 15.6.6 节"游标"。NOT FOUND 条件也会在检索不到行的 SELECT ... INTO var_list 语句中发生。

- SQLEXCEPTION：不以 '00'、'01' 或 '02' 开头的 SQLSTATE 值类的简写。

```
DECLARE CONTINUE HANDLER FOR SQLEXCEPTION
  BEGIN
    -- 处理程序体
  END;
```

有关服务器在条件发生时如何选择处理程序的信息，请参见第 15.6.7.6 节"处理程序的作用域规则"。

如果发生了没有声明处理程序的条件，采取的操作取决于条件类：

- 对于 SQLEXCEPTION 条件，存储程序在引发条件的语句处终止，就像有一个 EXIT 处理程序一样。如果程序由另一个存储程序调用，调用程序使用应用于其自己的处理程序的处理程序选择规则来处理条件。

- 对于 SQLWARNING 条件，程序继续执行，就像有一个 CONTINUE 处理程序一样。

- 对于 NOT FOUND 条件，如果条件正常引发，操作是 CONTINUE。如果由 SIGNAL 或 RESIGNAL 引发，操作是 EXIT。

以下示例使用 SQLSTATE '23000' 的处理程序，该状态发生在重复键错误时：

```
mysql> CREATE TABLE test.t (s1 INT, PRIMARY KEY (s1));
Query OK, 0 rows affected (0.00 sec)

mysql> delimiter //

mysql> CREATE PROCEDURE handlerdemo ()
       BEGIN
         DECLARE CONTINUE HANDLER FOR SQLSTATE '23000' SET @x2 = 1;
         SET @x = 1;
         INSERT INTO test.t VALUES (1);
         SET @x = 2;
         INSERT INTO test.t VALUES (1);
         SET @x = 3;
       END;
       //
Query OK, 0 rows affected (0.00 sec)

mysql> CALL handlerdemo()//
Query OK, 0 rows affected (0.00 sec)

mysql> SELECT @x//
    +------+
    | @x   |
    +------+
    | 3    |
    +------+
    1 row in set (0.00 sec)
```

注意，过程执行后 @x 为 3，这表明在错误发生后执行继续到过程的末尾。如果不存在 DECLARE ... HANDLER 语句，MySQL 将在第二个 INSERT 因 PRIMARY KEY 约束失败后采取默认操作 (EXIT)，SELECT @x 将返回 2。

要忽略条件，请为其声明 CONTINUE 处理程序并将其与空块相关联。例如：

```
DECLARE CONTINUE HANDLER FOR SQLWARNING BEGIN END;
```

块标签的作用域不包括在块内声明的处理程序的代码。因此，与处理程序相关联的语句不能使用 ITERATE 或 LEAVE 来引用包含处理程序声明的块的标签。考虑以下示例，其中 REPEAT 块的标签为 retry：

```
CREATE PROCEDURE p ()
BEGIN
  DECLARE i INT DEFAULT 3;
  retry:
     REPEAT
       BEGIN
         DECLARE CONTINUE HANDLER FOR SQLWARNING
           BEGIN
             ITERATE retry;    # 非法
           END;
         IF i < 0 THEN
           LEAVE retry;        # 合法
         END IF;
         SET i = i - 1;
       END;
     UNTIL FALSE END REPEAT;
END;
```

retry 标签在块内的 IF 语句的作用域内。它不在 CONTINUE 处理程序的作用域内，因此该处的引用无效并导致错误：

```
ERROR 1308 (42000): LEAVE with no matching label: retry
```

要避免在处理程序中引用外部标签，请使用以下策略之一：

- 要离开块，请使用 EXIT 处理程序。如果不需要块清理，BEGIN ... END 处理程序体可以为空：

```
DECLARE EXIT HANDLER FOR SQLWARNING BEGIN END;
```

否则，将清理语句放在处理程序体中：

```
DECLARE EXIT HANDLER FOR SQLWARNING
  BEGIN
    block cleanup statements
  END;
```

- 要继续执行，请在 CONTINUE 处理程序中设置状态变量，该变量可以在封闭块中检查以确定处理程序是否被调用。以下示例为此目的使用变量 done：

```
CREATE PROCEDURE p ()
BEGIN
  DECLARE i INT DEFAULT 3;
  DECLARE done INT DEFAULT FALSE;
  retry:
     REPEAT
       BEGIN
         DECLARE CONTINUE HANDLER FOR SQLWARNING
           BEGIN
             SET done = TRUE;
           END;
         IF done OR i < 0 THEN
           LEAVE retry;
         END IF;
         SET i = i - 1;
       END;
     UNTIL FALSE END REPEAT;
END;
```
