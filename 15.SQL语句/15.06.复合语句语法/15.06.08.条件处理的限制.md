### 15.6.8 条件处理的限制

SIGNAL、RESIGNAL 和 GET DIAGNOSTICS 不允许作为预处理语句使用。例如，以下语句是无效的：

```
PREPARE stmt1 FROM 'SIGNAL SQLSTATE "02000"';
```

类别 '04' 中的 SQLSTATE 值不被特殊处理。它们的处理方式与其他异常相同。

在标准 SQL 中，第一个条件与前一个 SQL 语句返回的 SQLSTATE 值相关。在 MySQL 中，这不能保证，因此要获取主错误，你不能这样做：

```
GET DIAGNOSTICS CONDITION 1 @errno = MYSQL_ERRNO;
```

而应该这样做：

```
GET DIAGNOSTICS @cno = NUMBER;
GET DIAGNOSTICS CONDITION @cno @errno = MYSQL_ERRNO;
```
