### 15.6.5.8 WHILE 语句

```
[begin_label:] WHILE search_condition DO
    statement_list
END WHILE [end_label]
```

WHILE 语句中的语句列表会在 search_condition 表达式为真时重复执行。statement_list 由一个或多个 SQL 语句组成，每个语句都以分号 (;) 语句分隔符终止。

WHILE 语句可以带标签。关于标签使用的规则，请参见 Section 15.6.2, "Statement Labels"。

示例：

```
CREATE PROCEDURE dowhile()
BEGIN
  DECLARE v1 INT DEFAULT 5;

  WHILE v1 > 0 DO
     ...
     SET v1 = v1 - 1;
  END WHILE;
END;
```
