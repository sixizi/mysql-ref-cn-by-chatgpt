### 15.6.5.6 REPEAT 语句

```
[begin_label:] REPEAT
    statement_list
UNTIL search_condition
END REPEAT [end_label]
```

REPEAT 语句中的语句列表会重复执行，直到 search_condition 表达式为真。因此，REPEAT 循环至少会执行一次。statement_list 由一个或多个语句组成，每个语句以分号（;）语句分隔符结尾。

REPEAT 语句可以带有标签。关于标签使用的规则，请参见第 15.6.2 节"Statement Labels"。

示例：

```
mysql> delimiter //

mysql> CREATE PROCEDURE dorepeat(p1 INT)
       BEGIN
         SET @x = 0;
         REPEAT
           SET @x = @x + 1;
         UNTIL @x > p1 END REPEAT;
       END
       //
Query OK, 0 rows affected (0.00 sec)

mysql> CALL dorepeat(1000)//
Query OK, 0 rows affected (0.00 sec)

mysql> SELECT @x//
+------+
| @x   |
+------+
| 1001 |
+------+
1 row in set (0.00 sec)
```
