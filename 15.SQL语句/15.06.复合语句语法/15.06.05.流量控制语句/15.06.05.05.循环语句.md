### 15.6.5.5 LOOP 语句

```
[begin_label:] LOOP
    statement_list
END LOOP [end_label]
```

LOOP 实现了一个简单的循环构造，能够重复执行语句列表，该列表由一个或多个语句组成，每个语句都以分号 (;) 语句分隔符终止。循环内的语句重复执行，直到循环被终止。通常，这是通过 LEAVE 语句完成的。在存储函数中，也可以使用 RETURN，它会完全退出函数。

如果忽略包含循环终止语句，将导致无限循环。

LOOP 语句可以带标签。有关标签使用规则，请参见第 15.6.2 节"语句标签"。

示例：

```
CREATE PROCEDURE doiterate(p1 INT)
BEGIN
  label1: LOOP
     SET p1 = p1 + 1;
     IF p1 < 10 THEN
       ITERATE label1;
     END IF;
     LEAVE label1;
  END LOOP label1;
  SET @x = p1;
END;
```
