### 15.6.5.1 CASE 语句

```
CASE case_value
    WHEN when_value THEN statement_list
    [WHEN when_value THEN statement_list] ...
    [ELSE statement_list]
END CASE
```

或：

```
CASE
    WHEN search_condition THEN statement_list
    [WHEN search_condition THEN statement_list] ...
    [ELSE statement_list]
END CASE
```

CASE 语句为存储程序实现了一个复杂的条件构造。

> 注意
>
> 还有一个 CASE 操作符，它与这里描述的 CASE 语句不同。参见第 14.5 节"流控制函数"。CASE 语句不能有 ELSE NULL 子句，并且以 END CASE 而不是 END 终止。

对于第一种语法，case_value 是一个表达式。该值与每个 WHEN 子句中的 when_value 表达式进行比较，直到其中一个相等。当找到相等的 when_value 时，对应的 THEN 子句 statement_list 执行。如果没有 when_value 相等，则执行 ELSE 子句 statement_list（如果存在）。

此语法不能用于测试与 NULL 的相等性，因为 NULL = NULL 为假。参见第 5.3.4.6 节"使用 NULL 值"。

对于第二种语法，每个 WHEN 子句 search_condition 表达式被逐一计算，直到其中一个为真，此时执行其对应的 THEN 子句 statement_list。如果没有 search_condition 为真，则执行 ELSE 子句 statement_list（如果存在）。

如果没有 when_value 或 search_condition 与被测试的值匹配，且 CASE 语句不包含 ELSE 子句，则会产生 Case not found for CASE statement 错误。

每个 statement_list 由一个或多个 SQL 语句组成；不允许空的 statement_list。

要处理没有任何 WHEN 子句匹配值的情况，使用包含空 BEGIN ... END 块的 ELSE，如下例所示。（这里在 ELSE 子句中使用的缩进仅用于清晰起见，在其他方面没有意义。）

```
DELIMITER |

CREATE PROCEDURE p()
  BEGIN
    DECLARE v INT DEFAULT 1;

    CASE v
       WHEN 2 THEN SELECT v;
       WHEN 3 THEN SELECT 0;
       ELSE
         BEGIN
         END;
    END CASE;
  END;
  |
```
