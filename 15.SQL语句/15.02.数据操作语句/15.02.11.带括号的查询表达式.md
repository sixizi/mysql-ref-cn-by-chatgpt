# 带括号的查询表达式

MySQL 8.0.22 及更高版本支持根据上述语法的带括号的查询表达式。最简单的是，带括号的查询表达式包含单个 SELECT 或返回结果集的其他语句，并且不包含以下可选子句： (SELECT 1); (SELECT * FROM INFORMATION_SCHEMA.SCHEMATA WHERE SCHEMA_NAME = 'mysql'); （从 MySQL 8.0.19 开始支持 TABLE 和 VALUES 语句。）带括号的查询表达式还可以包含由一个或多个集合操作（​​例如 UNION）链接的查询，并以任何或所有可选子句结尾： mysql> (SELECT 1 AS result UNION SELECT 2); +--------+ |结果 | +--------+ |      1 | |      2 | +--------+ mysql> (SELECT 1 AS 结果 UNION SELECT 2) LIMIT 1; +--------+ |结果 | +--------+

官方英文版参见 [Parenthesized Query Expressions](https://dev.mysql.com/doc/refman/8.0/en/parenthesized-query-expressions.html)。
