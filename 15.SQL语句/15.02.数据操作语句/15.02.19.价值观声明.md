### 15.2.19 VALUES 语句

VALUES 是一个 DML 语句，它返回一个或多个行的集合作为一个表。换句话说，它是一个表值构造器，同时也可以作为独立的 SQL 语句使用。

```
VALUES row_constructor_list [ORDER BY column_designator] [LIMIT number]

row_constructor_list:
    ROW(value_list)[, ROW(value_list)][, ...]

value_list:
    value[, value][, ...]

column_designator:
    column_index
```

VALUES 语句由 VALUES 关键字后跟一个或多个行构造器列表组成，各行构造器之间用逗号分隔。行构造器由 ROW() 行构造器子句组成，其中包含一个或多个标量值的值列表，这些值用括号括起来。值可以是任何 MySQL 数据类型的字面量，也可以是解析为标量值的表达式。

ROW() 不能为空（但提供的每个标量值都可以是 NULL）。同一 VALUES 语句中的每个 ROW() 的值列表中必须有相同数量的值。

DEFAULT 关键字不受 VALUES 支持，会导致语法错误，除非在 INSERT 语句中用于提供值时使用。

VALUES 的输出是一个表：

```
mysql> VALUES ROW(1,-2,3), ROW(5,7,9), ROW(4,6,8);
+----------+----------+----------+
| column_0 | column_1 | column_2 |
+----------+----------+----------+
|        1 |       -2 |        3 |
|        5 |        7 |        9 |
|        4 |        6 |        8 |
+----------+----------+----------+
3 rows in set (0.00 sec)
```

VALUES 输出表的列具有隐式命名的列 column_0、column_1、column_2 等，始终从 0 开始。这个事实可以用来通过可选的 ORDER BY 子句按列对行进行排序，其方式与该子句在 SELECT 语句中的工作方式相同，如下所示：

```
mysql> VALUES ROW(1,-2,3), ROW(5,7,9), ROW(4,6,8) ORDER BY column_1;
+----------+----------+----------+
| column_0 | column_1 | column_2 |
+----------+----------+----------+
|        1 |       -2 |        3 |
|        4 |        6 |        8 |
|        5 |        7 |        9 |
+----------+----------+----------+
3 rows in set (0.00 sec)
```

VALUES 语句还支持 LIMIT 子句来限制输出中的行数。

VALUES 语句对列值的数据类型很宽松；你可以在同一列中混合类型，如下所示：

```
mysql> VALUES ROW("q", 42, '2019-12-18'),
     ->    ROW(23, "abc", 98.6),
     ->    ROW(27.0002, "Mary Smith", '{"a": 10, "b": 25}');
+----------+------------+--------------------+
| column_0 | column_1    | column_2           |
+----------+------------+--------------------+
| q        | 42          | 2019-12-18         |
| 23       | abc         | 98.6               |
| 27.0002  | Mary Smith  | {"a": 10, "b": 25} |
+----------+------------+--------------------+
3 rows in set (0.00 sec)
```

**重要**

VALUES 与一个或多个 ROW() 实例一起充当表值构造器；虽然它可以用于在 INSERT 或 REPLACE 语句中提供值，但不要将其与同样用于此目的的 VALUES 关键字混淆。你也不应该将其与在 INSERT ... ON DUPLICATE KEY UPDATE 中引用列值的 VALUES() 函数混淆。

你还应该记住，ROW() 是行值构造器（参见第 15.2.15.5 节"行子查询"），而 VALUES ROW() 是表值构造器；两者不能互换使用。

VALUES 可以在许多可以使用 SELECT 的情况下使用，包括以下列出的情况：

- 与 UNION 一起使用，如下所示：

```
mysql> SELECT 1,2 UNION SELECT 10,15;
+----+----+
| 1  | 2  |
+----+----+
| 1  | 2  |
| 10 | 15 |
+----+----+
2 rows in set (0.00 sec)

mysql> VALUES ROW(1,2) UNION VALUES ROW(10,15);
+----------+----------+
| column_0 | column_1 |
+----------+----------+
|        1 |        2 |
|       10 |       15 |
+----------+----------+
2 rows in set (0.00 sec)
```

你可以将具有多行的构造表联合在一起，如下所示：

```
mysql> VALUES ROW(1,2), ROW(3,4), ROW(5,6)
     >     UNION VALUES ROW(10,15),ROW(20,25);
+----------+----------+
| column_0 | column_1 |
+----------+----------+
|        1 |        2 |
|        3 |        4 |
|        5 |        6 |
|       10 |       15 |
|       20 |       25 |
+----------+----------+
5 rows in set (0.00 sec)
```

在这种情况下，你也可以（通常更可取）完全省略 UNION，使用单个 VALUES 语句，如下所示：

```
mysql> VALUES ROW(1,2), ROW(3,4), ROW(5,6), ROW(10,15), ROW(20,25);
+----------+----------+
| column_0 | column_1 |
+----------+----------+
|        1 |        2 |
|        3 |        4 |
|        5 |        6 |
|       10 |       15 |
|       20 |       25 |
+----------+----------+
```

VALUES 也可以在与 SELECT 语句、TABLE 语句或两者的联合中使用。

UNION 中的构造表必须包含相同数量的列，就像你使用 SELECT 一样。有关更多示例，请参见第 15.2.18 节"UNION 子句"。

你可以将 EXCEPT 和 INTERSECT 与 VALUES 以与 UNION 大致相同的方式使用，如下所示：

```
mysql> VALUES ROW(1,2), ROW(3,4), ROW(5,6)
     ->   INTERSECT
     -> VALUES ROW(10,15), ROW(20,25), ROW(3,4);
+----------+----------+
| column_0 | column_1 |
+----------+----------+
|        3 |        4 |
+----------+----------+
1 row in set (0.00 sec)

mysql> VALUES ROW(1,2), ROW(3,4), ROW(5,6)
     ->   EXCEPT
     -> VALUES ROW(10,15), ROW(20,25), ROW(3,4);
+----------+----------+
| column_0 | column_1 |
+----------+----------+
|        1 |        2 |
|        5 |        6 |
+----------+----------+
2 rows in set (0.00 sec)
```

有关更多信息，请参见第 15.2.4 节"EXCEPT 子句"和第 15.2.8 节"INTERSECT 子句"。

- 在联接中。有关更多信息和示例，请参见第 15.2.13.2 节"JOIN 子句"。

- 代替 INSERT 或 REPLACE 语句中的 VALUES()，在这种情况下其语义与此处描述的略有不同。有关详细信息，请参见第 15.2.7 节"INSERT 语句"。

- 代替 CREATE TABLE ... SELECT 和 CREATE VIEW ... SELECT 中的源表。有关更多信息和示例，请参见这些语句的描述。
