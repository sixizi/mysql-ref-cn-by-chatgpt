# UNION 子句

query_expression_body：请参见第 15.2.14 节“UNION、INTERSECT 和 EXCEPT 的集合操作” UNION 将多个查询块的结果组合到单个结果集中。此示例使用 SELECT 语句： mysql> SELECT 1, 2; +---+---+ | 1 | 2 | +---+---+ | 1 | 2 | +---+---+ mysql> 选择 'a', 'b'; +---+---+ |一个 |乙| +---+---+ |一个 |乙| +---+---+ mysql> SELECT 1, 2 UNION SELECT 'a', 'b'; +---+---+ | 1 | 2 | +---+---+ | 1 | 2 | |一个 |乙| +---+---+ MySQL 8.0 中的 UNION 处理与 MySQL 5.7 相比 在 MySQL 8.0 中，SELECT 和 UNION 的解析器规则被重构为更加一致（相同的 SELECT 语法在每个此类上下文中统一应用）并减少重复。

官方英文版参见 [UNION Clause](https://dev.mysql.com/doc/refman/8.0/en/union.html)。
