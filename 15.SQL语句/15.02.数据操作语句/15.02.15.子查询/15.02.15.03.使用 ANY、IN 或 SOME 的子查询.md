# 使用 ANY、IN 或 SOME 的子查询

语法： 操作数 Comparison_operator ANY（子查询） 操作数 IN（子查询） 操作数 Comparison_operator SOME（子查询） 其中，comparison_operator 是以下运算符之一： = > < >= <= <> != ANY 关键字必须跟在比较运算符之后，表示“如果子查询返回的列中的任何值的比较结果为 TRUE，则返回 TRUE”。例如： SELECT s1 FROM t1 WHERE s1 > ANY (SELECT s1 FROM t2);

官方英文版参见 [Subqueries with ANY, IN, or SOME](https://dev.mysql.com/doc/refman/8.0/en/any-in-some-subqueries.html)。
