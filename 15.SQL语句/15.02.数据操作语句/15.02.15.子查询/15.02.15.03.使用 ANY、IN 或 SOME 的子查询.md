### 15.2.15.3 使用 ANY、IN 或 SOME 的子查询

语法：

```
operand comparison_operator ANY (subquery)
operand IN (subquery)
operand comparison_operator SOME (subquery)
```

其中 comparison_operator 是以下运算符之一：

```
=   >   <   >=   <=   <>   !=
```

ANY 关键字必须跟在比较运算符之后，表示"如果比较对子查询返回的列中的任何值都为真，则返回 TRUE"。例如：

```
SELECT s1 FROM t1 WHERE s1 > ANY (SELECT s1 FROM t2);
```

假设表 t1 中有一行包含 (10)。如果表 t2 包含 (21,14,7)，则该表达式为 TRUE，因为 t2 中有一个值 7 小于 10。如果表 t2 包含 (20,10) 或表 t2 为空，则该表达式为 FALSE。如果表 t2 包含 (NULL,NULL,NULL)，则该表达式为未知（即 NULL）。

当与子查询一起使用时，IN 是 = ANY 的别名。因此，这两个语句是相同的：

```
SELECT s1 FROM t1 WHERE s1 = ANY (SELECT s1 FROM t2);
SELECT s1 FROM t1 WHERE s1 IN    (SELECT s1 FROM t2);
```

当与表达式列表一起使用时，IN 和 = ANY 不是同义词。IN 可以接受表达式列表，但 = ANY 不能。参见第 14.4.2 节"比较函数和运算符"。

NOT IN 不是 <> ANY 的别名，而是 <> ALL 的别名。参见第 15.2.15.4 节"使用 ALL 的子查询"。

SOME 是 ANY 的别名。因此，这两个语句是相同的：

```
SELECT s1 FROM t1 WHERE s1 <> ANY (SELECT s1 FROM t2);
SELECT s1 FROM t1 WHERE s1 <> SOME (SELECT s1 FROM t2);
```

SOME 这个词的使用很少见，但这个例子说明了为什么它可能有用。对大多数人来说，英文短语"a is not equal to any b"意思是"没有 b 等于 a"，但这不是 SQL 语法的含义。该语法的意思是"存在某个 b 使得 a 不等于它"。使用 <> SOME 有助于确保每个人都理解查询的真实含义。

在标量 IN、ANY 或 SOME 子查询中，如果表仅包含单个列，则可以使用 TABLE。如果 t2 只有一列，本节前面所示的语句可以按如下所示编写，在每种情况下用 TABLE t2 替换 SELECT s1 FROM t2：

```
SELECT s1 FROM t1 WHERE s1 > ANY (TABLE t2);

SELECT s1 FROM t1 WHERE s1 = ANY (TABLE t2);

SELECT s1 FROM t1 WHERE s1 IN (TABLE t2);

SELECT s1 FROM t1 WHERE s1 <> ANY      (TABLE t2);

SELECT s1 FROM t1 WHERE s1 <> SOME (TABLE t2);
```
