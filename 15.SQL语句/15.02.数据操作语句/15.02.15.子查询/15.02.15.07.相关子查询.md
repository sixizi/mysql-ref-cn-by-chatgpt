### 15.2.15.7 相关子查询

相关子查询是指包含对外部查询中也出现的表的引用的子查询。例如：

```
SELECT * FROM t1
  WHERE column1 = ANY (SELECT column1 FROM t2
                       WHERE t2.column2 = t1.column2);
```

注意子查询包含对 t1 的列的引用，即使子查询的 FROM 子句没有提及表 t1。因此，MySQL 会查看子查询外部，并在外部查询中找到 t1。

假设表 t1 包含一行，其中 column1 = 5 且 column2 = 6；同时，表 t2 包含一行，其中 column1 = 5 且 column2 = 7。简单表达式 ... WHERE column1 = ANY (SELECT column1 FROM t2) 将为 TRUE，但在此示例中，子查询内的 WHERE 子句为 FALSE（因为 (5,6) 不等于 (5,7)），所以整个表达式为 FALSE。

作用域规则：MySQL 从内向外进行计算。例如：

```
SELECT column1 FROM t1 AS x
  WHERE x.column1 = (SELECT column1 FROM t2 AS x
    WHERE x.column1 = (SELECT column1 FROM t3
      WHERE x.column2 = t3.column1));
```

在此语句中，x.column2 必须是表 t2 中的列，因为 SELECT column1 FROM t2 AS x ... 重命名了 t2。它不是表 t1 中的列，因为 SELECT column1 FROM t1 ... 是更外层的外部查询。

当启用了 optimizer_switch 变量的 subquery_to_derived 标志时，优化器可以将相关标量子查询转换为派生表。考虑此处显示的查询：

```
SELECT * FROM t1
    WHERE ( SELECT a FROM t2
              WHERE t2.a=t1.a ) > 0;
```

为了避免对给定派生表多次物化，我们可以改为物化一次派生表，该派生表在内部查询中引用的表的连接列（t2.a）上添加分组，然后在提升的谓词（t1.a = derived.a）上进行外连接，以便选择与外部行匹配的正确组。（如果子查询已经有显式分组，额外的分组将添加到分组列表的末尾。）之前显示的查询可以这样重写：

```
SELECT t1.* FROM t1
    LEFT OUTER JOIN
        (SELECT a, COUNT(*) AS ct FROM t2 GROUP BY a) AS derived
    ON t1.a = derived.a
        AND
        REJECT_IF(
            (ct > 1),
            "ERROR 1242 (21000): Subquery returns more than 1 row"
```

在重写的查询中，REJECT_IF() 表示一个内部函数，它测试给定的条件（此处为比较 ct > 1），如果条件为真，则引发给定的错误（在本例中为 ER_SUBQUERY_NO_1_ROW）。这反映了优化器在计算 JOIN 或 WHERE 子句时执行的基数检查，该检查仅在子查询返回不超过一行时才执行任何提升的谓词。

可以执行此类转换，前提是满足以下条件：

- 子查询可以是 SELECT 列表、WHERE 条件或 HAVING 条件的一部分，但不能是 JOIN 条件的一部分，也不能包含 OFFSET 子句。子查询可能包含 LIMIT 1，但不能包含其他 LIMIT 子句；它必须使用字面值 1，而不是其他值、占位符 (?) 或变量。此外，子查询不能包含任何集合操作，如 UNION。

- WHERE 子句可能包含一个或多个谓词，用 AND 组合。如果 WHERE 子句包含 OR 子句，则无法进行转换。WHERE 子句谓词中至少有一个必须符合转换条件，且其中任何一个都不能拒绝转换。

- 要符合转换条件，WHERE 子句谓词必须是等式谓词；其他比较谓词不符合转换条件。谓词必须使用等号运算符 = 进行比较；此上下文中不支持空安全运算符 <=>。

  操作数可以是列值、常量和使用这些的表达式，包括以列值作为参数调用的确定性函数。

- 仅包含内部引用的 WHERE 子句谓词不符合转换条件，因为它可以在分组之前进行计算。仅包含外部引用的 WHERE 子句谓词符合转换条件，即使它可以提升到外部查询块。这可以通过在派生表中添加不带分组的基数检查来实现。

- 要符合条件，WHERE 子句谓词必须有一个操作数仅包含内部引用，另一个操作数仅包含外部引用。如果谓词由于此规则不符合条件，则查询转换被拒绝。

- 相关列只能出现在子查询的 WHERE 子句中（不能在 SELECT 列表、JOIN 或 ORDER BY 子句、GROUP BY 列表或 HAVING 子句中）。子查询的 FROM 列表中的派生表内也不能有任何相关列。

- 相关列不能包含在聚合函数的参数列表中。

- 相关列必须在直接包含正在考虑进行转换的子查询的查询块中解析。

- 相关列不能出现在 WHERE 子句中的嵌套标量子查询中。

- 子查询不能包含任何窗口函数，且不能包含任何在子查询外部的查询块中进行聚合的聚合函数。COUNT() 聚合函数（如果包含在子查询的 SELECT 列表元素中）必须在最顶层，且不能是表达式的一部分。

另见第 15.2.15.8 节"派生表"。
