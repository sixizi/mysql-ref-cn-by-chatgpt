### 15.2.15.1 作为标量操作数的子查询

在最简单的形式中，子查询是返回单个值的标量子查询。标量子查询是一个简单的操作数，你可以在几乎任何允许单个列值或字面值的地方使用它，并且你可以期望它具有所有操作数都具有的那些特征：数据类型、长度、是否可以为 NULL 的指示等。例如：

```
CREATE TABLE t1 (s1 INT, s2 CHAR(5) NOT NULL);
INSERT INTO t1 VALUES(100, 'abcde');
SELECT (SELECT s2 FROM t1);
```

这个 SELECT 中的子查询返回单个值（'abcde'），其数据类型为 CHAR，长度为 5，字符集和排序规则等于 CREATE TABLE 时生效的默认值，并且有一个指示表明列中的值可以为 NULL。标量子查询选择的值的可空性不会被复制，因为如果子查询结果为空，则结果为 NULL。对于刚才显示的子查询，如果 t1 为空，即使 s2 是 NOT NULL，结果也会是 NULL。

有一些上下文中标量子查询无法使用。如果语句仅允许字面值，则不能使用子查询。例如，LIMIT 需要字面整数参数，LOAD DATA 需要字面字符串文件名。你不能使用子查询来提供这些值。

当你在以下部分中看到包含相当简洁的构造（SELECT column1 FROM t1）的示例时，想象你自己的代码包含更加多样和复杂的构造。

假设我们创建两个表：

```
CREATE TABLE t1 (s1 INT);
INSERT INTO t1 VALUES (1);
CREATE TABLE t2 (s1 INT);
INSERT INTO t2 VALUES (2);
```

然后执行一个 SELECT：

```
SELECT (SELECT s1 FROM t2) FROM t1;
```

结果是 2，因为 t2 中有一行包含列 s1，其值为 2。

前面的查询也可以这样写，使用 TABLE：

```
SELECT (TABLE t2) FROM t1;
```

标量子查询可以是表达式的一部分，但要记住括号，即使子查询是为函数提供参数的操作数。例如：

```
SELECT UPPER((SELECT s1 FROM t1)) FROM t2;
```

使用 SELECT UPPER((TABLE t1)) FROM t2 也可以获得相同的结果。
