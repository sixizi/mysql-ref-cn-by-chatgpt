### 15.2.16 TABLE 语句

TABLE 是一个 DML 语句，返回指定表的行和列。

```
TABLE table_name
    [ORDER BY column_name]
    [LIMIT number [OFFSET number]]
    [INTO OUTFILE 'file_name'
        [{FIELDS | COLUMNS}
            [TERMINATED BY 'string']
            [[OPTIONALLY] ENCLOSED BY 'char']
            [ESCAPED BY 'char']
        ]
        [LINES
            [STARTING BY 'string']
            [TERMINATED BY 'string']
        ]
    | INTO DUMPFILE 'file_name'
    | INTO var_name [, var_name] ...]
```

TABLE 语句在某些方面的作用类似于 SELECT。给定一个名为 t 的表，以下两个语句产生相同的输出：

```
TABLE t;

SELECT * FROM t;
```

你可以使用 ORDER BY 和 LIMIT 子句分别对 TABLE 产生的行进行排序和限制数量。这些子句的功能与用于 SELECT 时相同（包括 LIMIT 的可选 OFFSET 子句），如下所示：

```
mysql> TABLE t;
+----+----+
| a | b |
+----+----+
| 1 | 2 |
| 6 | 7 |
| 9 | 5 |
| 10 | -4 |
| 11 | -1 |
| 13 | 3 |
| 14 | 6 |
+----+----+
7 rows in set (0.00 sec)

mysql> TABLE t ORDER BY b;
+----+----+
| a | b |
+----+----+
| 10 | -4 |
| 11 | -1 |
| 1 | 2 |
| 13 | 3 |
| 9 | 5 |
| 14 | 6 |
| 6 | 7 |
+----+----+
7 rows in set (0.00 sec)

mysql> TABLE t LIMIT 3;
+---+---+
| a | b |
+---+---+
| 1 | 2 |
| 6 | 7 |
| 9 | 5 |
+---+---+
3 rows in set (0.00 sec)

mysql> TABLE t ORDER BY b LIMIT 3;
+----+----+
| a | b |
+----+----+
| 10 | -4 |
| 11 | -1 |
| 1 | 2 |
+----+----+
3 rows in set (0.00 sec)

mysql> TABLE t ORDER BY b LIMIT 3 OFFSET 2;
+----+----+
| a | b |
+----+----+
| 1 | 2 |
| 13 | 3 |
| 9 | 5 |
+----+----+
3 rows in set (0.00 sec)
```

TABLE 与 SELECT 在两个关键方面有所不同：

- TABLE 始终显示表的所有列。

  例外：TABLE 的输出不包括不可见列。参见第 15.1.25.10 节"不可见列"。

- TABLE 不允许对行进行任意过滤；即 TABLE 不支持任何 WHERE 子句。

要限制返回的表列、过滤超出 ORDER BY 和 LIMIT 所能实现的行，或两者兼有，请使用 SELECT。

TABLE 可以与临时表一起使用。

TABLE 也可以在许多其他构造中代替 SELECT 使用，包括以下列出的情况：

- 与集合运算符（如 UNION）一起使用，如下所示：

```
mysql> TABLE t1;
+---+----+
| a | b |
+---+----+
| 2 | 10 |
| 5 | 3 |
| 7 | 8 |
+---+----+
3 rows in set (0.00 sec)

mysql> TABLE t2;
+---+---+
| a | b |
+---+---+
| 1 | 2 |
| 3 | 4 |
| 6 | 7 |
+---+---+
3 rows in set (0.00 sec)

mysql> TABLE t1 UNION TABLE t2;
+---+----+
| a | b |
+---+----+
| 2 | 10 |
| 5 | 3 |
| 7 | 8 |
| 1 | 2 |
| 3 | 4 |
| 6 | 7 |
+---+----+
6 rows in set (0.00 sec)
```

上面所示的 UNION 等价于以下语句：

```
mysql> SELECT * FROM t1 UNION SELECT * FROM t2;
+---+----+
| a | b |
+---+----+
| 2 | 10 |
| 5 | 3 |
| 7 | 8 |
| 1 | 2 |
| 3 | 4 |
| 6 | 7 |
+---+----+
6 rows in set (0.00 sec)
```

TABLE 也可以在集合操作中与 SELECT 语句、VALUES 语句或两者一起使用。参见第 15.2.18 节"UNION 子句"、第 15.2.4 节"EXCEPT 子句"和第 15.2.8 节"INTERSECT 子句"，了解更多信息和示例。另见第 15.2.14 节"使用 UNION、INTERSECT 和 EXCEPT 的集合操作"。

- 与 INTO 一起使用以填充用户变量，以及与 INTO OUTFILE 或 INTO DUMPFILE 一起使用以将表数据写入文件。参见第 15.2.13.1 节"SELECT ... INTO 语句"，了解更多具体信息和示例。

- 在许多可以使用子查询的情况下。给定任何具有名为 a 的列的表 t1，以及具有单个列的第二个表 t2，以下语句是可能的：

```
SELECT * FROM t1 WHERE a IN (TABLE t2);
```

假设表 t1 的单个列名为 x，前面的语句等价于此处显示的每个语句（在任一情况下都产生完全相同的结果）：

```
SELECT * FROM t1 WHERE a IN (SELECT x FROM t2);

SELECT * FROM t1 WHERE a IN (SELECT * FROM t2);
```

参见第 15.2.15 节"子查询"，了解更多信息。

- 与 INSERT 和 REPLACE 语句一起使用，在你本来会使用 SELECT * 的地方。参见第 15.2.7.1 节"INSERT ... SELECT 语句"，了解更多信息和示例。

- TABLE 也可以在许多情况下用于代替 CREATE TABLE ... SELECT 或 CREATE VIEW ... SELECT 中的 SELECT。参见这些语句的描述，了解更多信息和示例。
