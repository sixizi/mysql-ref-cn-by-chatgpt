# 更改表示例

首先创建表 t1，如下所示：CREATE TABLE t1 (a INTEGER, b CHAR(10));要将表从 t1 重命名为 t2： ALTER TABLE t1 RENAME t2;要将列 a 从 INTEGER 更改为 TINYINT NOT NULL（名称保持不变），将列 b 从 CHAR(10) 更改为 CHAR(20) 并将其从 b 重命名为 c： ALTER TABLE t2 MODIFY a TINYINT NOT NULL, CHANGE b c CHAR(20);

官方英文版参见 [ALTER TABLE Examples](https://dev.mysql.com/doc/refman/8.0/en/alter-table-examples.html)。
