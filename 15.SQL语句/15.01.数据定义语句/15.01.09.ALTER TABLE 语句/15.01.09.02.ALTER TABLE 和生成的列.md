### 15.1.11.2 ALTER TABLE 和生成列

ALTER TABLE 对生成列允许的操作是 ADD、MODIFY 和 CHANGE。

- 可以添加生成列。
  ```
  CREATE TABLE t1 (c1 INT);
  ALTER TABLE t1 ADD COLUMN c2 INT GENERATED ALWAYS AS (c1 + 1) STORED;
  ```

- 可以修改生成列的数据类型和表达式。
  ```
  CREATE TABLE t1 (c1 INT, c2 INT GENERATED ALWAYS AS (c1 + 1) STORED);
  ALTER TABLE t1 MODIFY COLUMN c2 TINYINT GENERATED ALWAYS AS (c1 + 5) STORED;
  ```

- 如果没有其他列引用生成列，可以重命名或删除生成列。
  ```
  CREATE TABLE t1 (c1 INT, c2 INT GENERATED ALWAYS AS (c1 + 1) STORED);
  ALTER TABLE t1 CHANGE c2 c3 INT GENERATED ALWAYS AS (c1 + 1) STORED;
  ALTER TABLE t1 DROP COLUMN c3;
  ```

- 虚拟生成列不能改为存储生成列，反之亦然。要解决此问题，请删除该列，然后使用新定义添加它。
  ```
  CREATE TABLE t1 (c1 INT, c2 INT GENERATED ALWAYS AS (c1 + 1) VIRTUAL);
  ALTER TABLE t1 DROP COLUMN c2;
  ALTER TABLE t1 ADD COLUMN c2 INT GENERATED ALWAYS AS (c1 + 1) STORED;
  ```

- 非生成列可以改为存储生成列，但不能改为虚拟生成列。
  ```
  CREATE TABLE t1 (c1 INT, c2 INT);
  ALTER TABLE t1 MODIFY COLUMN c2 INT GENERATED ALWAYS AS (c1 + 1) STORED;
  ```

- 存储生成列（不是虚拟生成列）可以改为非生成列。存储的生成值成为非生成列的值。
  ```
  CREATE TABLE t1 (c1 INT, c2 INT GENERATED ALWAYS AS (c1 + 1) STORED);
  ALTER TABLE t1 MODIFY COLUMN c2 INT;
  ```

#### ALTER TABLE 语句

- 对于存储列，ADD COLUMN 不是原地操作（不使用临时表完成），因为表达式必须由服务器计算。对于存储列，索引更改是原地进行的，表达式更改不是原地进行的。列注释的更改是原地进行的。

- 对于非分区表，ADD COLUMN 和 DROP COLUMN 是虚拟列的原地操作。但是，添加或删除虚拟列不能与其他 ALTER TABLE 操作结合进行原地操作。

  对于分区表，ADD COLUMN 和 DROP COLUMN 不是虚拟列的原地操作。

- InnoDB 支持虚拟生成列上的二级索引。在虚拟生成列上添加或删除二级索引是原地操作。有关更多信息，请参见第 15.1.25.9 节"二级索引和生成列"。

- 当向表添加或修改 VIRTUAL 生成列时，不能保证由生成列表达式计算的数据不会超出列的范围。这可能导致返回不一致的数据和意外失败的语句。为了允许控制是否对此类列进行验证，ALTER TABLE 支持 WITHOUT VALIDATION 和 WITH VALIDATION 子句：

  - 使用 WITHOUT VALIDATION（如果未指定任何子句，则为默认值），执行原地操作（如果可能），不检查数据完整性，语句完成速度更快。但是，如果值超出范围，稍后从表读取时可能会报告该列的警告或错误。

  - 使用 WITH VALIDATION，ALTER TABLE 复制表。如果发生超出范围或任何其他错误，语句失败。由于执行了表复制，语句耗时更长。

  WITHOUT VALIDATION 和 WITH VALIDATION 仅允许用于 ADD COLUMN、CHANGE COLUMN 和 MODIFY COLUMN 操作。否则，会发生 ER_WRONG_USAGE 错误。

- 如果表达式计算导致截断或向函数提供不正确的输入，ALTER TABLE 语句将以错误终止，DDL 操作被拒绝。

- 更改列 col_name 默认值的 ALTER TABLE 语句也可能更改引用该列的生成列表达式的值（使用 col_name），这可能更改引用该列的生成列表达式的值（使用 DEFAULT(col_name)）。因此，如果任何生成列表达式使用 DEFAULT()，更改列定义的 ALTER TABLE 操作会导致表重建。
