### 15.1.19 CREATE LIBRARY 语句

```
CREATE LIBRARY [IF NOT EXISTS] [database.]library
    LANGUAGE language
    [COMMENT "comment_text"]
    AS code
```

该语句在指定的数据库中创建一个库。如果未指定数据库，则在当前数据库中创建该库。库名可以是任何有效的 SQL 标识符。LANGUAGE 必须是 JavaScript 或 Wasm（不区分大小写）。

COMMENT 是可选的。注释文本必须用引号括起来。

code 是一个字符串，由 JavaScript 代码或已编译 WebAssembly 代码的 Base64 或十六进制编码组成，在创建时检查其有效性。无效代码会导致语句被拒绝并返回错误。代码字符串可以用美元符号引用或单引号引用；只要未设置 ANSI_QUOTES SQL 模式，也可以用双引号引用。

要执行 CREATE LIBRARY，用户必须具有 CREATE ROUTINE 权限。

要使用在存储程序中使用此语句创建的库，用户必须具有 EXECUTE 权限。每当创建使用该库的函数或过程时都会检查此权限。

在以下示例中，第一条语句在 jslib 数据库中创建一个名为 lib1 的 JavaScript 库。随后的 SELECT 语句显示信息架构 LIBRARIES 表中对应于刚创建的库的行。

```
mysql> CREATE LIBRARY IF NOT EXISTS jslib.lib1 LANGUAGE JAVASCRIPT
    ->     AS $$
    $>       export function f(n) {
    $>         return n
    $>       }
    $>     $$;
Query OK, 0 rows affected (0.02 sec)

mysql> SELECT * FROM information_schema.LIBRARIES
    -> WHERE LIBRARY_SCHEMA='jslib'\G
```
