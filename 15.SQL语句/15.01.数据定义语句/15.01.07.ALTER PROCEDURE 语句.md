### 15.1.9 ALTER PROCEDURE 语句

```
ALTER PROCEDURE proc_name [characteristic ...]

characteristic: {
    COMMENT 'string'
  | LANGUAGE {SQL | JAVASCRIPT}
  | { CONTAINS SQL | NO SQL | READS SQL DATA | MODIFIES SQL DATA }
  | SQL SECURITY { DEFINER | INVOKER }
  | USING([library_reference][, library_reference][, ...])
}
```

该语句可用于更改存储过程的特性。在一个 ALTER PROCEDURE 语句中可以指定多个更改。但是，不能使用此语句更改存储过程的参数或主体；要进行此类更改，必须使用 DROP PROCEDURE 和 CREATE PROCEDURE 删除并重新创建该过程。

您必须对该过程具有 ALTER ROUTINE 权限。默认情况下，该权限会自动授予过程创建者。可以通过禁用 automatic_sp_privileges 系统变量来改变此行为。参见第 27.2.2 节"存储例程和 MySQL 权限"。

USING 子句特定于用 JavaScript 编写的存储程序（参见第 27.3 节"JavaScript 存储程序"），允许您指定要由存储过程导入的零个或多个库的列表，导致任何先前的此类列表被删除（就像它对 ALTER FUNCTION 所做的那样）。可能的结果列在此处：

- 使用了 USING 子句，并列出了一个或多个库：执行 ALTER PROCEDURE 语句后，该过程仅导入 ALTER FUNCTION 语句中列出的那些库；之前列出的任何库都将从列表中删除，不再导入。

- 该语句包含一个空的 USING 子句：之前导入的所有库都将从列表中删除；该函数不再导入任何库。

- 不使用 USING：不对创建过程时指定的库列表进行任何更改。

示例：

- `ALTER PROCEDURE myproc USING(lib1, lib2);`

  （USING 带有非空列表：）执行后，myproc 仅导入库 lib1 和 lib2，不导入其他库。

- `ALTER PROCEDURE myproc USING();`

  （USING 带有空列表：）执行后，myproc 不再导入任何库。

- `ALTER PROCEDURE myproc COMMENT "This procedure was altered";`

  （无 USING 子句：）该过程继续导入与发出此命令之前相同的库。
