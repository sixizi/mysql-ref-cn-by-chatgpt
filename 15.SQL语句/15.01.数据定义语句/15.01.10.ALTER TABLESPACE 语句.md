### 15.1.10 ALTER SERVER 语句

```
ALTER SERVER server_name
    OPTIONS (option[, option] ...)
```

修改 server_name 的服务器信息，调整 CREATE SERVER 语句中允许的任何选项。mysql.servers 表中的相应字段会相应地更新。此语句需要 SUPER 权限。

例如，更新 USER 选项：

```
ALTER SERVER s OPTIONS (USER 'sally');
```

ALTER SERVER 会导致隐式提交。参见第 15.3.3 节"导致隐式提交的语句"。

ALTER SERVER 不会写入二进制日志，无论使用的是哪种日志格式。
