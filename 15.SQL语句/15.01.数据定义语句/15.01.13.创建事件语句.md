### 15.1.13 ALTER VIEW 语句

```
ALTER
    [ALGORITHM = {UNDEFINED | MERGE | TEMPTABLE}]
    [MATERIALIZED] ...
    [DEFINER = user]
    [SQL SECURITY { DEFINER | INVOKER }]
    VIEW view_name [(column_list)]
    AS select_statement
    [WITH [CASCADED | LOCAL] CHECK OPTION]
```

该语句改变一个视图的定义，该视图必须存在。语法类似于 CREATE VIEW（参见第 15.1.28 节"CREATE VIEW 语句"）。该语句需要对视图拥有 CREATE VIEW 和 DROP 权限，以及对 SELECT 语句中引用的每一列拥有某些权限。只有视图的定义者或拥有 SET_ANY_DEFINER 或 ALLOW_NONEXISTENT_DEFINER 权限的用户才能执行 ALTER VIEW。

物化视图仅在 MySQL HeatWave 上受支持。参见查询物化视图以了解更多信息。
