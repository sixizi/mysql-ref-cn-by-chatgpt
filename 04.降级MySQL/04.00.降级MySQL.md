# 第 4 章 降级 MySQL

不支持从 MySQL 8.0 降级到 MySQL 5.7。

自 MySQL 8.0.35 起，支持在 MySQL 8.0 系列内部进行就地降级。所谓“就地”，是指在由不同 MySQL 服务器版本创建的现有 MySQL 数据目录上，启动并运行新的 MySQL 服务器二进制程序。

尝试降级到低于 MySQL 8.0.35 的版本时，会产生类似下面的错误：

```text
[ERROR] [MY-013171] [InnoDB] Cannot boot server version 80034 on data directory built by version 80035. Downgrade is not supported
```

以下是从 MySQL 8.0.36 就地降级到 MySQL 8.0.35 时的一条成功日志：

```text
[System] [MY-014064] [Server] Server downgrade from '80036' to '80035' started.
[System] [MY-014064] [Server] Server downgrade from '80036' to '80035' completed.
```

另一种做法是恢复升级前创建的备份。

官方英文版参见 [Downgrading MySQL](https://dev.mysql.com/doc/refman/8.0/en/downgrading.html)。
