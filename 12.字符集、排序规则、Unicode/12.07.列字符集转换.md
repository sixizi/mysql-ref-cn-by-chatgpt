### 12.7 列字符集转换

使用 `ALTER TABLE` 转换二进制或非二进制字符串列。

把 `VARBINARY` 转换为指定字符集的非二进制列：

```sql
ALTER TABLE t
  MODIFY col1 VARCHAR(50) CHARACTER SET greek;
```

前提是该二进制列中的所有值都使用同一个字符集编码。如果不同值使用不同字符集，MySQL 无法正确判断编码。

把非二进制列从 `latin1` 转为 `utf8mb4`：

```sql
ALTER TABLE t
  MODIFY col1 VARCHAR(50)
  CHARACTER SET utf8mb4
  COLLATE utf8mb4_0900_ai_ci;
```

如果源数据实际不是列声明的字符集，可以先转换为二进制类型，再转换到目标字符集。`BINARY` 转 `CHAR` 后可能残留 `0x00` 填充字节，可用 `TRIM(TRAILING 0x00 FROM col1)` 清理。
