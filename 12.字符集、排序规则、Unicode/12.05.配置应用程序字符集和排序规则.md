### 12.5 配置应用程序字符集和排序规则

应用程序不仅要配置存储数据的默认字符集，还要配置每次连接的字符集。

**按数据库配置**

```sql
CREATE DATABASE mydb
  CHARACTER SET latin1
  COLLATE latin1_swedish_ci;
```

应用程序连接后执行：

```sql
SET NAMES 'latin1';
```

**按服务器启动配置**

```ini
[mysqld]
character-set-server=latin1
collation-server=latin1_swedish_ci
```

**按编译时配置**

```sh
cmake . -DDEFAULT_CHARSET=latin1 -DDEFAULT_COLLATION=latin1_swedish_ci
```

如果用 `ALTER DATABASE` 修改默认值，依赖该默认值的已有存储例程需要删除并重建。还要确保操作系统、终端、文件编码和 Web 页面编码与 MySQL 连接字符集一致。
