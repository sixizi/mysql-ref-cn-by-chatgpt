### 12.8.1 在 SQL 语句中使用 COLLATE

`COLLATE` 可以显式指定表达式或比较使用的排序规则：

```sql
SELECT name
FROM t
ORDER BY name COLLATE utf8mb4_0900_ai_ci;
```

也可以在列定义中使用：

```sql
CREATE TABLE t (
  name VARCHAR(100) COLLATE utf8mb4_bin
);
```

常见适用位置：

- `SELECT` 列表
- `WHERE`、`HAVING` 条件
- `ORDER BY`、`GROUP BY`
- 聚合函数参数
- 列定义

示例：让比较不区分大小写：

```sql
SELECT * FROM t
WHERE name COLLATE utf8mb4_0900_ai_ci = 'abc';
```
