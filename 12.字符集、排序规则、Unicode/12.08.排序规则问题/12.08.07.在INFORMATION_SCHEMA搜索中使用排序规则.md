### 12.8.7 在 INFORMATION_SCHEMA 搜索中使用排序规则

`INFORMATION_SCHEMA` 字符串列通常使用 `utf8mb3`。但如果列值对应数据库、表等文件系统对象，比较可能受文件系统大小写敏感性和 `lower_case_table_names` 影响。

在区分大小写的文件系统上：

```sql
SELECT SCHEMA_NAME FROM INFORMATION_SCHEMA.SCHEMATA
WHERE SCHEMA_NAME = 'test';   -- 匹配 test
```

改为 `'TEST'` 可能不匹配；在 Windows 或 macOS 的不区分大小写文件系统上则可能匹配。

需要统一大小写行为时，可显式指定排序规则：

```sql
SELECT SCHEMA_NAME FROM INFORMATION_SCHEMA.SCHEMATA
WHERE SCHEMA_NAME COLLATE utf8mb3_general_ci = 'test';
```

也可以用 `UPPER()` 或 `LOWER()`。在真实对象名可能仅大小写不同的平台上，应明确查询是要匹配所有大小写变体，还是只匹配一个精确名称。
