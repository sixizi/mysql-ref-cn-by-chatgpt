### 12.8.6 排序规则效果示例

不同排序规则会改变比较、排序和 `GROUP BY` 的结果。

不区分大小写：

```sql
SELECT 'a' = 'A' COLLATE utf8mb4_0900_ai_ci;
-- 1
```

区分大小写：

```sql
SELECT 'a' = 'A' COLLATE utf8mb4_bin;
-- 0
```

排序差异：

```sql
CREATE TABLE t (name VARCHAR(20));
INSERT INTO t VALUES ('a'), ('B'), ('A'), ('b');

SELECT name FROM t
ORDER BY name COLLATE utf8mb4_0900_ai_ci;

SELECT name FROM t
ORDER BY name COLLATE utf8mb4_bin;
```

`_ai_ci` 会合并大小写不同的字符；`_bin` 会把不同编码视为不同值。
