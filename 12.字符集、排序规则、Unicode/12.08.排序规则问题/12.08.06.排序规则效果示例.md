### 12.8.6 排序规则效果示例

#### 示例 1：德语元音变音排序

假设表 T 中的列 X 包含以下 latin1 列值：
Muffler
Müller
MX Systems
MySQL

假设还使用以下语句检索列值：
SELECT X FROM T ORDER BY X COLLATE collation_name;

下表显示了使用 ORDER BY 和不同排序规则时值的结果顺序。

| latin1_swedish_ci | latin1_german1_ci | latin1_german2_ci |
|---|---|---|
| Muffler | Muffler | Müller |
| MX Systems | Müller | Muffler |
| Müller | MX Systems | MX Systems |
| MySQL | MySQL | MySQL |

在此示例中导致不同排序顺序的字符是 ü（德语"U 元音变音"）。

- 第一列显示使用瑞典语/芬兰语排序规则的 SELECT 结果，该规则规定 U 元音变音与 Y 排序。

- 第二列显示使用德语 DIN-1 规则的 SELECT 结果，该规则规定 U 元音变音与 U 排序。

- 第三列显示使用德语 DIN-2 规则的 SELECT 结果，该规则规定 U 元音变音与 UE 排序。

#### 示例 2：搜索德语元音变音

假设你有三个表，仅在使用的字符集和排序规则上有所不同：
mysql> SET NAMES utf8mb4;
mysql> CREATE TABLE german1 (
         c CHAR(10)
       ) CHARACTER SET latin1 COLLATE latin1_german1_ci;
mysql> CREATE TABLE german2 (
         c CHAR(10)
       ) CHARACTER SET latin1 COLLATE latin1_german2_ci;
mysql> CREATE TABLE germanutf8 (
         c CHAR(10)
       ) CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

每个表包含两条记录：
mysql> INSERT INTO german1 VALUES ('Bar'), ('Bär');
mysql> INSERT INTO german2 VALUES ('Bar'), ('Bär');
mysql> INSERT INTO germanutf8 VALUES ('Bar'), ('Bär');

上述排序规则中的两个具有 A = Ä 相等性，一个没有这样的相等性（latin1_german2_ci）。因此，比较产生如下所示的结果：
mysql> SELECT * FROM german1 WHERE c = 'Bär';
+------+
| c    |
+------+
| Bar  |
| Bär  |
+------+
mysql> SELECT * FROM german2 WHERE c = 'Bär';
+------+
| c    |
+------+
| Bär  |
+------+
mysql> SELECT * FROM germanutf8 WHERE c = 'Bär';
+------+
| c    |
+------+
| Bar  |
| Bär  |
+------+

这不是一个错误，而是 latin1_german1_ci 和 utf8mb4_unicode_ci 的排序属性的结果（显示的排序是根据德语 DIN 5007 标准进行的）。
