### 12.16 MySQL 服务器区域设置支持

区域设置主要影响语言相关的显示名称和格式，例如日期和月份名称。

查看当前设置：

```sql
SHOW VARIABLES LIKE 'lc_time_names';
SELECT @@lc_time_names;
```

设置区域：

```sql
SET lc_time_names = 'zh_CN';
```

示例：

```sql
SELECT DAYNAME('2026-01-01'), MONTHNAME('2026-01-01');
```

`lc_time_names` 影响日期名称的返回语言，但不改变日期值本身或存储格式。它也不等同于连接字符集配置。
