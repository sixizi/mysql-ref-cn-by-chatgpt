### 12.15 字符集配置

常用字符集配置项：

| 配置 | 作用 |
|---|---|
| `character-set-server` | 服务器默认字符集 |
| `collation-server` | 服务器默认排序规则 |
| `character-set-client` | 客户端发送语句的字符集 |
| `character-set-connection` | 服务器内部处理连接语句的字符集 |
| `character-set-results` | 返回结果的字符集 |
| `character-set-filesystem` | 文件系统相关字符串使用的字符集 |
| `character_sets_dir` | 字符集配置文件目录 |

示例：

```ini
[mysqld]
character-set-server=utf8mb4
collation-server=utf8mb4_0900_ai_ci

[client]
default-character-set=utf8mb4
```

修改配置后需要重启服务器或重新建立连接才能完全生效。
