### 12.3.4 表字符集和排序规则

创建表时可以指定字符集和排序规则：

```sql
CREATE TABLE t (
  name VARCHAR(100)
) CHARACTER SET utf8mb4
  COLLATE utf8mb4_0900_ai_ci;
```

也可以分别设置：

```sql
CREATE TABLE t (
  name VARCHAR(100)
) DEFAULT CHARACTER SET utf8mb4
  COLLATE utf8mb4_0900_ai_ci;
```

修改表默认值：

```sql
ALTER TABLE t
  CONVERT TO CHARACTER SET utf8mb4
  COLLATE utf8mb4_0900_ai_ci;
```

`CONVERT TO` 会转换已有字符列的数据；仅使用 `DEFAULT CHARACTER SET` 只改变后续列的默认值。
