### 12.3.8 字符集引导符

字符集引导符用于显式指定紧随其后的字符串字面值使用哪个字符集，格式为：

```sql
_charset_name'string'
_charset_name"string"
```

示例：

```sql
SELECT _utf8mb4'abc';
SELECT _latin1'abc';
```

可以在引导符后加 `COLLATE` 指定排序规则：

```sql
SELECT _utf8mb4'abc' COLLATE utf8mb4_0900_ai_ci;
```

常见写法：

| 写法 | 含义 |
|---|---|
| `_utf8mb4'x'` | 字符集为 `utf8mb4` |
| `_latin1'x'` | 字符集为 `latin1` |
| `N'x'` | 国家字符集字符串 |
| `_binary'x'` | 二进制字符串 |
