### 12.3.2 服务器字符集和排序规则

MySQL 服务器有一个服务器字符集和一个服务器排序规则。默认情况下，这些是 utf8mb4 和 utf8mb4_0900_ai_ci，但可以在服务器启动时通过命令行或选项文件显式设置，也可以在运行时更改。

最初，服务器字符集和排序规则取决于启动 mysqld 时使用的选项。你可以使用 --character-set-server 来指定字符集。同时，你可以添加 --collation-server 来指定排序规则。如果你没有指定字符集，这与指定 --character-set-server=utf8mb4 相同。如果你只指定字符集（例如，utf8mb4）但不指定排序规则，这与指定 --character-set-server=utf8mb4 --collation-server=utf8mb4_0900_ai_ci 相同，因为 utf8mb4_0900_ai_ci 是 utf8mb4 的默认排序规则。因此，以下三个命令都有相同的效果：

```
mysqld
mysqld --character-set-server=utf8mb4
mysqld --character-set-server=utf8mb4 \
  --collation-server=utf8mb4_0900_ai_ci
```

字符集和排序规则启动选项需要显式名称。--character-set-server 恰好接受一个值；多个值会被拒绝。对于此选项，值 utf8 会被拒绝，utf8_* 排序规则名称会被 --collation-server 拒绝。使用显式的 utf8mb3、utf8mb4、utf8mb3_* 或 utf8mb4_* 名称。这些限制也适用于从选项文件读取的设置。

改变这些设置的一种方法是重新编译。要在从源代码构建时更改默认服务器字符集和排序规则，请为 CMake 使用 DEFAULT_CHARSET 和 DEFAULT_COLLATION 选项。例如：

```
cmake . -DDEFAULT_CHARSET=latin1
```

或：

```
cmake . -DDEFAULT_CHARSET=latin1 \
  -DDEFAULT_COLLATION=latin1_german1_ci
```

mysqld 和 CMake 都会验证字符集/排序规则组合是否有效。如果无效，每个程序都会显示错误消息并终止。

如果在 CREATE DATABASE 语句中未指定数据库字符集和排序规则，则服务器字符集和排序规则将用作默认值。它们没有其他用途。

当前服务器字符集和排序规则可以从 character_set_server 和 collation_server 系统变量的值确定。这些变量可以在运行时更改。
