### 12.3.9 字符集和排序规则指定示例

创建数据库并指定默认值：

```sql
CREATE DATABASE d
  CHARACTER SET latin1
  COLLATE latin1_swedish_ci;
```

创建表并覆盖数据库默认值：

```sql
CREATE TABLE d.t (
  c CHAR(10)
) CHARACTER SET utf8mb4
  COLLATE utf8mb4_0900_ai_ci;
```

为单列覆盖表默认值：

```sql
CREATE TABLE d.t2 (
  c1 VARCHAR(20),
  c2 VARCHAR(20) CHARACTER SET utf8mb4 COLLATE utf8mb4_bin
) CHARACTER SET latin1;
```

在表达式中强制排序规则：

```sql
SELECT c2 FROM d.t2
WHERE c1 COLLATE utf8mb4_0900_ai_ci = 'A';
```
