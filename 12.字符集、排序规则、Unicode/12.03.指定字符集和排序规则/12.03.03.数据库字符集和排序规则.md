### 12.3.3 数据库字符集和排序规则

创建数据库时可以指定默认字符集和排序规则：

```sql
CREATE DATABASE mydb
  CHARACTER SET utf8mb4
  COLLATE utf8mb4_0900_ai_ci;
```

修改数据库默认值：

```sql
ALTER DATABASE mydb
  CHARACTER SET utf8mb4
  COLLATE utf8mb4_0900_ai_ci;
```

查看当前数据库的字符集和排序规则：

```sql
USE mydb;
SELECT @@character_set_database, @@collation_database;
```

这些值是该数据库中新建表的默认值，不会自动改变已有表。
