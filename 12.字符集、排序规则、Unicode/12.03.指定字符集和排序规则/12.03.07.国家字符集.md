### 12.3.7 国家字符集

标准 SQL 使用 `NCHAR` 和 `NVARCHAR` 表示国家字符集数据。在 MySQL 中：

- `NCHAR` 等价于 `CHAR` 的国家字符集形式。
- `NVARCHAR` 等价于 `VARCHAR` 的国家字符集形式。
- 国家字符集默认为 `utf8mb3`。

示例：

```sql
CREATE TABLE t (
  c1 NCHAR(10),
  c2 NVARCHAR(100)
);
```

也可以显式指定：

```sql
CREATE TABLE t (
  c1 NCHAR(10) CHARACTER SET utf8mb3
);
```

`N'...'` 是国家字符集字符串字面值写法，等价于使用国家字符集引导符。
