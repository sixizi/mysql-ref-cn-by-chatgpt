### 12.3.5 列字符集和排序规则

每个字符列都有自己的字符集和排序规则，可以覆盖表默认值：

```sql
CREATE TABLE t (
  name VARCHAR(100)
    CHARACTER SET utf8mb4
    COLLATE utf8mb4_0900_ai_ci,
  code VARCHAR(50)
    CHARACTER SET utf8mb4
    COLLATE utf8mb4_bin
) CHARACTER SET utf8mb4;
```

修改列：

```sql
ALTER TABLE t
  MODIFY name VARCHAR(100)
    CHARACTER SET utf8mb4
    COLLATE utf8mb4_0900_ai_ci;
```

如果只指定 `CHARACTER SET`，MySQL 使用该字符集的默认排序规则；如果只指定 `COLLATE`，MySQL 使用与该排序规则关联的字符集。
