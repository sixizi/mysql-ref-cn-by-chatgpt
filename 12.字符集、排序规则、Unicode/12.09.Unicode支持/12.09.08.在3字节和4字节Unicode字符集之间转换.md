### 12.9.8 在 3 字节和 4 字节 Unicode 字符集之间转换

把列从 `utf8mb3` 转换为 `utf8mb4`：

```sql
ALTER TABLE t
  DEFAULT CHARACTER SET utf8mb4;

ALTER TABLE t
  MODIFY name VARCHAR(100)
    CHARACTER SET utf8mb4
    COLLATE utf8mb4_0900_ai_ci;
```

注意事项：

- 列和索引的长度限制按字节计算，因此从 3 字节转为 4 字节后，可容纳或索引的字符数可能变少。
- 很长的 `VARCHAR` 或 `TEXT` 可能需要改成更长的类型。
- 索引前缀可能需要缩短，尤其是使用 `COMPACT` 或 `REDUNDANT` 行格式的 InnoDB 表。
- 连接两端和复制拓扑中的所有服务器都必须理解所用字符集。

如果从 4 字节字符集转回 `utf8mb3`，已有数据中不能包含 4 字节字符，否则会丢失或转换失败。
