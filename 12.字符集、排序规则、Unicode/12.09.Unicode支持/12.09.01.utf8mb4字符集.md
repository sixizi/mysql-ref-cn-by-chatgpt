### 12.9.1 utf8mb4 字符集

`utf8mb4` 是最多 4 字节的 UTF-8 编码，支持 BMP 和 BMP 之外的补充字符。它是 MySQL 8.0 默认字符集，也是官方推荐用于 Unicode 数据的字符集。

常见排序规则：

- `utf8mb4_0900_ai_ci`：基于 Unicode 9.0.0，不区分重音和大小写。
- `utf8mb4_0900_as_cs`：区分重音和大小写。
- `utf8mb4_general_ci`：较旧的通用排序规则，不区分大小写。
- `utf8mb4_unicode_ci`：基于 UCA 4.0.0 的 Unicode 排序规则。
- `utf8mb4_bin`：按编码比较。

示例：

```sql
CREATE TABLE t (
  name VARCHAR(100) CHARACTER SET utf8mb4
    COLLATE utf8mb4_0900_ai_ci
);
```

与 `utf8mb3` 不同，`utf8mb4` 可以存储 emoji 等 4 字节字符。
