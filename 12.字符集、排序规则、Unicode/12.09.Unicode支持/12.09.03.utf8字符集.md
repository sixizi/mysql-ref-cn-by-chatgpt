### 12.9.3 utf8 字符集

在 MySQL 8.0 中，`utf8` 是 `utf8mb3` 的别名，因此最多只支持 3 字节 UTF-8，不支持全部 Unicode 字符。

官方计划在未来版本中让 `utf8` 指向 `utf8mb4`。为了避免歧义和兼容性风险，应显式使用 `utf8mb4`。

示例：

```sql
CREATE TABLE t (
  name VARCHAR(100) CHARACTER SET utf8mb4
) CHARACTER SET utf8mb4;
```

不要在新表、新列和新连接配置中使用 `utf8`。
