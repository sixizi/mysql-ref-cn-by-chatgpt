## 12.2 MySQL 中的字符集和排序规则

**目录**

- [12.2.1 字符集字符库](./12.02.01.字符集字符库.md)
- [12.2.2 元数据使用的 UTF-8](./12.02.02.元数据使用的UTF-8.md)

MySQL Server 支持多种字符集，包括多个 Unicode 字符集。

查看可用字符集：

```sql
SHOW CHARACTER SET;
SELECT * FROM INFORMATION_SCHEMA.CHARACTER_SETS;
```

常用字符集包括：

| 字符集 | 说明 |
|---|---|
| `latin1` | cp1252 西欧字符集 |
| `utf8mb4` | 最多 4 字节 UTF-8，MySQL 8.0 推荐 |
| `utf8mb3` | 最多 3 字节 UTF-8，已弃用 |
| `ucs2` | UCS-2 Unicode，已弃用 |
| `binary` | 二进制伪字符集 |

查看可用排序规则：

```sql
SHOW COLLATION;
SELECT * FROM INFORMATION_SCHEMA.COLLATIONS;
```
