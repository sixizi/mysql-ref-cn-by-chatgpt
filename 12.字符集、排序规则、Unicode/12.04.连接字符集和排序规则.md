### 12.4 连接字符集和排序规则

连接是客户端与服务器之间的会话。连接字符集决定：

- 客户端发送语句使用的字符集：`character_set_client`
- 服务器内部处理语句使用的字符集：`character_set_connection`
- 返回结果使用的字符集：`character_set_results`
- 字面值比较使用的排序规则：`collation_connection`

查看连接设置：

```sql
SELECT * FROM performance_schema.session_variables
WHERE VARIABLE_NAME IN (
  'character_set_client',
  'character_set_connection',
  'character_set_results',
  'collation_connection'
);
```

配置连接：

```sql
SET NAMES 'utf8mb4';
SET NAMES 'utf8mb4' COLLATE 'utf8mb4_0900_ai_ci';
SET CHARACTER SET 'utf8mb4';
```

客户端程序也可以使用 `--default-character-set=utf8mb4`。

不能把 `character_set_client` 设置为 `ucs2`、`utf16`、`utf16le` 或 `utf32`。如果目标字符集不可用，MySQL 会回退到服务器默认字符集和排序规则。
