### 12.12 设置错误消息语言

MySQL 错误消息的语言由 `lc_messages` 系统变量控制：

```sql
SHOW VARIABLES LIKE 'lc_messages';
SET lc_messages = 'en_US';
```

也可以在配置文件中设置：

```ini
[mysqld]
lc_messages=en_US
```

常见语言值包括 `en_US`、`de_DE`、`fr_FR`、`ja_JP`、`zh_CN` 等，具体取决于服务器安装的语言文件。

错误消息的语言与其字符集是两个问题：消息字符集由服务器构造过程和 `character_set_results` 决定。
