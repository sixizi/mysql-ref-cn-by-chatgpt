### 12.10.7 亚洲字符集

**目录**

- [12.10.7.1 cp932 字符集](./12.10.07.01.cp932字符集.md)
- [12.10.7.2 gb18030 字符集](./12.10.07.02.gb18030字符集.md)

MySQL 支持多个亚洲字符集：

| 字符集 | 说明 |
|---|---|
| `big5` | Big5 繁体中文 |
| `gb2312` | GB2312 简体中文 |
| `gbk` | GBK 简体中文 |
| `gb18030` | 中国国家标准 GB18030 |
| `sjis` | Shift-JIS 日语 |
| `cp932` | Windows 日语版 SJIS |
| `ujis` | EUC-JP 日语 |
| `eucjpms` | Windows 日语版 UJIS |
| `euckr` | EUC-KR 韩语 |

如果需要同时支持简体中文、繁体中文、日文、韩文或其他语言，推荐使用 `utf8mb4`。

------
官方英文版参见 [Asian Character Sets](https://dev.mysql.com/doc/refman/8.0/en/charset-asian-sets.html)。
