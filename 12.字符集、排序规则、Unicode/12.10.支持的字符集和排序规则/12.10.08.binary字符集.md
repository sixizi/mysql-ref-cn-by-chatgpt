### 12.10.8 binary 字符集

`binary` 是二进制伪字符集，默认排序规则也是 `binary`。它不把字节解释为字符，而是直接按字节比较。

适用场景：

- 存储原始字节，例如哈希、压缩数据、加密数据。
- 需要字节级完全相等比较。

示例：

```sql
CREATE TABLE t (
  data VARBINARY(255)
);

SELECT BINARY 'abc' = BINARY 'ABC';  -- 0
```

`binary` 不适合需要语义化字符串比较的普通文本；文本数据应使用真实字符集，例如 `utf8mb4`。
