### 12.14.2 选择排序规则 ID

每个排序规则都有一个数字 ID。添加排序规则时必须选择：

- 不与内置排序规则冲突的 ID。
- 不与 MySQL 未来可能使用的 ID 冲突的 ID。

查看已使用 ID：

```sql
SELECT COLLATION_NAME, ID, CHARACTER_SET_NAME
FROM INFORMATION_SCHEMA.COLLATIONS
ORDER BY ID;
```

MySQL 官方为用户自定义排序规则预留了 ID 范围。不要随意使用已存在的 ID，否则会导致排序规则识别和比较行为异常。
