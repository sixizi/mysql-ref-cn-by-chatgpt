### 12.14.4.2 MySQL 支持的 LDML 语法

`Index.xml` 使用 LDML 规则描述排序差异。MySQL 支持其中的常用子集。

字符可以写字面字符，也可以写 `\unnnn` 形式的 Unicode 码点：

```xml
<reset>A</reset>
<reset>\u0041</reset>
```

常用规则：

| 标签 | 含义 |
|---|---|
| `<reset>` | 设置排序锚点 |
| `<p>` | 主要差异，例如不同字母 |
| `<s>` | 次要差异，例如重音 |
| `<t>` | 第三级差异，例如大小写 |
| `<i>` | 忽略指定字符 |
| `<x>` | 扩展规则 |
| `<context>` | 上下文规则 |

MySQL 主要按主要排序级别处理这些规则；部分二级或更高级规则会被识别，但在主要级别视为相等。
