### 12.6 错误消息字符集

MySQL 构造错误消息时：

- 消息模板使用 UTF-8（`utf8mb3`）。
- 表名、列名等标识符内部使用 UTF-8，直接复制。
- 非二进制字符串值会从其字符集转换为 UTF-8。
- 二进制字符串中可打印 ASCII 字节直接显示，其他字节用 `\xHH` 形式显示。

写入错误日志时，消息保持 UTF-8，不做转换。

发送给客户端时，服务器把消息从 UTF-8 转换为 `character_set_results`：

```sql
SET character_set_results = utf8mb4;
```

如果 `character_set_results` 是 `NULL`、`binary`、`utf8mb3` 或 `utf8mb4`，不做转换。目标字符集无法表示的字符会用 Unicode 码点转义：BMP 内使用 `\nnnn`，BMP 外使用 `\+nnnnnn`。
