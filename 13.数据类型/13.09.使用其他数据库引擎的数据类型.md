### 13.9 使用其他数据库引擎的数据类型

为兼容其他数据库，MySQL 在建表时映射常见厂商类型：

| 其他厂商类型 | MySQL 类型 |
|---|---|
| `BOOLEAN` | `TINYINT` |
| `CHARACTER VARYING(M)` | `VARCHAR(M)` |
| `FLOAT4` | `FLOAT` |
| `FLOAT8` | `DOUBLE` |
| `INT1` / `INT2` / `INT3` / `INT4` / `INT8` | `TINYINT` / `SMALLINT` / `MEDIUMINT` / `INT` / `BIGINT` |
| `LONG VARCHAR` | `MEDIUMTEXT` |
| `LONG VARBINARY` | `MEDIUMBLOB` |
| `NUMERIC` | `DECIMAL` |

映射发生在建表时；之后执行 `DESCRIBE` 会显示 MySQL 的等效类型。
