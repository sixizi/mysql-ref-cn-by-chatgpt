### 13.4.6 创建空间列

可在建表时声明空间列：

```sql
CREATE TABLE geo (
  id INT PRIMARY KEY,
  pt POINT SRID 4326,
  ln LINESTRING,
  area POLYGON,
  all_shapes GEOMETRY
);
```

`GEOMETRY` 可以存储任意几何对象；指定 `POINT`、`LINESTRING`、`POLYGON` 等具体类型能加强数据一致性。

如果列参与空间索引，需要声明非 `NULL` 并使用支持的存储引擎，例如 InnoDB。
