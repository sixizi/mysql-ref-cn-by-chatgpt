### 13.6 数据类型默认值

列默认值规则如下：

- 除 `BLOB`、`TEXT`、`GEOMETRY`、`JSON` 外，其他数据类型都可指定字面量默认值。
- 未指定默认值时，严格模式下插入缺失列会报错；非严格模式下可能填充隐式默认值。
- `NOT NULL` 列没有默认值时，插入必须提供值。
- MySQL 8.0.13 起，`BLOB`、`TEXT`、`GEOMETRY`、`JSON` 可用表达式默认值。

表达式默认值必须用括号包裹：

```sql
created_at DATETIME DEFAULT (CURRENT_TIMESTAMP),
metadata JSON DEFAULT ('{}')
```
