### 13.1.2 整数类型（精确值）：INTEGER、INT、SMALLINT、TINYINT、MEDIUMINT、BIGINT

整数类型按存储范围从小到大包括：

| 类型 | 有符号范围 | 无符号范围 |
|---|---|---|
| `TINYINT` | -128 到 127 | 0 到 255 |
| `SMALLINT` | -32768 到 32767 | 0 到 65535 |
| `MEDIUMINT` | -8388608 到 8388607 | 0 到 16777215 |
| `INT` / `INTEGER` | -2147483648 到 2147483647 | 0 到 4294967295 |
| `BIGINT` | -9223372036854775808 到 9223372036854775807 | 0 到 18446744073709551615 |

整数运算在 `BIGINT` 范围内是精确的；`BIGINT` 也常用于存储 64 位哈希值或高精度定点数的内部表示。
