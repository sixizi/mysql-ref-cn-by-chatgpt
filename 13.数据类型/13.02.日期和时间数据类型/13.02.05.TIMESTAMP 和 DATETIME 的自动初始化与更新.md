### 13.2.5 TIMESTAMP 和 DATETIME 的自动初始化与更新

`TIMESTAMP` 和 `DATETIME` 可以通过以下子句自动维护时间戳：

- `DEFAULT CURRENT_TIMESTAMP`：插入行时自动填充当前时间。
- `ON UPDATE CURRENT_TIMESTAMP`：更新行时自动更新该列。
- 两者可组合使用，也可分别指定不同的默认值和更新值。

示例：

```sql
CREATE TABLE audit (
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```

`explicit_defaults_for_timestamp` 启用时，不会自动为第一个 `TIMESTAMP` 列添加默认或更新行为；显式写明子句总是更清晰。
