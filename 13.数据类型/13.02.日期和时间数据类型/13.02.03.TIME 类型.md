### 13.2.3 TIME 类型

`TIME` 表示一天中的时间，也可表示两个事件之间的经过时间或持续时间。

范围是 `-838:59:59` 到 `838:59:59`，因此不能表示超过 838 小时的正负时间跨度。`TIME` 可带小数秒，例如 `TIME(3)`。

示例：

```sql
CREATE TABLE t (duration TIME(3));
INSERT INTO t VALUES ('12:30:15.123');
```

使用 `TIME` 存储持续时间时，应以 `-hh:mm:ss` 或数值格式表达，不要用日期类型代替。
