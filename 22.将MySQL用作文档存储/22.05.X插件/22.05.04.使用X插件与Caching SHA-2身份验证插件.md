### 22.5.4 将 X Plugin 与 Caching SHA-2 身份验证插件一起使用

X Plugin 支持使用 caching_sha2_password 身份验证插件创建的 MySQL 用户账户。有关此插件的更多信息，请参见第 8.4.1.1 节"Caching SHA-2 可插拔身份验证"。您可以使用 X Plugin 通过非 SSL 连接使用 SHA256_MEMORY 身份验证或通过 SSL 连接使用 PLAIN 身份验证来对此类账户进行身份验证。

虽然 caching_sha2_password 身份验证插件持有身份验证缓存，但此缓存不与 X Plugin 共享，因此 X Plugin 为 SHA256_MEMORY 身份验证使用自己的身份验证缓存。X Plugin 身份验证缓存存储用户账户密码的哈希值，无法使用 SQL 访问。如果修改或删除用户账户，相关条目将从缓存中删除。X Plugin 身份验证缓存由 mysqlx_cache_cleaner 插件维护，该插件默认启用，没有相关的系统变量或状态变量。

#### X Plugin 的连接压缩

在使用非 SSL X Protocol 连接对使用 caching_sha2_password 身份验证插件的账户进行身份验证之前，该账户必须至少通过带有 SSL 的 X Protocol 连接进行过一次身份验证，以将密码提供给 X Plugin 身份验证缓存。一旦通过 SSL 的初始身份验证成功，就可以使用非 SSL X Protocol 连接。

可以通过使用选项 --mysqlx_cache_cleaner=0 启动 MySQL 服务器来禁用 mysqlx_cache_cleaner 插件。如果这样做，X Plugin 身份验证缓存将被禁用，因此在使用 SHA256_MEMORY 身份验证进行身份验证时，必须始终为 X Protocol 连接使用 SSL。
