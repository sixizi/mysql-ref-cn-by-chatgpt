### 22.5.1 检查 X Plugin 安装

X Plugin 在 MySQL 8 中默认启用，因此安装或升级到 MySQL 8 会使该插件可用。您可以使用 SHOW plugins 语句查看插件列表，以验证 X Plugin 是否已安装在 MySQL 服务器实例上。

要使用 MySQL Shell 验证 X Plugin 是否已安装，请执行：

```
$> mysqlsh -u user --sqlc -P 3306 -e "SHOW plugins"
```

要使用 MySQL Client 验证 X Plugin 是否已安装，请执行：

```
$> mysql -u user -p -e "SHOW plugins"
```

如果 X Plugin 已安装，示例结果如下所示：

```
+----------------------------+----------+--------------------+---------+---------+
| Name                       | Status   | Type               | Library | License |
+----------------------------+----------+--------------------+---------+---------+

...

| mysqlx                         | ACTIVE    | DAEMON               | NULL     | GPL      |

...

+----------------------------+----------+--------------------+---------+---------+
```
