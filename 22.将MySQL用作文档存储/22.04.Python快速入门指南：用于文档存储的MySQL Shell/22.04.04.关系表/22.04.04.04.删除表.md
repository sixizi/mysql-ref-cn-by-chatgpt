### 22.4.4.4 删除表

你可以使用 delete() 方法从数据库中的表删除部分或全部记录。X DevAPI 提供了与 delete() 方法一起使用的其他方法，用于筛选和排序要删除的记录。

使用条件删除记录

下面的示例将搜索条件传递给 delete() 方法。所有匹配该条件的记录都会从 city 表中删除。在此示例中，一条记录匹配该条件。

```
mysql-py> db.city.delete().where("Name = 'Olympia'")
```

删除第一条记录

要删除 city 表中的第一条记录，请使用 limit() 方法，值为 1。

```
mysql-py> db.city.delete().limit(1)
```

删除表中的所有记录

你可以删除表中的所有记录。为此，请使用 delete() 方法而不指定搜索条件。

> **注意**
>
> 删除记录时不指定搜索条件时要小心；这样做会删除表中的所有记录。

删除表

drop_collection() 方法也用于 MySQL Shell 中从数据库删除关系表。例如，要从 world_x 数据库删除 citytest 表，请执行：

```
mysql-py> db.drop_collection("citytest")
```
