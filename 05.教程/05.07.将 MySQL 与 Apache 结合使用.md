## 5.7 将 MySQL 与 Apache 结合使用

有一些程序可以让你从 MySQL 数据库验证用户身份，也可以让你把日志文件写入 MySQL 表。

你可以将 Apache 日志格式改成易于 MySQL 读取的形式，方法是向 Apache 配置文件中加入以下内容：

```none
LogFormat \
        "\"%h\",%{%Y%m%d%H%M%S}t,%>s,\"%b\",\"%{Content-Type}o\",  \
        \"%U\",\"%{Referer}i\",\"%{User-Agent}i\""
```

要将这种格式的日志文件装载到 MySQL 中，可以使用类似下面的语句：

```sql
LOAD DATA INFILE '/local/access_log' INTO TABLE tbl_name
FIELDS TERMINATED BY ',' OPTIONALLY ENCLOSED BY '"' ESCAPED BY '\\'
```

指定的表应当创建为包含一些列，这些列与 `LogFormat` 行写入日志文件的字段相对应。
