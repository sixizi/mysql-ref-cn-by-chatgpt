### 5.6.6 使用外键

MySQL 支持外键，它允许跨表交叉引用相关数据；也支持外键约束，帮助保持相关数据的一致性。

外键关系涉及一个保存初始列值的父表，以及一个包含引用父列值的列值的子表。外键约束定义在子表上。

下面的示例通过单列外键关联 `parent` 和 `child` 表，并展示外键约束如何强制实现引用完整性。

使用以下 SQL 语句创建父表和子表：

```sql
CREATE TABLE parent (
    id INT NOT NULL,
    PRIMARY KEY (id)
) ENGINE=INNODB;


CREATE TABLE child (
    id INT,
    parent_id INT,
    INDEX par_ind (parent_id),
    FOREIGN KEY (parent_id)
        REFERENCES parent(id)
) ENGINE=INNODB;
```

向父表中插入一行，如下所示：

```sql
mysql> INSERT INTO parent (id) VALUES ROW(1);
```

验证数据是否已插入。只需选择 `parent` 表中的所有行即可，如下所示：

```sql
mysql> TABLE parent;
+----+
| id |
+----+
|  1 |
+----+
```

使用以下 SQL 语句向子表中插入一行：

```sql
mysql> INSERT INTO child (id,parent_id) VALUES ROW(1,1);
```

插入操作成功，因为父表中存在 `parent_id` 1。

向子表插入一行，其 `parent_id` 值在父表中不存在时，操作会被拒绝并返回错误，如下所示：

```sql
mysql> INSERT INTO child (id,parent_id) VALUES ROW(2,2);
ERROR 1452 (23000): Cannot add or update a child row: a foreign key constraint fails 
(`test`.`child`, CONSTRAINT `child_ibfk_1` FOREIGN KEY (`parent_id`) 
REFERENCES `parent` (`id`))
```

操作失败，因为指定的 `parent_id` 值在父表中不存在。

尝试从父表中删除之前插入的行同样会失败，如下所示：

```sql
mysql> DELETE FROM parent WHERE id = 1;
ERROR 1451 (23000): Cannot delete or update a parent row: a foreign key constraint fails 
(`test`.`child`, CONSTRAINT `child_ibfk_1` FOREIGN KEY (`parent_id`) 
REFERENCES `parent` (`id`))
```

该操作失败，因为子表中的记录包含被引用的 id（`parent_id`）值。

当某个操作影响父表中的一个键值，而该键值在子表中存在匹配行时，结果取决于 `FOREIGN KEY` 子句中 `ON UPDATE` 和 `ON DELETE` 子子句指定的引用操作。省略 `ON DELETE` 和 `ON UPDATE` 子句（如当前子表定义所示）等同于指定 `RESTRICT` 选项，该选项会拒绝影响父表中在子表有匹配行的键值的操作。

为了演示 `ON DELETE` 和 `ON UPDATE` 引用操作，删除子表并重新创建它，使其包含使用 `CASCADE` 选项的 `ON UPDATE` 和 `ON DELETE` 子子句。`CASCADE` 选项会在删除或更新父表中的行时，自动删除或更新子表中的匹配行。

```sql
DROP TABLE child;

CREATE TABLE child (
    id INT,
    parent_id INT,
    INDEX par_ind (parent_id),
    FOREIGN KEY (parent_id)
        REFERENCES parent(id)
        ON UPDATE CASCADE
        ON DELETE CASCADE
) ENGINE=INNODB;
```

使用这里展示的语句向子表中插入一些行：

```sql
mysql> INSERT INTO child (id,parent_id) VALUES ROW(1,1), ROW(2,1), ROW(3,1);
```

像这样验证数据是否已插入：

```sql
mysql> TABLE child;
+------+-----------+
| id   | parent_id |
+------+-----------+
|    1 |         1 |
|    2 |         1 |
|    3 |         1 |
+------+-----------+
```

使用这里展示的 SQL 语句更新父表中的 ID，将其从 1 改为 2：

```sql
mysql> UPDATE parent SET id = 2 WHERE id = 1;
```

像这样选择父表中的所有行，验证更新是否成功：

```sql
mysql> TABLE parent;
+----+
| id |
+----+
|  2 |
+----+
```

像这样验证 `ON UPDATE CASCADE` 引用操作是否更新了子表：

```sql
mysql> TABLE child;
+------+-----------+
| id   | parent_id |
+------+-----------+
|    1 |         2 |
|    2 |         2 |
|    3 |         2 |
+------+-----------+
```

为了演示 `ON DELETE CASCADE` 引用操作，从父表中删除 `parent_id = 2` 的记录；这会删除父表中的所有记录。

```sql
mysql> DELETE FROM parent WHERE id = 2;
```

由于子表中的所有记录都关联到 `parent_id = 2`，`ON DELETE CASCADE` 引用操作会删除子表中的所有记录，如下所示：

```sql
mysql> TABLE child;
Empty set (0.00 sec)
```

关于外键约束的更多信息，请参见 [15.1.20.5，外键约束](https://dev.mysql.com/doc/refman/8.0/en/create-table-foreign-keys.html)。
