### 5.6.8 计算每日访问次数

下面的示例展示如何使用位组函数计算用户每月访问某个网页的天数。

```sql
CREATE TABLE t1 (year YEAR, month INT UNSIGNED,
             day INT UNSIGNED);
INSERT INTO t1 VALUES(2000,1,1),(2000,1,20),(2000,1,30),(2000,2,2),
            (2000,2,23),(2000,2,23);
```

示例表包含表示用户访问该页面的年-月-日值。要确定这些访问发生在每个月中的多少个不同日期，可以使用以下查询：

```sql
SELECT year,month,BIT_COUNT(BIT_OR(1<<day)) AS days FROM t1
       GROUP BY year,month;
```

该查询返回：

```none
+------+-------+------+
| year | month | days |
+------+-------+------+
| 2000 |     1 |    3 |
| 2000 |     2 |    2 |
+------+-------+------+
```

这个查询计算表中每个年/月组合出现在多少个不同日期上，并自动去除重复条目。
