### 5.6.7 在两个键上搜索

使用单个键的 `OR` 已经得到良好优化，`AND` 的处理也是如此。

较棘手的情况是在两个不同键上搜索并用 `OR` 组合条件：

```sql
SELECT field1_index, field2_index FROM test_table
WHERE field1_index = '1' OR  field2_index = '1'
```

这种情况也已被优化。参见 [10.2.1.3，索引合并优化](https://dev.mysql.com/doc/refman/8.0/en/index-merge-optimization.html)。

你还可以使用 [`UNION`](https://dev.mysql.com/doc/refman/8.0/en/union.html) 组合两个独立 [`SELECT`](https://dev.mysql.com/doc/refman/8.0/en/select.html) 语句的输出，从而高效解决这个问题。参见 [15.2.18，UNION 子句](https://dev.mysql.com/doc/refman/8.0/en/union.html)。

每个 `SELECT` 只搜索一个键，因此可以被优化：

```sql
SELECT field1_index, field2_index
    FROM test_table WHERE field1_index = '1'
UNION
SELECT field1_index, field2_index
    FROM test_table WHERE field2_index = '1';
```
