## 5.5 在批处理模式下使用 mysql

在前几节中，你以交互方式使用 `mysql` 输入语句并查看结果。你也可以在批处理模式下运行 `mysql`。为此，请将要运行的语句放入一个文件，然后让 `mysql` 从该文件读取输入：

```terminal
$> mysql < batch-file
```

如果你在 Windows 上运行 `mysql`，并且文件中的某些特殊字符导致问题，可以使用以下方式：

```terminal
C:\> mysql -e "source batch-file"
```

如果需要在命令行中指定连接参数，命令可能像下面这样：

```terminal
$> mysql -h host -u user -p < batch-file
Enter password: ********
```

以这种方式使用 `mysql` 时，你实际上是在创建一个脚本文件，然后执行这个脚本。

如果希望脚本即使在其中某些语句产生错误时也继续执行，应使用 `--force` 命令行选项。

为什么要使用脚本？原因有以下几个：

- 如果某个查询需要反复运行（例如每天或每周运行一次），将它做成脚本可以避免每次执行时重新输入。

- 可以通过复制并编辑类似的现有脚本文件，基于现有查询生成新查询。

- 批处理模式在开发查询时也很有用，尤其是多行语句或多语句序列。如果出现错误，不必重新输入所有内容；只需编辑脚本改正错误，然后让 `mysql` 再次执行它。

- 如果某个查询产生大量输出，可以让输出经过分页程序，而不是看着它从屏幕顶部滚走：

  ```terminal
  $> mysql < batch-file | more
  ```

- 可以把输出保存到文件中，供后续处理使用：

  ```terminal
  $> mysql < batch-file > mysql.out
  ```

- 可以把脚本分发给其他人，使他们也能运行其中的语句。

- 某些场景不允许交互式使用，例如通过 `cron` 作业运行查询时。此时必须使用批处理模式。

在批处理模式下运行 `mysql` 时，默认输出格式与交互模式不同，前者更简洁。例如，`SELECT DISTINCT species FROM pet` 在 `mysql` 交互模式下运行的输出如下：

```none
+---------+
| species |
+---------+
| bird    |
| cat     |
| dog     |
| hamster |
| snake   |
+---------+
```

而在批处理模式下，输出如下：

```none
species
bird
cat
dog
hamster
snake
```

如果想在批处理模式下获得交互式输出格式，请使用 `mysql -t`。如果要在输出中回显已执行的语句，请使用 `mysql -v`。

你还可以在 `mysql` 提示符下使用 `source` 命令或 `\.` 命令来执行脚本：

```sql
mysql> source filename;
mysql> \. filename
```
