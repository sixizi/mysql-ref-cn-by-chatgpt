### 5.3.1 创建和选择数据库

如果管理员在设置权限时已经为你创建了数据库，你可以直接开始使用。否则，你需要自己创建：

```sql
mysql> CREATE DATABASE menagerie;
```

在 Unix 上，数据库名区分大小写（与 SQL 关键字不同），因此必须始终将数据库写成 `menagerie`，而不是 `Menagerie`、`MENAGERIE` 或其他变体。表名也是如此。（在 Windows 上，这个限制不适用，但在同一条查询中必须始终使用相同大小写引用数据库和表。不过，出于多种原因，建议的最佳实践是始终使用创建数据库时的大小写。）

> **注意**
>
> 如果创建数据库时收到类似 `ERROR 1044 (42000): Access denied for user 'micah'@'localhost' to database 'menagerie'` 的错误，说明你的用户账户没有执行该操作所需的权限。请与管理员讨论，或参见 [8.2，访问控制和账户管理](../../08.安全性/08.02.访问控制和账户管理/08.02.00.访问控制和账户管理.md)。

创建数据库并不会选择它作为当前数据库；你必须显式选择。要让 `menagerie` 成为当前数据库，请使用：

```sql
mysql> USE menagerie
Database changed
```

数据库只需要创建一次，但每次开始一个 `mysql` 会话时都必须选择它。你可以如示例所示发出 `USE` 语句，也可以在调用 `mysql` 时通过命令行选择数据库；只需在所有可能需要的连接参数之后指定数据库名。例如：

```terminal
$> mysql -h host -u user -p menagerie
Enter password: ********
```

> **重要**
>
> 上例命令中的 `menagerie` **不是**你的密码。如果希望在命令行上通过 `-p` 选项提供密码，必须不带中间空格（例如写成 `-p`_`password`_，而不是 `-p` _`password`_）。不过，不建议把密码放在命令行上，因为这会使其暴露给同一机器上其他已登录用户的窥探。

> **注意**
>
> 可以随时使用 `SELECT DATABASE()` 查看当前选择的数据库。
