### 5.3.3 向表中装载数据

创建表之后，需要向其中填充数据。`LOAD DATA` 和 `INSERT` 语句对此很有用。

假设你的宠物记录可以描述如下。（注意，MySQL 期望日期采用 `'YYYY-MM-DD'` 格式；这可能与你在其他地方习惯的格式不同。）

| name | owner | species | sex | birth | death |
| --- | --- | --- | --- | --- | --- |
| Fluffy | Harold | cat | f | 1993-02-04 | |
| Claws | Gwen | cat | m | 1994-03-17 | |
| Buffy | Harold | dog | f | 1989-05-13 | |
| Fang | Benny | dog | m | 1990-08-27 | |
| Bowser | Diane | dog | m | 1979-08-31 | 1995-07-29 |
| Chirpy | Gwen | bird | f | 1998-09-11 | |
| Whistler | Gwen | bird | | 1997-12-09 | |
| Slim | Benny | snake | m | 1996-04-29 | |

由于开始时表是空的，填充它的一种简单方法是：创建一个文本文件，每个动物一行，然后用一条语句将文件内容装载到表中。

你可以创建一个 `pet.txt` 文件，每行包含一条记录，值之间用制表符分隔，并按 `CREATE TABLE` 语句中列出列的顺序排列。对于缺失值，例如未知性别或仍在世的动物的死亡日期，可以使用 `NULL`。要在文本文件中表示 `NULL`，请使用 `\N`（反斜杠后接大写 N）。例如，鸟 Whistler 的记录看起来如下（值之间的空白是一个制表符）：

```none
Whistler        Gwen    bird    \N      1997-12-09      \N
```

要将文本文件 `pet.txt` 装载到 `pet` 表中，请使用：

```sql
mysql> LOAD DATA LOCAL INFILE '/path/pet.txt' INTO TABLE pet;
```

如果你是在 Windows 上使用以 `\r\n` 作为行结束符的编辑器创建该文件，应改用：

```sql
mysql> LOAD DATA LOCAL INFILE '/path/pet.txt' INTO TABLE pet
       LINES TERMINATED BY '\r\n';
```

（在运行 macOS 的 Apple 机器上，你可能需要使用 `LINES TERMINATED BY '\r'`。）

如果需要，你可以在 `LOAD DATA` 语句中显式指定列值分隔符和行结束标记，但默认值分别是制表符和换行符。对于正确读取 `pet.txt` 文件来说，这些默认值已经足够。

如果该语句失败，很可能是你的 MySQL 安装默认没有启用本地文件功能。关于如何更改此设置，参见 [8.1.6，LOAD DATA LOCAL 的安全注意事项](https://dev.mysql.com/doc/refman/8.0/en/load-data-local-security.html)。

当你希望一次添加一条新记录时，`INSERT` 语句很有用。在最简单的形式中，你按 `CREATE TABLE` 语句中列出列的顺序为每一列提供值。假设 Diane 得到了一只名叫 “Puffball” 的新仓鼠。你可以像这样使用 `INSERT` 语句添加一条新记录：

```sql
mysql> INSERT INTO pet
       VALUES ('Puffball','Diane','hamster','f','1999-03-30',NULL);
```

这里的字符串和日期值被指定为带引号的字符串。此外，在 `INSERT` 中可以直接插入 `NULL` 表示缺失值；不像 `LOAD DATA` 那样使用 `\N`。

从这个示例可以看出，如果最初装载记录时使用多条 `INSERT` 语句而不是一条 `LOAD DATA` 语句，需要输入的内容会多得多。
