知道如何输入 SQL 语句后，你就可以访问数据库了。

假设你家里养了几只宠物（也就是你的“动物园”），并且希望记录它们的各种信息。你可以创建一些表来保存数据，并把所需信息装载进去。随后，你可以通过从表中检索数据，回答关于这些动物的不同类型的问题。本节展示如何执行以下操作：

- 创建数据库
- 创建表
- 向表中装载数据
- 以多种方式从表中检索数据
- 使用多个表

这个“动物园”数据库很简单（这是刻意为之），但不难想到现实世界中可能使用类似数据库的场景。例如，农场主可以用这样的数据库跟踪牲畜，兽医可以用它跟踪病历。MySQL 网站提供了包含后续各节使用的部分查询和示例数据的“动物园”发行版，可在 [https://dev.mysql.com/doc/](https://dev.mysql.com/doc/) 以压缩 tar 文件和 Zip 格式获得。

使用 `SHOW` 语句查看服务器上当前存在哪些数据库：

```sql
mysql> SHOW DATABASES;
+----------+
| Database |
+----------+
| mysql    |
| test     |
| tmp      |
+----------+
```

`mysql` 数据库描述用户的访问权限。`test` 数据库通常作为用户试验内容的工作区提供。

你的机器上语句显示的数据库列表可能不同；如果你没有 `SHOW DATABASES` 权限，`SHOW DATABASES` 不会显示你没有权限访问的数据库。参见 [15.7.7.14，SHOW DATABASES 语句](../../15.SQL语句/15.07.数据库管理语句/15.07.00.数据库管理语句.md)。

如果 `test` 数据库存在，请尝试访问它：

```sql
mysql> USE test
Database changed
```

与 `QUIT` 一样，`USE` 不需要分号。（如果你愿意，也可以用分号结束这类语句；这不会有任何问题。）`USE` 语句还有另一个特别之处：它必须在单行中给出。

如果有访问权限，你可以将 `test` 数据库用于后续示例；但其他有权访问该数据库的人也可能删除你在其中创建的任何内容。因此，你可能应该请 MySQL 管理员允许你使用一个自己的数据库。假设你想把它命名为 `menagerie`。管理员需要执行类似下面的语句：

```sql
mysql> GRANT ALL ON menagerie.* TO 'your_mysql_name'@'your_client_host';
```

其中 `your_mysql_name` 是分配给你的 MySQL 用户名，`your_client_host` 是你连接服务器时使用的主机。
