#### 5.3.4.7 模式匹配

MySQL 提供标准 SQL 模式匹配，也提供一种基于扩展正则表达式的模式匹配形式，后者类似于 Unix 的 `vi`、`grep` 和 `sed` 等工具所使用的正则表达式。

SQL 模式匹配允许使用 `_` 匹配任意单个字符，使用 `%` 匹配任意数量的字符（包括零个字符）。在 MySQL 中，SQL 模式默认不区分大小写。下面是一些示例。使用 SQL 模式时，不要使用 `=` 或 `<>`；应改用 `LIKE` 或 `NOT LIKE` 比较运算符。

查找以 `b` 开头的名字：

```sql
mysql> SELECT * FROM pet WHERE name LIKE 'b%';
+--------+--------+---------+------+------------+------------+
| name   | owner  | species | sex  | birth      | death      |
+--------+--------+---------+------+------------+------------+
| Buffy  | Harold | dog     | f    | 1989-05-13 | NULL       |
| Bowser | Diane  | dog     | m    | 1989-08-31 | 1995-07-29 |
+--------+--------+---------+------+------------+------------+
```

查找以 `fy` 结尾的名字：

```sql
mysql> SELECT * FROM pet WHERE name LIKE '%fy';
+--------+--------+---------+------+------------+-------+
| name   | owner  | species | sex  | birth      | death |
+--------+--------+---------+------+------------+-------+
| Fluffy | Harold | cat     | f    | 1993-02-04 | NULL  |
| Buffy  | Harold | dog     | f    | 1989-05-13 | NULL  |
+--------+--------+---------+------+------------+-------+
```

查找包含 `w` 的名字：

```sql
mysql> SELECT * FROM pet WHERE name LIKE '%w%';
+----------+-------+---------+------+------------+------------+
| name     | owner | species | sex  | birth      | death      |
+----------+-------+---------+------+------------+------------+
| Claws    | Gwen  | cat     | m    | 1994-03-17 | NULL       |
| Bowser   | Diane | dog     | m    | 1989-08-31 | 1995-07-29 |
| Whistler | Gwen  | bird    | NULL | 1997-12-09 | NULL       |
+----------+-------+---------+------+------------+------------+
```

要查找恰好包含五个字符的名字，可以使用五个 `_` 模式字符：

```sql
mysql> SELECT * FROM pet WHERE name LIKE '_____';
+-------+--------+---------+------+------------+-------+
| name  | owner  | species | sex  | birth      | death |
+-------+--------+---------+------+------------+-------+
| Claws | Gwen   | cat     | m    | 1994-03-17 | NULL  |
| Buffy | Harold | dog     | f    | 1989-05-13 | NULL  |
+-------+--------+---------+------+------------+-------+
```

MySQL 提供的另一种模式匹配使用扩展正则表达式。测试这种类型的模式是否匹配时，请使用 `REGEXP_LIKE()` 函数（或 `REGEXP` / `RLIKE` 运算符，它们是 `REGEXP_LIKE()` 的同义词）。

以下列表描述扩展正则表达式的一些特征：

- `.` 匹配任意单个字符。

- 字符类 `[...]` 匹配方括号内的任意字符。例如，`[abc]` 匹配 `a`、`b` 或 `c`。要表示字符范围，请使用连字符：`[a-z]` 匹配任意字母，`[0-9]` 匹配任意数字。

- `*` 匹配它前面内容的零个或多个实例。例如，`x*` 匹配任意数量的 `x` 字符，`[0-9]*` 匹配任意数量的数字，`.*` 匹配任意数量的任意字符。

- 只要模式匹配被测试值中的任意位置，正则表达式模式匹配就成功。（这与 `LIKE` 模式匹配不同；后者只有在模式匹配整个值时才成功。）

- 若要将模式锚定到被测试值的开头或结尾，请在模式开头使用 `^`，或在模式结尾使用 `$`。

为了演示扩展正则表达式的工作方式，下面把此前展示的 `LIKE` 查询改写为使用 `REGEXP_LIKE()`。

要查找以 `b` 开头的名字，使用 `^` 匹配名字的开头：

```sql
mysql> SELECT * FROM pet WHERE REGEXP_LIKE(name, '^b');
+--------+--------+---------+------+------------+------------+
| name   | owner  | species | sex  | birth      | death      |
+--------+--------+---------+------+------------+------------+
| Buffy  | Harold | dog     | f    | 1989-05-13 | NULL       |
| Bowser | Diane  | dog     | m    | 1979-08-31 | 1995-07-29 |
+--------+--------+---------+------+------------+------------+
```

要让正则表达式比较区分大小写，可以使用区分大小写的排序规则，或使用 `BINARY` 关键字把其中一个字符串转换为二进制字符串，或指定 `c` 匹配控制字符。以下每个查询都只匹配名字开头的小写 `b`：

```sql
SELECT * FROM pet WHERE REGEXP_LIKE(name, '^b' COLLATE utf8mb4_0900_as_cs);
SELECT * FROM pet WHERE REGEXP_LIKE(name, BINARY '^b');
SELECT * FROM pet WHERE REGEXP_LIKE(name, '^b', 'c');
```

要查找以 `fy` 结尾的名字，使用 `$` 匹配名字的结尾：

```sql
mysql> SELECT * FROM pet WHERE REGEXP_LIKE(name, 'fy$');
+--------+--------+---------+------+------------+-------+
| name   | owner  | species | sex  | birth      | death |
+--------+--------+---------+------+------------+-------+
| Fluffy | Harold | cat     | f    | 1993-02-04 | NULL  |
| Buffy  | Harold | dog     | f    | 1989-05-13 | NULL  |
+--------+--------+---------+------+------------+-------+
```

要查找包含 `w` 的名字，请使用：

```sql
mysql> SELECT * FROM pet WHERE REGEXP_LIKE(name, 'w');
+----------+-------+---------+------+------------+------------+
| name     | owner | species | sex  | birth      | death      |
+----------+-------+---------+------+------------+------------+
| Claws    | Gwen  | cat     | m    | 1994-03-17 | NULL       |
| Bowser   | Diane | dog     | m    | 1989-08-31 | 1995-07-29 |
| Whistler | Gwen  | bird    | NULL | 1997-12-09 | NULL       |
+----------+-------+---------+------+------------+------------+
```

因为正则表达式模式只要出现在被测试值的任意位置就会匹配，所以在前一个查询中，没有必要像 SQL 模式那样在模式两侧放置通配符以匹配整个值。

要查找恰好包含五个字符的名字，可以用 `^` 和 `$` 匹配名字的开头和结尾，中间放五个 `.`：

```sql
mysql> SELECT * FROM pet WHERE REGEXP_LIKE(name, '^.....$');
+-------+--------+---------+------+------------+-------+
| name  | owner  | species | sex  | birth      | death |
+-------+--------+---------+------+------------+-------+
| Claws | Gwen   | cat     | m    | 1994-03-17 | NULL  |
| Buffy | Harold | dog     | f    | 1989-05-13 | NULL  |
+-------+--------+---------+------+------------+-------+
```

也可以使用 `{n}`（“重复 n 次”）运算符改写前一个查询：

```sql
mysql> SELECT * FROM pet WHERE REGEXP_LIKE(name, '^.{5}$');
+-------+--------+---------+------+------------+-------+
| name  | owner  | species | sex  | birth      | death |
+-------+--------+---------+------+------------+-------+
| Claws | Gwen   | cat     | m    | 1994-03-17 | NULL  |
| Buffy | Harold | dog     | f    | 1989-05-13 | NULL  |
+-------+--------+---------+------+------------+-------+
```

关于正则表达式语法的更多信息，参见 [14.8.2，正则表达式](https://dev.mysql.com/doc/refman/8.0/en/regexp.html)。
