#### 5.3.4.5 日期计算

MySQL 提供多个函数，可用于对日期执行计算，例如计算年龄或提取日期的各个部分。

要确定每只宠物的年龄（以年为单位），请使用 `TIMESTAMPDIFF()` 函数。它的参数依次是希望结果使用的单位，以及要计算差值的两个日期。以下查询为每只宠物显示出生日期、当前日期和以年计的年龄。这里使用别名 `age`，让最终输出列的标签更有意义。

```sql
mysql> SELECT name, birth, CURDATE(),
       TIMESTAMPDIFF(YEAR,birth,CURDATE()) AS age
       FROM pet;
+----------+------------+------------+------+
| name     | birth      | CURDATE()  | age  |
+----------+------------+------------+------+
| Fluffy   | 1993-02-04 | 2003-08-19 |   10 |
| Claws    | 1994-03-17 | 2003-08-19 |    9 |
| Buffy    | 1989-05-13 | 2003-08-19 |   14 |
| Fang     | 1990-08-27 | 2003-08-19 |   12 |
| Bowser   | 1989-08-31 | 2003-08-19 |   13 |
| Chirpy   | 1998-09-11 | 2003-08-19 |    4 |
| Whistler | 1997-12-09 | 2003-08-19 |    5 |
| Slim     | 1996-04-29 | 2003-08-19 |    7 |
| Puffball | 1999-03-30 | 2003-08-19 |    4 |
+----------+------------+------------+------+
```

这个查询可以工作，但如果行按某种顺序呈现，结果会更容易浏览。可以在查询中添加 `ORDER BY name` 子句，按名字排序输出：

```sql
mysql> SELECT name, birth, CURDATE(),
       TIMESTAMPDIFF(YEAR,birth,CURDATE()) AS age
       FROM pet ORDER BY name;
+----------+------------+------------+------+
| name     | birth      | CURDATE()  | age  |
+----------+------------+------------+------+
| Bowser   | 1989-08-31 | 2003-08-19 |   13 |
| Buffy    | 1989-05-13 | 2003-08-19 |   14 |
| Chirpy   | 1998-09-11 | 2003-08-19 |    4 |
| Claws    | 1994-03-17 | 2003-08-19 |    9 |
| Fang     | 1990-08-27 | 2003-08-19 |   12 |
| Fluffy   | 1993-02-04 | 2003-08-19 |   10 |
| Puffball | 1999-03-30 | 2003-08-19 |    4 |
| Slim     | 1996-04-29 | 2003-08-19 |    7 |
| Whistler | 1997-12-09 | 2003-08-19 |    5 |
+----------+------------+------------+------+
```

如果要按 `age` 而不是 `name` 排序，只需使用另一个 `ORDER BY` 子句：

```sql
mysql> SELECT name, birth, CURDATE(),
       TIMESTAMPDIFF(YEAR,birth,CURDATE()) AS age
       FROM pet ORDER BY age;
+----------+------------+------------+------+
| name     | birth      | CURDATE()  | age  |
+----------+------------+------------+------+
| Chirpy   | 1998-09-11 | 2003-08-19 |    4 |
| Puffball | 1999-03-30 | 2003-08-19 |    4 |
| Whistler | 1997-12-09 | 2003-08-19 |    5 |
| Slim     | 1996-04-29 | 2003-08-19 |    7 |
| Claws    | 1994-03-17 | 2003-08-19 |    9 |
| Fluffy   | 1993-02-04 | 2003-08-19 |   10 |
| Fang     | 1990-08-27 | 2003-08-19 |   12 |
| Bowser   | 1989-08-31 | 2003-08-19 |   13 |
| Buffy    | 1989-05-13 | 2003-08-19 |   14 |
+----------+------------+------------+------+
```

类似的查询可用于确定已经死亡的动物死亡时的年龄。首先检查 `death` 值是否为 `NULL`，确定哪些动物已经死亡；然后对于 `death` 不为 `NULL` 的记录，计算 `death` 与 `birth` 之间的差值：

```sql
mysql> SELECT name, birth, death,
       TIMESTAMPDIFF(YEAR,birth,death) AS age
       FROM pet WHERE death IS NOT NULL ORDER BY age;
+--------+------------+------------+------+
| name   | birth      | death      | age  |
+--------+------------+------------+------+
| Bowser | 1989-08-31 | 1995-07-29 |    5 |
+--------+------------+------------+------+
```

查询使用 `death IS NOT NULL` 而不是 `death <> NULL`，因为 `NULL` 是一个特殊值，不能用普通比较运算符进行比较。这一点稍后会讨论；参见 [5.3.4.6，使用 NULL 值](./05.03.04.06.使用 NULL 值.md)。

如果你想了解哪些动物下个月过生日呢？对于这类计算，年份和日期无关；只需要提取 `birth` 列的月份部分。MySQL 提供多个提取日期部分的函数，例如 `YEAR()`、`MONTH()` 和 `DAYOFMONTH()`。这里适合使用 `MONTH()`。要查看它的效果，可以运行一个简单查询，同时显示 `birth` 和 `MONTH(birth)`：

```sql
mysql> SELECT name, birth, MONTH(birth) FROM pet;
+----------+------------+--------------+
| name     | birth      | MONTH(birth) |
+----------+------------+--------------+
| Fluffy   | 1993-02-04 |            2 |
| Claws    | 1994-03-17 |            3 |
| Buffy    | 1989-05-13 |            5 |
| Fang     | 1990-08-27 |            8 |
| Bowser   | 1989-08-31 |            8 |
| Chirpy   | 1998-09-11 |            9 |
| Whistler | 1997-12-09 |           12 |
| Slim     | 1996-04-29 |            4 |
| Puffball | 1999-03-30 |            3 |
+----------+------------+--------------+
```

查找下个月过生日的动物也很简单。假设当前月份是 4 月，那么月份值为 `4`，可以这样查找 5 月（月份 `5`）出生的动物：

```sql
mysql> SELECT name, birth FROM pet WHERE MONTH(birth) = 5;
+-------+------------+
| name  | birth      |
+-------+------------+
| Buffy | 1989-05-13 |
+-------+------------+
```

如果当前月份是 12 月，就有一点小麻烦。不能简单地把月份数字 `12` 加一并查找出生月份为 `13` 的动物，因为没有这样的月份。此时应查找 1 月（月份 `1`）出生的动物。

可以把查询写成无论当前是哪个月都能工作的形式，从而不必硬编码特定月份。`DATE_ADD()` 可以在给定日期上添加时间间隔。如果在 `CURDATE()` 的值上加一个月，再用 `MONTH()` 提取月份部分，就得到了应查找生日的月份：

```sql
mysql> SELECT name, birth FROM pet
       WHERE MONTH(birth) = MONTH(DATE_ADD(CURDATE(),INTERVAL 1 MONTH));
```

完成同一任务的另一种方法是：先用取模函数 `MOD` 把当前月份为 `12` 时的值折回到 `0`，再加 `1` 得到下个月：

```sql
mysql> SELECT name, birth FROM pet
       WHERE MONTH(birth) = MOD(MONTH(CURDATE()), 12) + 1;
```

`MONTH()` 返回 `1` 到 `12` 之间的数字，而 `MOD(something,12)` 返回 `0` 到 `11` 之间的数字。因此加法必须在 `MOD()` 之后进行，否则我们会从 11 月（`11`）直接跳到 1 月（`1`）。

如果计算使用了无效日期，计算会失败并产生警告：

```sql
mysql> SELECT '2018-10-31' + INTERVAL 1 DAY;
+-------------------------------+
| '2018-10-31' + INTERVAL 1 DAY |
+-------------------------------+
| 2018-11-01                    |
+-------------------------------+
mysql> SELECT '2018-10-32' + INTERVAL 1 DAY;
+-------------------------------+
| '2018-10-32' + INTERVAL 1 DAY |
+-------------------------------+
| NULL                          |
+-------------------------------+
mysql> SHOW WARNINGS;
+---------+------+----------------------------------------+
| Level   | Code | Message                                |
+---------+------+----------------------------------------+
| Warning | 1292 | Incorrect datetime value: '2018-10-32' |
+---------+------+----------------------------------------+
```
