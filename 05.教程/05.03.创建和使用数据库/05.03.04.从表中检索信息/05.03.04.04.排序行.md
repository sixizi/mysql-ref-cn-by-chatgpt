#### 5.3.4.4 排序行

你可能已经注意到，在前面示例中，结果行并非按特定顺序显示。如果行按某种有意义的方式排序，查询输出通常更容易查看。要对结果排序，请使用 `ORDER BY` 子句。

下面是按日期排序的动物生日：

```sql
mysql> SELECT name, birth FROM pet ORDER BY birth;
+----------+------------+
| name     | birth      |
+----------+------------+
| Buffy    | 1989-05-13 |
| Bowser   | 1989-08-31 |
| Fang     | 1990-08-27 |
| Fluffy   | 1993-02-04 |
| Claws    | 1994-03-17 |
| Slim     | 1996-04-29 |
| Whistler | 1997-12-09 |
| Chirpy   | 1998-09-11 |
| Puffball | 1999-03-30 |
+----------+------------+
```

在字符类型列上，排序和所有其他比较操作一样，通常不区分大小写。这意味着对于仅大小写不同的列值，顺序是未定义的。可以对某一列使用 `BINARY` 强制区分大小写排序，例如：`ORDER BY BINARY` _`col_name`_。

默认排序顺序为升序，最小的值排在最前面。若要按相反（降序）顺序排序，请在用于排序的列名后添加 `DESC` 关键字：

```sql
mysql> SELECT name, birth FROM pet ORDER BY birth DESC;
+----------+------------+
| name     | birth      |
+----------+------------+
| Puffball | 1999-03-30 |
| Chirpy   | 1998-09-11 |
| Whistler | 1997-12-09 |
| Slim     | 1996-04-29 |
| Claws    | 1994-03-17 |
| Fluffy   | 1993-02-04 |
| Fang     | 1990-08-27 |
| Bowser   | 1989-08-31 |
| Buffy    | 1989-05-13 |
+----------+------------+
```

可以对多个列排序，并且不同列可以使用不同的方向。例如，要先按动物种类升序排序，再在同一动物种类内按出生日期降序排序（最年幼的动物在前），请使用以下查询：

```sql
mysql> SELECT name, species, birth FROM pet
       ORDER BY species, birth DESC;
+----------+---------+------------+
| name     | species | birth      |
+----------+---------+------------+
| Chirpy   | bird    | 1998-09-11 |
| Whistler | bird    | 1997-12-09 |
| Claws    | cat     | 1994-03-17 |
| Fluffy   | cat     | 1993-02-04 |
| Fang     | dog     | 1990-08-27 |
| Bowser   | dog     | 1989-08-31 |
| Buffy    | dog     | 1989-05-13 |
| Puffball | hamster | 1999-03-30 |
| Slim     | snake   | 1996-04-29 |
+----------+---------+------------+
```

`DESC` 关键字只作用于紧挨在它前面的列名（这里是 `birth`）；它不影响 `species` 列的排序顺序。
