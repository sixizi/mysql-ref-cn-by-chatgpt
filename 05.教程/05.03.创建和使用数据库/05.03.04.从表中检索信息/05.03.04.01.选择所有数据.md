#### 5.3.4.1 选择所有数据

`SELECT` 最简单的形式是从表中检索所有数据：

```sql
mysql> SELECT * FROM pet;
+----------+--------+---------+------+------------+------------+
| name     | owner  | species | sex  | birth      | death      |
+----------+--------+---------+------+------------+------------+
| Fluffy   | Harold | cat     | f    | 1993-02-04 | NULL       |
| Claws    | Gwen   | cat     | m    | 1994-03-17 | NULL       |
| Buffy    | Harold | dog     | f    | 1989-05-13 | NULL       |
| Fang     | Benny  | dog     | m    | 1990-08-27 | NULL       |
| Bowser   | Diane  | dog     | m    | 1979-08-31 | 1995-07-29 |
| Chirpy   | Gwen   | bird    | f    | 1998-09-11 | NULL       |
| Whistler | Gwen   | bird    | NULL | 1997-12-09 | NULL       |
| Slim     | Benny  | snake   | m    | 1996-04-29 | NULL       |
| Puffball | Diane  | hamster | f    | 1999-03-30 | NULL       |
+----------+--------+---------+------+------------+------------+
```

这种 `SELECT` 形式使用 `*`，它是“选择所有列”的简写。如果你想查看整张表，例如刚刚装载初始数据集之后，这很有用。例如，你可能碰巧觉得 Bowser 的出生日期看起来不太对。查阅原始血统证书后发现，正确的出生年份应为 1989 年，而不是 1979 年。

至少有两种修正方法：

- 编辑文件 `pet.txt` 修正错误，然后清空表并使用 `DELETE` 和 `LOAD DATA` 重新装载：

  ```sql
  mysql> DELETE FROM pet;
  mysql> LOAD DATA LOCAL INFILE 'pet.txt' INTO TABLE pet;
  ```

  不过，如果这样做，还必须重新输入 Puffball 的记录。

- 使用 `UPDATE` 语句只修正错误记录：

  ```sql
  mysql> UPDATE pet SET birth = '1989-08-31' WHERE name = 'Bowser';
  ```

  `UPDATE` 只修改相关记录，不需要重新装载表。

`SELECT *` 会选择所有列的原则有一个例外。如果表中包含不可见列，`*` 不包含它们。更多信息参见 [15.1.20.10，不可见列](../../../15.SQL语句/15.01.数据定义语句/15.01.00.数据定义语句.md)。
