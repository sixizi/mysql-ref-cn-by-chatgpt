#### 5.3.4.8 统计行数

数据库常用于回答“某种类型的数据在表中出现了多少次”这类问题。例如，你可能想知道自己有多少只宠物、每个主人有多少只宠物，或者想对这些动物执行各种统计操作。

统计动物总数等价于问“`pet` 表中有多少行”，因为每只宠物对应一条记录。`COUNT(*)` 用于统计行数，因此统计动物数量的查询如下：

```sql
mysql> SELECT COUNT(*) FROM pet;
+----------+
| COUNT(*) |
+----------+
|        9 |
+----------+
```

此前你已经检索过拥有宠物的人员名单。如果想了解每个主人各有多少只宠物，可以使用 `COUNT()`：

```sql
mysql> SELECT owner, COUNT(*) FROM pet GROUP BY owner;
+--------+----------+
| owner  | COUNT(*) |
+--------+----------+
| Benny  |        2 |
| Diane  |        2 |
| Gwen   |        3 |
| Harold |        2 |
+--------+----------+
```

上面的查询使用 `GROUP BY` 将每个 `owner` 的所有记录分为一组。将 `COUNT()` 与 `GROUP BY` 结合使用，有助于按不同分组刻画数据特征。以下示例展示执行动物统计的不同方式。

每个物种的动物数量：

```sql
mysql> SELECT species, COUNT(*) FROM pet GROUP BY species;
+---------+----------+
| species | COUNT(*) |
+---------+----------+
| bird    |        2 |
| cat     |        2 |
| dog     |        3 |
| hamster |        1 |
| snake   |        1 |
+---------+----------+
```

每种性别的动物数量：

```sql
mysql> SELECT sex, COUNT(*) FROM pet GROUP BY sex;
+------+----------+
| sex  | COUNT(*) |
+------+----------+
| NULL |        1 |
| f    |        4 |
| m    |        4 |
+------+----------+
```

（在这个输出中，`NULL` 表示性别未知。）

每种物种与性别组合的动物数量：

```sql
mysql> SELECT species, sex, COUNT(*) FROM pet GROUP BY species, sex;
+---------+------+----------+
| species | sex  | COUNT(*) |
+---------+------+----------+
| bird    | NULL |        1 |
| bird    | f    |        1 |
| cat     | f    |        1 |
| cat     | m    |        1 |
| dog     | f    |        1 |
| dog     | m    |        2 |
| hamster | f    |        1 |
| snake   | m    |        1 |
+---------+------+----------+
```

使用 `COUNT()` 时不必检索整张表。例如，如果只对狗和猫执行前面的查询，可以这样写：

```sql
mysql> SELECT species, sex, COUNT(*) FROM pet
       WHERE species = 'dog' OR species = 'cat'
       GROUP BY species, sex;
+---------+------+----------+
| species | sex  | COUNT(*) |
+---------+------+----------+
| cat     | f    |        1 |
| cat     | m    |        1 |
| dog     | f    |        1 |
| dog     | m    |        2 |
+---------+------+----------+
```

或者，如果只想统计性别已知的动物按性别分布的数量：

```sql
mysql> SELECT species, sex, COUNT(*) FROM pet
       WHERE sex IS NOT NULL
       GROUP BY species, sex;
+---------+------+----------+
| species | sex  | COUNT(*) |
+---------+------+----------+
| bird    | f    |        1 |
| cat     | f    |        1 |
| cat     | m    |        1 |
| dog     | f    |        1 |
| dog     | m    |        2 |
| hamster | f    |        1 |
| snake   | m    |        1 |
+---------+------+----------+
```

如果在 `COUNT()` 值之外还指定要选择的列，就应提供列出相同列的 `GROUP BY` 子句。否则会出现以下情况：

- 如果启用了 `ONLY_FULL_GROUP_BY` SQL 模式，会发生错误：

  ```sql
  mysql> SET sql_mode = 'ONLY_FULL_GROUP_BY';
  Query OK, 0 rows affected (0.00 sec)

  mysql> SELECT owner, COUNT(*) FROM pet;
  ERROR 1140 (42000): In aggregated query without GROUP BY, expression
  #1 of SELECT list contains nonaggregated column 'menagerie.pet.owner';
  this is incompatible with sql_mode=only_full_group_by
  ```

- 如果未启用 `ONLY_FULL_GROUP_BY`，查询会把所有行作为单个组处理，但为每个被命名列选择的值是非确定性的。服务器可以从任意行中选择该值：

  ```sql
  mysql> SET sql_mode = '';
  Query OK, 0 rows affected (0.00 sec)

  mysql> SELECT owner, COUNT(*) FROM pet;
  +--------+----------+
  | owner  | COUNT(*) |
  +--------+----------+
  | Harold |        8 |
  +--------+----------+
  1 row in set (0.00 sec)
  ```

另见 [14.19.3，MySQL 对 GROUP BY 的处理](https://dev.mysql.com/doc/refman/8.0/en/group-by-handling.html)。关于 `COUNT(expr)` 的行为和相关优化，参见 [14.19.1，聚合函数说明](https://dev.mysql.com/doc/refman/8.0/en/aggregate-functions.html)。
