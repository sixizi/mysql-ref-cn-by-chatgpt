## 5.1 连接服务器和断开服务器

要连接服务器，调用 `mysql` 时通常需要提供 MySQL 用户名，很可能还需要提供密码。如果服务器运行的机器不是你登录的机器，还必须指定主机名。请联系管理员，了解连接时应使用的连接参数，也就是应使用的主机、用户名和密码。知道正确参数后，你应该能够像下面这样连接：

```terminal
$> mysql -h host -u user -p
Enter password: ********
```

`host` 和 `user` 分别表示运行 MySQL 服务器的主机名和你的 MySQL 账户用户名。请根据你的环境替换为合适的值。`********` 表示你的密码；当 `mysql` 显示 `Enter password:` 提示时输入它。

如果连接成功，你会看到一些介绍信息，随后出现 `mysql>` 提示符：

```terminal
$> mysql -h host -u user -p
Enter password: ********
Welcome to the MySQL monitor.  Commands end with ; or \g.
Your MySQL connection id is 25338 to server version: 8.0.46-standard

Type 'help;' or '\h' for help. Type '\c' to clear the buffer.

mysql>
```

`mysql>` 提示符告诉你 `mysql` 已经准备好接收 SQL 语句。

如果你是在运行 MySQL 的同一台机器上登录，可以省略主机，只需使用：

```terminal
$> mysql -u user -p
```

如果尝试登录时收到类似 `ERROR 2002 (HY000): Can't connect to local MySQL server through socket '/tmp/mysql.sock' (2)` 的错误，说明 MySQL 服务器守护进程（Unix）或服务（Windows）没有运行。请咨询管理员，或阅读[第 2 章，安装 MySQL](https://dev.mysql.com/doc/refman/8.0/en/installing.html)中与你的操作系统对应的部分。

关于尝试登录时经常遇到的其他问题，请参见 [B.3.2，使用 MySQL 程序时的常见错误](../B.错误消息和常见问题/B.3.问题与常见错误/B.3.2.使用 MySQL 程序时的常见错误/B.3.2.00.使用 MySQL 程序时的常见错误.md)。

某些 MySQL 安装允许用户以匿名（未命名）用户身份连接本地主机上运行的服务器。如果你的机器是这样，你应该可以不带任何选项调用 `mysql` 来连接该服务器：

```terminal
$> mysql
```

成功连接后，你可以在 `mysql>` 提示符下输入 `QUIT`（或 `\q`）随时断开连接：

```sql
mysql> QUIT
Bye
```

在 Unix 上，也可以按 Control+D 断开连接。

以下各节中的大多数示例都假设你已经连接到服务器。这些示例用 `mysql>` 提示符表示这一状态。
