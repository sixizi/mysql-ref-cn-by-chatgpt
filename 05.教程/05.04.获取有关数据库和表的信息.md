## 5.4 获取有关数据库和表的信息

如果你忘记了数据库或表的名称，或者忘记了某个表的结构（例如列的名称），该怎么办？MySQL 通过多条语句提供其支持的数据库和表的信息，解决了这个问题。

你之前已经见过 [`SHOW DATABASES`](https://dev.mysql.com/doc/refman/8.0/en/show-databases.html)，它列出服务器管理的数据库。要了解当前选择了哪个数据库，可以使用 `DATABASE()` 函数：

```sql
mysql> SELECT DATABASE();
+------------+
| DATABASE() |
+------------+
| menagerie  |
+------------+
```

如果尚未选择任何数据库，结果为 `NULL`。

要了解默认数据库包含哪些表（例如当你不确定某个表的名称时），可以使用以下语句：

```sql
mysql> SHOW TABLES;
+---------------------+
| Tables_in_menagerie |
+---------------------+
| event               |
| pet                 |
+---------------------+
```

该语句输出中的列名始终为 ``Tables_in_`db_name`_``，其中 `_`db_name`_` 是数据库名称。更多信息请参见 [15.7.7.39，SHOW TABLES 语句](https://dev.mysql.com/doc/refman/8.0/en/show-tables.html)。

如果想了解表的结构，[`DESCRIBE`](https://dev.mysql.com/doc/refman/8.0/en/describe.html) 语句非常有用；它会显示表中每一列的信息：

```sql
mysql> DESCRIBE pet;
+---------+-------------+------+-----+---------+-------+
| Field   | Type        | Null | Key | Default | Extra |
+---------+-------------+------+-----+---------+-------+
| name    | varchar(20) | YES  |     | NULL    |       |
| owner   | varchar(20) | YES  |     | NULL    |       |
| species | varchar(20) | YES  |     | NULL    |       |
| sex     | char(1)     | YES  |     | NULL    |       |
| birth   | date        | YES  |     | NULL    |       |
| death   | date        | YES  |     | NULL    |       |
+---------+-------------+------+-----+---------+-------+
```

`Field` 表示列名，`Type` 是列的数据类型，`NULL` 表示该列是否可以包含 `NULL` 值，`Key` 表示该列是否已建立索引，`Default` 指定列的默认值。`Extra` 显示列的特殊信息：如果某列创建时使用了 `AUTO_INCREMENT` 选项，该值会显示为 `auto_increment`，而不是空白。

`DESC` 是 [`DESCRIBE`](https://dev.mysql.com/doc/refman/8.0/en/describe.html) 的简写形式。更多信息请参见 [15.8.1，DESCRIBE 语句](https://dev.mysql.com/doc/refman/8.0/en/describe.html)。

你可以使用 [`SHOW CREATE TABLE`](https://dev.mysql.com/doc/refman/8.0/en/show-create-table.html) 语句获取创建现有表所需的 [`CREATE TABLE`](https://dev.mysql.com/doc/refman/8.0/en/create-table.html) 语句。参见 [15.7.7.10，SHOW CREATE TABLE 语句](https://dev.mysql.com/doc/refman/8.0/en/show-create-table.html)。

如果表上有索引，``SHOW INDEX FROM `_tbl_name`_`` 会生成与这些索引有关的信息。关于该语句的更多信息，请参见 [15.7.7.22，SHOW INDEX 语句](https://dev.mysql.com/doc/refman/8.0/en/show-index.html)。
