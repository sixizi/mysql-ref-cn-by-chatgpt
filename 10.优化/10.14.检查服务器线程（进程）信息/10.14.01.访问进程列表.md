## 进程信息的来源

进程信息可从以下来源获得：

- SHOW PROCESSLIST 语句：Section 15.7.7.33, "SHOW PROCESSLIST Statement"

- mysqladmin processlist 命令：Section 6.5.2, "mysqladmin — A MySQL Server Administration Program"

- INFORMATION_SCHEMA PROCESSLIST 表：Section 28.3.28, "The INFORMATION_SCHEMA PROCESSLIST Table"

- Performance Schema processlist 表：Section 29.12.23.9, "The processlist Table"

- Performance Schema threads 表中名称前缀为 PROCESSLIST_ 的列：Section 29.12.23.10, "The threads Table"

- sys schema processlist 和 session 视图：Section 30.4.3.22, "The processlist and x$processlist Views"，以及 Section 30.4.3.33, "The session and x$session Views"

threads 表与 SHOW PROCESSLIST、INFORMATION_SCHEMA PROCESSLIST 和 mysqladmin processlist 的比较如下：

- 访问 threads 表不需要互斥锁，对服务器性能的影响最小。其他来源会产生负面的性能后果，因为它们需要互斥锁。

  注意

  基于 Performance Schema processlist 表的 SHOW PROCESSLIST 的替代实现可用，它与 threads 表一样，不需要互斥锁，具有更好的性能特性。有关详情，请参见 Section 29.12.23.9, "The processlist Table"。

- threads 表显示后台线程，而其他来源则不显示。它还为每个线程提供其他来源没有的额外信息，例如线程是前台线程还是后台线程，以及与线程关联的服务器内的位置。这意味着 threads 表可用于监视其他来源无法监视的线程活动。

- 您可以启用或禁用 Performance Schema 线程监视，如 Section 29.12.23.10, "The threads Table" 中所述。

出于这些原因，使用其他线程信息来源执行服务器监视的数据库管理员可能希望改用 threads 表进行监视。

sys schema processlist 视图以更易于访问的格式呈现来自 Performance Schema threads 表的信息。sys schema session 视图呈现有关用户会话的信息，类似于 sys schema processlist 视图，但过滤掉了后台进程。

## 访问进程列表所需的权限

对于大多数进程信息来源，如果您拥有 PROCESS 权限，您可以看到所有线程，即使是属于其他用户的线程。否则（没有 PROCESS 权限），非匿名用户可以访问有关其自己线程的信息，但不能访问其他用户的线程，匿名用户无法访问线程信息。

Performance Schema threads 表也提供线程信息，但表访问使用不同的权限模型。请参见 Section 29.12.23.10, "The threads Table"。

## 进程列表条目的内容

每个进程列表条目包含多条信息。下面的列表使用 SHOW PROCESSLIST 输出中的标签来描述它们。其他进程信息来源使用类似的标签。

- Id 是与线程关联的客户端的连接标识符。

- User 和 Host 指示与线程关联的账户。

- db 是线程的默认数据库，如果未选择任何数据库，则为 NULL。

- Command 和 State 指示线程正在执行的操作。

  大多数状态对应于非常快速的操作。如果线程在给定状态下停留许多秒，可能存在需要调查的问题。

  以下部分列出了可能的 Command 值和按类别分组的 State 值。其中一些值的含义是不言而喻的。对于其他值，提供了额外的描述。

  注意

  检查进程列表信息的应用程序应该意识到命令和状态可能会发生变化。

- Time 指示线程处于其当前状态的时间长度。线程对当前时间的概念在某些情况下可能会改变：线程可以使用 SET TIMESTAMP = value 更改时间。对于副本 SQL 线程，该值是最后一个复制事件的时间戳与副本主机的实时时间之间的秒数。请参见 Section 19.2.3, "Replication Threads"。

- Info 指示线程正在执行的语句，如果线程未执行任何语句，则为 NULL。对于 SHOW PROCESSLIST，此值仅包含语句的前 100 个字符。要查看完整语句，请使用 SHOW FULL PROCESSLIST（或查询不同的进程信息来源）。
