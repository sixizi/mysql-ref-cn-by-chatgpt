### 10.8.4 获取命名连接的执行计划信息

要获取在命名连接中执行的可解释语句的执行计划，使用以下语句：

```
EXPLAIN [options] FOR CONNECTION connection_id;
```

EXPLAIN FOR CONNECTION 返回当前在给定连接中执行查询所使用的 EXPLAIN 信息。由于数据（和支持统计信息）的变化，它可能会产生与在等效查询文本上运行 EXPLAIN 不同的结果。这种行为差异在诊断更多瞬时性能问题时很有用。例如，如果你在一个会话中运行一个耗时很长的语句，在另一个会话中使用 EXPLAIN FOR CONNECTION 可能会产生关于延迟原因的有用信息。

connection_id 是连接标识符，可从 INFORMATION_SCHEMA PROCESSLIST 表或 SHOW PROCESSLIST 语句获得。如果你拥有 PROCESS 权限，可以指定任何连接的标识符。否则，只能指定你自己的连接的标识符。在所有情况下，你必须拥有足够的权限来解释指定连接上的查询。

如果命名连接未执行语句，结果为空。否则，EXPLAIN FOR CONNECTION 仅在命名连接中执行的语句是可解释的情况下适用。这包括 SELECT、DELETE、INSERT、REPLACE 和 UPDATE。（但是，EXPLAIN FOR CONNECTION 不适用于预处理语句，即使是这些类型的预处理语句。）

如果命名连接正在执行可解释的语句，输出是你在语句本身上使用 EXPLAIN 会获得的内容。

如果命名连接正在执行不可解释的语句，会发生错误。例如，你不能为当前会话命名连接标识符，因为 EXPLAIN 本身不可解释：

```
mysql> SELECT CONNECTION_ID();
+-----------------+
| CONNECTION_ID() |
+-----------------+
|             373 |
+-----------------+
1 row in set (0.00 sec)

mysql> EXPLAIN FOR CONNECTION 373;
ERROR 1889 (HY000): EXPLAIN FOR CONNECTION command is supported
only for SELECT/UPDATE/INSERT/DELETE/REPLACE
```

Com_explain_other 状态变量指示执行的 EXPLAIN FOR CONNECTION 语句的数量。
