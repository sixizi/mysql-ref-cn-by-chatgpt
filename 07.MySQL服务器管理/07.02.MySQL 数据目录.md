## 7.2 MySQL 数据目录

MySQL 服务器管理的信息存储在一个称为数据目录的目录下。以下列表简要描述了数据目录中通常找到的项目，并提供了其他信息的交叉引用：

- 数据目录子目录。数据目录的每个子目录都是一个数据库目录，对应于服务器管理的一个数据库。所有 MySQL 安装都有某些标准数据库：

  - mysql 目录对应于 mysql 系统模式，其中包含 MySQL 服务器运行时所需的信息。此数据库包含数据字典表和系统表。参见第 7.3 节"The mysql System Schema"。

  - performance_schema 目录对应于 Performance Schema，它提供用于在运行时检查服务器内部执行的信息。参见第 29 章"MySQL Performance Schema"。

  - sys 目录对应于 sys 模式，它提供一组对象来帮助更轻松地解释 Performance Schema 信息。参见第 30 章"MySQL sys Schema"。

  - ndbinfo 目录对应于 ndbinfo 数据库，该数据库存储特定于 NDB Cluster 的信息（仅在为包含 NDB Cluster 而构建的安装中存在）。参见第 25.6.15 节"ndbinfo: The NDB Cluster Information Database"。

  其他子目录对应于用户或应用程序创建的数据库。

  > 注意
  >
  > INFORMATION_SCHEMA 是一个标准数据库，但其实现不使用相应的数据库目录。

- 服务器写入的日志文件。参见第 7.4 节"MySQL Server Logs"。

- InnoDB 表空间和日志文件。参见第 17 章"The InnoDB Storage Engine"。

- 默认/自动生成的 SSL 和 RSA 证书和密钥文件。参见第 8.3.3 节"Creating SSL and RSA Certificates and Keys"。

- 服务器进程 ID 文件（服务器运行时）。

- mysqld-auto.cnf 文件，用于存储持久化的全局系统变量设置。参见第 15.7.6.1 节"SET Syntax for Variable Assignment"。

前面列表中的某些项目可以通过重新配置服务器来重新定位到其他位置。此外，--datadir 选项可以更改数据目录本身的位置。对于给定的 MySQL 安装，请检查服务器配置以确定项目是否已被移动。
