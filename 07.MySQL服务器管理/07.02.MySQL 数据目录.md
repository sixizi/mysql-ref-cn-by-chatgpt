### 7.2 MySQL 数据目录

MySQL 数据目录保存数据库对象、表数据、日志、状态文件和服务器运行产物。

关键内容包括：

- 每个数据库对应一个子目录。
- `#pid`、`#error.log` 等服务器运行文件。
- `mysql` 系统模式中的授权表和数据字典表。
- `datadir`、`innodb_data_home_dir`、`log_bin` 等变量决定位置。

备份、迁移和权限管理都应以数据目录为单位规划，不要手工修改表文件。
