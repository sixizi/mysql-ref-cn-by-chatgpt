错误日志记录服务器启动、运行、关闭和严重故障信息。

常用配置：

```ini
[mysqld]
log_error = /var/log/mysql/error.log
log_error_verbosity = 3
```

现代 MySQL 使用组件化错误日志架构，可配置过滤器、输出格式和多个输出目标。
