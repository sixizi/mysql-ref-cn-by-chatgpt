### 7.4.2.8 输出到系统日志的错误日志

错误日志可输出到系统日志：

- Linux 使用 syslog。
- Windows 使用 Windows Event Log。

配置示例：

```ini
log_error_services = 'log_filter_internal; log_sink_syseventlog'
```

使用系统日志时，应确认采集器保留策略和权限。
