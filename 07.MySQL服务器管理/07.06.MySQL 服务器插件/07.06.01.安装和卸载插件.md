### 7.6.1 安装和卸载插件

安装插件：

```sql
INSTALL PLUGIN plugin_name SONAME 'plugin_name.so';
```

卸载插件：

```sql
UNINSTALL PLUGIN plugin_name;
```

插件也可在配置文件中用 `plugin-load-add` 自动加载。卸载前应确认没有对象依赖该插件。
