### 7.6.9.1 锁服务

锁服务提供命名锁和 `GET_LOCK()` 之外的可并发锁：

```sql
SELECT service_get_read_locks('ns', 'lock1', 10);
SELECT service_release_locks('ns', 'lock1');
```

特点：

- 支持读写锁。
- 支持多层命名空间。
- 连接断开时自动释放。

适合多客户端协作执行一次性任务。
