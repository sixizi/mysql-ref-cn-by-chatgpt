### 7.6.8.2 Keyring 服务

MySQL Server 支持一个 keyring 服务，该服务使内部组件和插件能够安全地存储敏感信息以供后续检索。MySQL 发行版提供了一个 keyring 接口，可在两个级别访问：

- 在 SQL 级别，作为一组可加载函数，每个函数都映射到对服务例程的调用。

- 作为 C 语言接口，可从服务器插件或可加载函数作为插件服务调用。

本节描述如何使用 keyring 服务函数在 MySQL keyring keystore 中存储、检索和删除密钥。有关使用函数的 SQL 接口的信息，请参见第 8.4.5.15 节"通用 Keyring 密钥管理函数"。有关常规 keyring 信息，请参见第 8.4.5 节"MySQL Keyring"。

keyring 服务使用启用的任何底层 keyring 插件（如果有）。如果未启用任何 keyring 插件，keyring 服务调用将失败。

keystore 中的"记录"由数据（密钥本身）和通过其访问密钥的唯一标识符组成。标识符有两部分：

- key_id：密钥 ID 或名称。以 mysql_ 开头的 key_id 值由 MySQL Server 保留。

- user_id：会话有效用户 ID。如果没有用户上下文，此值可以为 NULL。该值不一定是"用户"；其含义取决于应用程序。

  实现 keyring 函数接口的函数将 CURRENT_USER() 的值作为 user_id 值传递给 keyring 服务函数。

keyring 服务函数具有以下共同特征：

- 每个函数返回 0 表示成功，1 表示失败。

- key_id 和 user_id 参数形成唯一组合，指示要使用 keyring 中的哪个密钥。

- key_type 参数提供有关密钥的其他信息，例如其加密方法或预期用途。

- Keyring 服务函数将密钥 ID、用户名、类型和值视为二进制字符串，因此比较区分大小写。例如，MyKey 和 mykey 的 ID 指的是不同的密钥。

这些 keyring 服务函数可用：

- my_key_fetch()

  从 keyring 中解混淆并检索密钥及其类型。该函数为用于存储返回的密钥和密钥类型的缓冲区分配内存。调用者应在不再需要时将内存清零或混淆，然后释放它。

  语法：
  bool my_key_fetch(const char *key_id, const char **key_type,
                    const char* user_id, void **key, size_t *key_len)

  参数：

  - key_id, user_id：以空字符结尾的字符串，作为一对形成唯一标识符，指示要获取哪个密钥。

  - key_type：缓冲区指针的地址。该函数将指针存储到其中，该指针指向以空字符结尾的字符串，提供有关密钥的其他信息（在添加密钥时存储）。

  - key：缓冲区指针的地址。该函数将指针存储到其中，该指针指向包含获取的密钥数据的缓冲区。

  - key_len：变量的地址，该函数将 *key 缓冲区的大小（以字节为单位）存储到其中。

  返回值：

  成功返回 0，失败返回 1。

- my_key_generate()

  生成给定类型和长度的新随机密钥，并将其存储在 keyring 中。密钥的长度为 key_len，与从 key_id 和 user_id 形成的标识符相关联。类型和长度值必须与底层 keyring 插件支持的值一致。请参见第 8.4.5.13 节"支持的 Keyring 密钥类型和长度"。

  语法：
  bool my_key_generate(const char *key_id, const char *key_type,
                       const char *user_id, size_t key_len)

  参数：

  - key_id, user_id：以空字符结尾的字符串，作为一对形成要生成的密钥的唯一标识符。

  - key_type：以空字符结尾的字符串，提供有关密钥的其他信息。

  - key_len：要生成的密钥的大小（以字节为单位）。

  返回值：

  成功返回 0，失败返回 1。

- my_key_remove()

  从 keyring 中删除密钥。

  语法：
  bool my_key_remove(const char *key_id, const char* user_id)

  参数：

  - key_id, user_id：以空字符结尾的字符串，作为一对形成要删除的密钥的唯一标识符。

  返回值：

  成功返回 0，失败返回 1。

- my_key_store()

  混淆并在 keyring 中存储密钥。

  语法：
  bool my_key_store(const char *key_id, const char *key_type,
                    const char* user_id, void *key, size_t key_len)

  参数：

  - key_id, user_id：以空字符结尾的字符串，作为一对形成要存储的密钥的唯一标识符。

  - key_type：以空字符结尾的字符串，提供有关密钥的其他信息。

  - key：包含要存储的密钥数据的缓冲区。

  - key_len：密钥缓冲区的大小（以字节为单位）。

  返回值：

  成功返回 0，失败返回 1。
