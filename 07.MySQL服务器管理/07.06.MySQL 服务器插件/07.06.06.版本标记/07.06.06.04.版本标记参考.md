### 7.6.6.4 克隆和并发 DDL

在 MySQL 26.7 中，默认情况下允许在捐赠者上进行并发 DDL。捐赠者上的并发 DDL 支持由 clone_block_ddl 变量控制。可以使用 SET 语句动态启用和禁用并发 DDL 支持，如下所示：

```
SET GLOBAL clone_block_ddl={OFF|ON}
```

默认设置是 clone_block_ddl=OFF，允许在捐赠者上进行并发 DDL。

并发 DDL 操作的效果是否被克隆取决于 DDL 操作是否在克隆操作获取动态快照之前完成。

无论 clone_block_ddl 设置如何，在克隆操作期间不允许的 DDL 操作包括：

- ALTER TABLE tbl_name DISCARD TABLESPACE;

- ALTER TABLE tbl_name IMPORT TABLESPACE;

- ALTER INSTANCE DISABLE INNODB REDO_LOG;
