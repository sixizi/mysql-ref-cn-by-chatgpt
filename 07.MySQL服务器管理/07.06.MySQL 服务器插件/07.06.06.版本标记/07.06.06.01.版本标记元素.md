### 7.6.6.1 安装 Clone 插件

本节描述如何安装和配置 clone 插件。对于远程克隆操作，必须在捐献者和接收者 MySQL 服务器实例上安装 clone 插件。

有关安装或卸载插件的常规信息，请参见第 7.6.1 节"安装和卸载插件"。

要使服务器能够使用该插件，插件库文件必须位于 MySQL 插件目录中（由 plugin_dir 系统变量命名的目录）。如有必要，在服务器启动时设置 plugin_dir 的值以告诉服务器插件目录位置。

#### Clone 插件

插件库文件的基本名称是 mysql_clone.so。文件名后缀因平台而异（例如，Unix 和类 Unix 系统为 .so，Windows 为 .dll）。

要在服务器启动时加载插件，使用 --plugin-load-add 选项来命名包含该插件的库文件。使用此插件加载方法时，每次服务器启动时都必须给出该选项。例如，将这些行放在 my.cnf 文件中，根据需要调整平台的插件库文件名扩展名。（插件库文件名扩展名取决于您的平台。常见的后缀是 Unix 和类 Unix 系统为 .so，Windows 为 .dll。）

```
[mysqld]
plugin-load-add=mysql_clone.so
```

修改 my.cnf 后，重启服务器以使新设置生效。

> 注意
>
> 从以前的 MySQL 版本升级时重启服务器期间，--plugin-load-add 选项不能用于加载 clone 插件。在这种情况下，尝试使用 plugin-load-add=mysql_clone.so 重启服务器会引发错误 [ERROR] [MY-013238] [Server] Error installing plugin 'clone': Cannot install during upgrade。为了防止这种情况发生，请在尝试使用 plugin-load-add=mysql_clone.so 启动服务器之前升级服务器。

或者，要在运行时加载插件，使用此语句，根据需要调整平台的 .so 后缀：

```
INSTALL PLUGIN clone SONAME 'mysql_clone.so';
```

INSTALL PLUGIN 加载插件，并将其注册在 mysql.plugins 系统表中，以使插件在后续每次正常服务器启动时都被加载，而无需 --plugin-load-add。

要验证插件安装，检查信息模式 PLUGINS 表或使用 SHOW PLUGINS 语句（请参见第 7.6.2 节"获取服务器插件信息"）。例如：

```
mysql> SELECT PLUGIN_NAME, PLUGIN_STATUS
       FROM INFORMATION_SCHEMA.PLUGINS
       WHERE PLUGIN_NAME = 'clone';
+------------------------+---------------+
| PLUGIN_NAME            | PLUGIN_STATUS |
+------------------------+---------------+
| clone                  | ACTIVE        |
+------------------------+---------------+
```

如果插件初始化失败，请检查服务器错误日志中与 clone 或插件相关的诊断消息。

如果插件之前已使用 INSTALL PLUGIN 注册或使用 --plugin-load-add 加载，您可以在服务器启动时使用 --clone 选项来控制插件激活状态。例如，要在启动时加载插件并防止其在运行时被删除，使用这些选项：

```
[mysqld]
plugin-load-add=mysql_clone.so
clone=FORCE_PLUS_PERMANENT
```

如果要防止服务器在没有 clone 插件的情况下运行，使用 --clone 选项，其值为 FORCE 或 FORCE_PLUS_PERMANENT，以强制服务器启动在插件初始化失败时失败。

有关插件激活状态的更多信息，请参见控制插件激活状态。
