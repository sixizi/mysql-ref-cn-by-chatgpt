### 7.6.5.2 ddl_rewriter 插件选项

本节描述控制 ddl_rewriter 插件操作的命令选项。如果在启动时指定的值不正确，ddl_rewriter 插件可能无法正确初始化，服务器将不会加载它。

要控制 ddl_rewriter 插件的激活，请使用此选项：

- --ddl-rewriter[=value]

  命令行格式                                    --ddl-rewriter[=value]
  类型                                          枚举
  默认值                                        ON
  有效值                                        ON

                                                OFF

                                                FORCE

                                                FORCE_PLUS_PERMANENT

  此选项控制服务器在启动时如何加载 ddl_rewriter 插件。仅当插件已通过 INSTALL PLUGIN 注册或使用 --plugin-load 或 --plugin-load-add 加载时，此选项才可用。参见第 7.6.5.1 节"安装或卸载 ddl_rewriter"。

  选项值应为插件加载选项可用的值之一，如第 7.6.1 节"安装和卸载插件"中所述。例如，--ddl-rewriter=OFF 在服务器启动时禁用该插件。
