### 7.6.6.14 Clone Plugin Limitations

Clone Plugin 受以下限制：

- 捐赠者和接收者可以在同一 MySQL 服务器系列中使用不同的补丁版本。例如，支持在 MySQL 26.10.0 和 MySQL 26.10.2 之间双向克隆。

- 跨 MySQL 服务器系列的克隆仅支持从 LTS 捐赠者克隆到紧随其后的 LTS 接收者。例如，如果 MySQL 28.4 是 MySQL 9.7 之后的下一个 LTS 系列，则支持从 MySQL 9.7 LTS 克隆到 MySQL 28.4 LTS。

- 不支持其他跨系列克隆操作。这包括当任一服务器是 Innovation 版本时的克隆、克隆到较旧的 LTS 系列，以及跳过 LTS 系列的克隆。例如，不支持从 MySQL 26.10 Innovation 克隆到 MySQL 26.10 Innovation、从 MySQL 28.4 LTS 克隆到 MySQL 9.7 LTS，或从 MySQL 9.7 LTS 克隆到 MySQL 30.4 LTS。

- 一次只能克隆单个 MySQL 实例。不支持在单个克隆操作中克隆多个 MySQL 实例。

- 由 mysqlx_port 指定的 X Protocol 端口不支持远程克隆操作（在 CLONE INSTANCE 语句中指定捐赠者 MySQL 服务器实例的端口号时）。

- Clone Plugin 不支持克隆 MySQL 服务器配置。接收者 MySQL 服务器实例保留其配置，包括持久化系统变量设置（参见 Section 7.1.9.3, "Persisted System Variables"）。

- Clone Plugin 不支持克隆二进制日志。

- Clone Plugin 仅克隆存储在 InnoDB 中的数据。其他存储引擎数据不被克隆。MyISAM 和 CSV 表（存储在任何模式中，包括 sys 模式）被克隆为空表。

- 不支持通过 MySQL Router 连接到捐赠者 MySQL 服务器实例。

### The Keyring Proxy Bridge Plugin

- 本地克隆操作不支持克隆使用绝对路径创建的通用表空间。具有与源表空间文件相同路径的克隆表空间文件会导致冲突。
