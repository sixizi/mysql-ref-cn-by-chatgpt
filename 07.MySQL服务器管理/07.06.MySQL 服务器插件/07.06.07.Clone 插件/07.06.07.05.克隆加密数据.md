### 7.6.6.5 克隆加密数据

支持克隆加密数据。以下要求适用：

- 克隆远程数据时需要安全连接，以确保未加密的表空间密钥在网络上的安全传输。表空间密钥在捐赠者处解密，然后在接收者处使用接收者主密钥重新加密。如果加密连接不可用或在 CLONE INSTANCE 语句中使用了 REQUIRE NO SSL 子句，则会报告错误。有关为克隆配置加密连接的信息，请参见 Configuring an Encrypted Connection for Cloning。

- 克隆数据到使用本地管理密钥环的本地数据目录时，在克隆目录上启动 MySQL 服务器时必须使用相同的密钥环。

- 克隆数据到使用本地管理密钥环的远程数据目录（接收者目录）时，在克隆目录上启动 MySQL 服务器时必须使用接收者密钥环。

注意

克隆操作进行中时，无法修改 innodb_redo_log_encrypt 和 innodb_undo_log_encrypt 变量设置。

有关数据加密功能的信息，请参见 Section 17.13, "InnoDB Data-at-Rest Encryption"。
