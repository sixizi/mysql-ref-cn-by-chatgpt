### 7.6.6.11 停止克隆操作

如有必要，可以使用 KILL QUERY processlist_id 语句停止克隆操作。

在接收端 MySQL 服务器实例上，可以从 clone_status 表的 PID 列检索克隆操作的进程列表标识符 (PID)。

```
mysql> SELECT * FROM performance_schema.clone_status\G
*************************** 1. row ***************************
                 ID: 1
                PID: 8
              STATE: In Progress
         BEGIN_TIME: 2019-07-15 11:58:36.767
           END_TIME: NULL
             SOURCE: LOCAL INSTANCE
        DESTINATION: /path/to/clone_dir/
           ERROR_NO: 0
      ERROR_MESSAGE:
        BINLOG_FILE:
    BINLOG_POSITION: 0
      GTID_EXECUTED:
```

也可以从 INFORMATION_SCHEMA PROCESSLIST 表的 ID 列、SHOW PROCESSLIST 输出的 Id 列或 Performance Schema threads 表的 PROCESSLIST_ID 列检索进程列表标识符。这些获取 PID 信息的方法可以在捐赠端或接收端 MySQL 服务器实例上使用。
