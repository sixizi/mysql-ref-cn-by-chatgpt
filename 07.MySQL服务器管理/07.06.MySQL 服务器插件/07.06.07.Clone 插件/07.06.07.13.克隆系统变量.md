### 7.6.6.13 Clone 系统变量

本节描述控制 clone 插件操作的系统变量。如果在启动时指定的值不正确，clone 插件可能无法正确初始化，服务器不会加载它。在这种情况下，服务器也可能为其他 clone 设置产生错误消息，因为它无法识别它们。

每个系统变量都有一个默认值。系统变量可以在服务器启动时使用命令行选项或选项文件中的选项进行设置。它们可以在运行时使用 SET 语句动态更改，这使您能够修改服务器的操作而无需停止并重新启动它。

设置全局系统变量的运行时值通常需要 SYSTEM_VARIABLES_ADMIN 权限（或已弃用的 SUPER 权限）。有关更多信息，请参见第 7.1.9.1 节"系统变量权限"。

Clone 变量在执行克隆操作的接收方 MySQL 服务器实例上配置。

- clone_autotune_concurrency

  命令行格式：--clone-autotune-concurrency
  系统变量：clone_autotune_concurrency
  作用域：Global
  动态：Yes
  SET_VAR 提示适用：No
  类型：Boolean
  默认值：ON

  当启用 clone_autotune_concurrency（默认值）时，为远程克隆操作动态生成额外的线程以优化数据传输速度。该设置仅适用于接收方 MySQL 服务器实例。

  在克隆操作期间，线程数逐步增加，目标是当前线程数的两倍。在每次增加时评估对数据传输速度的影响。该过程根据以下规则继续或停止：

  - 如果数据传输速度因增量增加而下降超过 5%，该过程停止。

  - 如果在达到目标的 25% 后至少有 5% 的改进，该过程继续。否则，该过程停止。

  - 如果在达到目标的 50% 后至少有 10% 的改进，该过程继续。否则，该过程停止。

  - 如果在达到目标后至少有 25% 的改进，该过程继续朝向当前线程数两倍的新目标。否则，该过程停止。

  自动调优过程不支持减少线程数。

  clone_max_concurrency 变量定义可以生成的最大线程数。

  如果禁用 clone_autotune_concurrency，clone_max_concurrency 定义为远程克隆操作生成的线程数。

- clone_buffer_size

  命令行格式：--clone-buffer-size
  系统变量：clone_buffer_size
  作用域：Global
  动态：Yes
  SET_VAR 提示适用：No
  类型：Integer
  默认值：4194304
  最小值：1048576
  最大值：268435456
  单位：bytes

  定义在本地克隆操作期间传输数据时使用的中间缓冲区的大小。默认值为 4 mebibytes (MiB)。较大的缓冲区大小可能允许 I/O 设备驱动程序并行获取数据，这可以改进克隆性能。

- clone_block_ddl

  命令行格式：--clone-block-ddl
  系统变量：clone_block_ddl
  作用域：Global
  动态：Yes
  SET_VAR 提示适用：No
  类型：Boolean
  默认值：OFF

  在克隆操作期间在捐赠方 MySQL 服务器实例上启用独占备份锁，这会阻止捐赠方上的并发 DDL 操作。请参见第 7.6.6.4 节"克隆和并发 DDL"。

- clone_delay_after_data_drop

  命令行格式：--clone-delay-after-data-drop
  系统变量：clone_delay_after_data_drop
  作用域：Global
  动态：Yes
  SET_VAR 提示适用：No
  类型：Integer
  默认值：0
  最小值：0
  最大值：3600
  单位：seconds

  指定在远程克隆操作开始时在接收方 MySQL 服务器实例上删除现有数据后立即的延迟期。该延迟旨在为接收方主机上的文件系统提供足够的时间来释放空间，然后从捐赠方 MySQL 服务器实例克隆数据。某些文件系统（如 VxFS）在后台进程中异步释放空间。在这些文件系统上，在删除现有数据后过早克隆数据可能导致克隆操作失败，原因是空间不足。最大延迟期为 3600 秒（1 小时）。默认设置为 0（无延迟）。

  此变量仅适用于远程克隆操作，并在接收方 MySQL 服务器实例上配置。

- clone_ddl_timeout

  命令行格式：--clone-ddl-timeout
  系统变量：clone_ddl_timeout
  作用域：Global
  动态：Yes
  SET_VAR 提示适用：No
  类型：Integer
  默认值：300
  最小值：0
  最大值：2592000
  单位：seconds

  克隆操作等待备份锁的时间（以秒为单位）。备份锁在执行克隆操作时阻止并发 DDL。此设置应用于捐赠方和接收方 MySQL 服务器实例。

  设置为 0 意味着克隆操作不等待备份锁。在这种情况下，执行并发 DDL 操作可能导致克隆操作失败。

  如果 clone_block_ddl 设置为 OFF（默认值），在克隆操作期间允许在捐赠方上进行并发 DDL。在这种情况下，克隆操作不必在捐赠方上等待备份锁。请参见第 7.6.6.4 节"克隆和并发 DDL"。

- clone_donor_timeout_after_network_failure

  命令行格式：--clone-donor-timeout-after-network-failure
  系统变量：clone_donor_timeout_after_network_failure
  作用域：Global
  动态：Yes
  SET_VAR 提示适用：No
  类型：Integer
  默认值：5
  最小值：0
  最大值：30
  单位：minutes

  定义捐赠方允许接收方在网络故障后重新连接和重新启动克隆操作的时间量（以分钟为单位）。有关更多信息，请参见第 7.6.6.9 节"远程克隆操作故障处理"。

  此变量在捐赠方 MySQL 服务器实例上设置。在接收方 MySQL 服务器实例上设置它没有效果。

- clone_enable_compression

  命令行格式：--clone-enable-compression
  系统变量：clone_enable_compression
  作用域：Global
  动态：Yes
  SET_VAR 提示适用：No
  类型：Boolean
  默认值：OFF

  在远程克隆操作期间启用网络层数据压缩。压缩以 CPU 为代价节省网络带宽。启用压缩可能会改进数据传输速率。此设置仅应用于接收方 MySQL 服务器实例。

- clone_max_concurrency

  命令行格式：--clone-max-concurrency
  系统变量：clone_max_concurrency
  作用域：Global
  动态：Yes
  SET_VAR 提示适用：No
  类型：Integer
  默认值：16
  最小值：1
  最大值：128
  单位：threads

  定义远程克隆操作的最大并发线程数。默认值为 16。更多的线程数可以改进克隆性能，但也会减少允许的同时客户端连接数，这可能会影响现有客户端连接的性能。此设置仅应用于接收方 MySQL 服务器实例。

  如果启用 clone_autotune_concurrency（默认值），clone_max_concurrency 是可以为远程克隆操作动态生成的最大线程数。如果禁用 clone_autotune_concurrency，clone_max_concurrency 定义为远程克隆操作生成的线程数。

  建议远程克隆操作的最小数据传输速率为每个线程 1 mebibyte (MiB)。远程克隆操作的数据传输速率由 clone_max_data_bandwidth 变量控制。

- clone_max_data_bandwidth

  命令行格式：--clone-max-data-bandwidth
  系统变量：clone_max_data_bandwidth
  作用域：Global
  动态：Yes
  SET_VAR 提示适用：No
  类型：Integer
  默认值：0
  最小值：0
  最大值：1048576
  单位：miB/second

  定义远程克隆操作的最大数据传输速率（以 mebibytes (MiB) 每秒为单位）。此变量有助于管理克隆操作的性能影响。仅当捐赠方磁盘 I/O 带宽饱和、影响性能时才应设置限制。值为 0 表示"无限制"，允许克隆操作以最高可能的数据传输速率运行。此设置仅适用于接收方 MySQL 服务器实例。

  最小数据传输速率为每个线程 1 MiB 每秒。例如，如果有 8 个线程，最小传输速率为 8 MiB 每秒。clone_max_concurrency 变量控制为远程克隆操作生成的最大线程数。

  由 clone_max_data_bandwidth 指定的请求数据传输速率可能与 performance_schema.clone_progress 表中 DATA_SPEED 列报告的实际数据传输速率不同。如果您的克隆操作未达到所需的数据传输速率且您有可用带宽，请检查接收方和捐赠方上的 I/O 使用情况。如果有未充分利用的带宽，I/O 是下一个最可能的瓶颈。

- clone_max_network_bandwidth

  命令行格式：--clone-max-network-bandwidth
  系统变量：clone_max_network_bandwidth
  作用域：Global
  动态：Yes
  SET_VAR 提示适用：No
  类型：Integer
  默认值：0
  最小值：0
  最大值：1048576
  单位：miB/second

  指定远程克隆操作的最大近似网络传输速率（以 mebibytes (MiB) 每秒为单位）。此变量可用于管理克隆操作对网络带宽的性能影响。仅当网络带宽饱和、影响捐赠方实例性能时才应设置。值为 0 表示"无限制"，允许以网络上最高可能的数据传输速率进行克隆，提供最佳性能。此设置仅适用于接收方 MySQL 服务器实例。

- clone_ssl_ca

  命令行格式：--clone-ssl-ca=file_name
  系统变量：clone_ssl_ca
  作用域：Global
  动态：Yes
  SET_VAR 提示适用：No
  类型：File name
  默认值：empty string

  指定证书颁发机构 (CA) 文件的路径。用于为远程克隆操作配置加密连接。此设置在接收方上配置，并在连接到捐赠方时使用。

- clone_ssl_cert

  命令行格式：--clone-ssl-cert=file_name
  系统变量：clone_ssl_cert
  作用域：Global
  动态：Yes
  SET_VAR 提示适用：No
  类型：File name
  默认值：empty string

  指定公钥证书的路径。用于为远程克隆操作配置加密连接。此设置在接收方上配置，并在连接到捐赠方时使用。

- clone_ssl_key

  命令行格式：--clone-ssl-key=file_name
  系统变量：clone_ssl_key
  作用域：Global
  动态：Yes
  SET_VAR 提示适用：No
  类型：File name
  默认值：empty string

  指定私钥文件的路径。用于为远程克隆操作配置加密连接。此设置在接收方上配置，并在连接到捐赠方时使用。

- clone_valid_donor_list

  命令行格式：--clone-valid-donor-list=value
  系统变量：clone_valid_donor_list
  作用域：Global
  动态：Yes
  SET_VAR 提示适用：No
  类型：String
  默认值：NULL

  定义用于远程克隆操作的有效捐赠方主机地址。此设置应用于接收方 MySQL 服务器实例。允许使用以下格式的逗号分隔值列表："HOST1:PORT1,HOST2:PORT2,HOST3:PORT3"。不允许使用空格。

  clone_valid_donor_list 变量通过提供对克隆数据源的控制来增加安全性。配置 clone_valid_donor_list 所需的权限与执行远程克隆操作所需的权限不同，这允许将这些责任分配给不同的角色。配置 clone_valid_donor_list 需要 SYSTEM_VARIABLES_ADMIN 权限，而执行远程克隆操作需要 CLONE_ADMIN 权限。

  不支持 Internet Protocol 版本 6 (IPv6) 地址格式。不支持 Internet Protocol 版本 6 (IPv6) 地址格式。可以改用 IPv6 地址的别名。IPv4 地址可以按原样使用。
