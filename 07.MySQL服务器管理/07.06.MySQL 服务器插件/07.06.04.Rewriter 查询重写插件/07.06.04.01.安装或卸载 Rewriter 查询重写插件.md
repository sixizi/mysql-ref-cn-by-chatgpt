### 7.6.4.1 安装或卸载 Rewriter 查询重写插件

安装 Rewriter 插件：

```sql
INSTALL PLUGIN rewriter SONAME 'rewriter.so';
```

创建规则表后即可使用。卸载前应先清理相关规则，确认应用不再依赖重写行为。
