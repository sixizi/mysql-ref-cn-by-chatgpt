### 7.6.3.1 Thread Pool Elements

MySQL Thread Pool 包含以下元素：

- 一个插件库文件实现了线程池代码的插件，以及几个提供线程池操作信息的关联监控表：
MySQL Thread Pool

  - 在 MySQL 26.10 中，监控表是 Performance Schema 表；参见第 29.12.16 节"Performance Schema Thread Pool Tables"。

  - 在较早版本的 MySQL 中，监控表是 INFORMATION_SCHEMA 表（参见第 28.5 节"INFORMATION_SCHEMA Thread Pool Tables"）。INFORMATION_SCHEMA 表已弃用；预计在 MySQL 的未来版本中将被删除。应用程序应从 INFORMATION_SCHEMA 表迁移到 Performance Schema 表。例如，如果应用程序使用此查询：
    SELECT * FROM INFORMATION_SCHEMA.TP_THREAD_STATE;

    应用程序应改用此查询：
    SELECT * FROM performance_schema.tp_thread_state;

  有关线程池工作原理的详细说明，参见第 7.6.3.3 节"Thread Pool Operation"。

- 多个系统变量与线程池相关。当服务器成功加载线程池插件时，thread_handling 系统变量的值为 loaded-dynamically。

  其他相关系统变量由线程池插件实现，除非启用该插件，否则不可用。有关使用这些变量的信息，参见第 7.6.3.3 节"Thread Pool Operation"和第 7.6.3.4 节"Thread Pool Tuning"。

- Performance Schema 具有公开线程池信息的工具，可用于调查操作性能。要识别它们，请使用此查询：
  SELECT * FROM performance_schema.setup_instruments
  WHERE NAME LIKE '%thread_pool%';

  有关更多信息，参见第 29 章"MySQL Performance Schema"。
