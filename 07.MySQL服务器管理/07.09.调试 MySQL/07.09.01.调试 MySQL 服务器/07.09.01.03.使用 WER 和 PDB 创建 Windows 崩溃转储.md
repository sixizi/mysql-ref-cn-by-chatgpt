### 7.9.1.3 使用 WER 和 PDB 创建 Windows 崩溃转储

程序数据库文件（后缀为 pdb）包含在 MySQL 的 ZIP 存档调试二进制文件和测试套件发行版中。这些文件在 MySQL 安装出现问题时提供调试信息。这是与标准 MSI 或 Zip 文件分开的单独下载。

注意

PDB 文件在标记为"ZIP 存档调试二进制文件和测试套件"的单独文件中提供。

PDB 文件包含有关 mysqld 和其他工具的更详细信息，可以创建更详细的跟踪和转储文件。您可以将这些文件与 WinDbg 或 Visual Studio 一起使用来调试 mysqld。

有关 PDB 文件的更多信息，请参阅 Microsoft 知识库文章 121366。有关可用调试选项的更多信息，请参阅 Debugging Tools for Windows。

要使用 WinDbg，请安装完整的 Windows Driver Kit (WDK) 或安装独立版本。

重要

.exe 和 .pdb 文件必须完全匹配（版本号和 MySQL 服务器版本都要相同）；否则 WinDBG 在尝试加载符号时会报错。

1. 要生成 minidump mysqld.dmp，在 my.ini 中的 [mysqld] 部分启用 core-file 选项。进行这些更改后重启 MySQL 服务器。

2. 创建一个目录来存储生成的文件，例如 c:\symbols

3. 使用查找 GUI 或从命令行确定 windbg.exe 可执行文件的路径，例如：dir /s /b windbg.exe -- 常见的默认位置是 C:\Program Files\Debugging Tools for Windows (x64)\windbg.exe

4. 启动 windbg.exe，为其提供 mysqld.exe、mysqld.pdb、mysqld.dmp 的路径和源代码。或者，从 WinDbg GUI 中传入每个路径。例如：
   windbg.exe -i "C:\mysql-26.10.0-winx64\bin\"^
    -z "C:\mysql-26.10.0-winx64\data\mysqld.dmp"^
    -srcpath "E:\ade\mysql_archives\26.10\26.10.0\mysql-26.10.0"^
    -y "C:\mysql-26.10.0-winx64\bin;SRV*c:\symbols*http://msdl.microsoft.com/download/symbols"^
    -v -n -c "!analyze -vvvvv"

注意

^ 字符和换行符会被 Windows 命令行处理器删除，因此请确保空格保持完整。
