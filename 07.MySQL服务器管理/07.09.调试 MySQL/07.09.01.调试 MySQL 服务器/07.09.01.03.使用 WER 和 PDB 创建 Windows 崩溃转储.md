### 7.9.1.3 使用 WER 和 PDB 创建 Windows 崩溃转储

在 Windows 上，可结合 Windows Error Reporting 和 PDB 文件生成崩溃转储：

- 服务器需要导出 PDB 符号。
- 系统需启用 WER 崩溃转储策略。
- 转储文件保留调用栈和模块信息。

拿到 dump 后，用对应版本的调试工具和符号文件分析。
