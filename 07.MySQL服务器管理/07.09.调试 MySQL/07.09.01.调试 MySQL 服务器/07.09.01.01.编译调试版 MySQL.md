### 7.9.1.1 为调试编译 MySQL

如果你遇到某些非常特殊的问题，你总是可以尝试调试 MySQL。为此，你必须使用 -DWITH_DEBUG=1 选项配置 MySQL。你可以通过执行 mysqld --help 来检查 MySQL 是否使用调试功能编译。如果 --debug 标志在选项中列出，则表示你已启用调试功能。在这种情况下，mysqladmin ver 也会将 mysqld 版本列为 mysql ... --debug。

如果在使用 -DWITH_DEBUG=1 CMake 选项配置 mysqld 时它停止崩溃，你可能发现了编译器错误或 MySQL 中的时序错误。在这种情况下，你可以尝试使用 CMAKE_C_FLAGS 和 CMAKE_CXX_FLAGS CMake 选项添加 -g，而不使用 -DWITH_DEBUG=1。如果 mysqld 崩溃，你至少可以使用 gdb 附加到它，或在核心文件上使用 gdb 来找出发生了什么。

当你为调试配置 MySQL 时，你会自动启用许多额外的安全检查函数来监控 mysqld 的健康状况。如果它们发现"意外"情况，会向 stderr 写入一条条目，mysqld_safe 会将其定向到错误日志！这也意味着，如果你遇到 MySQL 的某些意外问题并且使用的是源代码分发版本，你应该做的第一件事是为调试配置 MySQL。如果你认为发现了错误，请使用第 1.6 节"如何报告错误或问题"中的说明。

在 Windows MySQL 分发版中，mysqld.exe 默认编译时支持跟踪文件。
