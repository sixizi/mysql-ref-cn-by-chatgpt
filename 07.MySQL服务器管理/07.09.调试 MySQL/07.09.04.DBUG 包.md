### 7.9.4 DBUG 包

MySQL 服务器和大多数 MySQL 客户端都是使用 DBUG 包编译的，该包最初由 Fred Fish 创建。当你为调试配置 MySQL 时，此包可以生成程序执行情况的跟踪文件。参见第 7.9.1.2 节"创建跟踪文件"。

本节总结了可以在 MySQL 程序命令行调试选项中指定的参数值，这些程序已使用调试支持进行编译。

DBUG 包可以通过使用 `--debug[=debug_options]` 或 `-#[debug_options]` 选项调用程序来使用。如果指定 `--debug` 或 `-#` 选项而不提供 debug_options 值，大多数 MySQL 程序使用默认值。服务器默认值在 Unix 上为 `d:t:i:o,/tmp/mysqld.trace`，在 Windows 上为 `d:t:i:O,\mysqld.trace`。此默认值的效果是：

- d：为所有调试宏启用输出

- t：跟踪函数调用和退出

- i：向输出行添加 PID

- o,/tmp/mysqld.trace, O,\mysqld.trace：设置调试输出文件。

大多数客户端程序使用默认 debug_options 值 `d:t:o,/tmp/program_name.trace`，不管平台如何。

以下是一些示例调试控制字符串，如在 shell 命令行上指定的那样：

```
--debug=d:t
--debug=d:f,main,subr1:F:L:t,20
--debug=d,input,output,files:n
--debug=d:t:i:O,\\mysqld.trace
```

对于 mysqld，还可以通过设置 debug 系统变量在运行时更改 DBUG 设置。此变量具有全局和会话值：

```
mysql> SET GLOBAL debug = 'debug_options';
mysql> SET SESSION debug = 'debug_options';
```

更改全局 debug 值需要足够的权限来设置全局系统变量。更改会话 debug 值需要足够的权限来设置受限制的会话系统变量。参见第 7.1.9.1 节"系统变量权限"。

debug_options 值是冒号分隔的字段序列：

```
field_1:field_2:...:field_N
```

值中的每个字段由一个强制标志字符组成，可选地前面有 `+` 或 `-` 字符，可选地后面跟一个逗号分隔的修饰符列表：

```
[+|-]flag[,modifier,modifier,...,modifier]
```

下表描述了允许的标志字符。无法识别的标志字符被静默忽略。

| 标志 | 描述 |
|------|------|
| d | 为当前状态启用来自 DBUG_XXX 宏的输出。可能后跟关键字列表，仅为具有该关键字的 DBUG 宏启用输出。空关键字列表为所有宏启用输出。在 MySQL 中，要启用的常见调试宏关键字是 enter、exit、error、warning、info 和 loop。 |
| D | 在每行调试器输出后延迟。参数是延迟，以十分之一秒为单位，受机器能力限制。例如，D,20 指定两秒的延迟。 |
| f | 将调试、跟踪和分析限制为命名函数列表。空列表启用所有函数。仍然必须给出适当的 d 或 t 标志；此标志仅在启用时限制其操作。 |
| F | 为调试或跟踪输出的每一行标识源文件名。 |
| i | 为调试或跟踪输出的每一行用 PID 或线程 ID 标识进程。 |
| L | 为调试或跟踪输出的每一行标识源文件行号。 |
| n | 为调试或跟踪输出的每一行打印当前函数嵌套深度。 |
| N | 为调试输出的每一行编号。 |
| o | 将调试器输出流重定向到指定文件。默认输出是 stderr。 |
| O | 类似于 o，但文件在每次写入之间真正刷新。需要时，文件在每次写入之间关闭并重新打开。 |
| a | 类似于 o，但以追加方式打开。 |
| A | 类似于 O，但以追加方式打开。 |
| p | 将调试器操作限制为指定的进程。进程必须用 DBUG_PROCESS 宏标识，并与列表中的一个匹配才能进行调试器操作。 |
| P | 为调试或跟踪输出的每一行打印当前进程名。 |
| r | 推送新状态时，不继承前一个状态的函数嵌套级别。当输出要从左边距开始时很有用。 |
| t | 启用函数调用/退出跟踪行。可能后跟列表（仅包含一个修饰符），给出数字最大跟踪级别，超过该级别不会为调试或跟踪宏输出任何内容。默认值是编译时选项。 |
| T | 为输出的每一行打印当前时间戳。 |

前导 `+` 或 `-` 字符和尾部修饰符列表用于标志字符，如 d 或 f，可以为所有适用的修饰符或仅某些修饰符启用调试操作：

- 没有前导 `+` 或 `-` 时，标志值设置为完全按给定的修饰符列表。

- 使用前导 `+` 或 `-` 时，列表中的修饰符被添加到或从当前修饰符列表中减去。

以下示例显示了这对 d 标志的工作原理。空 d 列表为所有调试宏启用输出。非空列表仅为列表中的宏关键字启用输出。

这些语句将 d 值设置为按给定的修饰符列表：

```
mysql> SET debug = 'd';
mysql> SELECT @@debug;
+---------+
| @@debug |
+---------+
| d       |
+---------+
mysql> SET debug = 'd,error,warning';
mysql> SELECT @@debug;
+-----------------+
| @@debug         |
+-----------------+
| d,error,warning |
+-----------------+
```

前导 `+` 或 `-` 添加到或从当前 d 值中减去：

```
mysql> SET debug = '+d,loop';
mysql> SELECT @@debug;
+----------------------+
| @@debug              |
+----------------------+
| d,error,warning,loop |
+----------------------+

mysql> SET debug = '-d,error,loop';
mysql> SELECT @@debug;
+-----------+
| @@debug   |
+-----------+
| d,warning |
+-----------+
```

添加到"启用所有宏"不会导致任何更改：

```
mysql> SET debug = 'd';
mysql> SELECT @@debug;
+---------+
| @@debug |
+---------+
| d       |
+---------+

mysql> SET debug = '+d,loop';
mysql> SELECT @@debug;
+---------+
| @@debug |
+---------+
| d       |
+---------+
```

禁用所有启用的宏会完全禁用 d 标志：

```
mysql> SET debug = 'd,error,loop';
mysql> SELECT @@debug;
+--------------+
| @@debug      |
+--------------+
| d,error,loop |
+--------------+

mysql> SET debug = '-d,error,loop';
mysql> SELECT @@debug;
+---------+
| @@debug |
+---------+
|         |
+---------+
```
