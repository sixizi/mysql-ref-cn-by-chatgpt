### 7.9.2 调试 MySQL 客户端

要能够使用集成调试包调试 MySQL 客户端，应该使用 -DWITH_DEBUG=1 配置 MySQL。参见第 2.8.7 节"MySQL 源代码配置选项"。

在运行客户端之前，应该设置 MYSQL_DEBUG 环境变量：

```
$> MYSQL_DEBUG=d:t:O,/tmp/client.trace
$> export MYSQL_DEBUG
```

这会导致客户端在 /tmp/client.trace 中生成跟踪文件。

如果你的客户端代码出现问题，应该尝试连接到服务器并使用已知可用的客户端运行查询。通过在调试模式下运行 mysql 来执行此操作（假设你已使用调试功能编译了 MySQL）：

```
$> mysql --debug=d:t:O,/tmp/client.trace
```

这在你发送错误报告时提供有用的信息。参见第 1.6 节"如何报告错误或问题"。

#### The LOCK_ORDER Tool

如果你的客户端在某个"合法"的代码处崩溃，应该检查你的 mysql.h 包含文件是否与你的 MySQL 库文件匹配。一个非常常见的错误是将来自旧 MySQL 安装的旧 mysql.h 文件与新 MySQL 库一起使用。
