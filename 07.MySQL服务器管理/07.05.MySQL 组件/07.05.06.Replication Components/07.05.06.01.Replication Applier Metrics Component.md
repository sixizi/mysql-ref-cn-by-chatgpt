### 7.5.6.1 Replication Applier Metrics Component

Replication Applier Metrics 组件实现了两个 Performance Schema 表，列表如下：

- replication_applier_metrics：显示给定复制通道的复制应用程序的统计信息。

- replication_applier_progress_by_worker：显示具有给定 ID 和通道名称的工作线程的复制应用程序的统计信息。

- 目的：在 MySQL Performance Schema 中提供复制应用程序统计表。

- URN：file://component_replication_applier_metrics

有关安装说明，请参见 Section 7.5.1，"Installing and Uninstalling Components"。

重要

当 replica_parallel_workers=0 时，replication_applier_metrics 组件不起作用。
