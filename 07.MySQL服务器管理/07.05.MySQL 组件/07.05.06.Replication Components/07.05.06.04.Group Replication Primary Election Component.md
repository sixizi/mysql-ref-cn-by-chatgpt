### 7.5.6.4 Group Replication 主选举组件

在故障转移时，当处于单主模式下，使用复制组成员最新状态作为选择新主的标准。

URN: file://component_group_replication_elect_prefers_most_updated

复制组件

在安装 Group Replication 主选举组件之前，必须使用 INSTALL PLUGIN 或 --plugin-load-add 安装 Group Replication 插件（参见第 20.2.1.2 节"为 Group Replication 配置实例"）；否则，INSTALL COMPONENT 语句将被拒绝并显示错误。如果在安装了 Group Replication 主选举组件的情况下尝试卸载 Group Replication 插件，UNINSTALL PLUGIN 将失败并显示错误：Plugin 'group_replication' cannot be uninstalled now. Please uninstall the component 'component_group_replication_elect_prefers_most_updated' and then UNINSTALL PLUGIN group_replication。

满足这些条件后，可以分别使用 INSTALL COMPONENT 和 UNINSTALL COMPONENT 安装和卸载 Group Replication 主选举组件。有关这些语句的描述以及第 7.5.1 节"安装和卸载组件"的更多信息，请参阅相关文档。

要启用该组件，请在每个复制组成员上将 group_replication_elect_prefers_most_updated.enabled 系统变量设置为 ON。这意味着在故障转移时，该组件选择最新的从库作为新主库，基于从库积压中有多少事务；积压最小（落后事务最少）的从库被选为新主库。

为了使最新状态选择工作，Group Replication 主选举组件必须安装在所有组成员上；group_replication_elect_prefers_most_updated.enabled 对每个组成员也必须为 ON。如果组件不可用，或者没有一个从库是最新的，则使用加权选择；在最大权重匹配的情况下，具有最低 UUID（按字典序）的服务器被提升为主库。

状态变量。Group Replication 主选举组件提供两个状态变量，如下所示，用于监控：

- Gr_latest_primary_election_by_most_uptodate_members_trx_delta：当使用最新状态选择选择新主库时，这是新主库和最新从库处理的事务数之间的差异。

- Gr_latest_primary_election_by_most_uptodate_member_timestamp：每当使用最新状态方法选举新主库时，都会设置此时间戳。

这些状态变量的值在组件安装或卸载时、组引导时、成员加入组时（包括自动重新加入）以及服务器重启时重置。

日志。当故障转移时的主选择使用最新状态方法时，组件会向日志写入类似于此处所示的消息，宣布更改、标识新主库，并提供需要从积压中应用的事务数：

ER_GRP_PRIMARY_ELECTION_METHOD_MOST_UPDATE

2024-10-08T16:07:48.100736Z 0 [Note] [MY-015562] [Server] Plugin group_replication reported: 'Group Replication Primary Election: Member with uuid 8a94f357-aab4-11df-86ab-c80aa9420000 was elected primary since it was the most up-to-date member with 100 transactions more than second most up-to-date member 8a94f468-aab4-11df-86ab-c80aa9420000. In case of a tie member weight and then uuid lexical order was used over the most updated members.'

当主选择使用成员权重顺序时，组件会写入日志消息，宣布更改、按 UUID 标识新主库及其权重值。消息类似于此处所示：

ER_GRP_PRIMARY_ELECTION_METHOD_MEMBER_WEIGHT

2024-10-08T16:07:48.100736Z 0 [Note] [MY-015563] [Server] Plugin group_replication reported: 'Group Replication Primary Election: Member with uuid 8a94f357-aab4-11df-86ab-c80aa9420000 was elected primary since it was highest weight member with value 70. In case of a tie uuid lexical order was used.'
