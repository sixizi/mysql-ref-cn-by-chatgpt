### 7.5.6.2 Group Replication 流控统计组件

Group Replication 流控统计组件（component_group_replication_flow_control_stats）启用了多个全局状态变量，这些变量提供关于 Group Replication 流控执行的信息。

- 目的：支持 Group Replication 全局变量，以补充通常用于测量与流控执行相关的统计信息的变量。

- URN：file://component_group_replication_flow_control_stats

复制组件

在安装 Group Replication 流控统计组件之前，必须使用 INSTALL PLUGIN 或 --plugin-load-add 安装 Group Replication 插件（参见第 20.2.1.2 节"为 Group Replication 配置实例"）；否则，INSTALL COMPONENT 语句将被拒绝，错误为 Cannot satisfy dependency for service 'group_replication_flow_control_metrics_service' required by component 'mysql:group_replication_flow_control_stats'。如果在安装了 Group Replication 流控统计组件的情况下尝试卸载 Group Replication 插件，UNINSTALL PLUGIN 将失败，错误为 Plugin 'group_replication' cannot be uninstalled now. Please uninstall the component 'component_group_replication_flow_control_stats' and then UNINSTALL PLUGIN group_replication。

在满足这些条件的前提下，Group Replication 流控统计组件可以分别使用 INSTALL COMPONENT 和 UNINSTALL COMPONENT 进行安装和卸载。有关这些语句的描述以及第 7.5.1 节"安装和卸载组件"的更多信息，请参见相关文档。

Group Replication 流控统计组件提供以下全局状态变量及其含义：

- Gr_flow_control_throttle_active_count：当前被限流的事务数。

- Gr_flow_control_throttle_count：已被限流的事务数。

- Gr_flow_control_throttle_last_throttle_timestamp：最近一次事务被限流的日期和时间。

- Gr_flow_control_throttle_time_sum：事务被限流的时间总和，单位为微秒。

这些变量的值可以通过查询 Performance Schema 的 global_status 表获得，如下所示：

```
mysql> SELECT * FROM performance_schema.global_status
    -> WHERE VARIABLE_NAME LIKE 'Gr_flow_control%';
+--------------------------------------------------+---------------------+
| VARIABLE_NAME                                   | VARIABLE_VALUE      |
+--------------------------------------------------+---------------------+
| Gr_flow_control_throttle_active_count           | 10                  |
+--------------------------------------------------+---------------------+
| Gr_flow_control_throttle_count                  | 10                  |
+--------------------------------------------------+---------------------+
| Gr_flow_control_throttle_last_throttle_timestamp | 2024-07-01 12:50:56 |
+--------------------------------------------------+---------------------+
| Gr_flow_control_throttle_time_sum               | 10                  |
+--------------------------------------------------+---------------------+
```

您也可以在 SHOW GLOBAL STATUS 的输出中观察这些值，如下所示：

```
mysql> SHOW GLOBAL STATUS LIKE 'Gr\_flow\_control%';
+--------------------------------------------------+---------------------+
| Variable_Name                                   | Value               |
+--------------------------------------------------+---------------------+
| Gr_flow_control_throttle_active_count           | 10                  |
+--------------------------------------------------+---------------------+
| Gr_flow_control_throttle_count                  | 10                  |
+--------------------------------------------------+---------------------+
| Gr_flow_control_throttle_last_throttle_timestamp | 2024-07-01 12:50:56 |
+--------------------------------------------------+---------------------+
| Gr_flow_control_throttle_time_sum               | 10                  |
+--------------------------------------------------+---------------------+
```

所有之前列出的状态变量在以下任何事件发生时都会被重置：

- 服务器重启。

复制组件

- 组被引导。

- 新成员加入或成员自动重新加入。

由于这些变量反映的是本地成员观察到的情况，所有这些状态变量都具有成员作用域。
