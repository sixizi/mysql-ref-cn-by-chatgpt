### 7.5.2 获取组件信息

mysql.component 系统表包含有关当前已加载组件的信息，并显示哪些组件已使用 INSTALL COMPONENT 注册。从该表中选择数据可以显示已安装的组件。例如：

```
mysql> SELECT * FROM mysql.component;
+--------------+--------------------+------------------------------------+
| component_id | component_group_id | component_urn                      |
+--------------+--------------------+------------------------------------+
|            1 |                  1 | file://component_validate_password |
|            2 |                  2 | file://component_log_sink_json     |
+--------------+--------------------+------------------------------------+
```

#### 错误日志组件

component_id 和 component_group_id 值供内部使用。component_urn 是在 INSTALL COMPONENT 和 UNINSTALL COMPONENT 语句中用于加载和卸载组件的 URN。
