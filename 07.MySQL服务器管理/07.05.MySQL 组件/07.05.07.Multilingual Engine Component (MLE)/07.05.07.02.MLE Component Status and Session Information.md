### 7.5.7.2 MLE 组件状态和会话信息

安装 MLE 组件后，你可以获取有关该组件的信息，如下所示：

```
mysql> SHOW STATUS LIKE 'mle%';
+-------------------------+---------------+
| Variable_name           | Value         |
+-------------------------+---------------+
| mle_heap_status         | Not Allocated |
| mle_languages_supported | JavaScript    |
| mle_memory_used         | 0             |
| mle_status              | Inactive      |
+-------------------------+---------------+
4 rows in set (0.01 sec)
```

与其他 MySQL 状态变量一样，你也可以通过从 Performance Schema 的 global_status 表中选择来访问这些变量。

MLE 组件的状态由 mle_status 状态变量指示。在用户创建或调用使用 MLE 支持的语言的存储过程或函数之前，该变量保持为 Inactive，此时它会变为（很短暂地）Initializing 或（通常）Active。在服务器关闭或重启时，它保持 Active 状态，此时值为 Pending shutdown。

你可以使用 MLE 组件提供的可加载函数 mle_session_state() 获取 MLE 存储程序的状态信息和控制台输出。有关此函数的更多信息，请参阅该函数的描述。

mle_languages_supported 显示此组件实例支持的语言列表；在 MySQL 26.10 中，这始终是 JavaScript。

有关与 MLE 组件内存使用相关的状态变量的信息，请参阅第 7.5.7.3 节"MLE 组件内存和线程使用"。

你也可以从系统状态变量获取有关 MLE 会话的信息。mle_sessions 状态变量提供活跃 MLE 会话的数量。mle_sessions_max 显示自 MLE 组件激活以来任何时刻同时活跃的最大 MLE 会话数。mle_session_resets 显示通过调用 mle_session_reset() 清除会话状态的次数。有关这些状态变量的更多信息，请参阅这些状态变量的描述。

多个 JavaScript 库 SQL 语句的计数作为状态变量保存。这些包括 Com_create_library、Com_drop_library、Com_alter_library、Com_show_create_library 和 Com_show_library_status；这些分别表示执行的 CREATE LIBRARY、DROP LIBRARY、ALTER LIBRARY、SHOW CREATE LIBRARY 和 SHOW LIBRARY STATUS 语句的数量。有关更多信息，请参阅 Com_xxx 变量。
