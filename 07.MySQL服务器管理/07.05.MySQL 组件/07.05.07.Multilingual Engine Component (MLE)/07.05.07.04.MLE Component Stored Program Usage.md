### 7.5.7.4 MLE 组件存储程序使用

几个系统状态变量提供关于 MLE 存储程序使用情况的信息。mle_stored_procedures、mle_stored_functions 和 mle_stored_programs 状态变量分别显示当前缓存的 MLE 存储过程、MLE 存储函数和 MLE 存储程序的数量，跨越所有用户会话。

可以从两个状态变量获得额外的 MLE 存储程序指标：mle_stored_program_bytes_max 提供最大当前 MLE 存储程序的大小（以字节为单位），mle_stored_program_sql_max 显示任何 MLE 存储程序执行的 SQL 语句的最大数量。

关于 MLE 存储程序的其他信息可以在信息架构 ROUTINES 表中找到。

MySQL Enterprise Edition 26.10 中的 MLE 存储程序支持导入的 JavaScript 库。关于 MLE JavaScript 库的信息可在两个信息架构表 LIBRARIES 和 ROUTINE_LIBRARIES 中获得。有关其使用的更多信息和示例，请参阅这些表的描述，以及第 27.3.8 节"使用 JavaScript 库"。

SHOW LIBRARY STATUS 也可以提供关于一个或多个 JavaScript 库的有用信息；请参阅第 27.3.8 节"使用 JavaScript 库"。
