### 7.5.9.6 Option Tracker 函数

Option Tracker 提供下表所示的函数。关于每个函数的更详细信息在表后的列表中提供。

这些函数为读取和更新 mysql_option.option_usage 表（参见第 7.5.9.1 节"Option Tracker 表"）和 performance_schema.mysql_option 表提供了安全接口；此外，使用这些函数所做的更改会传播到 Group Replication 从属服务器，而使用 SQL 所做的更改则不会。基于这些原因，你应该始终使用 Option Tracker 函数来修改选项使用数据，而不是尝试直接更新这两个表中的任何一个。

表 7.11 Option Tracker 函数

| 名称 | 描述 |
|------|------|
| option_tracker_option_register() | 向 Option Tracker 注册一个选项 |
| option_tracker_option_unregister() | 从 Option Tracker 注销一个选项 |
| option_tracker_usage_get() | 获取向 Option Tracker 注册的选项的使用数据 |
| option_tracker_usage_set() | 设置向 Option Tracker 注册的选项的使用数据 |

- option_tracker_option_register()

  此函数使用提供的选项名称、容器名称和启用值向 Option Tracker 注册选项；即，将对应于此选项的行插入到 Performance Schema mysql_option 表中。

  语法：

  ```
  int option_tracker_option_register(
    string option_name,
    string container_name
    int enabled
  )
  ```

  参数：

  - option_name：选项的名称。这是一个不区分大小写的字符串。此参数不能为 null，但可以是空字符串。

  - container_name：容器的名称。此参数不区分大小写，不能是空字符串或 null。

  - enabled：如果选项已启用则为 1，如果已禁用则为 0。

  返回值：

  成功时返回 0，否则返回非零值。非零值通常为 1，但不保证一定是 1。

  示例：

  ```
  mysql> SELECT option_tracker_option_register('Berry Picker', 'component_berry_picker', 0);
  +-----------------------------------------------------------------------------+
  | option_tracker_option_register('Berry Picker', 'component_berry_picker', 0) |
  +-----------------------------------------------------------------------------+
  |                                                                           0 |
  +-----------------------------------------------------------------------------+
  ```

  你可以通过查询 mysql_option 表来验证选项是否已注册，如下所示：

  ```
  mysql> SELECT * FROM performance_schema.mysql_option WHERE OPTION_NAME='Berry Picker';
  +--------------+----------------+------------------------+
  | OPTION_NAME | OPTION_ENABLED | OPTION_CONTAINER        |
  +--------------+----------------+------------------------+
  | Berry Picker | FALSE          | component_berry_picker |
  +--------------+----------------+------------------------+
  ```

  此函数工作不需要命名的容器实际存在。

  调用者必须具有 OPTION_TRACKER_UPDATER 权限；此权限必须始终显式授予。

  对此函数的连续调用对 mysql_option 表没有影响，并返回 1，表示函数调用未成功；要将给定选项的状态从禁用更改为启用，需要使用 option_tracker_option_unregister() 注销它，然后重新注册它，如下所示：

  ```
  mysql> SELECT option_tracker_option_register('Berry Picker', 'component_berry_picker', 0);
  +-----------------------------------------------------------------------------+
  | option_tracker_option_register('Berry Picker', 'component_berry_picker', 0) |
  +-----------------------------------------------------------------------------+
  |                                                                           0 |
  +-----------------------------------------------------------------------------+

  mysql> SELECT * FROM performance_schema.mysql_option WHERE OPTION_NAME='Berry Picker';
  +--------------+----------------+------------------------+
  | OPTION_NAME | OPTION_ENABLED | OPTION_CONTAINER        |
  +--------------+----------------+------------------------+
  | Berry Picker | FALSE          | component_berry_picker |
  +--------------+----------------+------------------------+

  mysql> SELECT option_tracker_option_register('Berry Picker', 'component_berry_picker', 1);
  +-----------------------------------------------------------------------------+
  | option_tracker_option_register('Berry Picker', 'component_berry_picker', 1) |
  +-----------------------------------------------------------------------------+
  |                                                                           1 |
  +-----------------------------------------------------------------------------+

  mysql> SELECT * FROM performance_schema.mysql_option WHERE OPTION_NAME='Berry Picker';
  +--------------+----------------+------------------------+
  | OPTION_NAME | OPTION_ENABLED | OPTION_CONTAINER        |
  +--------------+----------------+------------------------+
  | Berry Picker | FALSE          | component_berry_picker |
  +--------------+----------------+------------------------+

  mysql> SELECT option_tracker_option_unregister('Berry Picker');
  +--------------------------------------------------+
  | option_tracker_option_unregister('Berry Picker') |
  +--------------------------------------------------+
  |                                                0 |
  +--------------------------------------------------+

  mysql> SELECT * FROM performance_schema.mysql_option WHERE OPTION_NAME='Berry Picker';
  Empty set (0.00 sec)

  mysql> SELECT option_tracker_option_register('Berry Picker', 'component_berry_picker', 1);
  +-----------------------------------------------------------------------------+
  | option_tracker_option_register('Berry Picker', 'component_berry_picker', 1) |
  +-----------------------------------------------------------------------------+
  |                                                                           0 |
  +-----------------------------------------------------------------------------+

  mysql> SELECT * FROM performance_schema.mysql_option WHERE OPTION_NAME='Berry Picker';
  +--------------+----------------+------------------------+
  | OPTION_NAME | OPTION_ENABLED | OPTION_CONTAINER        |
  +--------------+----------------+------------------------+
  | Berry Picker | TRUE           | component_berry_picker |
  +--------------+----------------+------------------------+
  ```

  对此函数的调用不会更新 mysql_option.option_usage 表；要添加或更新使用信息，请使用 option_tracker_usage_set()。

- option_tracker_option_unregister()

  此函数注销之前注册的选项；即，它从 mysql_option 表中删除相应的行。

  语法：

  ```
  int option_tracker_option_unregister(
    string option_name
  )
  ```

  参数：

  - option_name：要注销的选项的名称。这是一个不区分大小写的字符串，不能为 null，但可以是空字符串。

  返回值：

  成功时返回 0，否则返回非零值。非零值通常为 1，但不保证一定是 1。

  示例：

  ```
  mysql> SELECT * FROM performance_schema.mysql_option
      ->   WHERE OPTION_NAME='Berry Picker';
  +--------------+----------------+------------------------+
  | OPTION_NAME | OPTION_ENABLED | OPTION_CONTAINER        |
  +--------------+----------------+------------------------+
  | Berry Picker | TRUE           | component_berry_picker |
  +--------------+----------------+------------------------+

  mysql> SELECT option_tracker_option_unregister('Berry Picker');
  +--------------------------------------------------+
  | option_tracker_option_unregister('berry picker') |
  +--------------------------------------------------+
  |                                                0 |
  +--------------------------------------------------+

  mysql> SELECT * FROM performance_schema.mysql_option
      -> WHERE OPTION_NAME='Berry Picker';
  Empty set (0.00 sec)
  ```

  如前所述，选项名称不区分大小写，如下所示：

  ```
  mysql> SELECT * FROM performance_schema.mysql_option
      ->   WHERE OPTION_NAME='Berry Picker';
  +--------------+----------------+------------------------+
  | OPTION_NAME | OPTION_ENABLED | OPTION_CONTAINER        |
  +--------------+----------------+------------------------+
  | Berry Picker | TRUE           | component_berry_picker |
  +--------------+----------------+------------------------+

  mysql> SELECT option_tracker_option_unregister('berry picker');
  +--------------------------------------------------+
  | option_tracker_option_unregister('berry picker') |
  +--------------------------------------------------+
  |                                                0 |
  +--------------------------------------------------+

  mysql> SELECT * FROM performance_schema.mysql_option
      ->   WHERE OPTION_NAME='Berry Picker';
  Empty set (0.00 sec)
  ```

  如果在 mysql_option 表中找不到对应于选项名称的行，option_tracker_option_unregister() 返回非零值表示失败。

- option_tracker_usage_get()

  此函数返回与以下查询相同的值：

  ```
  mysql> SELECT USAGE_DATA FROM mysql_option.option_usage
      ->   WHERE OPTION_NAME='JavaScript Stored Program';
  +-------------------------------------------------------+
  | USAGE_DATA                                            |
  +-------------------------------------------------------+
  | {"used": "false", "usedDate": "2024-10-17T20:24:41Z"} |
  +-------------------------------------------------------+
  ```

  语法：

  ```
  string option_tracker_usage_get(
    option_name
  )
  ```

  参数：

  - option_name：一个不区分大小写的字符串。

  返回值：

  JSON 格式的字符串。有关此值的更多信息，请参见 option_tracker_usage_set() 函数的描述。

  示例：

  ```
  mysql> SELECT option_tracker_usage_get('Berry Picker');
  +----------------------------------------------------+
  | option_tracker_usage_get('Berry Picker')           |
  +----------------------------------------------------+
  | {"used": true, "usedDate": "2024-10-16T09:14:41Z"} |
  +----------------------------------------------------+
  ```

- option_tracker_usage_set()

  为命名的选项设置使用数据。

  语法：

  ```
  int option_tracker_usage_set(
    string option_name,
    string usage_data
  )
  ```

  参数：

  - option_name：选项名称，一个不区分大小写的字符串。这可以是空字符串，但不能为 null。

  - usage_data：为命名选项记录的使用数据。这应该是 JSON 格式的字符串，通常采用如下所示的形式：

    ```
    {
        "used": "boolean"
        "usedDate": "ISO8601 date"
    }
    ```

    如果在当前会话期间已使用该选项，used 键应为 true，否则为 false。usedDate 应该是 ISO 8601 格式的带引号的日期和时间值，例如 "2024-10-17T20:24:41Z"。虽然这不是必需的，但通常期望这是当前的 UTC 日期和时间。你可以使用 UTC_DATE() 和 UTC_TIME() 获取此值，类似于此处所示的内容（强调文本）：

    ```
    SELECT option_tracker_option_set(
       'Berry Picker',
      CONCAT(UTC_DATE(), 'T', UTC_TIME(), 'Z')
    );
    ```

    所示的 usage_data 形式，带有 used 和 usedDate 键，是推荐的形式。可以在 JSON 字符串中包含其他键和值，但其他应用程序也可能无法读取、理解甚至允许它们。

  返回类型：

  一个整数：成功时返回 0，否则返回非零值（通常为 1）。

  示例：

  ```
  mysql> SELECT option_tracker_usage_set(
      ->   'Berry Picker', '{"used": true, "usedDate": "2024-10-17T20:38:23Z"}');
  +------------------------------------------------------------------------------------------------+
  | option_tracker_usage_set('Berry Picker', '{"used": true, "usedDate": "2024-10-17T20:38:23Z"}') |
  +------------------------------------------------------------------------------------------------+
  |                                                                                              0 |
  +------------------------------------------------------------------------------------------------+

  mysql> SELECT option_tracker_usage_get('Berry Picker');
  +----------------------------------------------------+
  | option_tracker_usage_get('Berry Picker')           |
  +----------------------------------------------------+
  | {"used": true, "usedDate": "2024-10-17T20:38:23Z"} |
  +----------------------------------------------------+
  ```

  option_tracker_usage_set() 要求调用该函数的用户被显式授予 OPTION_TRACKER_UPDATER 权限；option_tracker_usage_get() 要求 OPTION_TRACKER_UPDATER 或 OPTION_TRACKER_OBSERVER 之一。即使对于 MySQL root 用户也是如此。
