- option_tracker_usage:AWS keyring plugin

使用 AWS keyring plugin 调用通用密钥环函数的次数。

- option_tracker_usage:Binary Log

启用二进制日志时，每 600 秒（10 分钟）递增一次。

- option_tracker_usage:Health Monitor

通过 SQL 查询访问 Health Monitor 表的总次数。仅限 MySQL Enterprise Edition。

- option_tracker_usage:Connection control component

失败的连接尝试被延迟的次数。

- option_tracker_usage:Connection DoS control

失败的连接尝试被延迟的次数。

- option_tracker_usage:Encrypted File keyring

调用任何通用密钥环函数（参见第 8.4.5.15 节"通用密钥环密钥管理函数"）的次数。

- option_tracker_usage:Enterprise AUDIT

当调用任何 Audit Log 插件函数或打开新的审计输出文件进行写入时，此计数递增。有关更多信息，请参见第 8.4.6 节"MySQL Enterprise Audit 插件（已弃用）"。

- option_tracker_usage:Enterprise Data Masking

每次使用 MySQL Enterprise Data Masking 函数时，此值递增。参见第 8.5 节"MySQL Enterprise Data Masking"。

- option_tracker_usage:Enterprise Encryption

每次调用 MySQL Enterprise Encryption 函数时递增。有关更多信息，请参见第 8.6 节"MySQL Enterprise Encryption"。

- option_tracker_usage:Enterprise Firewall

每次调用 MySQL Enterprise Firewall 管理函数，或添加、标记或拒绝语句时，此状态变量递增。参见第 8.4.9 节"MySQL Enterprise Firewall"。

- option_tracker_usage:Enterprise Thread Pool

MySQL Thread Pool 插件被初始化或添加新连接的次数。有关更多信息，请参见第 7.6.3 节"MySQL Thread Pool"。

- option_tracker_usage:File keyring

每次调用任何通用密钥环函数（参见第 8.4.5.15 节"通用密钥环密钥管理函数"）时，此变量递增。

- option_tracker_usage:Group Replication

每当 MySQL Group Replication 插件运行时，此状态变量每 600 秒（10 分钟）递增一次。参见第 20 章"Group Replication"。

- option_tracker_usage:Hashicorp keyring

使用 Hashicorp keyring 组件调用任何通用密钥环函数（参见第 8.4.5.15 节"通用密钥环密钥管理函数"）的次数。

- option_tracker_usage:Hypergraph Optimizer

使用 Hypergraph Optimizer 优化查询的次数。仅限 MySQL HeatWave。

- option_tracker_usage:HyperLogLog

每次调用 HLL() 聚合函数时递增。仅限 MySQL HeatWave。

- option_tracker_usage:JavaScript Library

创建或使用 JavaScript 库的次数。参见第 27.3.8 节"使用 JavaScript 库"。

- option_tracker_usage:JavaScript Stored Program

每次调用 JavaScript 程序时递增。参见第 27.3 节"JavaScript 存储程序"。

- option_tracker_usage:JSON Duality View

打开 JSON duality view 的次数。参见第 27.7 节"JSON Duality Views"。

- option_tracker_usage:Kerberos authentication

当使用 Kerberos 身份验证组件调用任何通用密钥环函数（参见第 8.4.5.15 节"通用密钥环密钥管理函数"）时。

- option_tracker_usage:LDAP Simple authentication

每次使用 authentication_ldap_simple 插件调用任何通用密钥环函数（参见第 8.4.5.15 节"通用密钥环密钥管理函数"）时递增。

- option_tracker_usage:MySQL Server

每当 MySQL 服务器重启时，此状态变量重置为 0。之后，只要服务器运行，它每 600 秒（10 分钟）递增一次。

- option_tracker_usage-MySQL_Shell_VSC_HeatWave_Chat

在 MySQL Shell for VS Code 中执行 \chat 提示符的次数。

- option_tracker_usage-MySQL_Shell_VSC_Natural_Language_to_SQL

在 MySQL Shell for VS Code 中执行 \nl 命令的次数。

- option_tracker_usage-MySQL_Shell_VSC_Lakehouse_Navigator

在 MySQL HeatWave Navigator 中启动数据加载过程的次数。

- option_tracker_usage-MySQL_Shell

创建 MySQL Shell 用户会话的次数。

- option_tracker_usage-MySQL_Shell_for_VS_Code

创建 MySQL Shell for VS Code 用户会话的次数。

- option_tracker_usage-MySQL_Shell_Dump

使用 MySQL Shell dump 实用程序的次数。

- option_tracker_usage-MySQL_Shell_VSC_Dump

使用 MySQL Shell for VS Code dump 实用程序的次数。

- option_tracker_usage-MySQL_Shell_Dump_Load

使用 MySQL Shell dump 加载实用程序的次数。

- option_tracker_usage-MySQL_Shell_VSC_Dump_Load

使用 MySQL Shell for VS Code dump 加载实用程序的次数。

- option_tracker_usage-MySQL_Shell_MRS

由 MySQL REST Service 执行数据库操作的次数。

- option_tracker_usage-MySQL_Shell_VSC_MRS

由 MySQL Shell for VS Code 中的 MySQL REST Service 执行数据库操作的次数。

- option_tracker_usage-MySQL_Shell_Copy

使用 MySQL Shell copy 实用程序的次数。

- option_tracker_usage-MySQL_Shell_Upgrade_Checker

使用 MySQL Shell checkForServerUpgrade 实用程序的次数。

- option_tracker_usage:MySQL Telemetry

每 1000 次导出跟踪、日志或指标时递增。

- option_tracker_usage:OCI Authentication

每次调用任何 OCI Authentication 插件函数时递增。

- option_tracker_usage:Oracle Key Vault keyring

使用 Oracle Key Vault keyring 插件调用任何通用密钥环函数（参见第 8.4.5.15 节"通用密钥环密钥管理函数"）的次数。

- option_tracker_usage:PAM authentication

使用 PAM Authentication 插件调用任何通用密钥环函数（参见第 8.4.5.15 节"通用密钥环密钥管理函数"）的次数。有关更多信息，请参见第 8.4.1.4 节"PAM 可插拔身份验证"。

- option_tracker_usage:Password validation

使用 component_validate_password 评估、验证或更改密码强度的次数。参见第 8.4.4 节"密码验证组件"。

- option_tracker_usage:Replication Replica

每当启用复制且此服务器充当副本时，每 600 秒（10 分钟）递增一次；每次重置辅助服务器或更改主服务器时重置。

- option_tracker_usage:SASL LDAP Authentication

使用 authentication_ldap_sasl 插件评估、验证或更改密码强度的次数。有关更多信息，请参见第 8.4.1.6 节"LDAP 可插拔身份验证"。

- option_tracker_usage:Scheduler

使用 Scheduler 组件创建、执行或删除计划任务的次数。参见第 7.5.5 节"Scheduler 组件"。

- option_tracker_usage:Traditional MySQL Optimizer

使用传统 MySQL 优化器执行查询的次数。

- option_tracker_usage:Vector

每次调用 DISTANCE() 函数或其别名 VECTOR_DISTANCE() 时递增（仅限 MySQL HeatWave）。

- option_tracker_usage:WebAssembly Library

创建或使用 WebAssembly 库的次数。有关更多信息，请参见第 27.3.9 节"使用 WebAssembly 库"。

- option_tracker_usage:WebauthN authentication

使用 WebauthN 身份验证插件调用任何通用密钥环函数（参见第 8.4.5.15 节"通用密钥环密钥管理函数"）的次数。有关更多信息，请参见第 8.4.1.11 节"WebAuthn 可插拔身份验证"。

- option_tracker_usage:Windows authentication

每次使用 MySQL Windows 身份验证插件调用任何通用密钥环函数（参见第 8.4.5.15 节"通用密钥环密钥管理函数"）时，此值递增。有关更多信息，请参见第 8.4.1.5 节"Windows 可插拔身份验证"。

- option_tracker.gr_complete_table_received

通过 Group Replication 接收的完整表的数量。

- option_tracker.gr_complete_table_sent

通过 Group Replication 发送的完整表的数量。

- option_tracker.gr_error_received

通过 Group Replication 接收的错误数量。

- option_tracker.gr_error_sent

通过 Group Replication 发送的错误数量。

- option_tracker.gr_reset_request_received

通过 Group Replication 接收的重置请求数量。

- option_tracker.gr_reset_request_sent

通过 Group Replication 发送的重置请求数量。

- option_tracker.gr_single_row_received

通过 Group Replication 接收的单行数量。

- option_tracker.gr_single_row_sent

通过 Group Replication 发送的单行数量。
