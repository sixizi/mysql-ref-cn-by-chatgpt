### 7.5.9.2 Option Tracker 支持的组件

要在 mysql_option.option_usage 和 mysql_option 表中显示，组件或插件必须使用 Option Tracker 支持进行编写和编译。在 MySQL 26.10 中提供此类支持的组件和插件如下表所示：

表 7.8 具有 Option Tracker 支持的组件和插件

| 名称 | 容器 | 启用 | 增量 |
|------|------|------|------|
| AWS keyring plugin | keyring_aws plugin | always | 当使用此组件调用任何通用密钥环函数（参见第 8.4.5.15 节"通用密钥环密钥管理函数"）时 |
| Binary Log | mysql_server | 当启用二进制日志记录时（即设置了 --log-bin） | 启用时每 10 分钟 |
| Connection control component | component_connection_control component | 当 component_connection_control.failed_connections_threshold != 0 时 | 当连接失败尝试被延迟时 |
| Connection DoS control plugin | connection_control plugin | 当 connection_control_failed_connections_threshold != 0 时 | 当连接失败尝试被延迟时 |
| Encrypted File keyring | component_keyring_encrypted_file | always | 当使用此组件调用任何通用密钥环函数（参见第 8.4.5.15 节"通用密钥环密钥管理函数"）时 |
| Enterprise AUDIT | audit_log plugin | audit_log_disable = OFF | 当调用此插件的任何函数时，或打开新的审计输出文件进行写入时 |
| Enterprise Data Masking | component_masking | always | 当调用此组件的任何函数时 |
| Enterprise Encryption | component_enterprise_encryption | always | 当调用此组件的任何函数时 |
| Enterprise Firewall | MYSQL_FIREWALL plugin | 当 mysql_firewall_mode = ON 时 | 当调用此插件的任何管理函数（参见 MySQL Enterprise Firewall 管理函数）时，或添加、标记或拒绝语句时 |
| Enterprise Firewall | component_firewall | 当 component_firewall.enabled = ON 时 | 当调用此组件的任何管理函数（参见 MySQL Enterprise Firewall 组件函数）时，或添加、标记或拒绝语句时 |
| Enterprise Thread Pool | thread_pool plugin | always | 当初始化插件或添加新连接时 |
| File keyring | component_keyring_file | always | 当使用此组件调用任何通用密钥环函数（参见第 8.4.5.15 节"通用密钥环密钥管理函数"）时 |
| Group Replication | group_replication plugin | 当 Group Replication 正在运行时 | 启用插件时每 10 分钟；每当启用或禁用插件时；当插件在晋升为组主节点时设置 read_only 为 off 时 |
| Hashicorp keyring | component_keyring_hashicorp | always | 当使用此组件调用任何通用密钥环函数（参见第 8.4.5.15 节"通用密钥环密钥管理函数"）时 |
| Hashicorp keyring | keyring_hashicorp plugin | always | 当使用此插件调用任何通用密钥环函数（参见第 8.4.5.15 节"通用密钥环密钥管理函数"）时 |
| Hypergraph Optimizer | mysql_server | 当服务器使用 hypergraph optimizer 支持编译时（仅 MySQL HeatWave） | 每次使用 hypergraph optimizer 执行查询时 |
| HyperLogLog | component_hll | always | 每当调用 HLL() 聚合函数时（仅 MySQL HeatWave） |
| JavaScript Library | component:mle | always | 每当创建或使用 JavaScript 库时 |
| JavaScript Stored Program | component:mle | always | 每当调用 JavaScript 存储程序时 |
| JSON Duality View | mysql_server | always | 每当打开 JSON duality view 时（参见第 27.7 节"JSON Duality Views"） |
| Kerberos authentication | authentication_kerberos plugin | always | 当使用此组件调用任何通用密钥环函数（参见第 8.4.5.15 节"通用密钥环密钥管理函数"）时 |
| LDAP Simple authentication | authentication_ldap_simple plugin | always | 当使用此插件调用任何通用密钥环函数（参见第 8.4.5.15 节"通用密钥环密钥管理函数"）时 |
| MySQL Server | mysql_server | always | 每 10 分钟 |
| MySQL Telemetry | component_telemetry | always | 每 1000 次导出跟踪、日志或指标时 |
| OCI Authentication | authentication_oci plugin | always | 当调用此插件的任何函数时 |
| Oracle Key Vault keyring | keyring_okv plugin | always | 当使用此插件调用任何通用密钥环函数（参见第 8.4.5.15 节"通用密钥环密钥管理函数"）时 |
| PAM authentication | authentication_pam plugin | always | 当使用此插件调用任何通用密钥环函数（参见第 8.4.5.15 节"通用密钥环密钥管理函数"）时 |
| Password validation | component_validate_password | always | 每当使用此组件评估、验证或更改密码强度时 |
| Replication Replica | mysql_server | 当服务器充当副本时（至少一个通道） | 启用复制时每 10 分钟；每次重置辅助节点或更改主节点时 |
| SASL LDAP Authentication | authentication_ldap_sasl plugin | always | 当使用此插件调用任何通用密钥环函数（参见第 8.4.5.15 节"通用密钥环密钥管理函数"）时 |
| Scheduler | component_scheduler | always | 每当创建、运行或删除计划任务时 |
| Traditional MySQL Optimizer | mysql_server | always | 每次使用传统优化器执行查询时 |
| Vector | component_vector | always | 每当调用 DISTANCE() 函数（或其别名 VECTOR_DISTANCE()）时（仅 MySQL HeatWave） |
| WebAssembly Library | component:mle | always | 每当创建或使用 WebAssembly 库时 |
| WebauthN authentication | authentication_webauth plugin | always | 当使用此插件调用任何通用密钥环函数（参见第 8.4.5.15 节"通用密钥环密钥管理函数"）时 |
| Windows authentication | authentication_windows plugin | always | 当使用此插件调用任何通用密钥环函数（参见第 8.4.5.15 节"通用密钥环密钥管理函数"）时 |

表的"名称"列中显示的组件名称是 mysql_option.option_usage 表的 OPTION_NAME 列显示的值（参见第 7.5.9.1 节"Option Tracker 表"）以及 Performance Schema mysql_option 表的 OPTION_NAME 列。与此组件关联的 Option Tracker 状态变量（使用计数器）的名称是通过在此值前面加上 option_tracker_usage: 形成的。

表的"容器"列中显示的名称是 performance_schema.mysql_option 表的 OPTION_CONTAINER 列中显示的值。

"启用"列显示组件启用的条件。

"增量"列显示导致此组件的使用计数器增加的事件或操作。

注意

Enterprise Data Masking 以前称为 Enterprise Data Masking and Deidentification。
