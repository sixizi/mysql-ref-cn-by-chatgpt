### 7.7.1 安装和卸载可加载函数

安装和卸载可加载函数：

```sql
CREATE FUNCTION function_name RETURNS STRING SONAME 'library.so';
DROP FUNCTION function_name;
```

- 函数库必须位于服务器插件目录。
- 函数注册信息写入 `mysql.func`。

卸载前应确认没有视图、存储过程或应用依赖该函数。

------
官方英文版参见 [Installing and Uninstalling Loadable Functions](https://dev.mysql.com/doc/refman/8.0/en/function-loading.html)。
