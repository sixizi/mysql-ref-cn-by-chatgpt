### 7.7.2 获取可加载函数的信息

Performance Schema 的 user_defined_functions 表包含有关当前已安装的可加载函数的信息：

```
SELECT * FROM performance_schema.user_defined_functions;
```

mysql.func 系统表也列出了已安装的可加载函数，但仅限于使用 CREATE FUNCTION 安装的函数。user_defined_functions 表列出了使用 CREATE FUNCTION 安装的可加载函数，以及由组件或插件自动安装的可加载函数。这种差异使得 user_defined_functions 相比 mysql.func 更适合用于检查已安装的可加载函数。参见第 29.12.23.12 节"user_defined_functions 表"。
