### 7.7.2 获取可加载函数信息

查看可加载函数信息：

```sql
SELECT * FROM mysql.func;
SHOW FUNCTION STATUS WHERE Db = '';
```

也可查看 `performance_schema.user_defined_functions`，确认函数名称、后端库和状态。

------
官方英文版参见 [Obtaining Information About Loadable Functions](https://dev.mysql.com/doc/refman/8.0/en/obtaining-loadable-function-information.html)。
