### 7.8.4 在多服务器环境中使用客户端程序

要使用客户端程序连接到监听与编译到客户端中不同网络接口的 MySQL 服务器，可以使用以下方法之一：

- 使用 `--host=host_name --port=port_number` 启动客户端以通过 TCP/IP 连接到远程服务器，使用 `--host=127.0.0.1 --port=port_number` 通过 TCP/IP 连接到本地服务器，或使用 `--host=localhost --socket=file_name` 通过 Unix 套接字文件或 Windows 命名管道连接到本地服务器。

- 使用 `--protocol=TCP` 启动客户端以通过 TCP/IP 连接，使用 `--protocol=SOCKET` 通过 Unix 套接字文件连接，使用 `--protocol=PIPE` 通过命名管道连接，或使用 `--protocol=MEMORY` 通过共享内存连接。对于 TCP/IP 连接，可能还需要指定 `--host` 和 `--port` 选项。对于其他类型的连接，可能需要指定 `--socket` 选项来指定 Unix 套接字文件或 Windows 命名管道名称，或指定 `--shared-memory-base-name` 选项来指定共享内存名称。共享内存连接仅在 Windows 上受支持。

- 在 Unix 上，在启动客户端之前设置 `MYSQL_UNIX_PORT` 和 `MYSQL_TCP_PORT` 环境变量以指向 Unix 套接字文件和 TCP/IP 端口号。如果通常使用特定的套接字文件或端口号，可以在 `.login` 文件中放置设置这些环境变量的命令，以便每次登录时都应用这些设置。参见第 6.9 节"环境变量"。

- 在选项文件的 `[client]` 组中指定默认 Unix 套接字文件和 TCP/IP 端口号。例如，可以在 Windows 上使用 `C:\my.cnf`，或在 Unix 上使用主目录中的 `.my.cnf` 文件。参见第 6.2.2.2 节"使用选项文件"。

- 在 C 程序中，可以在 `mysql_real_connect()` 调用中指定套接字文件或端口号参数。还可以通过调用 `mysql_options()` 让程序读取选项文件。参见 C API 基本函数描述。

- 如果使用 Perl DBD::mysql 模块，可以从 MySQL 选项文件读取选项。例如：

```
$dsn = "DBI:mysql:test;mysql_read_default_group=client;"
        . "mysql_read_default_file=/usr/local/mysql/data/my.cnf";
$dbh = DBI->connect($dsn, $user, $password);
```

参见第 31.9 节"MySQL Perl API"。

其他编程接口可能提供类似的读取选项文件的功能。
