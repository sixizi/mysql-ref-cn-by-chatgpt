### 7.8.2.2 将多个 MySQL 实例作为 Windows 服务启动

在 Windows 上，MySQL 服务器可以作为 Windows 服务运行。安装、控制和删除单个 MySQL 服务的过程在第 2.3.3.8 节"将 MySQL 作为 Windows 服务启动"中进行了描述。

要设置多个 MySQL 服务，除了必须对每个实例唯一的其他参数外，还必须确保每个实例使用不同的服务名称。

对于以下说明，假设您想从两个不同版本的 MySQL 运行 mysqld 服务器，这两个版本分别安装在 C:\mysql-5.7.9 和 C:\mysql-26.10.0。（如果您运行 5.7.9 作为生产服务器，但也想使用 26.10.0 进行测试，可能会出现这种情况。）

要将 MySQL 安装为 Windows 服务，请使用 --install 或 --install-manual 选项。有关这些选项的信息，请参见第 2.3.3.8 节"将 MySQL 作为 Windows 服务启动"。

#### 在 Windows 上运行多个 MySQL 实例

根据前面的信息，您有几种方式来设置多个服务。以下说明描述了一些示例。在尝试任何方法之前，请关闭并删除任何现有的 MySQL 服务。

- **方法 1：在标准选项文件之一中为所有服务指定选项。** 为此，为每个服务器使用不同的服务名称。假设您想使用服务名称 mysqld1 运行 5.7.9 mysqld，使用服务名称 mysqld2 运行 26.10.0 mysqld。在这种情况下，您可以为 5.7.9 使用 [mysqld1] 组，为 26.10.0 使用 [mysqld2] 组。例如，您可以像这样设置 C:\my.cnf：

  ```
  # options for mysqld1 service
  [mysqld1]
  basedir = C:/mysql-5.7.9
  port = 3307
  enable-named-pipe
  socket = mypipe1

  # options for mysqld2 service
  [mysqld2]
  basedir = C:/mysql-26.10.0
  port = 3308
  enable-named-pipe
  socket = mypipe2
  ```

  按如下方式安装服务，使用完整的服务器路径名称以确保 Windows 为每个服务注册正确的可执行程序：

  ```
  C:\> C:\mysql-5.7.9\bin\mysqld --install mysqld1
  C:\> C:\mysql-26.10.0\bin\mysqld --install mysqld2
  ```

  要启动服务，请使用服务管理器，或使用 NET START 或 SC START 和相应的服务名称：

  ```
  C:\> SC START mysqld1
  C:\> SC START mysqld2
  ```

  要停止服务，请使用服务管理器，或使用 NET STOP 或 SC STOP 和相应的服务名称：

  ```
  C:\> SC STOP mysqld1
  C:\> SC STOP mysqld2
  ```

- **方法 2：在单独的文件中为每个服务器指定选项，并在安装服务时使用 --defaults-file 来告诉每个服务器要使用什么文件。** 在这种情况下，每个文件应该使用 [mysqld] 组列出选项。

  使用此方法，要为 5.7.9 mysqld 指定选项，请创建一个如下所示的文件 C:\my-opts1.cnf：

  ```
  [mysqld]
  basedir = C:/mysql-5.7.9
  port = 3307
  enable-named-pipe
  socket = mypipe1
  ```

  对于 26.10.0 mysqld，请创建一个如下所示的文件 C:\my-opts2.cnf：

  ```
  [mysqld]
  basedir = C:/mysql-26.10.0
  port = 3308
  enable-named-pipe
  socket = mypipe2
  ```

  按如下方式安装服务（在单行上输入每个命令）：

  ```
  C:\> C:\mysql-5.7.9\bin\mysqld --install mysqld1
             --defaults-file=C:\my-opts1.cnf
  C:\> C:\mysql-26.10.0\bin\mysqld --install mysqld2
             --defaults-file=C:\my-opts2.cnf
  ```

  当您将 MySQL 服务器安装为服务并使用 --defaults-file 选项时，服务名称必须在选项之前。

  安装服务后，以与前面示例相同的方式启动和停止它们。

要删除多个服务，对每个服务使用 SC DELETE mysqld_service_name。或者，对每个服务使用 mysqld --remove，在 --remove 选项后指定服务名称。如果服务名称是默认值 (MySQL)，在使用 mysqld --remove 时可以省略它。
