### 7.8.2.2 将多个 MySQL 实例作为 Windows 服务启动

将多个实例注册为 Windows 服务：

```bat
mysqld --install MySQL80-A --defaults-file=C:\mysql-a\my.ini
mysqld --install MySQL80-B --defaults-file=C:\mysql-b\my.ini
net start MySQL80-A
net start MySQL80-B
```

服务名必须唯一，启动用户需要能访问对应数据目录。

------
官方英文版参见 [Starting Multiple MySQL Instances as Windows Services](https://dev.mysql.com/doc/refman/8.0/en/multiple-windows-services.html)。
