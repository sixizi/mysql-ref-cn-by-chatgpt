### 7.8.2 在 Windows 上运行多个 MySQL 实例

**目录**

- [7.8.2.1 在 Windows 命令行启动多个 MySQL 实例](./07.08.02.01.在 Windows 命令行启动多个 MySQL 实例.md)
- [7.8.2.2 将多个 MySQL 实例作为 Windows 服务启动](./07.08.02.02.将多个 MySQL 实例作为 Windows 服务启动.md)

Windows 上可运行多个 MySQL 实例，常见方式有：

- 使用不同配置文件和 `--defaults-file` 从命令行启动。
- 安装多个 Windows 服务。

每个实例必须拥有独立数据目录、端口、服务名和日志文件。
