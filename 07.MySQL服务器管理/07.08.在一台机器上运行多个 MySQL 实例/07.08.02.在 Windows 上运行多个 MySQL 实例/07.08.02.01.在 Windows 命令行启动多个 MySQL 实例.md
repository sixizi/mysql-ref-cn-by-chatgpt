### 7.8.2.1 在 Windows 命令行启动多个 MySQL 实例

在 Windows 命令行启动多个实例：

```bat
mysqld --defaults-file=C:\mysql-a\my.ini --console
mysqld --defaults-file=C:\mysql-b\my.ini --console
```

- 各配置文件指定不同 `datadir` 和 `port`。
- 可用 `mysqladmin shutdown` 分别管理实例。

------
官方英文版参见 [Starting Multiple MySQL Instances at the Windows Command Line](https://dev.mysql.com/doc/refman/8.0/en/multiple-windows-command-line-servers.html)。
