### 7.3 mysql 系统模式

`mysql` 系统模式保存服务器运行所需的系统表：

- 授权表：`user`、`db`、`tables_priv` 等。
- 数据字典表：`tables`、`columns`、`tablespaces` 等。
- 帮助表、时区表、组件和插件注册表。
- 复制、组复制和优化器统计相关表。

绝大多数系统表由服务器维护。日常操作应使用 SQL 语句或官方工具，不要直接 `UPDATE` 系统表。
