### 7.1.16 资源组

资源组将服务器线程映射到 CPU 亲和性和执行优先级：

```sql
CREATE RESOURCE GROUP batch_group TYPE = USER VCPU = 2-3 THREAD_PRIORITY = 10;
SET RESOURCE GROUP batch_group;
ALTER RESOURCE GROUP batch_group VCPU = 4;
```

Windows 支持有限，Unix 上的线程优先级范围取决于平台和权限。
