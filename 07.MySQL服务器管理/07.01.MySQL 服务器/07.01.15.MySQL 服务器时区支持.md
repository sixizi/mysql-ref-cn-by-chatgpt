### 7.1.15 MySQL 服务器时区支持

MySQL 可使用操作系统时区表，并为会话和服务器分别设置时区：

```sh
mysql_tzinfo_to_sql /usr/share/zoneinfo | mysql -u root -p mysql
```

```sql
SET GLOBAL time_zone = 'UTC';
SET SESSION time_zone = 'Asia/Singapore';
```

时间戳列存储 UTC 值并按时区转换；`DATETIME` 不做时区转换。
