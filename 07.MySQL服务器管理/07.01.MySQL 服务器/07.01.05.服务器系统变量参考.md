### 7.1.5 服务器系统变量参考

系统变量参考按变量名列出作用域、动态性、默认值和版本信息。

```sql
SHOW VARIABLES LIKE 'max_connections';
SELECT @@GLOBAL.max_connections;
```

修改变量前必须确认作用域是 `GLOBAL`、`SESSION` 还是两者均可，以及是否支持动态修改。
