### 7.1.8 服务器系统变量

系统变量分为全局变量和会话变量，有些可动态修改，有些只能重启后生效。

```sql
SET GLOBAL max_connections = 500;
SET SESSION sql_mode = 'STRICT_TRANS_TABLES';
```

`SET PERSIST` 可同时修改变量并写入 `mysqld-auto.cnf`。
