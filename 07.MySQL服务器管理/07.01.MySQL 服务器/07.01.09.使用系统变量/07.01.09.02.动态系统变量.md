### 7.1.9.2 动态系统变量

动态系统变量可在服务器运行时修改：

```sql
SET GLOBAL max_connections = 500;
SET SESSION max_execution_time = 1000;
```

动态修改只影响后续行为，已有连接的会话变量通常保持不变；持久化配置需另行写入配置文件或使用 `SET PERSIST`。
