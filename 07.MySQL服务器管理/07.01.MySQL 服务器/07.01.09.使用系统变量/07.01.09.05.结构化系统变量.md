### 7.1.9.5 结构化系统变量

结构化系统变量以点号路径访问，常用于插件或服务器组件：

```sql
SET GLOBAL some_structured_var.key1 = 1;
SET GLOBAL some_structured_var.key2 = 'value';
```

这类变量通常没有对应的普通字符串变量名，必须使用完整路径设置成员。
