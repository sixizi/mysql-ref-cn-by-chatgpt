### 7.1.9.3 持久化系统变量

持久化系统变量写入 `mysqld-auto.cnf`：

```sql
SET PERSIST max_connections = 500;
SET PERSIST_ONLY back_log = 500;
```

- `SET PERSIST`：立即修改并持久化。
- `SET PERSIST_ONLY`：只写入文件，不修改当前运行值。
- `RESET PERSIST`：移除持久化项。

`mysqld-auto.cnf` 应由服务器管理，不要手工编辑。
