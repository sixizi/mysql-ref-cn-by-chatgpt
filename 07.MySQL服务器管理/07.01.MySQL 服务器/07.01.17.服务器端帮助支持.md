### 7.1.17 服务器端帮助支持

MySQL 服务器支持 HELP 语句，该语句从 MySQL 参考手册返回信息（参见第 15.8.3 节"HELP 语句"）。此信息存储在 mysql 模式中的多个表中（参见第 7.3 节"mysql 系统模式"）。HELP 语句的正常运行需要这些帮助表被初始化。

对于在 Unix 上使用二进制或源代码分发的 MySQL 新安装，帮助表内容初始化在初始化数据目录时发生（参见第 2.9.1 节"初始化数据目录"）。对于 Linux 上的 RPM 分发或 Windows 上的二进制分发，内容初始化作为 MySQL 安装过程的一部分发生。

对于使用二进制分发的 MySQL 升级，帮助表内容由服务器自动升级。要手动升级，请在 share 或 share/mysql 目录中找到 fill_help_tables.sql 文件。切换到该目录，并使用 mysql 客户端处理该文件，如下所示：

```
mysql -u root -p mysql < fill_help_tables.sql
```

此处显示的命令假设您使用具有修改 mysql 模式中表的权限的帐户（如 root）连接到服务器。根据需要调整连接参数。
