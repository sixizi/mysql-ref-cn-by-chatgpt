### 7.1.18 服务器跟踪客户端会话状态

会话状态跟踪向客户端驱动返回会话变化，用于连接池恢复状态：

- `session_track_gtids`
- `session_track_schema`
- `session_track_state_change`
- `session_track_system_variables`

```sql
SET SESSION session_track_schema = ON;
```

连接复用前应根据跟踪结果重置默认数据库、字符集、时区和其他系统变量。
