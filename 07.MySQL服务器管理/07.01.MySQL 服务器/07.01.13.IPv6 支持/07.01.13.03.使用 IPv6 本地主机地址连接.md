### 7.1.13.3 使用 IPv6 本地主机地址连接

本机测试可使用 IPv6 环回地址：

```sh
mysql --host=::1
```

也可将账号主机设置为 `::1`：

```sql
CREATE USER 'app'@'::1' IDENTIFIED BY 'password';
```

这是验证服务器 IPv6 能力的最小路径。
