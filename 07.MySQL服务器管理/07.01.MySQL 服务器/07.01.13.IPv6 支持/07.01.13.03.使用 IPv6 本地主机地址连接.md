### 7.1.13.3 使用 IPv6 本地主机地址连接

以下过程展示了如何配置 MySQL 以允许客户端使用 ::1 本地主机地址连接到本地服务器的 IPv6 连接。此处的说明假设您的系统支持 IPv6。

1. 使用适当的 bind_address 设置启动 MySQL 服务器，以允许其接受 IPv6 连接。例如，在服务器选项文件中放入以下行并重启服务器：
   ```
   [mysqld]
   bind_address = *
   ```

   将 * （或 ::）指定为 bind_address 的值允许在所有服务器主机 IPv4 和 IPv6 接口上进行 IPv4 和 IPv6 连接。如果要将服务器绑定到特定地址列表，可以为 bind_address 指定逗号分隔的值列表。此示例指定了 IPv4 和 IPv6 的本地主机地址：
   ```
   [mysqld]
   bind_address = 127.0.0.1,::1
   ```

   有关更多信息，请参见 Section 7.1.8"服务器系统变量"中的 bind_address 描述。

2. 以管理员身份连接到服务器，并为可以从 ::1 本地 IPv6 主机地址连接的本地用户创建账户：
   ```
   mysql> CREATE USER 'ipv6user'@'::1' IDENTIFIED BY 'ipv6pass';
   ```

   有关账户名中 IPv6 地址的允许语法，请参见 Section 8.2.4"指定账户名"。除了 CREATE USER 语句外，您还可以发出 GRANT 语句为账户授予特定权限，尽管这对于此过程中的其余步骤不是必需的。

3. 调用 mysql 客户端使用新账户连接到服务器：
   ```
   $> mysql -h ::1 -u ipv6user -pipv6pass
   ```

4. 尝试一些显示连接信息的简单语句：
   ```
   mysql> STATUS
   ...
   Connection:   ::1 via TCP/IP
   ...

   mysql> SELECT CURRENT_USER(), @@bind_address;
   +----------------+----------------+
   | CURRENT_USER() | @@bind_address |
   +----------------+----------------+
   | ipv6user@::1   | ::             |
   +----------------+----------------+
   ```
