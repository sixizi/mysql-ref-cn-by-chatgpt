### 7.1.13.5 从代理获取 IPv6 地址

如果你没有公共 IPv6 地址来使你的系统能够在本地网络外通过 IPv6 通信，你可以从 IPv6 代理获取一个。Wikipedia IPv6 Tunnel Broker 页面列出了几个代理及其功能，例如它们是否提供静态地址和支持的路由协议。

在配置服务器主机使用代理提供的 IPv6 地址后，使用适当的 bind_address 设置启动 MySQL 服务器，以允许服务器接受 IPv6 连接。你可以指定 * （或 ::）作为 bind_address 值，或将服务器绑定到代理提供的特定 IPv6 地址。有关更多信息，请参见第 7.1.8 节"服务器系统变量"中的 bind_address 描述。

请注意，如果代理分配动态地址，下次连接到代理时为你的系统提供的地址可能会改变。如果是这样，你创建的任何命名原始地址的账户都会变成无效。要绑定到特定地址但避免此地址变更问题，你可能能够与代理协商获得静态 IPv6 地址。

以下示例展示了如何在 Gentoo Linux 上使用 Freenet6 作为代理和 gogoc IPv6 客户端包。

1. 通过访问此 URL 并注册在 Freenet6 创建账户：
   http://gogonet.gogo6.com

2. 创建账户后，转到此 URL，登录，并为 IPv6 代理创建用户 ID 和密码：
   http://gogonet.gogo6.com/page/freenet6-registration

3. 以 root 身份安装 gogoc：
   $> emerge gogoc

4. 编辑 /etc/gogoc/gogoc.conf 以设置 userid 和 passwd 值。例如：
   userid=gogouser
   passwd=gogopass

5. 启动 gogoc：
   $> /etc/init.d/gogoc start

   要在每次系统启动时启动 gogoc，执行此命令：
   $> rc-update add gogoc default

6. 使用 ping6 尝试 ping 一个主机：
   $> ping6 ipv6.google.com

7. 要查看你的 IPv6 地址：
   $> ifconfig tun
