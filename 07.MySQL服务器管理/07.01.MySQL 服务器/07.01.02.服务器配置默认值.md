### 7.1.2 服务器配置默认值

MySQL 服务器有许多操作参数，你可以在服务器启动时使用命令行选项或配置文件（选项文件）来更改这些参数。也可以在运行时更改许多参数。有关在启动时或运行时设置参数的一般说明，请参见第 7.1.7 节"服务器命令选项"和第 7.1.8 节"服务器系统变量"。

在 Windows 上，MySQL Installer 与用户交互，并在基础安装目录中创建一个名为 my.ini 的文件作为默认选项文件。

注意

在 Windows 上，.ini 或 .cnf 选项文件扩展名可能不会显示。

完成安装过程后，你可以随时编辑默认选项文件以修改服务器使用的参数。例如，要使用文件中以 # 字符开头注释的参数设置，请删除 #，并根据需要修改参数值。要禁用设置，可以在行的开头添加 # 或将其删除。

对于非 Windows 平台，在服务器安装或数据目录初始化过程中都不会创建默认选项文件。按照第 6.2.2.2 节"使用选项文件"中给出的说明创建你的选项文件。没有选项文件的情况下，服务器只会以其默认设置启动——请参见第 7.1.2 节"服务器配置默认值"了解如何检查这些设置。

有关选项文件格式和语法的更多信息，请参见第 6.2.2.2 节"使用选项文件"。
