### 7.1.11 服务器 SQL 模式

SQL 模式控制服务器对数据和语句的处理方式：

```sql
SELECT @@sql_mode;
SET GLOBAL sql_mode = 'STRICT_TRANS_TABLES,NO_ENGINE_SUBSTITUTION';
```

常用模式：

- `STRICT_TRANS_TABLES`：对无效数据返回错误。
- `ONLY_FULL_GROUP_BY`：约束非聚合列。
- `NO_ENGINE_SUBSTITUTION`：禁止用默认引擎静默替换。
- `ANSI_QUOTES`：将双引号解释为标识符引用。

修改 SQL 模式可能改变写入和查询行为，应先在测试环境验证。
