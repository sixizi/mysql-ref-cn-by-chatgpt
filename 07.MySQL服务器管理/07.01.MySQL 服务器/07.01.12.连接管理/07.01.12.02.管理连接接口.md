### 7.1.12.2 管理连接管理

如"连接卷管理"中所述，为了在普通连接接口上已建立 max_connections 个连接的情况下仍能执行管理操作，MySQL 服务器允许具有 CONNECTION_ADMIN 权限（或已弃用的 SUPER 权限）的用户建立单个管理连接。

服务器还允许为管理连接专用一个 TCP/IP 端口，如以下部分所述。

- 管理接口特性

- 管理接口对加密连接的支持

#### 管理接口特性

管理连接接口具有以下特性：

- 服务器仅在启动时将 admin_address 系统变量设置为指示其 IP 地址时才启用该接口。如果未设置 admin_address，服务器不维护管理接口。

- admin_port 系统变量指定接口 TCP/IP 端口号（默认 33062）。

- 管理连接数没有限制，但仅允许具有 SERVICE_CONNECTION_ADMIN 权限的用户连接。

- create_admin_listener_thread 系统变量使数据库管理员能够在启动时选择管理接口是否具有自己的独立线程。默认值为 OFF；即，主接口上普通连接的管理器线程也处理管理接口的连接。

服务器 my.cnf 文件中的这些行在环回接口上启用管理接口，并将其配置为使用端口号 33064（即与默认端口不同的端口）：

```
[mysqld]
admin_address=127.0.0.1
admin_port=33064
```

MySQL 客户端程序通过指定适当的连接参数连接到主接口或管理接口。如果本地主机上运行的服务器对主接口和管理接口使用默认 TCP/IP 端口号 3306 和 33062，这些命令连接到这些接口：

```
mysql --protocol=TCP --port=3306
mysql --protocol=TCP --port=33062
```

#### 管理接口对加密连接的支持

管理接口具有自己的加密连接配置参数。这些参数对应于主接口参数，但允许独立配置管理接口的加密连接：

admin_tls_xxx 和 admin_ssl_xxx 系统变量类似于 tls_xxx 和 ssl_xxx 系统变量，但它们为管理接口而非主接口配置 TLS 上下文。

有关配置连接加密支持的一般信息，请参见第 8.3.1 节"配置 MySQL 使用加密连接"和第 8.3.2 节"加密连接 TLS 协议和密码"。该讨论是针对主连接接口编写的，但管理连接接口的参数名称类似。将该讨论与以下备注一起使用，这些备注提供特定于管理接口的信息。

管理接口的 TLS 配置遵循以下规则：

- 管理接口支持加密连接。对于接口上的连接，适用的 TLS 上下文取决于是否配置了任何非默认管理 TLS 参数：

  - 如果所有管理 TLS 参数都具有其默认值，管理接口使用与主接口相同的 TLS 上下文。

  - 如果任何管理 TLS 参数具有非默认值，管理接口使用由其自己的参数定义的 TLS 上下文。（如果任何 admin_tls_xxx 或 admin_ssl_xxx 系统变量设置为与其默认值不同的值，就会出现这种情况。）如果无法从这些参数创建有效的 TLS 上下文，管理接口将回退到主接口 TLS 上下文。

- 可以通过将 admin_tls_version 系统变量设置为空值来禁用对管理接口的加密连接，以指示不支持任何 TLS 版本。例如，服务器 my.cnf 文件中的这些行禁用管理接口上的加密连接：

```
[mysqld]
admin_tls_version=''
```

示例：

- 服务器 my.cnf 文件中的此配置启用管理接口，但不设置特定于该接口的任何 TLS 参数：

```
[mysqld]
admin_address=127.0.0.1
```

因此，管理接口支持加密连接（因为启用管理接口时默认支持加密），并使用主接口 TLS 上下文。当客户端连接到管理接口时，应使用与主接口上普通连接相同的证书和密钥文件。例如（在一行上输入命令）：

```
mysql --protocol=TCP --port=33062
      --ssl-ca=ca.pem
      --ssl-cert=client-cert.pem
      --ssl-key=client-key.pem
```

- 此服务器配置启用管理接口并设置特定于该接口的 TLS 证书和密钥文件参数：

```
[mysqld]
admin_address=127.0.0.1
admin_ssl_ca=admin-ca.pem
admin_ssl_cert=admin-server-cert.pem
admin_ssl_key=admin-server-key.pem
```

因此，管理接口支持使用其自己的 TLS 上下文的加密连接。当客户端连接到管理接口时，应使用特定于该接口的证书和密钥文件。例如（在一行上输入命令）：

```
mysql --protocol=TCP --port=33062
      --ssl-ca=admin-ca.pem
      --ssl-cert=admin-client-cert.pem
      --ssl-key=admin-client-key.pem
```
