### 17.6.3.9 表空间 AUTOEXTEND_SIZE 配置

默认情况下，当文件表或通用表空间需要额外空间时，表空间按照以下规则逐步扩展：

- 如果表空间小于一个区的大小，则每次扩展一个页。

- 如果表空间大于 1 个区但小于 32 个区，则每次扩展一个区。

- 如果表空间大于 32 个区，则每次扩展 4 个区。

有关区大小的信息，请参见第 17.11.2 节"文件空间管理"。

文件表或通用表空间的扩展量可通过指定 AUTOEXTEND_SIZE 选项来配置。配置更大的扩展大小可以帮助避免碎片化并便于大量数据的导入。

要为文件表配置扩展大小，请在 CREATE TABLE 或 ALTER TABLE 语句中指定 AUTOEXTEND_SIZE 大小：

```
CREATE TABLE t1 (c1 INT) AUTOEXTEND_SIZE = 4M;

ALTER TABLE t1 AUTOEXTEND_SIZE = 8M;
```

要为通用表空间配置扩展大小，请在 CREATE TABLESPACE 或 ALTER TABLESPACE 语句中指定 AUTOEXTEND_SIZE 大小：

```
CREATE TABLESPACE ts1 AUTOEXTEND_SIZE = 4M;

ALTER TABLESPACE ts1 AUTOEXTEND_SIZE = 8M;
```

注意

AUTOEXTEND_SIZE 选项也可在创建撤销表空间时使用，但撤销表空间的扩展行为不同。有关更多信息，请参见第 17.6.3.4 节"撤销表空间"。

AUTOEXTEND_SIZE 设置必须是 4M 的倍数。指定不是 4M 倍数的 AUTOEXTEND_SIZE 设置将返回错误。

AUTOEXTEND_SIZE 默认设置为 0，这会导致表空间按照上述默认行为进行扩展。

允许的最大 AUTOEXTEND_SIZE 为 4GB。最大表空间大小在第 17.21 节"InnoDB 限制"中描述。

最小 AUTOEXTEND_SIZE 设置取决于 InnoDB 页大小，如下表所示：

| InnoDB 页大小 | 最小 AUTOEXTEND_SIZE |
|---|---|
| 4K | 4M |
| 8K | 4M |
| 16K | 4M |
| 32K | 8M |
| 64K | 16M |

默认 InnoDB 页大小为 16K（16384 字节）。要确定 MySQL 实例的 InnoDB 页大小，请查询 innodb_page_size 设置：

```
mysql> SELECT @@GLOBAL.innodb_page_size;
+---------------------------+
| @@GLOBAL.innodb_page_size |
+---------------------------+
|                     16384 |
+---------------------------+
```

当表空间的 AUTOEXTEND_SIZE 设置被更改时，之后发生的第一次扩展会将表空间大小增加到 AUTOEXTEND_SIZE 设置的倍数。后续扩展为配置的大小。

当使用非零 AUTOEXTEND_SIZE 设置创建文件表或通用表空间时，表空间以指定的 AUTOEXTEND_SIZE 大小初始化。

ALTER TABLESPACE 不能用于配置文件表的 AUTOEXTEND_SIZE。必须使用 ALTER TABLE。

对于在文件表中创建的表，SHOW CREATE TABLE 仅在 AUTOEXTEND_SIZE 配置为非零值时才显示该选项。

要确定任何 InnoDB 表空间的 AUTOEXTEND_SIZE，请查询信息架构 INNODB_TABLESPACES 表。例如：

```
mysql> SELECT NAME, AUTOEXTEND_SIZE FROM INFORMATION_SCHEMA.INNODB_TABLESPACES
       WHERE NAME LIKE 'test/t1';
+---------+-----------------+
| NAME    | AUTOEXTEND_SIZE |
+---------+-----------------+
| test/t1 |         4194304 |
+---------+-----------------+

mysql> SELECT NAME, AUTOEXTEND_SIZE FROM INFORMATION_SCHEMA.INNODB_TABLESPACES
       WHERE NAME LIKE 'ts1';
+------+-----------------+
| NAME | AUTOEXTEND_SIZE |
+------+-----------------+
| ts1  |          4194304 |
+------+-----------------+
```

注意

AUTOEXTEND_SIZE 为 0（默认设置）意味着表空间按照上述默认表空间扩展行为进行扩展。
