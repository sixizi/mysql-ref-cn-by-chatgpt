# 3.9 使用 MySQL APT 仓库升级 MySQL

在 Debian 和 Ubuntu 平台上，使用 MySQL APT 仓库可对 MySQL 及其组件执行原地升级。

详细步骤参见官方指南 [Upgrading MySQL with the MySQL APT Repository](https://dev.mysql.com/doc/mysql-apt-repo-quick-guide/en/index.html#repo-upgrade)。
