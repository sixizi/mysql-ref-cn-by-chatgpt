# 3.10 使用 MySQL SLES 仓库升级 MySQL

在 SUSE Linux Enterprise Server（SLES）平台上，使用 MySQL SLES 仓库可对 MySQL 及其组件执行原地升级。

详细步骤参见官方指南 [Upgrading MySQL with the MySQL SLES Repository](https://dev.mysql.com/doc/mysql-sles-repo-quick-guide/en/index.html#repo-upgrade)。
