# 3.11 在 Windows 上升级 MySQL

Windows 上有两种升级方式：

- 使用 MySQL Installer
- 使用 Windows ZIP 压缩包发行版

选择方式取决于现有安装方式。开始前，应阅读本章中不特定于 Windows 的升级说明。

**注意**

- 无论选择哪种方式，升级前都必须备份当前 MySQL 安装。
- 不支持非 GA 版本之间的升级，或从非 GA 版本升级到 GA 版本。非 GA 版本可能存在重大开发变化，可能出现兼容性问题或服务器无法启动。

## 使用 MySQL Installer 升级

如果当前服务器安装由 MySQL Installer 完成，且升级发生在同一发布系列内，使用 MySQL Installer 是最佳方式。MySQL Installer 不支持跨发布系列升级，例如从 5.7 到 8.0；也不提供提醒你升级的指示器。

操作步骤：

1. 启动 MySQL Installer。
2. 在仪表板中点击 `Catalog` 下载最新目录。只有仪表板在服务器版本号旁显示箭头时，已安装服务器才可升级。
3. 点击 `Upgrade`，所有有新版本的产品会出现在列表中。
4. 除 MySQL 服务器外，取消选择其他产品；如需同时升级其他产品则可保留。点击 `Next`。
5. 点击 `Execute` 开始下载。下载完成后点击 `Next` 开始升级。升级到 MySQL 8.0.16 或更高时，可能出现跳过系统表升级检查和过程的选项。
6. 配置服务器。

MySQL Installer 不支持 Community 版本与 Commercial 版本之间的升级；如需此类升级，应使用 ZIP 压缩包方式。

## 使用 Windows ZIP 发行版升级

1. 从 MySQL 下载页面获取最新 Windows ZIP Archive 发行版。
2. 如果服务器正在运行，先停止。作为服务运行时：

   ```powershell
   SC STOP mysqld_service_name
   ```

   或：

   ```powershell
   NET STOP mysqld_service_name
   ```

   不作为服务运行时，可使用对应版本的 `mysqladmin`：

   ```powershell
   & "C:\Program Files\MySQL\MySQL Server 5.7\bin\mysqladmin" -u root shutdown
   ```

3. 解压 ZIP 压缩包。可以覆盖现有 MySQL 安装（通常位于 `C:\mysql`），或安装到不同目录（如 `C:\mysql8`）。推荐覆盖现有安装。
4. 重启服务器。作为服务运行时使用 `SC START` 或 `NET START`，否则直接调用 `mysqld`。
5. MySQL 8.0.16 之前，以管理员身份运行 `mysql_upgrade` 检查表、按需修复并更新授权表。MySQL 8.0.16 起无需此步骤。
6. 如果遇到错误，参见官方 Windows MySQL 服务器安装故障排除文档。
