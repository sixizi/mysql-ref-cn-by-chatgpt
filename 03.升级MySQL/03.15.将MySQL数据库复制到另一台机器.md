# 3.15 将 MySQL 数据库复制到另一台机器

如果需要在不同架构之间传输数据库，可使用 `mysqldump` 生成包含 SQL 语句的文件，再把该文件传输到另一台机器，并作为 `mysql` 客户端的输入。

使用以下命令查看可用选项：

```terminal
$ mysqldump --help
```

**注意**

如果在创建 dump 的服务器上启用 GTID（`gtid_mode=ON`），默认情况下 `mysqldump` 会把 `gtid_executed` 集合内容写入 dump。具体结果取决于涉及的 MySQL 服务器版本；请查看 `mysqldump` 的 `--set-gtid-purged` 选项说明，确认所用版本的行为以及如何调整。

## 直接通过网络传输

在数据库所在机器上执行以下命令，是最简单但不是最快的方式：

```terminal
$ mysqladmin -h 'other_hostname' create db_name
$ mysqldump db_name | mysql -h 'other_hostname' db_name
```

如果要从远程机器通过慢速网络复制数据库，可在本地执行：

```terminal
$ mysqladmin create db_name
$ mysqldump -h 'other_hostname' --compress db_name | mysql db_name
```

## 使用压缩文件传输

在源机器上：

```terminal
$ mysqldump --quick db_name | gzip > db_name.gz
```

把文件传输到目标机器后：

```terminal
$ mysqladmin create db_name
$ gunzip < db_name.gz | mysql db_name
```

## 使用 `mysqldump` 与 `mysqlimport`

对大型表，这种方法比仅使用 `mysqldump` 快得多。设 `DUMPDIR` 为存储输出的目录完整路径。

先创建目录并导出：

```terminal
$ mkdir DUMPDIR
$ mysqldump --tab=DUMPDIR db_name
```

把 `DUMPDIR` 中的文件传输到目标机器对应目录后，在目标机器加载：

```terminal
$ mysqladmin create db_name
$ cat DUMPDIR/*.sql | mysql db_name
$ mysqlimport db_name DUMPDIR/*.txt
```

不要忘记复制 `mysql` 数据库，因为授权表存储在其中。在新机器上的 `mysql` 数据库就位前，可能需要以 MySQL root 用户身份执行命令。导入 `mysql` 数据库后，执行以下命令让服务器重新加载授权表信息：

```terminal
$ mysqladmin flush-privileges
```
