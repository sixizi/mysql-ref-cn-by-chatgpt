# 3.2 升级路径

- 支持从 MySQL 5.7 升级到 MySQL 8.0。不过，仅支持在正式可用（GA）版本之间升级。对 MySQL 8.0，必须从 MySQL 5.7 GA 版本（5.7.9 或更高）升级；不支持从 MySQL 5.7 的非 GA 版本升级。
- 建议先升级到当前发布系列的最新版本，再升级到下一个版本。例如，升级到 MySQL 8.0 之前，先升级到最新的 MySQL 5.7 版本。
- 不支持跳过版本升级。例如，不支持直接从 MySQL 5.6 升级到 8.0。
- 发布系列进入 GA 状态后，支持在同一发布系列内从一个 GA 版本升级到另一个 GA 版本。例如，从 MySQL `8.0.x` 升级到 `8.0.y` 受支持；跳过某个小版本也受支持，例如从 `8.0.x` 升级到 `8.0.z`。
- MySQL 8.0.11 是 MySQL 8.0 发布系列中的第一个 GA 版本。
- 涉及开发状态非 GA 版本的升级不受支持。
