本章描述升级 MySQL 安装的步骤。升级是常见操作：你可能需要获取同一发布系列中的缺陷修复，或获取主要 MySQL 版本之间的重要新特性。应先在测试系统上执行升级，确认一切正常后再升级生产系统。

**说明**

本章中需要使用具有管理权限的 MySQL 账户执行的命令，在命令行中包含 `-u root` 来指定 MySQL root 用户。需要 root 密码的命令还包含 `-p` 选项。`-p` 后面没有选项值，因此命令会提示输入密码；在提示出现时输入密码并按 Enter。

可以使用 `mysql` 命令行客户端执行 SQL 语句。请以 root 身份连接，以确保具备所需权限：

```terminal
$ mysql -u root -p
```
