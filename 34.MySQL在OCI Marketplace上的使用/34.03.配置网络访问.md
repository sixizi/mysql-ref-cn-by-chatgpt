## 34.3 配置网络访问

关于 OCI 安全规则的信息，请参阅 Oracle 文档中的 “Security Rules”。

> **重要**
>
> 你必须在以下端口启用入站访问：
>
> - 22：SSH
> - 3306：MySQL
> - 33060：可选的 MySQL X Protocol，由 MySQL Shell 使用

------

官方英文版参见 [Configuring Network Access](https://dev.mysql.com/doc/refman/8.0/en/mysql-oci-marketplace-network-configuration.html)。
