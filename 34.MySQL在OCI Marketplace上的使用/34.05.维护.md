## 34.5 维护

该产品由用户自行管理，这意味着升级和维护由你负责。

### 升级 MySQL

现有安装基于 RPM。要升级 MySQL 服务器，请参阅本手册第 3.7 节 “在 Unix/Linux 上升级基于二进制文件或软件包的 MySQL 安装”。

你可以使用 `scp` 将所需的 RPM 复制到 OCI 计算实例；如果已配置对 OCI Object Storage 的访问，也可以从对象存储复制。文件存储也是一种选择。更多信息请参阅 Oracle 文档中的 “File Storage and NFS”。

### 备份和恢复

MySQL Enterprise Backup 是推荐的备份和恢复解决方案。更多信息请参阅 “Backing Up to Cloud Storage”。

关于 MySQL Enterprise Backup 的信息，请参阅 “Getting Started with MySQL Enterprise Backup”。

关于 MySQL 默认备份和恢复机制的信息，请参阅第 9 章 “备份和恢复”。
