### 34.5 维护

本产品是用户管理的，这意味着您负责升级和维护。

#### 升级 MySQL

现有安装是基于 RPM 的，要升级 MySQL 服务器，请参见第 3.7 节"在 Unix/Linux 上升级 MySQL 二进制或基于包的安装"。

您可以使用 scp 将所需的 RPM 复制到 OCI Compute Instance，或从 OCI Object Storage 复制（如果您已配置访问权限）。File Storage 也是一个选项。有关更多信息，请参见 File Storage 和 NFS。

#### 备份和恢复

MySQL Enterprise Backup 是首选的备份和恢复解决方案。有关更多信息，请参见备份到云存储。

有关 MySQL Enterprise Backup 的信息，请参见 MySQL Enterprise Backup 入门。

有关默认 MySQL 备份和恢复的信息，请参见第 9 章备份和恢复。
