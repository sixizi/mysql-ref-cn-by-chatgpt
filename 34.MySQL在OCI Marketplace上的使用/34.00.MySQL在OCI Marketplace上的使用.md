本章介绍如何将 MySQL Enterprise Edition 部署为 Oracle Cloud Infrastructure（OCI）Marketplace 应用。该产品采用 BYOL 授权模式。

> **注意**
>
> 关于 OCI Marketplace 的更多信息，请参阅 Oracle 文档中的 “Overview of Marketplace”。

MySQL Enterprise Edition Marketplace 应用是一个 OCI 计算实例，运行 Oracle Linux 7.9，并包含 MySQL EE 8.0。部署镜像上的 MySQL EE 安装方式与 Oracle RPM 软件包安装类似。

关于 MySQL Enterprise Edition 的更多信息，请参阅第 32 章 “MySQL Enterprise Edition”。

关于 MySQL 高级配置的更多信息，请参阅 “Secure Deployment Guide”。

关于 Oracle Linux 7 的更多信息，请参阅 Oracle Linux 文档。

该产品由用户自行管理，这意味着升级和维护由你负责。
