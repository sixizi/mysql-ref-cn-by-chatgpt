## 34.2 在 Oracle Cloud Infrastructure 上部署 MySQL EE

要在 Oracle Cloud Infrastructure 上部署 MySQL EE，请执行以下步骤：

1. 打开 OCI Marketplace 并选择 MySQL。

   系统会显示 MySQL 条目。

2. 点击 **Launch Instance**，开始应用启动流程。

   系统会显示 **Create Compute Instance** 对话框。

关于如何填写各个字段，请参阅 Oracle 文档中的 “To create a Linux instance”。默认情况下，MySQL 服务器监听 3306 端口，并配置了一个用户：`root`。

> **重要**
>
> 部署完成且 MySQL 服务器启动后，你必须连接到该计算实例，并从 MySQL 日志文件中获取写入其中的默认 `root` 密码。
>
> 更多信息请参见[使用 SSH 连接](./34.04.连接.md)。

以下 MySQL 软件已安装：

- MySQL Server EE
- MySQL Enterprise Backup
- MySQL Shell
- MySQL Router

### MySQL 配置

出于安全原因，以下组件已启用：

- SELinux：更多信息请参阅 Oracle 文档中的 “Configuring and Using SELinux”。
- `firewalld`：更多信息请参阅 Oracle 文档中的 “Controlling the firewalld Firewall Service”。

以下 MySQL 插件已启用：

- `thread_pool`
- `validate_password`

启动时会发生以下情况：

- MySQL Server 读取 `/etc/my.cnf` 以及 `/etc/my.cnf.d/` 目录中所有名称匹配 `*.cnf` 的文件。
- `/usr/bin/mkcnf` 会根据所选 OCI 实例形态创建 `/etc/my.cnf.d/perf-tuning.cnf`。

> **注意**
>
> 要禁用该机制，请移除 `/etc/systemd/system/mysqld.service.d/perf-tuning.conf`。

以下实例形态会配置性能调优：

- `VM.Standard2.1`
- `VM.Standard2.2`
- `VM.Standard2.4`
- `VM.Standard2.8`
- `VM.Standard2.16`
- `VM.Standard2.24`
- `VM.Standard.E2.1`
- `VM.Standard.E2.2`
- `VM.Standard.E2.4`
- `VM.Standard.E2.8`
- `VM.Standard.E3.Flex`
- `VM.Standard.E4.Flex`
- `BM.Standard2.52`

对于其他所有实例形态，使用 `VM.Standard2.1` 的调优配置。
