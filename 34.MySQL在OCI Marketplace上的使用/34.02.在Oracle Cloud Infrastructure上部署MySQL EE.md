### 34.2 在 Oracle Cloud Infrastructure 上部署 MySQL EE

要在 Oracle Cloud Infrastructure 上部署 MySQL EE，请执行以下操作：

1. 打开 OCI Marketplace 并搜索 MySQL。

   MySQL 列表将显示。

2. 选择 MySQL Enterprise Edition。

   MySQL Enterprise Edition 概览将显示。

3. 单击 Launch Instance 开始应用程序启动过程。

#### MySQL Configuration

创建计算实例对话框将显示。

有关如何完成字段的信息，请参阅 To create a Linux instance。

默认情况下，MySQL 服务器在端口 3306 上侦听，并配置有单个用户 root。

> **重要**
>
> 部署完成且 MySQL 服务器启动后，您必须连接到计算实例并检索默认 root 密码，该密码已写入 MySQL 日志文件。
>
> 有关更多信息，请参阅 Connecting with SSH。

安装了以下 MySQL 软件：

- MySQL Server EE

- MySQL Enterprise Backup

- MySQL Shell

- MySQL Router

#### MySQL Configuration

为了安全起见，启用了以下功能：

- SELinux：有关更多信息，请参阅 Configuring and Using SELinux

- firewalld：有关更多信息，请参阅 Controlling the firewalld Firewall Service

启用了以下 MySQL 插件：

- thread_pool

- validate_password

启动时，会发生以下情况：

- MySQL Server 读取 /etc/my.cnf 和 /etc/my.cnf.d/ 中所有名为 *.cnf 的文件。

- /etc/my.cnf.d/perf-tuning.cnf 由 /usr/bin/mkcnf 基于选定的 OCI shape 创建。

> **注意**
>
> 要禁用此机制，请删除 /etc/systemd/system/mysqld.service.d/perf-tuning.conf。

为以下 shape 配置了性能调优：

- VM.Standard2.1

- VM.Standard2.2

- VM.Standard2.4

- VM.Standard2.8

- VM.Standard2.16

#### Configuring Network Access

- VM.Standard2.24

- VM.Standard.E2.1

- VM.Standard.E2.2

- VM.Standard.E2.4

- VM.Standard.E2.8

- VM.Standard.E3.Flex

- VM.Standard.E4.Flex

- BM.Standard2.52

> **重要**
>
> 对于所有其他 shape，使用 VM.Standard2.1 的调优。
