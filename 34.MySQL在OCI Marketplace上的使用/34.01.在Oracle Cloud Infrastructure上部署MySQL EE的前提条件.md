## 34.1 在 Oracle Cloud Infrastructure 上部署 MySQL EE 的前提条件

以下假设成立：

- 你熟悉 OCI 术语。如果你刚开始使用 OCI，请先参阅 Oracle 文档中的 “Getting Started”。
- 你有权访问已正确配置的虚拟云网络（VCN）和子网。更多信息请参阅 “Virtual Networking”。
- 你拥有在租户的区间中部署 OCI Marketplace 应用所需的权限。更多信息请参阅 “How Policies Work”。
