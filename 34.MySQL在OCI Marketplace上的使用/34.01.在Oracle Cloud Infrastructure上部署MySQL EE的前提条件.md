本章介绍如何将 MySQL Enterprise Edition 部署为 Oracle Cloud Infrastructure (OCI) Marketplace 应用程序。这是一个 BYOL 产品。

注意

有关 OCI Marketplace 的更多信息，请参阅 Overview of Marketplace。

MySQL Enterprise Edition Marketplace 应用程序是一个 OCI 计算实例，运行 Oracle Linux 9.3，配备 MySQL EE 8.4。已部署镜像上的 MySQL EE 安装类似于 RPM 安装，如第 2.5.4 节"在 Linux 上使用 Oracle 提供的 RPM 包安装 MySQL"中所述。

有关 MySQL Enterprise Edition 的更多信息，请参阅第 32 章 MySQL Enterprise Edition。

有关 MySQL 高级配置的更多信息，请参阅 Secure Deployment Guide。

有关 Oracle Linux 9 的更多信息，请参阅 Oracle Linux Documentation

## 34.1 在 Oracle Cloud Infrastructure 上部署 MySQL EE 的前置条件

做出以下假设：

- 您熟悉 OCI 术语。如果您是 OCI 新手，请参阅 Getting Started。

- 您有权访问正确配置的虚拟云网络 (VCN) 和子网。有关更多信息，请参阅 Virtual Networking。

- 您拥有在租户的某个隔间中部署 OCI Marketplace 应用程序所需的权限。有关更多信息，请参阅 How Policies Work。
