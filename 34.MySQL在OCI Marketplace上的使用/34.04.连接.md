## 34.4 连接

本节介绍连接到 OCI 计算实例上已部署 MySQL 服务器的各种方法。

### 使用 SSH 连接

本节介绍从 Unix 类平台连接到 OCI 计算实例的部分细节。关于使用 SSH 连接的更多信息，请参阅 Oracle 文档中的 “Accessing an Oracle Linux Instance Using SSH” 和 “Connecting to Your Instance”。

要使用 SSH 连接到计算实例上运行的 Oracle Linux，请运行以下命令：

```terminal
ssh opc@computeIP
```

其中，`opc` 是计算实例用户，`computeIP` 是你的计算实例 IP 地址。

要查找为 `root` 用户创建的临时密码，请运行以下命令：

```terminal
sudo grep 'temporary password' /var/log/mysqld.log
```

要修改默认密码，请使用生成的临时密码登录服务器，命令如下：

```terminal
mysql -uroot -p
```

然后执行：

```sql
ALTER USER 'root'@'localhost' IDENTIFIED BY 'MyNewPass4!';
```

### 使用 MySQL 客户端连接

> **注意**
>
> 要从本地 MySQL 客户端连接，必须先在 MySQL 服务器上创建允许远程登录的用户。

要从本地 MySQL 客户端连接 MySQL 服务器，请在 shell 会话中运行以下命令：

```terminal
mysql -uroot -p -hcomputeIP
```

其中，`computeIP` 是你的计算实例 IP 地址。

### 使用 MySQL Shell 连接

要从本地 MySQL Shell 连接 MySQL 服务器，请运行以下命令启动 shell 会话：

```terminal
mysqlsh \connect root@computeIP
```

其中，`computeIP` 是你的计算实例 IP 地址。

关于 MySQL Shell 连接的更多信息，请参阅 MySQL Shell 文档中的 “MySQL Shell Connections”。

### 使用 Workbench 连接

要从 MySQL Workbench 连接 MySQL 服务器，请参阅 MySQL Workbench 文档中的 “Connections in MySQL Workbench”。
