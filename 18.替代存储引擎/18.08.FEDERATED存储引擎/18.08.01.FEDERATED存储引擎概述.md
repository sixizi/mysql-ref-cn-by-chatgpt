### 18.8.1 FEDERATED 存储引擎概述

普通表由表定义和数据组成；`FEDERATED` 表的表定义保存在本地服务器，但实际数据保存在远程服务器上。

一个 `FEDERATED` 表包含两个部分：

- **远程服务器**：保存实际表和数据。远程表可以是远程 `mysqld` 支持的任意存储引擎，例如 `MyISAM` 或 `InnoDB`。
- **本地服务器**：保存与远程表一致的表定义。本地没有数据文件，表定义中包含指向远程表的连接字符串。

对本地 `FEDERATED` 表执行查询或修改时，本应作用于本地数据文件的操作会被发送到远程服务器执行。

客户端访问 `FEDERATED` 表时的大致流程：

1. 本地存储引擎根据 `FEDERATED` 表的列构造指向远程表的 SQL 语句。
2. 通过 MySQL client API 把语句发送到远程服务器。
3. 远程服务器执行语句，本地服务器读取受影响行数或结果集。
4. 如果有结果集，本地服务器把各列转换为 `FEDERATED` 引擎使用的内部格式，再返回给客户端。

实现上，本地服务器通过 MySQL client C API 与远程服务器通信：使用 `mysql_real_query()` 发送语句，使用 `mysql_store_result()` 读取结果集，并用 `mysql_fetch_row()` 逐行取回数据。
