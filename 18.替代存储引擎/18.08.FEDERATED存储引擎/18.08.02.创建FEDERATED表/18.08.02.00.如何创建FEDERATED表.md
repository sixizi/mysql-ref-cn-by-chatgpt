### 18.8.2 如何创建 FEDERATED 表

创建 `FEDERATED` 表的基本步骤：

1. 在远程服务器上创建目标表，或使用 `SHOW CREATE TABLE` 记录已有表的定义。
2. 在本地服务器上创建结构完全相同的表，并添加连接远程表的连接信息。

远程服务器上的示例表：

```sql
CREATE TABLE test_table (
  id INT(20) NOT NULL AUTO_INCREMENT,
  name VARCHAR(32) NOT NULL DEFAULT '',
  other INT(20) NOT NULL DEFAULT '0',
  PRIMARY KEY (id),
  INDEX name (name),
  INDEX other_key (other)
) ENGINE=MyISAM
  DEFAULT CHARSET=utf8mb4;
```

本地表可以通过两种方式指向远程表：

- 在 `CREATE TABLE` 中使用 `CONNECTION` 字符串。
- 先用 `CREATE SERVER` 保存连接参数，再在 `CONNECTION` 中引用该服务器名。

**重要**：本地表的列定义必须与远程表完全相同。

在远程主机上为表添加索引可以提升 `FEDERATED` 查询性能。MySQL 会把 `WHERE` 条件发送到远程服务器执行，从而减少从远程传回整张表的数据量。
