### 18.8.2.2 使用 CREATE SERVER 创建 FEDERATED 表

如果同一台远程服务器上要创建多个 `FEDERATED` 表，可以先用 `CREATE SERVER` 统一定义连接参数。

```sql
CREATE SERVER server_name
  FOREIGN DATA WRAPPER wrapper_name
  OPTIONS (option [, option] ...);
```

与 `CONNECTION='mysql://fed_user@remote_host:9306/federated/test_table'` 等价的定义：

```sql
CREATE SERVER fedlink
  FOREIGN DATA WRAPPER mysql
  OPTIONS (
    USER 'fed_user',
    HOST 'remote_host',
    PORT 9306,
    DATABASE 'federated'
  );
```

创建 `FEDERATED` 表时仍使用 `CONNECTION`，但值为服务器名和远程表名：

```sql
CREATE TABLE test_table (
  id INT(20) NOT NULL AUTO_INCREMENT,
  name VARCHAR(32) NOT NULL DEFAULT '',
  other INT(20) NOT NULL DEFAULT '0',
  PRIMARY KEY (id),
  INDEX name (name),
  INDEX other_key (other)
) ENGINE=FEDERATED
  DEFAULT CHARSET=utf8mb4
  CONNECTION='fedlink/test_table';
```

如果 `CONNECTION` 中只写服务器名，例如 `'fedlink'`，远程表名会使用本地表名。

`CREATE SERVER` 会更新 `mysql.servers` 表，各参数的对应关系如下：

| 含义 | `CONNECTION` 字段 | `CREATE SERVER` 选项 | `mysql.servers` 列 |
|---|---|---|---|
| 连接协议 | `scheme` | `wrapper_name` | `Wrapper` |
| 远程用户 | `user_name` | `USER` | `Username` |
| 远程密码 | `password` | `PASSWORD` | `Password` |
| 远程主机 | `host_name` | `HOST` | `Host` |
| 远程端口 | `port_num` | `PORT` | `Port` |
| 远程数据库 | `db_name` | `DATABASE` | `Db` |
