### 18.8.2.1 使用 CONNECTION 创建 FEDERATED 表

可以在 `CREATE TABLE` 的存储引擎定义之后使用 `CONNECTION` 字符串：

```sql
CREATE TABLE federated_table (
  id INT(20) NOT NULL AUTO_INCREMENT,
  name VARCHAR(32) NOT NULL DEFAULT '',
  other INT(20) NOT NULL DEFAULT '0',
  PRIMARY KEY (id),
  INDEX name (name),
  INDEX other_key (other)
) ENGINE=FEDERATED
  DEFAULT CHARSET=utf8mb4
  CONNECTION='mysql://fed_user@remote_host:9306/federated/test_table';
```

`CONNECTION` 取代了早期 MySQL 版本中使用的 `COMMENT`。

连接字符串格式：

```text
scheme://user_name[:password]@host_name[:port_num]/db_name/tbl_name
```

字段含义：

| 字段 | 含义 |
|---|---|
| `scheme` | 连接协议，目前仅支持 `mysql` |
| `user_name` | 远程服务器上的用户名，需要拥有目标表所需权限 |
| `password` | 可选，对应用户密码 |
| `host_name` | 远程主机名或 IP 地址 |
| `port_num` | 可选端口，默认 `3306` |
| `db_name` | 远程表所在数据库 |
| `tbl_name` | 远程表名，可与本地表名不同 |

示例：

```sql
CONNECTION='mysql://username:password@hostname:port/database/tablename'
CONNECTION='mysql://username@hostname/database/tablename'
CONNECTION='mysql://username:password@hostname/database/tablename'
```
