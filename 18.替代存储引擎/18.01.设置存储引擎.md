## 18.1 设置存储引擎

创建新表时，可以在 `CREATE TABLE` 中用 `ENGINE` 表选项显式指定存储引擎：

```sql
-- MySQL 8.0 默认就是 InnoDB；只有修改过默认引擎时才需要显式指定。
CREATE TABLE t1 (i INT) ENGINE = INNODB;

-- 同一列定义可以切换到其他引擎。
CREATE TABLE t2 (i INT) ENGINE = CSV;
CREATE TABLE t3 (i INT) ENGINE = MEMORY;
```

省略 `ENGINE` 时，MySQL 使用默认存储引擎。MySQL 8.0 的默认引擎是 `InnoDB`。

可以通过以下方式设置或查看默认引擎：

- 服务器启动选项：`--default-storage-engine`
- 配置文件选项：`default-storage-engine`
- 当前会话变量：`default_storage_engine`

```sql
SET default_storage_engine = NDBCLUSTER;
```

如果使用 `CREATE TEMPORARY TABLE`，临时表的默认引擎可以用 `default_tmp_storage_engine` 单独设置，既能在启动时配置，也能在运行时修改。

要把已有表转换为其他存储引擎，使用 `ALTER TABLE` 指定新的引擎：

```sql
ALTER TABLE t ENGINE = InnoDB;
```

如果请求的存储引擎不可用或未编译进服务器，MySQL 会回退到默认存储引擎。默认情况下，`CREATE TABLE` 或 `ALTER TABLE` 遇到这种替换只产生警告。为了避免这种隐式替换，可以启用 `NO_ENGINE_SUBSTITUTION` SQL 模式；启用后，如果指定引擎不可用，语句会报错，而不是改用默认引擎。

表和列定义保存在 MySQL 数据字典中。各个存储引擎会按自己的方式创建所需的额外文件，例如数据文件或索引文件。
