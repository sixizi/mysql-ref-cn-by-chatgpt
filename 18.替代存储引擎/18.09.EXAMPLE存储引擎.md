### 18.9 EXAMPLE 存储引擎

`EXAMPLE` 是一个不执行任何操作的存根存储引擎，主要用于在 MySQL 源码中示范如何编写新的存储引擎，主要面向开发者。

如果从源码构建 MySQL，可以在 `CMake` 中使用以下选项包含该引擎：

```sh
-DWITH_EXAMPLE_STORAGE_ENGINE
```

源码位于 MySQL 源码发行版的 `storage/example` 目录。

示例：

```sql
CREATE TABLE test (i INT) ENGINE = EXAMPLE;
INSERT INTO test VALUES (1),(2),(3);
SELECT * FROM test;
```

创建 `EXAMPLE` 表不会生成文件，不能写入数据，查询总是返回空结果。`INSERT` 会报错：

```text
ERROR 1031 (HY000): Table storage engine for 'test' doesn't have this option
```

该引擎不支持索引和分区。
