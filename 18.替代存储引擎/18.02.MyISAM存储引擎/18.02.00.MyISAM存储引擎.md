`MyISAM` 基于早期的 `ISAM` 存储引擎并做了大量扩展。它不提供事务、行级锁或外键支持，但结构简单、存储占用小，常用于只读或读多写少的 Web、数据仓库等场景。

### 主要特性

| 特性 | 支持情况 |
|---|---|
| B-tree 索引 | 支持 |
| 备份 / 时间点恢复 | 由服务器层实现，支持 |
| 聚簇索引 | 不支持 |
| 压缩数据 | 支持压缩行格式，压缩表只读 |
| 数据缓存 | 不支持 |
| 加密数据 | 通过服务器层加密函数实现，支持 |
| 外键 | 不支持 |
| 全文索引 | 支持 |
| 空间数据类型和空间索引 | 支持 |
| Hash 索引 | 不支持 |
| 索引缓存 | 支持 |
| 锁粒度 | 表级 |
| MVCC | 不支持 |
| 复制 | 由服务器层实现，支持 |
| 存储上限 | 256TB |
| 事务 | 不支持 |

每个 `MyISAM` 表在磁盘上由两个文件组成：

- `.MYD`：数据文件
- `.MYI`：索引文件

表和列定义保存在 MySQL 数据字典中，而不是 `MyISAM` 自己的文件里。

显式创建 `MyISAM` 表的方式如下：

```sql
CREATE TABLE t (i INT) ENGINE = MYISAM;
```

MySQL 8.0 的默认引擎是 `InnoDB`，因此要创建 `MyISAM` 表通常需要显式写 `ENGINE=MYISAM`。

可以用 `mysqlcheck` 或 `myisamchk` 检查、修复 `MyISAM` 表，也可以用 `myisampack` 压缩表以节省空间。
