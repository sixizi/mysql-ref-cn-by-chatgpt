##### 18.2.4.1 损坏的 MyISAM 表

`MyISAM` 表在正常情况下是可靠的：SQL 语句返回之前，服务器会完成该语句涉及的所有表修改。但以下情况仍可能导致表损坏：

- `mysqld` 在写入过程中被杀死
- 计算机意外关机或重启
- 硬件故障
- 外部程序（例如 `myisamchk`）在服务器同时修改表时访问并修改该表
- MySQL 或 `MyISAM` 代码存在缺陷

典型症状包括：

- 查询表时报出 `Incorrect key file for table: '...'`
- 查询找不到本应存在的行
- 查询返回不完整结果

可用的检查和修复手段：

```sql
CHECK TABLE t;
REPAIR TABLE t;
```

服务器停止时，也可以使用：

```terminal
myisamchk t
myisamchk -r t
```

如果表经常损坏，应先查看错误日志中是否有 `restarted mysqld` 记录，判断损坏是否由服务器异常退出引起。如果没有服务器重启记录，则更可能是正常使用中出现的缺陷，应尝试构造可复现的测试用例。
