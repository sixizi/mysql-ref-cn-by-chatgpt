##### 18.2.4.2 表未正确关闭导致的问题

每个 `MyISAM` 索引文件（`.MYI`）的头部都有一个计数器，用于判断表是否被正确关闭。如果 `CHECK TABLE` 或 `myisamchk` 报出下面这类警告：

```text
clients are using or haven't closed the table properly
```

说明该计数器与实际状态不一致。这不一定代表表已损坏，但应进一步检查表。

计数器的工作方式：

1. 表第一次被更新时，索引文件头部的计数器加 1。
2. 后续更新不再修改该计数器。
3. 表最后一次被关闭时，如果期间发生过更新，计数器减 1。
4. 修复或检查确认表正常后，计数器会重置为 0。

计数器可能失真的常见情况包括：

- 在没有执行 `LOCK TABLES` 和 `FLUSH TABLES` 的情况下复制表
- MySQL 在一次更新和最终关闭之间崩溃
- 在服务器正在使用表时运行 `myisamchk --recover` 或 `myisamchk --update-state`
- 多个 `mysqld` 共享同一个数据目录，其中一个服务器对正在使用的表执行 `REPAIR TABLE` 或 `CHECK TABLE`

通常不建议多个 `mysqld` 实例共享同一数据目录。如果必须这样做，应避免在表正被其他服务器使用时执行 `REPAIR TABLE`。
