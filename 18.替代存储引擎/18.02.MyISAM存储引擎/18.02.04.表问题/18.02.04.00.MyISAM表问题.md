#### 18.2.4 MyISAM 表问题

**目录**

- [18.2.4.1 损坏的 MyISAM 表](./18.02.04.01.损坏的MyISAM表.md)
- [18.2.4.2 表未正确关闭导致的问题](./18.02.04.02.表未正确关闭导致的问题.md)

MySQL 的文件格式经过了大量测试，但在某些情况下表仍可能损坏。常见诱因包括：

- `mysqld` 在写入过程中被强制终止
- 服务器或主机意外断电
- 硬件故障
- 外部程序同时修改服务器正在使用的表
- MySQL 或 `MyISAM` 代码中的缺陷

如果表损坏，常见症状是查询返回错误或不完整结果，例如：

```text
Incorrect key file for table: '...'. Try to repair it
```

可以使用 `CHECK TABLE`、`REPAIR TABLE` 或 `myisamchk` 检查和修复 `MyISAM` 表。
