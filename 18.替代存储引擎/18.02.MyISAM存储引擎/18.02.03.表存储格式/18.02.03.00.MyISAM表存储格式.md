#### 18.2.3 MyISAM 表存储格式

- [18.2.3.2 动态表特征](./18.02.03.02.动态表特征.md)

`MyISAM` 支持三种存储格式：

| 格式 | 选择方式 |
|---|---|
| 静态 / 固定长度 | 默认格式，用于没有变长列的表 |
| 动态 | 表中包含 `VARCHAR`、`VARBINARY`、`BLOB` 或 `TEXT` 时自动使用 |
| 压缩 | 只能由 `myisampack` 工具生成，表为只读 |

对没有 `BLOB` 或 `TEXT` 列的表，可以在 `CREATE TABLE` 或 `ALTER TABLE` 中用 `ROW_FORMAT` 强制指定 `FIXED` 或 `DYNAMIC`：

```sql
CREATE TABLE t (
  id INT,
  name VARCHAR(100)
) ENGINE=MYISAM
  ROW_FORMAT=DYNAMIC;
```

压缩表可以用 `myisamchk --unpack` 解压缩。
