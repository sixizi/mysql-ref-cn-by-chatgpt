## 18.4 CSV 存储引擎

**目录**

- [18.4.1 修复和检查 CSV 表](./18.04.01.修复和检查CSV表.md)
- [18.4.2 CSV 限制](./18.04.02.CSV限制.md)

`CSV` 存储引擎用逗号分隔值文本文件保存数据。该引擎总是被编译进 MySQL 服务器。

创建 `CSV` 表时，服务器会在数据库目录中创建一个以表名开头、扩展名为 `.CSV` 的纯文本数据文件。插入或更新数据时，引擎会把结果以 CSV 格式写入该文件。

```sql
CREATE TABLE test (
  i INT NOT NULL,
  c CHAR(10) NOT NULL
) ENGINE=CSV;

INSERT INTO test VALUES (1, 'record one'), (2, 'record two');

SELECT * FROM test;
```

对应 `test.CSV` 文件的内容形如：

```csv
"1","record one"
"2","record two"
```

除了数据文件，服务器还会创建一个同名 `.CSM` 元数据文件，用于记录表状态和行数。

这种格式可以直接被电子表格软件读取，甚至写入，适合和其他脚本或应用交换数据。
