### 18.4.1 修复和检查 CSV 表

`CSV` 存储引擎支持 `CHECK TABLE` 和 `REPAIR TABLE`。

`CHECK TABLE` 会检查：

- 字段分隔符是否正确
- 转义字段是否正确配对，引号是否匹配
- 每行字段数量是否与表定义一致
- 是否存在对应的 `.CSM` 元数据文件

检查到第一行无效数据时立即返回错误。例如：

```sql
CHECK TABLE csvtest;
```

正常结果示例：

```text
test.csvtest  check  status  OK
```

损坏表的结果示例：

```text
test.csvtest  check  error  Corrupt
```

`REPAIR TABLE` 会从现有 `CSV` 文件中复制尽可能多的有效行，然后用恢复出的行替换原文件。第一个损坏行之后的所有行都会被丢弃，即使其中还有有效数据。

```sql
REPAIR TABLE csvtest;
```

因此，修复前应先备份原始 `.CSV` 文件，以防需要手工恢复更多数据。
