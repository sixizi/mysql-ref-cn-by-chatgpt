## 18.11 存储引擎架构概述

**目录**

- [18.11.1 可插拔存储引擎架构](./18.11.01.可插拔存储引擎架构.md)
- [18.11.2 通用数据库服务器层](./18.11.02.通用数据库服务器层.md)

MySQL 的可插拔存储引擎架构允许数据库开发人员为特定应用需求选择专用存储引擎，同时避免把底层存储实现细节暴露给应用代码。

MySQL Server 把应用开发者和 DBA 与存储层的底层实现隔离开，提供一致的应用模型和 API。因此，即使不同存储引擎的能力不同，应用也不需要直接感知这些差异。

可插拔架构提供所有存储引擎共用的管理和支持服务；存储引擎本身负责对底层物理数据执行实际操作。

这种模块化设计适合数据仓库、事务处理、高可用等不同场景。应用需求和存储引擎改变时，通常不需要大幅修改代码或业务流程，因为 MySQL Server 会用统一的 API 屏蔽存储引擎复杂度。
