### 18.11.1 可插拔存储引擎架构

MySQL Server 使用可插拔存储引擎架构，可以在运行中的服务器上加载或卸载存储引擎。

**加载存储引擎**

使用存储引擎前，需要先用 `INSTALL PLUGIN` 加载其插件共享库。例如 `EXAMPLE` 引擎插件名为 `example`，共享库为 `ha_example.so`：

```sql
INSTALL PLUGIN example SONAME 'ha_example.so';
```

要求：

- 插件文件必须位于 MySQL 插件目录，目录由系统变量 `plugin_dir` 指定。
- 执行 `INSTALL PLUGIN` 的用户必须拥有 `mysql.plugin` 表的 `INSERT` 权限。

**卸载存储引擎**

```sql
UNINSTALL PLUGIN example;
```

如果卸载仍被现有表使用的存储引擎，这些表会变得不可访问，但仍保留在磁盘上（如果适用）。卸载前应确认没有表使用该存储引擎。
