## 18.7 MERGE 存储引擎

**目录**

- [18.7.1 MERGE 表的优点和缺点](./18.07.01.MERGE表的优点和缺点.md)
- [18.7.2 MERGE 表问题](./18.07.02.MERGE表问题.md)

`MERGE` 存储引擎（也称为 `MRG_MyISAM`）把一组结构完全相同的 `MyISAM` 表作为一个逻辑表使用。

“完全相同”要求：

- 列的数据类型一致
- 列的顺序一致
- 索引的定义和顺序一致

但以下差异不影响合并：

- 对应列或索引的名称可以不同
- 表、列或索引的注释可以不同
- `AVG_ROW_LENGTH`、`MAX_ROWS`、`PACK_KEYS` 等表选项可以不同

创建 `MERGE` 表时，MySQL 会创建一个 `.MRG` 文件，其中记录了底层 `MyISAM` 表的名称。底层表不必和 `MERGE` 表位于同一数据库中。

基本语法：

```sql
CREATE TABLE t1 (
  a INT NOT NULL AUTO_INCREMENT PRIMARY KEY,
  message CHAR(20)
) ENGINE=MyISAM;

CREATE TABLE t2 (
  a INT NOT NULL AUTO_INCREMENT PRIMARY KEY,
  message CHAR(20)
) ENGINE=MyISAM;

CREATE TABLE total (
  a INT NOT NULL AUTO_INCREMENT,
  message CHAR(20),
  INDEX(a)
) ENGINE=MERGE
  UNION=(t1,t2)
  INSERT_METHOD=LAST;
```

`UNION` 指定要合并的底层表。`INSERT_METHOD` 决定插入位置：

| 值 | 含义 |
|---|---|
| `FIRST` | 插入第一个底层表 |
| `LAST` | 插入最后一个底层表 |
| `NO` 或省略 | 不允许插入 |

对 `MERGE` 表执行 `DROP TABLE` 只会删除逻辑映射，不会删除底层 `MyISAM` 表。
