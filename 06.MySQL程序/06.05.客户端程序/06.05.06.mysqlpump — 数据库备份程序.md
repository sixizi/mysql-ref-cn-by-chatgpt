### 6.5.6 mysqlshow — 显示数据库、表和列信息

mysqlshow 客户端可用于快速查看存在哪些数据库、它们的表，或表的列或索引。

mysqlshow 提供了一个命令行界面来执行多个 SQL SHOW 语句。参见第 15.7.7 节"SHOW 语句"。也可以通过直接使用这些语句获得相同的信息。例如，可以从 mysql 客户端程序发出这些语句。

调用 mysqlshow 的方式如下：

```
mysqlshow [options] [db_name [tbl_name [col_name]]]
```

- 如果未给定数据库，则显示数据库名称列表。

- 如果未给定表，则显示数据库中所有匹配的表。

- 如果未给定列，则显示表中所有匹配的列和列类型。

输出仅显示你拥有某些权限的数据库、表或列的名称。

如果最后一个参数包含 shell 或 SQL 通配符字符（*、?、% 或 _），则仅显示与通配符匹配的名称。如果数据库名称包含任何下划线，应使用反斜杠转义这些下划线（某些 Unix shell 需要两个反斜杠）以获得正确的表或列列表。* 和 ? 字符被转换为 SQL % 和 _ 通配符。当尝试显示名称中包含 _ 的表的列时，这可能会导致一些混淆，因为在这种情况下，mysqlshow 仅显示与该模式匹配的表名。通过在命令行末尾添加额外的 % 作为单独的参数，可以轻松解决此问题。

  要明确指定没有密码且 mysqlshow 不应提示输入密码，使用 --skip-password1 选项。

  --password1 和 --password 是同义词，--skip-password1 和 --skip-password 也是如此。

- --ssl-fips-mode={OFF|ON|STRICT}

  命令行格式：--ssl-fips-mode={OFF|ON|STRICT}

  已弃用：是

  类型：Enumeration

  默认值：OFF

  有效值：OFF、ON、STRICT

  控制是否在客户端启用 FIPS 模式。--ssl-fips-mode 选项与其他 --ssl-xxx 选项的不同之处在于它不用于建立加密连接，而是用于影响允许哪些密码操作。参见第 8.8 节"FIPS 支持"。

  允许以下 --ssl-fips-mode 值：

  - OFF：禁用 FIPS 模式。

  - ON：启用 FIPS 模式。

  - STRICT：启用"严格" FIPS 模式。

  注意

  如果 OpenSSL FIPS 对象模块不可用，--ssl-fips-mode 唯一允许的值是 OFF。在这种情况下，将 --ssl-fips-mode 设置为 ON 或 STRICT 会导致客户端在启动时产生警告并以非 FIPS 模式运行。

  此选项已弃用。预计在 MySQL 的未来版本中将其删除。

  命令行格式：--tls-sni-servername=server_name

  类型：String

  服务器名称指示 (SNI) 是 TLS 协议的扩展（必须使用 TLS 扩展编译 OpenSSL 才能使此选项起作用）。MySQL 的 SNI 实现仅代表客户端。

  TLSv1,TLSv1.1,TLSv1.2（否则）

  加密连接允许的 TLS 协议。该值是一个或多个逗号分隔的协议名称的列表。可以为此选项命名的协议取决于用于编译 MySQL 的 SSL 库。有关详细信息，参见第 8.3.2 节"加密连接 TLS 协议和密码"。

- --user=user_name, -u user_name

  命令行格式：--user=user_name,

  类型：String

  用于连接到服务器的 MySQL 帐户的用户名。

- --verbose, -v

  命令行格式：--verbose

  详细模式。打印有关程序执行操作的更多信息。此选项可多次使用以增加信息量。

- --version, -V

  命令行格式：--version

  显示版本信息并退出。

- --zstd-compression-level=level

  类型：Integer

  用于连接到使用 zstd 压缩算法的服务器的压缩级别。允许的级别为 1 到 22，较大的值表示压缩级别越来越高。默认 zstd 压缩级别为 3。压缩级别设置对不使用 zstd 压缩的连接没有影响。

  有关更多信息，参见第 6.2.8 节"连接压缩控制"。
