### 6.6.4.3 myisamchk 修复选项

myisamchk 支持以下选项用于表修复操作（在给定 --recover 或 --safe-recover 等选项时执行的操作）：

- --backup, -B

  命令行格式：--backup

  将 .MYD 文件备份为 file_name-time.BAK

- --character-sets-dir=dir_name

  命令行格式：--character-sets-dir=path
  类型：String
  默认值：[none]

  字符集安装的目录。参见第 12.15 节"字符集配置"。

- --correct-checksum

  命令行格式：--correct-checksum

  修正表的校验和信息。

- --data-file-length=len, -D len

  命令行格式：--data-file-length=len
  类型：Numeric

  数据文件的最大长度（当数据文件"满"时重新创建数据文件）。

- --extend-check, -e

  命令行格式：--extend-check

  执行修复操作，尝试从数据文件中恢复每一行可能的数据。通常，这也会找到很多垃圾行。除非你别无选择，否则不要使用此选项。

  另请参见表检查选项下对此选项的描述。

  有关输出格式的说明，请参见第 6.6.4.5 节"使用 myisamchk 获取表信息"。

- --force, -f

  命令行格式：--force

  覆盖旧的中间文件（名称如 tbl_name.TMD 的文件），而不是中止。

- --keys-used=val, -k val

  命令行格式：--keys-used=val
  类型：Numeric

  对于 myisamchk，选项值是一个位值，表示要更新哪些索引。选项值的每个二进制位对应一个表索引，其中第一个索引是位 0。选项值 0 禁用对所有索引的更新，可用于加快插入速度。停用的索引可以通过使用 myisamchk -r 重新激活。

- --max-record-length=len

  命令行格式：--max-record-length=len
  类型：Numeric

  如果 myisamchk 无法分配内存来保存大于给定长度的行，则跳过这些行。

- --quick, -q

  命令行格式：--quick

  通过仅修改索引文件而不修改数据文件来实现更快的修复。可以指定此选项两次，以强制 myisamchk 在存在重复键的情况下修改原始数据文件。

- --recover, -r

  命令行格式：--recover

  执行可以修复几乎所有问题的修复，除了不唯一的唯一键（这是 MyISAM 表中极其不可能的错误）。如果要恢复表，这是首先要尝试的选项。只有当 myisamchk 报告无法使用 --recover 恢复表时，才应尝试 --safe-recover。（在 --recover 失败的极不可能的情况下，数据文件保持完整。）

  如果你有大量内存，应该增加 myisam_sort_buffer_size 的值。

- --safe-recover, -o

  命令行格式：--safe-recover

  使用旧的恢复方法执行修复，该方法按顺序读取所有行，并根据找到的行更新所有索引树。这比 --recover 慢一个数量级，但可以处理 --recover 无法处理的几个极其不可能的情况。此恢复方法也使用的磁盘空间远少于 --recover。通常，应该首先使用 --recover 进行修复，然后仅在 --recover 失败时使用 --safe-recover。

  如果你有大量内存，应该增加 key_buffer_size 的值。

- --set-collation=name

  命令行格式：--set-collation=name
  类型：String

  指定用于排序表索引的排序规则。字符集名称由排序规则名称的第一部分隐含。

- --sort-recover, -n

  命令行格式：--sort-recover

  强制 myisamchk 使用排序来解析键，即使临时文件会非常大。

- --tmpdir=dir_name, -t dir_name

  命令行格式：--tmpdir=dir_name
  类型：Directory name

  用于存储临时文件的目录的路径。如果未设置此项，myisamchk 使用 TMPDIR 环境变量的值。--tmpdir 可以设置为目录路径列表，这些路径以轮询方式依次用于创建临时文件。目录名称之间的分隔符在 Unix 上是冒号 (:)，在 Windows 上是分号 (;)。

- --unpack, -u

  命令行格式：--unpack

  解包使用 myisampack 打包的表。
