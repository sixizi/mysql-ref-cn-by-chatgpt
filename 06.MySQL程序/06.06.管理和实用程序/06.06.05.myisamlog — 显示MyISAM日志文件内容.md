### 6.6.5 myisamlog — 显示 MyISAM 日志文件内容

myisamlog 处理 MyISAM 日志文件的内容。要创建这样的文件，请使用 --log-isam=log_file 选项启动服务器。

myisampack — 生成压缩的只读 MyISAM 表

调用 myisamlog 的方式如下：

myisamlog [options] [file_name [tbl_name] ...]

默认操作是更新 (-u)。如果执行恢复操作 (-r)，则执行所有写入以及可能的更新和删除，错误仅被计数。如果未给定 log_file 参数，默认日志文件名为 myisam.log。如果在命令行上指定了表名，则仅更新这些表。

myisamlog 支持以下选项：

- -?, -I

  显示帮助消息并退出。

- -c N

  仅执行 N 条命令。

- -f N

  指定最大打开文件数。

- -F filepath/

  指定文件路径，末尾带有斜杠。

- -i

  退出前显示额外信息。

- -o offset

  指定起始偏移量。

- -p N

  从路径中移除 N 个组件。

- -r

  执行恢复操作。

- -R record_pos_file record_pos

  指定记录位置文件和记录位置。

- -u

  执行更新操作。

- -v

  详细模式。打印有关程序执行操作的更多输出。此选项可以多次给定以产生越来越多的输出。

- -w write_file

  指定写入文件。

- -V

  显示版本信息。
