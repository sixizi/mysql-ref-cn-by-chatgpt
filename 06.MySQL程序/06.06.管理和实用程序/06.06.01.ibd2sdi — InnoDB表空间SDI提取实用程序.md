### 6.6.1 ibd2sdi — InnoDB 表空间 SDI 提取工具

ibd2sdi 是一个从 InnoDB 表空间文件中提取序列化字典信息 (SDI) 的工具。

SDI 数据存在于所有持久化的 InnoDB 表空间文件中。

ibd2sdi 可以在文件表表空间文件 (*.ibd 文件)、通用表空间文件 (*.ibd 文件)、系统表空间文件 (ibdata* 文件) 和数据字典表空间 (mysql.ibd) 上运行。不支持用于临时表空间或撤销表空间。

ibd2sdi 可以在运行时或服务器离线时使用。在 DDL 操作、ROLLBACK 操作以及与 SDI 相关的撤销日志清除操作期间，可能会有一个短时间间隔，在此期间 ibd2sdi 无法读取存储在表空间中的 SDI 数据。

ibd2sdi 对表空间中的 SDI 执行未提交的读取。不访问重做日志和撤销日志。

调用 ibd2sdi 工具的方式如下：

ibd2sdi [options] file_name1 [file_name2 file_name3 ...]

ibd2sdi 支持多文件表空间，如 InnoDB 系统表空间，但一次只能在一个表空间上运行。对于多文件表空间，请按顺序指定每个文件：

ibd2sdi ibdata1 ibdata2

多文件表空间的文件必须按升序页码顺序指定。如果两个连续的文件具有相同的空间 ID，则后面的文件必须从前一个文件的最后一个页码 + 1 开始。

ibd2sdi 以 JSON 格式输出 SDI（包含 id、type 和 data 字段）。

## ibd2sdi 选项

ibd2sdi 支持以下选项：

- --help, -h

  命令行格式：--help

  类型：Boolean

  默认值：false

  显示帮助消息并退出。例如：

  Usage: ./ibd2sdi [-v] [-c <strict-check>] [-d <dump file name>] [-n] filename1 [filenames]

ibd2sdi — InnoDB 表空间 SDI 提取工具

  参见 http://dev.mysql.com/doc/refman/26.10/en/ibd2sdi.html 获取使用提示。

  -h, --help           显示此帮助并退出。

  -v, --version        显示版本信息并退出。

  -#, --debug[=name]   输出调试日志。参见 http://dev.mysql.com/doc/refman/26.10/en/dbug-package.html

  -d, --dump-file=name
                       将表空间 SDI 转储到用户传递的文件中。
                       如果不指定文件名，将默认输出到标准输出

  -s, --skip-data      跳过从 SDI 记录中检索数据。仅检索 id 和 type。

  -i, --id=#           检索与用户传递的 id 匹配的 SDI 记录。

  -t, --type=#         检索与用户传递的 type 匹配的 SDI 记录。

  -c, --strict-check=name
                       由用户指定严格的校验和算法。
                       允许的值为 innodb、crc32、none。

  -n, --no-check       忽略校验和验证。

  -p, --pretty         对 SDI 输出进行美化格式化。如果为 false，SDI 将不可读但大小会更小
                       （默认为开启；使用 --skip-pretty 禁用。）

  变量 (--variable-name=value)
  和布尔选项 {FALSE|TRUE} 值（读取选项后）
  --------------------------------- ----------------------------------------
  debug                             （无默认值）
  dump-file                         （无默认值）
  skip-data                         FALSE
  id                                0
  type                              0
  strict-check                      crc32
  no-check                          FALSE
  pretty                            TRUE

- --version, -v

  命令行格式：--version

  类型：Boolean

  默认值：false

  显示版本信息并退出。例如：

  ibd2sdi   Ver 26.10.0 for Linux on x86_64 (Source distribution)

- --debug[=debug_options], -# [debug_options]

  命令行格式：--debug=options

  类型：String

  默认值：[none]

  打印调试日志。有关调试选项，请参见第 7.9.4 节"DBUG 包"。

  ibd2sdi --debug=d:t /tmp/ibd2sdi.trace

  此选项仅在使用 WITH_DEBUG 构建 MySQL 时可用。Oracle 提供的 MySQL 发行版二进制文件不使用此选项构建。

- --dump-file=, -d

  命令行格式：--dump-file=file

  类型：File name

  默认值：[none]

  将序列化字典信息 (SDI) 转储到指定的转储文件中。如果未指定转储文件，表空间 SDI 将转储到标准输出。

  ibd2sdi --dump-file=file_name ../data/test/t1.ibd

- --skip-data, -s

  命令行格式：--skip-data

  类型：Boolean

  默认值：false

  跳过从序列化字典信息 (SDI) 中检索数据字段值，仅检索 id 和 type 字段值，这些是 SDI 记录的主键。

  $> ibd2sdi --skip-data ../data/test/t1.ibd
  ["ibd2sdi"
  ,
  {
    "type": 1,
    "id": 330
  }
  ,
  {
    "type": 2,
    "id": 7
  }
  ]

- --id=#, -i #

  命令行格式：--id=#

  类型：Integer

  默认值：0

  检索与指定的表或表空间对象 id 匹配的序列化字典信息 (SDI)。对象 id 对于对象类型是唯一的。表和表空间对象 ID 也可以在 mysql.tables 和 mysql.tablespace 数据字典表的 id 列中找到。有关数据字典表的信息，请参见第 16.1 节"数据字典架构"。

  $> ibd2sdi --id=7 ../data/test/t1.ibd
  ["ibd2sdi"
  ,
  {
    "type": 2,
    "id": 7,
    "object":
     {
       "mysqld_version_id": 80003,
       "dd_version": 80003,
       "sdi_version": 1,
       "dd_object_type": "Tablespace",
       "dd_object": {
           "name": "test/t1",
           "comment": "",
           "options": "",
           "se_private_data": "flags=16417;id=2;server_version=80003;space_version=1;",
           "engine": "InnoDB",
           "files": [
               {
                   "ordinal_position": 1,
                   "filename": "./test/t1.ibd",
                   "se_private_data": "id=2;"
               }
           ]
       }
   }
  }
  ]

- --type=#, -t #

  命令行格式：--type=#

  类型：Enumeration

  默认值：0

  有效值：1

  检索与指定对象类型匹配的序列化字典信息 (SDI)。为表 (type=1) 和表空间 (type=2) 对象提供 SDI。

  此示例显示测试数据库中表空间 ts1 的输出：

  $> ibd2sdi --type=2 ../data/test/ts1.ibd
  ["ibd2sdi"
  ,
  {
    "type": 2,
    "id": 7,
    "object":
     {
       "mysqld_version_id": 80003,
       "dd_version": 80003,
       "sdi_version": 1,
       "dd_object_type": "Tablespace",
       "dd_object": {
           "name": "test/ts1",
           "comment": "",
           "options": "",
           "se_private_data": "flags=16417;id=2;server_version=80003;space_version=1;",
           "engine": "InnoDB",
           "files": [
               {
                   "ordinal_position": 1,
                   "filename": "./test/ts1.ibd",
                   "se_private_data": "id=2;"
               }
           ]
       }
   }
  }
  ]

  由于 InnoDB 处理默认值元数据的方式，即使未使用 DEFAULT 定义，ibd2sdi 输出中给定表列的默认值也可能存在且非空。考虑使用以下语句在名为 i 的数据库中创建的两个表：

  CREATE TABLE t1 (c VARCHAR(16) NOT NULL);

  CREATE TABLE t2 (c VARCHAR(16) NOT NULL DEFAULT "Sakila");

  使用 ibd2sdi，我们可以看到两个表中列 c 的 default_value 都是非空的，实际上被填充到长度，如下所示：

  $> ibd2sdi ../data/i/t1.ibd | grep -m1 '\"default_value\"' | cut -b34- | sed -e s/,//
  "AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA\nAAAAAAAAAAA="

  $> ibd2sdi ../data/i/t2.ibd     | grep -m1 '\"default_value\"' | cut -b34- | sed -e s/,//
  "BlNha2lsYQAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA\nAAAAAAAAAAA="

  使用 JSON 感知工具（如 jq）检查 ibd2sdi 输出可能更容易，如下所示：

  $> ibd2sdi ../data/i/t1.ibd | jq '.[1]["object"]["dd_object"]["columns"][0]["default_value"]'
  "AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA\nAAAAAAAAAAA="

  $> ibd2sdi ../data/i/t2.ibd | jq '.[1]["object"]["dd_object"]["columns"][0]["default_value"]'
  "BlNha2lsYQAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA\nAAAAAAAAAAA="

  有关更多信息，请参见 MySQL Internals 文档。

- --strict-check, -c

  命令行格式：--strict-check=algorithm

  类型：Enumeration

  默认值：crc32

  有效值：crc32

  innodb

  none

  指定用于验证所读页面校验和的严格校验和算法。选项包括 innodb、crc32 和 none。

  在此示例中，指定了 innodb 校验和算法的严格版本：

  ibd2sdi --strict-check=innodb ../data/test/t1.ibd

  在此示例中，指定了 crc32 校验和算法的严格版本：

  ibd2sdi -c crc32 ../data/test/t1.ibd

  如果未指定 --strict-check 选项，将对非严格 innodb、crc32 和 none 校验和执行验证。

- --no-check, -n

  命令行格式：--no-check

  类型：Boolean

  默认值：false

  跳过对所读页面的校验和验证。

  ibd2sdi --no-check ../data/test/t1.ibd

- --pretty, -p

  命令行格式：--pretty

  类型：Boolean

  默认值：false

  以 JSON 美化打印格式输出 SDI 数据。默认启用。如果禁用，SDI 不可读但大小更小。使用 --skip-pretty 禁用。

  ibd2sdi --skip-pretty ../data/test/t1.ibd
