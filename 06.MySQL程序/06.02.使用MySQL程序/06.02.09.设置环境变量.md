### 6.2.9 设置环境变量

环境变量可以在命令提示符处设置以影响当前命令处理器的调用，或永久设置以影响未来的调用。要永久设置变量，可以在启动文件中设置它，或使用系统为此目的提供的界面。请查阅命令解释器的文档以获取具体详情。第 6.9 节"环境变量"列出了所有影响 MySQL 程序操作的环境变量。

要为环境变量指定值，请使用适合您的命令处理器的语法。例如，在 Windows 上，可以设置 USER 变量来指定您的 MySQL 账户名。为此，请使用以下语法：

```
SET USER=your_name
```

Unix 上的语法取决于您的 shell。假设您想使用 MYSQL_TCP_PORT 变量指定 TCP/IP 端口号。典型的语法（例如对于 sh、ksh、bash、zsh 等）如下：

```
MYSQL_TCP_PORT=3306
export MYSQL_TCP_PORT
```

第一个命令设置变量，export 命令将变量导出到 shell 环境，以便其值对 MySQL 和其他进程可访问。

对于 csh 和 tcsh，使用 setenv 使 shell 变量对环境可用：

```
setenv MYSQL_TCP_PORT 3306
```

设置环境变量的命令可以在命令提示符处执行以立即生效，但设置仅在您注销前保持。要使设置在每次登录时生效，请使用系统提供的界面或将适当的命令放在命令解释器每次启动时读取的启动文件中。

在 Windows 上，可以使用系统控制面板（在"高级"下）设置环境变量。

在 Unix 上，典型的 shell 启动文件是 bash 的 .bashrc 或 .bash_profile，或 tcsh 的 .tcshrc。

假设您的 MySQL 程序安装在 /usr/local/mysql/bin 中，并且您想轻松调用这些程序。为此，设置 PATH 环境变量的值以包含该目录。例如，如果您的 shell 是 bash，将以下行添加到您的 .bashrc 文件：

```
PATH=${PATH}:/usr/local/mysql/bin
```

bash 对登录和非登录 shell 使用不同的启动文件，因此您可能想将设置添加到 .bashrc 以用于非登录 shell，并添加到 .bash_profile 以用于登录 shell，以确保无论如何都设置 PATH。

如果您的 shell 是 tcsh，将以下行添加到您的 .tcshrc 文件：

```
setenv PATH ${PATH}:/usr/local/mysql/bin
```

如果主目录中不存在相应的启动文件，请使用文本编辑器创建它。

修改 PATH 设置后，在 Windows 上打开新的控制台窗口或在 Unix 上重新登录，以使设置生效。
