### 6.3.1 mysqld — MySQL 服务器

mysqld 也称为 MySQL Server，是一个单线程多任务程序，负责 MySQL 安装中的大部分工作。它不会生成额外的进程。MySQL Server 管理对 MySQL 数据目录的访问，该目录包含数据库和表。数据目录也是其他信息（如日志文件和状态文件）的默认位置。

注意

某些安装包包含名为 mysqld-debug 的服务器调试版本。调用此版本而不是 mysqld 以获得调试支持、内存分配检查和跟踪文件支持（参见第 7.9.1.2 节"创建跟踪文件"）。

### mysqld_safe — MySQL 服务器启动脚本

当 MySQL 服务器启动时，它会监听来自客户端程序的网络连接，并代表这些客户端管理对数据库的访问。

mysqld 程序有许多可在启动时指定的选项。要获得完整的选项列表，请运行以下命令：

mysqld --verbose --help

MySQL Server 还有一组系统变量，这些变量影响其运行时的操作。系统变量可以在服务器启动时设置，其中许多可以在运行时更改以实现动态服务器重新配置。MySQL Server 还有一组状态变量，提供有关其操作的信息。您可以监视这些状态变量以访问运行时性能特征。

有关 MySQL Server 命令选项、系统变量和状态变量的完整描述，请参见第 7.1 节"MySQL 服务器"。有关安装 MySQL 和设置初始配置的信息，请参见第 2 章"安装 MySQL"。
