### 2.4.2 在 macOS 上使用原生包安装 MySQL

该包位于磁盘镜像 (.dmg) 文件内，你需要先在 Finder 中双击其图标来挂载它。然后应该会挂载镜像并显示其内容。

> 注意
>
> 在继续安装之前，请确保使用 MySQL Manager Application（在 macOS Server 上）、偏好设置窗格或命令行上的 mysqladmin shutdown 来停止所有正在运行的 MySQL 服务器实例。

使用包安装程序安装 MySQL：

1. 下载包含 MySQL 包安装程序的磁盘镜像 (.dmg) 文件（社区版本可在此处获得）。双击该文件以挂载磁盘镜像并查看其内容。

   从磁盘中双击 MySQL 安装程序包。它的名称取决于你下载的 MySQL 版本。例如，对于 MySQL server 26.7.0，它可能被命名为 mysql-26.7.0-macos-10.13-x86_64.pkg。

2. 初始向导介绍屏幕引用了要安装的 MySQL 服务器版本。单击"继续"开始安装。

   MySQL 社区版显示相关 GNU 通用公共许可证的副本。单击"继续"，然后单击"同意"以继续。

3. 从"安装类型"页面，你可以单击"安装"以使用所有默认值执行安装向导，或单击"自定义"以更改要安装的组件（MySQL server、MySQL Test、偏好设置窗格、Launchd Support -- 除 MySQL Test 外，所有组件默认启用）。

   > 注意
   >
   > 虽然"更改安装位置"选项可见，但安装位置无法更改。

   图 2.5 MySQL 包安装程序向导：自定义

4. 单击"安装"以安装 MySQL Server。如果升级当前 MySQL Server 安装，安装过程到此结束，否则请按照向导的其他配置步骤进行新的 MySQL Server 安装。

5. 成功安装新的 MySQL Server 后，通过定义 root 密码并启用（或禁用）MySQL 服务器在启动时启动来完成配置。

6. 为 root 用户定义密码，并切换 MySQL Server 是否应在配置步骤完成后启动。

7. "摘要"是最后一步，引用成功且完整的 MySQL Server 安装。关闭向导。

MySQL 服务器现已安装。如果你选择不启动 MySQL，则使用命令行中的 launchctl 或通过单击 MySQL 偏好设置窗格中的"启动"来启动 MySQL。有关更多信息，请参见第 2.4.3 节"安装和使用 MySQL Launch Daemon"和第 2.4.4 节"安装和使用 MySQL 偏好设置窗格"。使用 MySQL 偏好设置窗格或 launchd 配置 MySQL 在启动时自动启动。

使用包安装程序安装时，文件被安装到 /usr/local 内与安装版本和平台名称匹配的目录中。例如，安装程序文件 mysql-26.7.0-macos10.15-x86_64.dmg 将 MySQL 安装到 /usr/local/mysql-26.7.0-macos10.15-x86_64/，并创建指向 /usr/local/mysql 的符号链接。下表显示了此 MySQL 安装目录的布局。

> 注意
>
> macOS 安装过程不会创建或安装示例 my.cnf MySQL 配置文件。

表 2.8 macOS 上的 MySQL 安装布局

| 目录 | 目录内容 |
|------|--------|
| bin | mysqld 服务器、客户端和实用程序 |
| data | 日志文件、数据库，其中 /usr/local/mysql/data/mysqld.local.err 是默认错误日志 |
| docs | 辅助文档，如发行说明和构建信息 |
| include | Include（头）文件 |
| lib | 库 |
| man | Unix 手册页 |
| mysql-test | MySQL 测试套件（使用安装程序包 (DMG) 时，"MySQL Test"在安装过程中默认禁用） |
| share | 杂项支持文件，包括错误消息、dictionary.txt 和 rewriter SQL |
| support-files | 支持脚本，如 mysqld_multi.server、mysql.server 和 mysql-log-rotate |
| /tmp/mysql.sock | MySQL Unix socket 的位置 |
