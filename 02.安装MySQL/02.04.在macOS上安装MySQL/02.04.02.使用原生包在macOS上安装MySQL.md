### 2.4.2 使用原生包在macOS上安装MySQL

运行官方 DMG 安装器后，MySQL 会安装到 `/usr/local/mysql` 并提供启动项。

```sh
/usr/local/mysql/support-files/mysql.server start
```

安装完成后应查看初始密码并完成安全设置。

------
官方英文版参见 [Installing MySQL on macOS Using Native Packages](https://dev.mysql.com/doc/refman/9.7/en/macos-installation-pkg.html)。
