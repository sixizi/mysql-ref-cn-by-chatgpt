### 2.5.2 使用MySQL APT仓库在Linux上安装MySQL

安装 MySQL APT 配置包后更新索引并安装：

```sh
sudo apt update
sudo apt install mysql-server
```

可使用 `mysql-apt-config` 选择发行系列和组件。

------
官方英文版参见 [Installing MySQL on Linux Using the MySQL APT Repository](https://dev.mysql.com/doc/refman/8.0/en/linux-installation-apt-repo.html)。
