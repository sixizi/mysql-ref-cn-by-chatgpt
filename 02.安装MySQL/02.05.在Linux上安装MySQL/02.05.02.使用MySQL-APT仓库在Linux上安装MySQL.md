### 2.5.2 使用MySQL APT仓库在Linux上安装MySQL

安装 `mysql-apt-config` 配置包后更新索引并安装：

```sh
sudo apt-get update
sudo apt-get install mysql-server
```

可使用 `sudo dpkg-reconfigure mysql-apt-config` 选择发行系列和组件。Innovation 组件名包含 `-innovation-`。
