### 2.5.6.3 在Windows和其他非Linux平台上使用Docker部署MySQL

非 Linux 平台可通过 Docker Desktop 运行 MySQL 镜像，但底层使用虚拟机。

- 数据卷应挂载到可靠路径。
- 注意宿主机与容器的路径格式差异。
- 生产部署优先使用官方原生包或云托管服务。

------
官方英文版参见 [Deploying MySQL on Windows and Other Non-Linux Platforms with Docker](https://dev.mysql.com/doc/refman/8.0/en/deploy-mysql-nonlinux-docker.html)。
