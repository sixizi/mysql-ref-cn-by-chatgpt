### 2.5.6.1 使用Docker部署MySQL服务器的基础步骤

```sh
docker run --name mysql \\
  -e MYSQL_ROOT_PASSWORD=secret \\
  -v mysql-data:/var/lib/mysql \\
  -p 3306:3306 -d mysql:26.10
```

使用命名卷或宿主机目录保存数据，避免容器删除后数据丢失。
