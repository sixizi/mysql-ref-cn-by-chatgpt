### 2.5.5 使用Oracle Debian包在Linux上安装MySQL

官方 Debian 包适合 Debian 和 Ubuntu 系统。

```sh
sudo dpkg -i mysql-*.deb
sudo apt --fix-broken install
```

安装后使用 systemd 启动，并检查初始化日志。

------
官方英文版参见 [Installing MySQL on Linux Using Debian Packages from Oracle](https://dev.mysql.com/doc/refman/26.7/en/linux-installation-debian.html)。
