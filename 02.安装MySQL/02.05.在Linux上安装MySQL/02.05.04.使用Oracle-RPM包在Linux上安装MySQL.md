### 2.5.4 使用Oracle RPM包在Linux上安装MySQL

官方 RPM 包按组件拆分，例如 server、client、common、libs 和 test。

- 使用包管理器安装以自动处理依赖。
- 生产环境至少安装 server 和 client 相关包。
- 升级前备份数据目录和配置文件。

------
官方英文版参见 [Installing MySQL on Linux Using RPM Packages from Oracle](https://dev.mysql.com/doc/refman/8.0/en/linux-installation-rpm.html)。
