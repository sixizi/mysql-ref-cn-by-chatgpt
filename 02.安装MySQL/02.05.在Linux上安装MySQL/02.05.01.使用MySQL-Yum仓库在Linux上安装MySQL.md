### 2.5.1 使用MySQL Yum仓库在Linux上安装MySQL

安装官方仓库 RPM 后：

```sh
sudo yum localinstall mysql97-community-release-{platform}-{version-number}.noarch.rpm
sudo yum install mysql-community-server
```

仓库配置 RPM 名称以 `mysql97` 开头，表示默认启用 MySQL 9.7 LTS 子仓库；MySQL 8.4 和 Innovation 系列默认禁用，当前 Innovation 版本为 26.10。首次启动服务器时会初始化数据目录，并可从 `mysqld.log` 中找到临时 root 密码。

------
官方英文版参见 [Installing MySQL on Linux Using the MySQL Yum Repository](https://dev.mysql.com/doc/refman/9.7/en/linux-installation-yum-repo.html)。
