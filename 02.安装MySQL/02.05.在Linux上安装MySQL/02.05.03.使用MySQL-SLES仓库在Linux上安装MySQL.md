### 2.5.3 使用MySQL SLES仓库在Linux上安装MySQL

SUSE 可安装 MySQL SLES 仓库配置包，再通过 `zypper` 安装：

```sh
sudo zypper install mysql-community-server
```

使用 systemd 管理服务，并通过错误日志确认初始化结果。

------
官方英文版参见 [Installing MySQL on Linux Using the MySQL SLES Repository](https://dev.mysql.com/doc/refman/8.0/en/linux-installation-sles-repo.html)。
