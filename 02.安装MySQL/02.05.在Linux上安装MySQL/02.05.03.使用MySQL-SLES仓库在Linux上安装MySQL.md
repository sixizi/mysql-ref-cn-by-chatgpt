### 2.5.3 使用MySQL SLES仓库在Linux上安装MySQL

SUSE 可安装以 `mysql97` 开头的 MySQL SLES 仓库配置包，再通过 `zypper` 安装。默认启用 MySQL 26.10 LTS；Innovation 组件名包含 `mysql-innovation-community` 和 `mysql-tools-innovation-community`。同一时间只应启用一个发行系列的子仓库。

```sh
sudo zypper install mysql-community-server
```

使用 systemd 管理服务，并通过错误日志确认初始化结果。

官方英文版参见 [Installing MySQL on Linux Using the MySQL SLES Repository](https://dev.mysql.com/doc/refman/26.10/en/linux-installation-sles-repo.html)。
