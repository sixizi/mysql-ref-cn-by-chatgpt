### 2.9.4 安全初始化MySQL账户

服务器初始化后，root 账户可能带有临时密码，或允许无密码登录，具体取决于初始化方式和发行包行为。

- 使用 `mysqld --initialize` 时，从错误日志中读取临时密码。
- 首次登录后立即修改 root 密码。
- 禁止或收紧远程 root 登录，仅授予应用账号所需权限。
- 可使用 `mysql_secure_installation` 交互式移除匿名账号和测试数据库。

示例：

```sh
mysql -u root -p
ALTER USER 'root'@'localhost' IDENTIFIED BY 'new_password';
```
