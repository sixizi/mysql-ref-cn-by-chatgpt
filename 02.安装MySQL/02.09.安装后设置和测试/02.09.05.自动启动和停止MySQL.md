### 2.9.5 自动启动和停止 MySQL

本节讨论启动和停止 MySQL 服务器的方法。

通常，你可以通过以下方式之一启动 mysqld 服务器：

- 直接调用 mysqld。这在任何平台上都有效。

- 在 Windows 上，你可以设置一个 MySQL 服务，在 Windows 启动时自动运行。参见第 2.3.3.8 节"将 MySQL 作为 Windows 服务启动"。

- 在 Unix 和类 Unix 系统上，你可以调用 mysqld_safe，它尝试确定 mysqld 的正确选项，然后使用这些选项运行它。参见第 6.3.2 节"mysqld_safe — MySQL 服务器启动脚本"。

- 在支持 systemd 的 Linux 系统上，你可以使用它来控制服务器。参见第 2.5.9 节"使用 systemd 管理 MySQL 服务器"。

- 在使用 System V 风格运行目录的系统上（即 /etc/init.d 和运行级别特定目录），调用 mysql.server。此脚本主要在系统启动和关闭时使用。它通常以 mysql 的名称安装。mysql.server 脚本通过调用 mysqld_safe 来启动服务器。参见第 6.3.3 节"mysql.server — MySQL 服务器启动脚本"。

- 在 macOS 上，安装一个 launchd 守护进程以在系统启动时启用自动 MySQL 启动。守护进程通过调用 mysqld_safe 来启动服务器。有关详细信息，参见第 2.4.3 节"安装和使用 MySQL 启动守护进程"。MySQL 偏好设置窗格也通过系统偏好设置提供启动和停止 MySQL 的控制。参见第 2.4.4 节"安装和使用 MySQL 偏好设置窗格"。

- 在 Solaris 上，使用服务管理框架 (SMF) 系统来启动和控制 MySQL 启动。

systemd、mysqld_safe 和 mysql.server 脚本、Solaris SMF 以及 macOS 启动项（或 MySQL 偏好设置窗格）可用于手动启动服务器，或在系统启动时自动启动。systemd、mysql.server 和启动项也可用于停止服务器。

下表显示了服务器和启动脚本从选项文件中读取的选项组。

表 2.16 MySQL 启动脚本和支持的服务器选项组

| 脚本 | 选项组 |
|------|--------|
| mysqld | [mysqld]、[server]、[mysqld-major_version] |
| mysqld_safe | [mysqld]、[server]、[mysqld_safe] |
| mysql.server | [mysqld]、[mysql.server]、[server] |

[mysqld-major_version] 表示具有 [mysqld-26.7] 和 [mysqld-26.7] 等名称的组由版本为 26.7.x、26.7.x 等的服务器读取。此功能可用于指定仅由给定发行版系列中的服务器读取的选项。

为了向后兼容，mysql.server 也读取 [mysql_server] 组，mysqld_safe 也读取 [safe_mysqld] 组。为了保持最新，你应该更新你的选项文件以使用 [mysql.server] 和 [mysqld_safe] 组。

有关 MySQL 配置文件及其结构和内容的更多信息，参见第 6.2.2.2 节"使用选项文件"。
