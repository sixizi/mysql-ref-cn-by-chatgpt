### 2.2 在Unix/Linux上使用通用二进制文件安装MySQL

通用二进制包无需编译，适合没有官方仓库的 Unix/Linux 系统。

```sh
tar -xvf mysql-*-linux-*.tar.xz -C /usr/local
ln -s /usr/local/mysql-* /usr/local/mysql
```

初始化数据目录、启动服务器并按安装说明完成权限配置。

------
官方英文版参见 [Installing MySQL on Unix/Linux Using Generic Binaries](https://dev.mysql.com/doc/refman/9.7/en/binary-installation.html)。
