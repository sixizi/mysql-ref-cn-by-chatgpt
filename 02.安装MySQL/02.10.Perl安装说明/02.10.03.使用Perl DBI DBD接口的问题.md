### 2.10.3 使用Perl DBI/DBD接口的问题

如果 Perl 报告无法找到 `../mysql/mysql.so`，通常是找不到 `libmysqlclient.so` 共享库。可通过以下方式修复：

- 将 `libmysqlclient.so` 复制到系统共享库目录，例如 `/usr/lib` 或 `/lib`。
- 修改编译 `DBD::mysql` 使用的 `-L` 选项，使其指向实际库路径。
- 在 Linux 中将库目录写入 `/etc/ld.so.conf`。
- 将库目录加入 `LD_RUN_PATH`；部分系统使用 `LD_LIBRARY_PATH`。

如果出现 `__moddi3` 或 `__divdi3` 符号解析错误，通常是 Perl 或 MySQL 与 `gcc` 编译配置不匹配。可在构建 `mysql.so` 时加入 `libgcc` 路径和 `-lgcc`，或确保 Perl 与 MySQL 使用同一编译器。
