### 2.6 使用Unbreakable Linux Network（ULN）安装MySQL

Oracle Linux 可通过 ULN 订阅启用 MySQL 通道并安装服务器。

- 使用 `yum-config-manager` 或 ULN Web 界面启用通道。
- 通过 `yum install mysql-server` 安装。
- 保持通道版本与业务升级策略一致。
