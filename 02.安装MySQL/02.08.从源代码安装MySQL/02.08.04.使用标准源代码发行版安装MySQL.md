### 2.8.4 使用标准源代码发行版安装MySQL

典型流程：

```sh
tar -xzf mysql-*.tar.gz
cd mysql-*
mkdir bld && cd bld
cmake .. -DWITH_BOOST=/path/to/boost
cmake --build . -j"$(nproc)"
sudo cmake --install .
```

安装后初始化数据目录并配置服务。

------
官方英文版参见 [Installing MySQL Using a Standard Source Distribution](https://dev.mysql.com/doc/refman/26.10/en/installing-source-distribution.html)。
