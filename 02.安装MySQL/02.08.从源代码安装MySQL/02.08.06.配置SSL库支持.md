### 2.8.6 配置SSL库支持

SSL 库用于支持加密连接、为随机数生成提供熵，以及执行其他加密相关操作。

如果您从源代码分发版编译MySQL，CMake会默认配置该分发版使用已安装的OpenSSL库。

`WITH_SSL` CMake 选项决定编译时使用的 SSL 库，默认值为 `-DWITH_SSL=system`，即使用系统 OpenSSL。也可以用路径显式指定 OpenSSL 安装位置：

```sh
cmake . -DWITH_SSL=system
cmake . -DWITH_SSL=path_name
```

系统必须安装 OpenSSL 1.0.1 或更新版本。在 EL8 上可用 `WITH_SSL=openssl3` 选择替代的 OpenSSL 系统包；由于该包不支持 LDAP 和 Kerberos 等身份验证插件，这些插件会被禁用。

要检查 `mysqld` 服务器是否支持加密连接，请检查 `tls_version` 系统变量的值：

```sql
mysql> SHOW VARIABLES LIKE 'tls_version';
+---------------+-----------------+
| Variable_name | Value           |
+---------------+-----------------+
| tls_version   | TLSv1.2,TLSv1.3 |
+---------------+-----------------+
```

如果结果包含 TLS 版本，则服务器支持加密连接；详见[8.3.1 配置MySQL使用加密连接](../../08.安全性/08.03.使用加密连接/08.03.01.配置MySQL使用加密连接.md)。
