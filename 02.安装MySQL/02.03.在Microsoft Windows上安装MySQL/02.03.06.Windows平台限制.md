### 2.3.7 Windows平台限制

Windows 版 MySQL 需要注意：

- 32 位进程默认可用用户地址空间有限，生产建议 64 位。
- 数据库名和表名大小写不敏感，但同一语句内应保持一致。
- `LOAD DATA` 和 `SELECT ... INTO OUTFILE` 路径建议使用 `/`。
- 管道中遇到 `^Z` 可能提前截断输入。
