MySQL 仅支持 64 位 Microsoft Windows。推荐方式是下载并运行 MSI，由其安装 MySQL 服务器和 MySQL Configurator，再立即完成配置。服务器在配置完成前不会启动；如果配置为 Windows 服务，系统重启后会自动启动。

MySQL 26.7 服务器需要 Microsoft Visual C++ 2019 Redistributable Package，应在安装服务器前确认已安装。调试二进制文件还需要 Visual Studio 2019。
