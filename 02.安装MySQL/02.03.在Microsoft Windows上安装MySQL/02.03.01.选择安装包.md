### 2.3.1 选择安装包

MySQL 26.7 在 Windows 上提供以下安装包：

- **MySQL Installation MSI**：文件名类似 `mysql-community-26.7.4.msi`，安装服务器并捆绑 MySQL Configurator，适合大多数用户。
- **MySQL noinstall ZIP 归档**：无需自动安装器，但同样包含 MySQL Configurator；主包为 `mysql-VERSION-winx64.zip`，测试套件和 PDB 调试信息位于 `mysql-VERSION-winx64-debug-test.zip`。
- **MySQL Docker 镜像**：Oracle 提供的 MySQL Docker 镜像专为 Linux 构建。在 Windows 上运行不受支持，需自行承担风险。
