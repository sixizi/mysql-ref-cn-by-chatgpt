### 2.3.5 Windows上MySQL服务器安装故障排除

常见启动问题包括：

- 端口 3306 被占用。
- `datadir` 不存在或权限不足。
- 选项文件路径或值错误。
- 服务账户无法访问数据目录或网络端口。

优先查看错误日志，并从命令行加 `--console` 启动获取直接输出。
