### 2.3.3.8 将MySQL作为Windows服务启动

将服务器注册为服务可实现开机自启和后台运行：

```powershell
bin\mysqld --install MySQL --defaults-file=C:\mysql\my.ini
net start MySQL
```

停止服务使用 `net stop MySQL`，移除服务使用 `mysqld --remove MySQL`。

------
官方英文版参见 [Starting MySQL as a Windows Service](https://dev.mysql.com/doc/refman/26.10/en/windows-start-service.html)。
