### 2.3.1 Windows上的MySQL安装布局

Windows 安装默认将服务器程序放在 `bin` 目录，数据目录通常位于 `ProgramData` 或安装目录下。

- 使用 MySQL Installer 时可在配置阶段修改数据目录。
- ZIP 安装需显式设置 `basedir` 和 `datadir`。
- 常用客户端工具也位于 `bin` 目录。
