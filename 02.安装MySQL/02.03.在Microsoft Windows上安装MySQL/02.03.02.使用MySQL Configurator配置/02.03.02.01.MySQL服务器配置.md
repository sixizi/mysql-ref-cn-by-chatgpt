### 2.3.2.1 MySQL服务器配置

MySQL Configurator 支持初始配置、重新配置，并参与卸载流程。它会生成 `my.ini`、默认将服务器注册为 Windows 服务、设置安装和数据路径，并可选择创建带常用角色的用户账户。高级选项还可配置错误日志、通用日志、慢查询日志、二进制日志和复制所需的唯一服务器 ID。

如果检测到已有 MySQL 服务器安装，Configurator 提供两种方式：

- **原位升级**：替换现有安装并可能升级数据 schema。原位升级要求现有实例正在运行，官方支持路径包括从 MySQL 8.4 升级到 9.7。
- **添加独立安装**：保留现有服务器，并在系统中共存多个 MySQL 服务器安装。

配置过程中可为不同使用场景选择内存策略、TCP/IP 或本地连接方式，并设置 root 密码和可选用户账户。
