### 2.3.2 配置：使用MySQL Configurator

**目录**

- [2.3.2.1 MySQL服务器配置](./02.03.02.01.MySQL服务器配置.md)
- [2.3.2.2 MySQL Configurator CLI](./02.03.02.02.MySQL Configurator CLI.md)

MySQL Configurator 是一个用于简化 Windows 上 MySQL 服务器配置的独立应用。它随 MySQL 服务器一起提供，MSI 和独立 ZIP 归档均包含该工具。

MySQL Configurator 可用于配置或重新配置服务器。可通过以下方式启动：

- MSI 在安装完成后提示立即运行 MySQL Configurator。
- MSI 在开始菜单中创建 MySQL Configurator 条目。
- 在命令行运行与 `mysqld.exe` 位于同一 `bin` 目录的 `mysql-configurator.exe`。
