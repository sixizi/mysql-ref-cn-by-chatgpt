### 2.3.2.2 MySQL Configurator CLI

MySQL Configurator 默认启动 GUI，也可通过 `mysql_configurator.exe --console` 进入 CLI 模式。CLI 功能自 MySQL Configurator 9.2.0 引入，执行时需要具备管理员权限的 Windows 用户，否则系统会提示凭据。

基本语法：

```sh
mysql_configurator.exe --console [--help] | [--action=action_name]
```

常用选项：

- `--console` 或 `-c`：启用 CLI 模式。
- `--action` 或 `-a`：指定 `configure`、`reconfigure`、`remove` 或 `upgrade`。
- `--help` 或 `-h`：显示总体帮助，或配合 `--action` 显示对应操作的帮助。
- 各操作专用选项：例如 `--datadir="C:\MySQL..."`、`--port=3306`。
