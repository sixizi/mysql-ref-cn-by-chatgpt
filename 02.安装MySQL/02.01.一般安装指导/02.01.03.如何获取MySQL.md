### 2.1.3 如何获取 MySQL

查看我们的下载页面 https://dev.mysql.com/downloads/ 了解当前 MySQL 版本的信息和下载说明。

对于使用 Yum 作为包管理系统的基于 RPM 的 Linux 平台，可以使用 MySQL Yum Repository 安装 MySQL。详见第 2.5.1 节"使用 MySQL Yum Repository 在 Linux 上安装 MySQL"。

对于基于 Debian 的 Linux 平台，可以使用 MySQL APT Repository 安装 MySQL。详见第 2.5.2 节"使用 MySQL APT Repository 在 Linux 上安装 MySQL"。

对于 SUSE Linux Enterprise Server (SLES) 平台，可以使用 MySQL SLES Repository 安装 MySQL。详见第 2.5.3 节"使用 MySQL SLES Repository"。

要获取最新的开发源代码，见第 2.8.5 节"使用开发源代码树安装 MySQL"。
