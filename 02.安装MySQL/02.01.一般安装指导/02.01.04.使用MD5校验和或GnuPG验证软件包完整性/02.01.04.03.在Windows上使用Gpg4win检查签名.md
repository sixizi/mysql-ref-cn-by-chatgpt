### 2.1.4.3 使用 Gpg4win 在 Windows 上进行签名检查

第 2.1.4.2 节"使用 GnuPG 进行签名检查"描述了如何使用 GPG 验证 MySQL 下载。该指南也适用于 Microsoft Windows，但另一个选项是使用 GUI 工具（如 Gpg4win）。您可以使用不同的工具，但我们的示例基于 Gpg4win，并使用其捆绑的 Kleopatra GUI。

下载并安装 Gpg4win，加载 Kleopatra，并添加 MySQL Release Engineering 证书。通过单击 File、Lookup on Server 来执行此操作。在搜索框中输入"Mysql Release Engineering"并按 Search。

图 2.1 Kleopatra：Lookup on Server 向导：查找证书

选择"MySQL Release Engineering"证书。Key-ID 必须引用"3A79 BD29"，或选择 Details... 以确认证书有效。现在，通过单击 Import 来导入它。当显示导入对话框时，选择 Okay，此证书现在应列在 Imported Certificates 选项卡下。

接下来，向证书授予信任。选择我们的证书，然后从主菜单选择 Certificates、Change Certification Power，并单击 Grant Power。

表 2.2 MySQL Server MSI for Microsoft Windows 的 MySQL 包和签名文件

| 分发文件 | mysql-26.7.0-winx64.msi |
| 签名文件 | mysql-26.7.0-winx64.msi.asc |

确保两个文件存储在同一目录中，然后运行以下命令来验证分发文件的签名。从 File、Decrypt/Verify Files... 加载对话框，然后选择 .asc 文件。
