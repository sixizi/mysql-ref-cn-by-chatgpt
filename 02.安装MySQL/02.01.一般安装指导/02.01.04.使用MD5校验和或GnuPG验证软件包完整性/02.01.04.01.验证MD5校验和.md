### 2.1.4.1 验证 MD5 校验和

下载 MySQL 软件包后，应确保其 MD5 校验和与 MySQL 下载页面上提供的校验和相匹配。每个软件包都有一个单独的校验和，可以与下载的软件包进行验证。正确的 MD5 校验和列在每个 MySQL 产品的下载页面上；应将其与下载的文件（产品）的 MD5 校验和进行比较。

每个操作系统和设置都提供了自己的 MD5 校验和检查工具版本。通常该命令名为 md5sum，或可能名为 md5，某些操作系统根本不提供该工具。在 Linux 上，它是 GNU Text Utilities 软件包的一部分，该软件包可用于多种平台。也可以从 http://www.gnu.org/software/textutils/ 下载源代码。如果安装了 OpenSSL，可以改用命令 `openssl md5 package_name`。Windows 版本的 md5 命令行工具可从 http://www.fourmilab.ch/md5/ 获得。winMd5Sum 是一个图形化 MD5 检查工具，可从 http://www.nullriver.com/index/products/winmd5sum 获得。我们的 Microsoft Windows 示例假设命令名为 md5.exe。

Linux 和 Microsoft Windows 示例：

```
$> md5sum mysql-standard-26.10.0-linux-i686.tar.gz
aaab65abbec64d5e907dcd41b8699945 mysql-standard-26.10.0-linux-i686.tar.gz

$> md5.exe mysql-installer-community-26.10.0.msi
aaab65abbec64d5e907dcd41b8699945 mysql-installer-community-26.10.0.msi
```

应验证生成的校验和（十六进制数字字符串）与下载页面上相应软件包下方显示的校验和相匹配。

> **注意**
>
> 确保验证存档文件（例如 .zip、.tar.gz 或 .msi 文件）的校验和，而不是存档内包含的文件的校验和。换句话说，在提取其内容之前验证该文件。
