### 8.7.2 更改 SELinux 模式

SELinux 支持强制、宽容和禁用三种模式。强制模式是默认模式。宽容模式允许在强制模式中不被允许的操作，并将这些操作记录到 SELinux 审计日志中。宽容模式通常用于开发策略或故障排除。在禁用模式中，策略不被强制执行，上下文也不应用于系统对象，这使得以后启用 SELinux 变得困难。

要查看当前的 SELinux 模式，使用前面提到的 sestatus 命令或 getenforce 实用程序。

```
$> getenforce
Enforcing
```

要更改 SELinux 模式，使用 setenforce 实用程序：

```
$> setenforce 0
$> getenforce
Permissive
```

```
$> setenforce 1
$> getenforce
Enforcing
```

使用 setenforce 所做的更改在系统重启时会丢失。要永久更改 SELinux 模式，编辑 /etc/selinux/config 文件并重启系统。
