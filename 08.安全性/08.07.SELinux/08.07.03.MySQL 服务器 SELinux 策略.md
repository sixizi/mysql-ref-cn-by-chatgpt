### 8.7.3 MySQL Server SELinux 策略

MySQL Server SELinux 策略模块通常默认安装。您可以使用 semodule -l 命令查看已安装的模块。MySQL Server SELinux 策略模块包括：

- mysqld_selinux

- mysqld_safe_selinux

有关 MySQL Server SELinux 策略模块的信息，请参考 SELinux 手册页。手册页提供了与 MySQL 服务相关联的类型和布尔值的信息。手册页的命名格式为 service-name_selinux。

man mysqld_selinux

如果 SELinux 手册页不可用，请参考您的发行版 SELinux 文档，了解如何使用 sepolicy manpage 实用程序生成手册页的信息。
