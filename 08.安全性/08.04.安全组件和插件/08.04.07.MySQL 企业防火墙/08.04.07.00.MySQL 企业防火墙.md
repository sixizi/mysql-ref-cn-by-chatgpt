#### 8.4.7 MySQL 企业防火墙

> **注意**
>
> MySQL 企业防火墙包含在商业产品 MySQL Enterprise Edition 中。有关商业产品的信息，请参见 <https://www.mysql.com/products/>。

MySQL Enterprise Edition 提供 MySQL 企业防火墙。这是一个应用层防火墙，允许数据库管理员根据已接受的语句模式列表匹配结果，允许或拒绝 SQL 语句执行。它有助于加固 MySQL Server，抵御 SQL 注入攻击，以及应用程序被用于合法查询负载特征之外用途的尝试。

注册到防火墙的每个 MySQL 账户都有自己的语句允许列表，因此可以为不同账户定制保护策略。对指定账户或账户组，防火墙可运行在记录、保护或检测模式，分别用于训练可接受语句模式、主动拒绝不可接受语句，或被动记录可疑语句。下图展示防火墙在这些模式下处理传入语句的方式。
