#### 8.4.7.2 安装或卸载 MySQL 企业防火墙

MySQL 企业防火墙的安装是一次性操作，会安装 [8.4.7.1 MySQL 企业防火墙的要素](08.04.07.01.MySQL 企业防火墙的要素.md) 中描述的元素。安装可以使用图形界面或手动完成：

- 在 Windows 上，MySQL Configurator 可以启用 MySQL 企业防火墙。在 “Type and Networking” 页签中勾选 “Enable MySQL Enterprise Firewall”。不要混淆 “Open Firewall port for network access”，该选项针对 Windows 防火墙，控制 Windows 是否阻止 MySQL 服务器监听的 TCP/IP 端口。
- MySQL Workbench 6.3.4 及以上版本可以安装防火墙、启用或禁用已安装的防火墙，或卸载防火墙。
- 手动安装需要运行 MySQL 安装目录中 `share` 目录下的脚本。

> **重要**
>
> 在执行本节步骤前，请先完整阅读本节。具体步骤会因环境不同而变化。

> **注意**
>
> 如果安装了 MySQL 企业防火墙，即使处于禁用状态也会有少量开销。若不打算使用防火墙，请不要安装它。

##### 安装 MySQL 企业防火墙

如果旧版本 MySQL 已经安装了 MySQL 企业防火墙，请先按本节后面的说明卸载旧安装，重启服务器后再安装当前版本。这种情况下还需要重新注册配置。

手动安装时，在 MySQL 安装的 `share` 目录中选择平台对应脚本：

- Windows：`win_install_firewall.sql`
- Linux：`linux_install_firewall.sql`

安装脚本会在运行脚本时指定的防火墙数据库中创建存储过程和表。`mysql` 系统库是传统存储位置，但推荐创建并使用自定义 schema。

使用 `mysql` 系统库安装：

```sh
$> mysql -u root -p -D mysql < linux_install_firewall.sql
Enter password: (enter root password here)
```

使用自定义 schema 安装：

1. 使用 `--loose-mysql-firewall-database=database-name` 启动服务器，将 `database-name` 替换为自定义 schema 名。加 `--loose` 前缀后，即使防火墙未安装，程序也只发出警告而不退出。
2. 连接服务器并创建自定义 schema：

```sql
mysql> CREATE DATABASE IF NOT EXISTS database-name;
```

3. 指定该 schema 运行安装脚本：

```sh
$> mysql -u root -p -D database-name < linux_install_firewall.sql
Enter password: (enter root password here)
```

安装后防火墙默认应处于启用状态。执行以下语句验证：

```sql
mysql> SHOW GLOBAL VARIABLES LIKE 'mysql_firewall_mode';
+---------------------+-------+
| Variable_name        | Value |
+---------------------+-------+
| mysql_firewall_mode | ON    |
+---------------------+-------+
```

如果插件初始化失败，请查看服务器错误日志中的诊断信息。

> **注意**
>
> 在源/副本复制、组复制或 InnoDB Cluster 中使用 MySQL 企业防火墙时，必须在源节点运行安装脚本之前准备副本节点。脚本中的 `INSTALL PLUGIN` 语句不会复制。

1. 在每个副本节点上，从安装脚本中提取 `INSTALL PLUGIN` 语句并手动执行。
2. 在源节点上按前述方式运行安装脚本。

##### 卸载 MySQL 企业防火墙

可以通过 MySQL Workbench 或命令行卸载防火墙。命令行卸载时，运行 `share` 目录中的卸载脚本。默认 `mysql` 库示例：

```sh
$> mysql -u root -p -D mysql < uninstall_firewall.sql
Enter password: (enter root password here)
```

如果安装时使用自定义 schema，请替换数据库名：

```sh
$> mysql -u root -p -D database-name < uninstall_firewall.sql
Enter password: (enter root password here)
```

该脚本会移除防火墙的插件、表、函数和存储过程。

官方英文版参见 [Installing or Uninstalling MySQL Enterprise Firewall](https://dev.mysql.com/doc/refman/8.4/en/firewall-installation.html)。
