#### 8.4.7.1 MySQL 企业防火墙的要素

MySQL 企业防火墙基于一个插件库实现，包含以下元素：

- 服务端插件 `MYSQL_FIREWALL` 在 SQL 语句执行前检查语句，并根据已注册的防火墙 profile 决定执行或拒绝该语句。
- `MYSQL_FIREWALL` 与服务端插件 `MYSQL_FIREWALL_USERS`、`MYSQL_FIREWALL_WHITELIST` 共同实现 Performance Schema 表和 `INFORMATION_SCHEMA` 表，用于查看已注册 profile。
- profile 会缓存到内存中以提高性能。防火墙数据库中的表为 profile 提供持久存储，使服务器重启后 profile 仍然存在。防火墙数据库可以是 `mysql` 系统库，也可以是自定义 schema；自定义 schema 是推荐做法。
- 存储过程负责注册防火墙 profile、设置运行模式，以及在缓存和持久存储之间传输防火墙数据等任务。
- 管理函数为缓存与持久存储同步等底层任务提供 API。
- 系统变量用于配置防火墙，状态变量用于提供运行时信息。
- `FIREWALL_ADMIN` 与 `FIREWALL_USER` 权限分别允许用户管理任意用户的防火墙规则，以及只管理自己的防火墙规则。
- `FIREWALL_EXEMPT` 权限使指定用户不受防火墙限制。配置防火墙的数据库管理员通常需要此权限，以避免错误配置导致管理员自身也被锁定。

官方英文版参见 [Elements of MySQL Enterprise Firewall](https://dev.mysql.com/doc/refman/8.4/en/firewall-elements.html)。
