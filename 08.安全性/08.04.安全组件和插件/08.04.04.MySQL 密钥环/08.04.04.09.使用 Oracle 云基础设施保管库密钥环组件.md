#### 8.4.4.9 使用 Oracle 云基础设施保管库密钥环组件

`component_keyring_oci` 是 MySQL Enterprise Edition 提供的密钥环组件，用于将密钥环数据存储在 Oracle Cloud Infrastructure（OCI）Vault 中。它支持持久化系统变量值的安全存储，以及服务器内部组件和插件使用的 MySQL 密钥环服务接口。

`component_keyring_oci` 支持标准 MySQL 密钥环服务接口，可用于将敏感信息（例如密码、私钥和证书）存储在 OCI Vault 中。服务器内部组件和插件可以使用密钥环服务存储和检索这些信息。

该组件支持安全存储持久化系统变量值。在这种情况下，敏感系统变量的名称和值以加密格式保存，解密它们的文件密钥又由存储在 OCI Vault 中的主密钥保护。

`component_keyring_oci` 只能生成 AES 类型的密钥，密钥大小为 16、24 或 32 字节。有关通用限制，请参阅[8.4.4.10节, “支持的密钥环密钥类型和长度”](#8.4.4.10)。

组件通过配置文件而不是系统变量进行配置。配置文件必须位于服务器组件目录中，包含以下信息：

- `oci_server`：OCI Vault 的服务器地址。
- `oci_tenancy`：OCI 租户的 OCID。
- `oci_user`：OCI 用户的 OCID。
- `oci_region`：OCI 区域。
- `oci_compartment`：OCI compartment 的 OCID。
- `oci_key`：OCI Vault master encryption key 的 OCID。
- `oci_ca_certificate`：可选 CA 证书，用于验证 OCI 服务器证书。
- `authentication_key`：用于签名请求的 RSA 私钥。

组件配置文件中的每个密钥使用 `key = value` 格式。注释行以 `#` 或 `;` 开头。

在服务器启动时，组件通过 manifest 文件加载。manifest 指定要加载的组件库及其配置文件。组件初始化时读取配置文件并连接到 OCI Vault。如果配置无效或无法访问 Vault，组件初始化将失败。

有关通用密钥环函数，请参阅[8.4.4.12节, “通用密钥环密钥管理功能”](#8.4.4.12)。

官方英文版参见 [Using the Oracle Cloud Infrastructure Vault Keyring Component](https://dev.mysql.com/doc/refman/8.4/en/keyring-oci-component.html)。
