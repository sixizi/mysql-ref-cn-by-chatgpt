MySQL 服务器支持一个密钥环，使内部服务器组件和插件能够安全地存储敏感信息，供以后检索。其实现包含以下元素：

- 管理后备存储或与存储后端通信的密钥环组件和插件。使用密钥环时，需要从可用组件和插件中安装一个。密钥环组件和插件都管理密钥环数据，但配置方式不同，并且可能存在操作差异。请参阅[8.4.4.1节, “密钥环组件与密钥环插件”](#8.4.4.1)。

可用的密钥环组件如下：

- `component_keyring_file`：将密钥环数据存储在服务器主机上的本地文件中。在 MySQL Community Edition 和 MySQL Enterprise Edition 发行版中可用。请参阅[8.4.4.4节, “使用 component_keyring_file 文件基础的密钥环组件”](#8.4.4.4)。
- `component_keyring_encrypted_file`：将密钥环数据存储在服务器主机上的加密且受密码保护的本地文件中。在 MySQL Enterprise Edition 发行版中可用。请参阅[8.4.4.5节, “使用 component_keyring_encrypted_file 加密文件基础的密钥环组件”](#8.4.4.5)。
- `component_keyring_oci`：将密钥环数据存储在 Oracle 云基础设施保管库中。在 MySQL Enterprise Edition 发行版中可用。请参阅[8.4.4.9节, “使用 Oracle 云基础设施保管库密钥环组件”](#8.4.4.9)。

可用的密钥环插件如下：

- `keyring_okv`：一个 KMIP 1.1 插件，可与 Oracle Key Vault 和 Gemalto SafeNet KeySecure Appliance 等 KMIP 兼容的后端密钥环存储产品配合使用。在 MySQL Enterprise Edition 发行版中可用。请参阅[8.4.4.6节, “使用 keyring_okv KMIP 插件”](#8.4.4.6)。
- `keyring_aws`：与 Amazon Web Services Key Management Service 通信以生成密钥，并使用本地文件存储密钥。在 MySQL Enterprise Edition 发行版中可用。请参阅[8.4.4.7节, “使用 keyring_aws 亚马逊网络服务密钥环插件”](#8.4.4.7)。
- `keyring_hashicorp`：与 HashiCorp Vault 通信以实现后端存储。在 MySQL Enterprise Edition 发行版中可用。请参阅[8.4.4.8节, “使用 HashiCorp Vault 密钥环插件”](#8.4.4.8)。

- 用于密钥环密钥管理的密钥环服务接口。此服务可在两个层级访问：
  - SQL 接口：在 SQL 语句中，调用[8.4.4.12节, “通用密钥环密钥管理功能”](#8.4.4.12)中描述的函数。
  - C 接口：在 C 语言代码中，调用[7.6.9.2节, “密钥环服务”](#7.6.9.2)中描述的密钥环服务函数。
- 密钥元数据访问：
  - Performance Schema `keyring_keys` 表公开密钥环中密钥的元数据，包括密钥 ID、密钥所有者和后端密钥 ID。该表不会公开任何敏感的密钥环数据，例如密钥内容。请参阅[29.12.18.2节, “keyring_keys 表”](#29.12.18.2)。
  - Performance Schema `keyring_component_status` 表提供当前使用的密钥环组件的状态信息（如果已安装）。请参阅[29.12.18.1节, “keyring_component_status 表”](#29.12.18.1)。
- 密钥迁移能力。MySQL 支持在密钥库之间迁移密钥，使数据库管理员能够将 MySQL 安装从一个密钥库切换到另一个密钥库。请参阅[8.4.4.11节, “在密钥环密钥库之间迁移密钥”](#8.4.4.11)。
- 密钥环插件的实现经过修订，以使用组件基础设施。这项工作由名为 `daemon_keyring_proxy_plugin` 的内置插件完成，它在插件和组件服务 API 之间充当桥梁。请参阅[7.6.8节, “密钥环代理桥插件”](#7.6.8)。

> **警告**
>
> 对于加密密钥管理，`component_keyring_file` 和 `component_keyring_encrypted_file` 组件并非法规合规解决方案。PCI、FIPS 等安全标准要求使用密钥管理系统，在密钥保管库或硬件安全模块（HSM）中安全地存储、管理和保护加密密钥。

在 MySQL 内部，密钥环服务的使用者包括：

- InnoDB 存储引擎使用密钥环存储其表空间加密密钥。请参阅[17.13节, “InnoDB 静态数据加密”](#17.13)。
- MySQL Enterprise Audit 使用密钥环存储审计日志文件加密密码。请参阅[加密审计日志文件](#encrypting-audit-log-files)。
- 二进制日志和中继日志管理支持基于密钥环的日志文件加密。启用日志文件加密后，密钥环会存储用于加密二进制日志文件和中继日志文件密码的密钥。请参阅[19.3.2节, “加密二进制日志文件和中继日志文件”](#19.3.2)。
- 用于解密文件密钥的主密钥存储在密钥环中；该文件密钥又用于解密敏感系统变量的持久化值。必须在 MySQL 服务器实例上启用密钥环组件，才能支持持久化系统变量值的安全存储，而密钥环插件不支持此功能。请参阅[持久化敏感系统变量](#persisting-sensitive-system-variables)。

有关密钥环的一般安装说明，请参阅[8.4.4.2节, “密钥环组件安装”](#8.4.4.2)和[8.4.4.3节, “密钥环插件安装”](#8.4.4.3)。有关特定密钥环组件或插件的安装和配置信息，请参阅描述该组件或插件的章节。

有关密钥环函数的使用信息，请参阅[8.4.4.12节, “通用密钥环密钥管理功能”](#8.4.4.12)。

密钥环组件、插件和函数访问提供密钥环接口的密钥环服务。有关访问此服务以及编写密钥环插件的信息，请参阅[7.6.9.2节, “密钥环服务”](#7.6.9.2)和[编写密钥环插件](#writing-keyring-plugins)。
