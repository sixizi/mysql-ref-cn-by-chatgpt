# MySQL Enterprise加密安装和升级

在MySQL 8.0.30之前的版本中，MySQL企业加密提供的功能是通过基于openssl_udf共享库单独创建它们来安装的。从MySQL 8.0.30开始，这些功能由MySQL组件component_enterprise_encryption提供，安装该组件会安装所有功能。

官方英文版参见 [MySQL Enterprise Encryption Installation and Upgrading](https://dev.mysql.com/doc/refman/8.0/en/enterprise-encryption-installation.html)。
