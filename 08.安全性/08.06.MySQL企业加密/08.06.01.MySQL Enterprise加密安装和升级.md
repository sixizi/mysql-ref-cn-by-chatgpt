### 8.6.1 MySQL Enterprise Encryption 安装和升级

这些函数由 MySQL 组件 component_enterprise_encryption 提供，安装该组件会安装所有函数。

MySQL Enterprise Encryption 函数由 MySQL component_enterprise_encryption 组件提供。

如果你从 MySQL 8.0.30 之前的版本升级：在安装组件之前，使用 DROP FUNCTION 语句卸载任何旧版函数：

```
DROP FUNCTION asymmetric_decrypt;
DROP FUNCTION asymmetric_derive;
DROP FUNCTION asymmetric_encrypt;
DROP FUNCTION asymmetric_sign;
DROP FUNCTION asymmetric_verify;
DROP FUNCTION create_asymmetric_priv_key;
DROP FUNCTION create_asymmetric_pub_key;
DROP FUNCTION create_dh_parameters;
DROP FUNCTION create_digest;
```

函数名必须以小写形式指定。这些语句需要 mysql 数据库的 DROP 权限。

要安装组件，请执行以下 INSTALL COMPONENT 语句：

```
INSTALL COMPONENT "file://component_enterprise_encryption";
```

INSTALL COMPONENT 需要 mysql.component 系统表的 INSERT 权限，因为它会向该表添加一行以注册组件。要验证组件是否已安装，请执行以下语句：

```
SELECT * FROM mysql.component;
```

在 mysql.component 中列出的组件由加载器服务在启动序列期间加载。

如果需要卸载组件，请执行 UNINSTALL COMPONENT 语句：

```
UNINSTALL COMPONENT "file://component_enterprise_encryption";
```

卸载组件会卸载其所有函数。有关更多详情，请参见第 7.5.1 节"安装和卸载组件"。

注意

安装组件会安装其所有函数，因此你不需要像在较早的 MySQL 版本中那样使用 CREATE FUNCTION 语句创建它们。

安装组件后，如果希望组件函数支持对旧版函数生成的内容进行解密和验证，请将 enterprise_encryption.rsa_support_legacy_padding 系统变量设置为 ON。此外，如果要更改组件函数生成的 RSA 密钥允许的最大长度，请使用 enterprise_encryption.maximum_rsa_key_size 系统变量设置适当的最大值。有关配置信息，请参见第 8.6.2 节"配置 MySQL Enterprise Encryption"。
