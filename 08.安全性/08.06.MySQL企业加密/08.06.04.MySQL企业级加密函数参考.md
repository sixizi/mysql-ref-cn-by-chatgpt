### 8.6.4 MySQL Enterprise Encryption 函数参考

MySQL Enterprise Encryption 函数由 MySQL component_enterprise_encryption 组件提供。参见第 8.6.5 节"MySQL Enterprise Encryption 组件函数描述"。

表 8.59 MySQL Enterprise Encryption 函数

| 名称 | 描述 |
|------|------|
| asymmetric_decrypt() | 使用私钥或公钥解密密文 |
| asymmetric_derive() | 从非对称密钥派生对称密钥 |
| asymmetric_encrypt() | 使用私钥或公钥加密明文 |
| asymmetric_sign() | 从摘要生成签名 |
| asymmetric_verify() | 验证签名是否与摘要匹配 |
| create_asymmetric_priv_key() | 创建私钥 |
| create_asymmetric_pub_key() | 创建公钥 |
| create_dh_parameters() | 生成共享 DH 密钥 |
| create_digest() | 从字符串生成摘要 |
