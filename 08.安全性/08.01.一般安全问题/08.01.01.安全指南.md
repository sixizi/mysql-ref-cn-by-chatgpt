### 8.1.1 安全指南

任何在连接到互联网的计算机上使用 MySQL 的人都应该阅读本节，以避免最常见的安全错误。

在讨论安全性时，有必要充分考虑保护整个服务器主机（不仅仅是 MySQL 服务器）免受所有类型的适用攻击：窃听、篡改、重放和拒绝服务。我们在这里不涵盖可用性和容错的所有方面。

MySQL 对所有连接、查询和用户可以尝试执行的其他操作使用基于访问控制列表 (ACL) 的安全性。还支持 MySQL 客户端和服务器之间的 SSL 加密连接。这里讨论的许多概念并非特定于 MySQL；相同的一般思想适用于几乎所有应用程序。

运行 MySQL 时，请遵循以下指南：

- 永远不要给任何人（除了 MySQL root 账户）访问 mysql 系统数据库中的 user 表的权限！这是至关重要的。

- 了解 MySQL 访问权限系统的工作原理（参见第 8.2 节"访问控制和账户管理"）。使用 GRANT 和 REVOKE 语句来控制对 MySQL 的访问。不要授予超过必要的权限。永远不要向所有主机授予权限。

  检查清单：

  - 尝试 `mysql -u root`。如果您能够成功连接到服务器而不被要求输入密码，任何人都可以以 MySQL root 用户身份连接到您的 MySQL 服务器并拥有完全权限！查看 MySQL 安装说明，特别注意有关设置 root 密码的信息。参见第 2.9.4 节"保护初始 MySQL 账户"。

  - 使用 SHOW GRANTS 语句检查哪些账户有权访问什么。然后使用 REVOKE 语句删除不必要的权限。

- 不要在数据库中存储明文密码。如果您的计算机被攻击，入侵者可以获取完整的密码列表并使用它们。相反，使用 SHA2() 或其他单向哈希函数并存储哈希值。

  为了防止使用彩虹表恢复密码，不要对纯密码使用这些函数；相反，选择某个字符串用作盐，并使用 hash(hash(password)+salt) 值。

- 假设所有密码都将受到使用已知密码列表的自动破解尝试，以及使用关于您的公开信息（如社交媒体帖子）的有针对性的猜测。不要选择由容易破解或猜测的项目组成的密码，例如字典单词、专有名词、运动队名称、首字母缩略词或众所周知的短语，特别是如果它们与您相关。使用大写字母、数字替换和添加以及特殊字符，如果以可预测的方式使用，不会有帮助。也不要选择您在任何地方看到过的任何密码示例，或其变体，即使它被呈现为强密码的示例。

  相反，选择尽可能长且不可预测的密码。这并不意味着组合需要是难以记住和重现的随机字符串，尽管如果您有例如可以生成和填充此类密码并安全存储它们的密码管理器软件，这是一个很好的方法。包含多个单词的密码短语易于创建、记住和重现，并且比由单个修改单词或可预测字符序列组成的典型用户选择的密码安全得多。要创建安全的密码短语，请确保其中的单词和其他项目不是已知的短语或引用，不以可预测的顺序出现，最好彼此之间完全没有先前的关系。

- 投资防火墙。这可以保护您免受任何软件中至少 50% 的所有类型的漏洞。将 MySQL 放在防火墙后面或在非军事区 (DMZ) 中。

#### 保持密码安全

检查清单：

- 尝试使用 nmap 等工具从互联网扫描您的端口。MySQL 默认使用端口 3306。此端口不应该可从不受信任的主机访问。作为检查 MySQL 端口是否打开的简单方法，请从某个远程机器尝试以下命令，其中 server_host 是运行 MySQL 服务器的主机的主机名或 IP 地址：
  ```
  $> telnet server_host 3306
  ```

  如果 telnet 挂起或连接被拒绝，端口被阻止，这是您想要的方式。如果您获得连接和一些垃圾字符，端口是打开的，应该在您的防火墙或路由器上关闭，除非您确实有充分的理由保持它打开。

- 访问 MySQL 的应用程序不应该信任用户输入的任何数据，应该使用适当的防御性编程技术编写。参见第 8.1.7 节"客户端编程安全指南"。

- 不要通过互联网传输纯（未加密）数据。这些信息可被任何有时间和能力拦截它并将其用于自己目的的人访问。相反，使用 SSL 或 SSH 等加密协议。MySQL 支持内部 SSL 连接。另一种技术是使用 SSH 端口转发为通信创建加密（和压缩）隧道。

- 学会使用 tcpdump 和 strings 实用程序。在大多数情况下，您可以通过发出如下命令来检查 MySQL 数据流是否未加密：
  ```
  $> tcpdump -l -i eth0 -w - src or dst port 3306 | strings
  ```

  这在 Linux 下有效，在其他系统下应该可以进行小的修改。

  **警告**

  如果您没有看到明文数据，这并不总是意味着信息实际上是加密的。如果您需要高安全性，请咨询安全专家。
