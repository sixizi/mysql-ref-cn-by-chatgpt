# MySQL Enterprise 数据脱敏和去识别组件安装

从 MySQL 8.0.33 开始，组件提供对 MySQL Enterprise Data Masking 和 De-Identification 功能的访问。此前，MySQL 将屏蔽和去识别功能作为包含插件和多个可加载函数的插件库文件来实现。

官方英文版参见 [MySQL Enterprise Data Masking and De-Identification Component Installation](https://dev.mysql.com/doc/refman/8.0/en/data-masking-components-installation.html)。
