# 数据屏蔽组件与数据屏蔽插件

在 8.0.33 之前，MySQL 使用服务器端插件启用了屏蔽和去识别功能，但在 MySQL 8.0.33 中过渡为使用组件基础架构。下表简要比较了 MySQL Enterprise Data Masking 和 De-Identification 组件以及插件库，以概述它们的差异。

官方英文版参见 [Data-Masking Components Versus the Data-Masking Plugin](https://dev.mysql.com/doc/refman/8.0/en/data-masking-components-vs-plugin.html)。
