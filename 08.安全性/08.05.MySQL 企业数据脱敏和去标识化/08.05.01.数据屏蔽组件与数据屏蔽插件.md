## 8.5.1 数据脱敏组件与数据脱敏插件的对比

之前，MySQL 使用服务器端插件来实现数据脱敏和去标识化功能，但现已过渡到使用组件基础设施作为替代实现方案。下表简要比较了 MySQL Enterprise 数据脱敏组件和插件库，以概述它们的差异。这可能有助于您从插件过渡到组件。

注意

一次只应启用数据脱敏组件或插件。同时启用组件和插件不受支持，结果可能不符合预期。

表 8.56 数据脱敏组件和插件元素的对比

| 类别 | 组件 | 插件 |
|------|------|------|
| 接口 | 服务函数、可加载函数 | 可加载函数 |
| 多字节字符集支持 | 是，用于通用脱敏函数 | 否 |
| 通用脱敏函数 | mask_inner()、mask_outer() | mask_inner()、mask_outer() |
| 特定类型的脱敏 | PAN、SSN、IBAN、UUID、Canada SIN、UK NIN | PAN、SSN |
| 特定类型的随机生成 | email、US phone、PAN、SSN、IBAN、UUID、Canada SIN、UK NIN | email、US phone、PAN、SSN |
| 从给定范围生成随机整数 | 是 | 是 |
| 持久化替换字典 | 数据库 | 文件 |
| 管理字典的权限 | 专用权限 | FILE |
| 安装/卸载期间自动化可加载函数注册/注销 | 是 | 否 |
| 现有函数的增强 | 为 gen_rnd_email() 函数添加了更多参数 | N/A |
