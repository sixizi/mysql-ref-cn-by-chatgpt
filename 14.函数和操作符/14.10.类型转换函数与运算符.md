### 14.10 类型转换函数与运算符

类型转换函数与操作符：

- `CAST(expr AS type)`：标准 SQL 转换。
- `CONVERT(expr, type)`：等价于 `CAST()`。
- `CONVERT(expr USING charset)`：转换字符集。
- `BINARY expr`：转换为二进制字符串比较。
- `COLLATE`：指定排序规则。

```sql
SELECT CAST('123' AS UNSIGNED);
SELECT CONVERT('abc' USING utf8mb4);
```
