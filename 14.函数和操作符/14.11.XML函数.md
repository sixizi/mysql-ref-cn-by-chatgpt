### 14.11 XML函数

MySQL 提供两个 XML 函数：

- `ExtractValue(xml, xpath)`：返回 XPath 匹配到的文本。
- `UpdateXML(xml, xpath, replacement)`：替换匹配片段。

```sql
SELECT ExtractValue('<a><b>1</b></a>', '/a/b');
```

这两个函数支持有限的 XPath 子集，不支持任意 XSLT 或复杂 XML 处理；复杂转换建议在应用层完成。
