### 14.17.1 JSON函数参考

常用 JSON 函数参考：

- `JSON_EXTRACT(json, path)` / `json->path`：提取值。
- `JSON_UNQUOTE(json)`：去掉 JSON 字符串引号。
- `json->>'path'`：等价于 `JSON_UNQUOTE(JSON_EXTRACT(...))`。
- `JSON_ARRAY_APPEND()`、`JSON_ARRAY_INSERT()`：操作数组。
- `JSON_CONTAINS_PATH()`：判断路径是否存在。
- `JSON_PRETTY()`：格式化输出。

MySQL 8.0 也支持 JSON 部分更新优化和多值索引。
