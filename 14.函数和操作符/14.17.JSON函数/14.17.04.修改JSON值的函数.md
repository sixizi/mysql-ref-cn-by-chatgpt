### 14.17.4 修改JSON值的函数

修改 JSON 值的函数：

- `JSON_SET()`：存在则更新，不存在则插入。
- `JSON_INSERT()`：仅在路径不存在时插入。
- `JSON_REPLACE()`：仅在路径存在时替换。
- `JSON_REMOVE()`：删除路径。
- `JSON_MERGE_PATCH()`：按 RFC 7396 合并。
- `JSON_MERGE_PRESERVE()`：保留数组元素并合并。

```sql
SELECT JSON_SET('{"a":1}', '$.b', 2);
```
