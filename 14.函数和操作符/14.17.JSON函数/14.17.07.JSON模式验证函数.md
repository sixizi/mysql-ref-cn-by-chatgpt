### 14.17.7 JSON模式验证函数

JSON Schema 验证函数：

- `JSON_SCHEMA_VALID(schema, document)`：返回 1 或 0。
- `JSON_SCHEMA_VALIDATION_REPORT(schema, document)`：返回详细验证报告。

```sql
SELECT JSON_SCHEMA_VALID('{"type":"object"}', '{}');
```

可用于写入前校验业务 JSON 结构，但复杂校验仍建议结合应用层或约束。
