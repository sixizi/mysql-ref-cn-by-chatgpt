### 14.17.2 创建JSON值的函数

创建 JSON 值的函数：

- `JSON_ARRAY(value, ...)`：创建数组。
- `JSON_OBJECT(key, value, ...)`：创建对象。
- `JSON_QUOTE(text)`：把字符串转为 JSON 字符串。
- `JSON_ARRAYAGG()`：聚合为 JSON 数组。
- `JSON_OBJECTAGG()`：聚合为 JSON 对象。

示例：

```sql
SELECT JSON_OBJECT('id', 1, 'tags', JSON_ARRAY('a','b'));
```
