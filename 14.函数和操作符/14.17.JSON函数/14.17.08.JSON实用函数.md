### 14.17.8 JSON实用函数

JSON 实用函数：

- `JSON_PRETTY()`：格式化输出。
- `JSON_STORAGE_FREE()`：部分更新后释放的空间。
- `JSON_ARRAYAGG()`、`JSON_OBJECTAGG()`：把查询结果聚合为 JSON。
- `JSON_MEMBER_OF()` / `MEMBER OF()`：判断值是否属于 JSON 数组。

这些函数主要用于展示、聚合和成员判断。
