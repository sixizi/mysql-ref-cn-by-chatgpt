### 14.17.6 JSON表函数

`JSON_TABLE()` 将 JSON 数组转换为关系行：

```sql
SELECT jt.*
FROM data,
JSON_TABLE(data.json, '$[*]' COLUMNS (
  id INT PATH '$.id',
  name VARCHAR(50) PATH '$.name'
)) AS jt;
```

它可以在 `FROM` 子句中展开嵌套数组、提取标量并定义错误处理。适合把 JSON 数据转成可查询、可连接的行集。
