JSON 函数用于创建、搜索、修改、验证和转换 JSON 文档。

主要分组：

- 创建：`JSON_ARRAY()`、`JSON_OBJECT()`。
- 搜索：`JSON_EXTRACT()`、`JSON_CONTAINS()`、`JSON_SEARCH()`。
- 修改：`JSON_SET()`、`JSON_INSERT()`、`JSON_REPLACE()`、`JSON_REMOVE()`。
- 表转换：`JSON_TABLE()`。
- 属性：`JSON_TYPE()`、`JSON_DEPTH()`、`JSON_LENGTH()`。
