### 14.17.5 返回JSON值属性的函数

返回 JSON 值属性的函数：

- `JSON_TYPE()`：返回 JSON 类型。
- `JSON_VALID()`：验证是否为有效 JSON。
- `JSON_DEPTH()`：嵌套深度。
- `JSON_LENGTH()`：数组长度、对象成员数或标量 1。
- `JSON_STORAGE_SIZE()`：内部存储字节数。
- `JSON_KEYS()`：顶层键。
- `JSON_PATH()`：从 JSON 路径提取路径文本。

这些函数适合校验结构、生成报告或估算存储。
