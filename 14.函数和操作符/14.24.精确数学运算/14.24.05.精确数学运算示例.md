### 14.26.5 精确数学示例

本节提供一些示例，展示 MySQL 中精确数学查询结果。这些示例演示了第 14.26.3 节"表达式处理"和第 14.26.4 节"舍入行为"中描述的原理。

示例 1. 尽可能使用给定的精确值：
```
mysql> SELECT (.1 + .2) = .3;
+----------------+
| (.1 + .2) = .3 |
+----------------+
|              1 |
+----------------+
```

对于浮点值，结果是不精确的：
```
mysql> SELECT (.1E0 + .2E0) = .3E0;
+----------------------+
| (.1E0 + .2E0) = .3E0 |
+----------------------+
|                    0 |
+----------------------+
```

查看精确值和近似值处理差异的另一种方法是多次将一个小数字加到总和中。考虑以下存储过程，它将 .0001 加到变量 1,000 次。
```
CREATE PROCEDURE p ()
BEGIN
  DECLARE i INT DEFAULT 0;
  DECLARE d DECIMAL(10,4) DEFAULT 0;
  DECLARE f FLOAT DEFAULT 0;
  WHILE i < 10000 DO
    SET d = d + .0001;
    SET f = f + .0001E0;
    SET i = i + 1;
  END WHILE;
  SELECT d, f;
END;
```

d 和 f 的总和在逻辑上应该是 1，但这仅对十进制计算成立。浮点计算引入了小错误：
```
+--------+------------------+
| d      | f                |
+--------+------------------+
| 1.0000 | 0.99999999999991 |
+--------+------------------+
```

示例 2. 乘法按标准 SQL 所需的精度执行。即，对于具有精度 S1 和 S2 的两个数字 X1 和 X2，结果的精度是 S1 + S2：
```
mysql> SELECT .01 * .01;
+-----------+
| .01 * .01 |
+-----------+
| 0.0001    |
+-----------+
```

示例 3. 精确值数字的舍入行为定义明确：

舍入行为（例如，使用 ROUND() 函数）独立于底层 C 库的实现，这意味着结果在各平台上是一致的。

- 精确值列（DECIMAL 和整数）和精确值数字的舍入使用"四舍五入"规则。小数部分为 .5 或更大的值舍入到最近的整数，如下所示：
```
mysql> SELECT ROUND(2.5), ROUND(-2.5);
+------------+-------------+
| ROUND(2.5) | ROUND(-2.5) |
+------------+-------------+
| 3          | -3          |
+------------+-------------+
```

- 浮点值的舍入使用 C 库，在许多系统上使用"舍入到最近的偶数"规则。小数部分恰好在两个整数之间的一半的值舍入到最近的偶数整数：
```
mysql> SELECT ROUND(2.5E0), ROUND(-2.5E0);
+--------------+---------------+
| ROUND(2.5E0) | ROUND(-2.5E0) |
+--------------+---------------+
|            2 |            -2 |
+--------------+---------------+
```

示例 4. 在严格模式下，插入超出列范围的值会导致错误，而不是截断为合法值。

当 MySQL 不在严格模式下运行时，会截断为合法值：
```
mysql> SET sql_mode='';
Query OK, 0 rows affected (0.00 sec)

mysql> CREATE TABLE t (i TINYINT);
Query OK, 0 rows affected (0.01 sec)

mysql> INSERT INTO t SET i = 128;
Query OK, 1 row affected, 1 warning (0.00 sec)

mysql> SELECT i FROM t;
+------+
| i    |
+------+
| 127  |
+------+
1 row in set (0.00 sec)
```

但是，如果严格模式生效，会发生错误：
```
mysql> SET sql_mode='STRICT_ALL_TABLES';
Query OK, 0 rows affected (0.00 sec)

mysql> CREATE TABLE t (i TINYINT);
Query OK, 0 rows affected (0.00 sec)

mysql> INSERT INTO t SET i = 128;
ERROR 1264 (22003): Out of range value adjusted for column 'i' at row 1

mysql> SELECT i FROM t;
Empty set (0.00 sec)
```

示例 5：在严格模式和设置了 ERROR_FOR_DIVISION_BY_ZERO 的情况下，除以零会导致错误，而不是 NULL 结果。

在非严格模式下，除以零的结果是 NULL：
```
mysql> SET sql_mode='';
Query OK, 0 rows affected (0.01 sec)

mysql> CREATE TABLE t (i TINYINT);
Query OK, 0 rows affected (0.00 sec)

mysql> INSERT INTO t SET i = 1 / 0;
Query OK, 1 row affected (0.00 sec)

mysql> SELECT i FROM t;
+------+
| i    |
+------+
| NULL |
+------+
1 row in set (0.03 sec)
```

但是，如果设置了适当的 SQL 模式，除以零是一个错误：
```
mysql> SET sql_mode='STRICT_ALL_TABLES,ERROR_FOR_DIVISION_BY_ZERO';
Query OK, 0 rows affected (0.00 sec)

mysql> CREATE TABLE t (i TINYINT);
Query OK, 0 rows affected (0.00 sec)

mysql> INSERT INTO t SET i = 1 / 0;
ERROR 1365 (22012): Division by 0

mysql> SELECT i FROM t;
Empty set (0.01 sec)
```

示例 6. 精确值文字被评估为精确值。

近似值文字使用浮点进行评估，但精确值文字作为 DECIMAL 处理：
```
mysql> CREATE TABLE t SELECT 2.5 AS a, 25E-1 AS b;
Query OK, 1 row affected (0.01 sec)
Records: 1 Duplicates: 0 Warnings: 0

mysql> DESCRIBE t;
+-------+-----------------------+------+-----+---------+-------+
| Field | Type                  | Null | Key | Default | Extra |
+-------+-----------------------+------+-----+---------+-------+
| a     | decimal(2,1) unsigned | NO   |     | 0.0     |       |
| b     | double                | NO   |     | 0       |       |
+-------+-----------------------+------+-----+---------+-------+
2 rows in set (0.01 sec)
```

示例 7. 如果聚合函数的参数是精确数值类型，结果也是精确数值类型，其精度至少与参数相同。

考虑这些语句：
```
mysql> CREATE TABLE t (i INT, d DECIMAL, f FLOAT);
mysql> INSERT INTO t VALUES(1,1,1);
mysql> CREATE TABLE y SELECT AVG(i), AVG(d), AVG(f) FROM t;
```

结果仅对浮点参数是 double。对于精确类型参数，结果也是精确类型：
```
mysql> DESCRIBE y;
+--------+---------------+------+-----+---------+-------+
| Field | Type           | Null | Key | Default | Extra |
+--------+---------------+------+-----+---------+-------+
| AVG(i) | decimal(14,4) | YES  |     | NULL    |       |
| AVG(d) | decimal(14,4) | YES  |     | NULL    |       |
| AVG(f) | double        | YES  |     | NULL    |       |
+--------+---------------+------+-----+---------+-------+
```

结果仅对浮点参数是 double。对于精确类型参数，结果也是精确类型。
