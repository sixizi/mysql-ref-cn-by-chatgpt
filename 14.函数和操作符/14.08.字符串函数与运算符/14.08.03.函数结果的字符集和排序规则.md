### 14.8.3 函数结果的字符集和排序规则

MySQL 有许多运算符和函数返回字符串。本节回答以下问题：这样的字符串的字符集和排序规则是什么？

对于接受字符串输入并返回字符串结果的简单函数，输出的字符集和排序规则与主要输入值的字符集和排序规则相同。例如，UPPER(X) 返回一个与 X 具有相同字符集和排序规则的字符串。这同样适用于 INSTR()、LCASE()、LOWER()、LTRIM()、MID()、REPEAT()、REPLACE()、REVERSE()、RIGHT()、RPAD()、RTRIM()、SOUNDEX()、SUBSTRING()、TRIM()、UCASE() 和 UPPER()。

注意

REPLACE() 函数与所有其他函数不同，它总是忽略字符串输入的排序规则，并执行区分大小写的比较。

如果字符串输入或函数结果是二进制字符串，该字符串具有二进制字符集和排序规则。这可以通过使用 CHARSET() 和 COLLATION() 函数来检查，这两个函数对于二进制字符串参数都返回 binary：

```
mysql> SELECT CHARSET(BINARY 'a'), COLLATION(BINARY 'a');
+---------------------+-----------------------+
| CHARSET(BINARY 'a') | COLLATION(BINARY 'a') |
+---------------------+-----------------------+
| binary              | binary                |
+---------------------+-----------------------+
```

对于组合多个字符串输入并返回单个字符串输出的操作，应用标准 SQL 的"聚合规则"来确定结果的排序规则：

- 如果出现显式 COLLATE Y，使用 Y。

- 如果同时出现显式 COLLATE Y 和 COLLATE Z，抛出错误。

- 否则，如果所有排序规则都是 Y，使用 Y。

- 否则，结果没有排序规则。

例如，对于 CASE ... WHEN a THEN b WHEN b THEN c COLLATE X END，结果的排序规则是 X。这同样适用于 UNION、||、CONCAT()、ELT()、GREATEST()、IF() 和 LEAST()。

对于转换为字符数据的操作，从这些操作产生的字符串的字符集和排序规则由 character_set_connection 和 collation_connection 系统变量定义，这些变量确定默认连接字符集和排序规则（参见第 12.4 节"连接字符集和排序规则"）。这仅适用于 BIN_TO_UUID()、CAST()、CONV()、FORMAT()、HEX() 和 SPACE()。

对于虚拟生成列的表达式，前述原则有一个例外。在这样的表达式中，无论连接字符集如何，BIN_TO_UUID()、CONV() 或 HEX() 结果都使用表字符集。

如果对字符串函数返回的结果的字符集或排序规则有任何疑问，请使用 CHARSET() 或 COLLATION() 函数来查找：

```
mysql> SELECT USER(), CHARSET(USER()), COLLATION(USER());
+----------------+-----------------+--------------------+
| USER()         | CHARSET(USER()) | COLLATION(USER()) |
+----------------+-----------------+--------------------+
| test@localhost | utf8mb3          | utf8mb3_general_ci |
+----------------+-----------------+--------------------+
mysql> SELECT CHARSET(COMPRESS('abc')), COLLATION(COMPRESS('abc'));
+--------------------------+----------------------------+
| CHARSET(COMPRESS('abc')) | COLLATION(COMPRESS('abc')) |
+--------------------------+----------------------------+
| binary                   | binary                      |
+--------------------------+----------------------------+
```
