### 14.9.1 自然语言全文检索

自然语言全文检索按相关度查找行：

```sql
CREATE TABLE articles (
  id INT PRIMARY KEY,
  body TEXT,
  FULLTEXT idx_body (body)
);

SELECT id, MATCH(body) AGAINST('database') AS score
FROM articles
WHERE MATCH(body) AGAINST('database');
```

默认模式为自然语言检索，返回相关性得分。搜索词太常见或被停用词过滤时可能没有结果。
