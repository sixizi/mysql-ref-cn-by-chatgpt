### 14.5 流程控制函数

流程控制函数在表达式内做条件判断：

- `CASE ... WHEN ... ELSE ... END`
- `IF(condition, true_value, false_value)`
- `IFNULL(value, replacement)`
- `NULLIF(value1, value2)`：两者相等返回 `NULL`，否则返回第一个值。

示例：

```sql
SELECT CASE WHEN score >= 60 THEN 'pass' ELSE 'fail' END;
```
