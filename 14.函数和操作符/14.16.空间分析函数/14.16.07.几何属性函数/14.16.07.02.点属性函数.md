### 14.16.7.2 点属性函数

Point 由 X 和 Y 坐标组成，可分别使用 ST_X() 和 ST_Y() 函数获取。这些函数还允许使用可选的第二个参数来指定 X 或 Y 坐标值，在这种情况下，函数结果是第一个参数的 Point 对象，其相应坐标被修改为等于第二个参数。

对于具有地理空间参考系统 (SRS) 的 Point 对象，可分别使用 ST_Longitude() 和 ST_Latitude() 函数获取经度和纬度。这些函数也允许使用可选的第二个参数来指定经度或纬度值，在这种情况下，函数结果是第一个参数的 Point 对象，其经度或纬度被修改为等于第二个参数。

除非另有说明，本节中的函数处理其几何参数的方式如下：

- 如果任何参数为 NULL，返回值为 NULL。

- 如果任何几何参数是有效的几何但不是 Point 对象，会发生 ER_UNEXPECTED_GEOMETRY_TYPE 错误。

- 如果任何几何参数不是语法上格式良好的几何，会发生 ER_GIS_INVALID_DATA 错误。

- 如果任何几何参数是语法上格式良好的几何但位于未定义的空间参考系统 (SRS) 中，会发生 ER_SRS_NOT_FOUND 错误。

- 如果提供了 X 或 Y 坐标参数且值为 -inf、+inf 或 NaN，会发生 ER_DATA_OUT_OF_RANGE 错误。

- 如果经度或纬度值超出范围，会发生错误：

  - 如果经度值不在范围 (−180, 180] 内，会发生 ER_LONGITUDE_OUT_OF_RANGE 错误。

  - 如果纬度值不在范围 [−90, 90] 内，会发生 ER_LATITUDE_OUT_OF_RANGE 错误。

  显示的范围以度为单位。由于浮点运算，确切的范围限制会略有偏差。

- 否则，返回值为非 NULL。

以下函数可用于获取点属性：

几何属性函数

- ST_Latitude(p [, new_latitude_val])

  使用代表具有地理空间参考系统 (SRS) 的有效 Point 对象 p 的单个参数，ST_Latitude() 以双精度数字形式返回 p 的纬度值。

  使用代表有效纬度值的可选第二个参数，ST_Latitude() 返回一个类似第一个参数的 Point 对象，其纬度等于第二个参数。

  ST_Latitude() 按本节介绍中所述处理其参数，另外如果 Point 对象有效但没有地理 SRS，会发生 ER_SRS_NOT_GEOGRAPHIC 错误。

  ```
  mysql> SET @pt = ST_GeomFromText('POINT(45 90)', 4326);
  mysql> SELECT ST_Latitude(@pt);
  +------------------+
  | ST_Latitude(@pt) |
  +------------------+
  |               45 |
  +------------------+
  mysql> SELECT ST_AsText(ST_Latitude(@pt, 10));
  +---------------------------------+
  | ST_AsText(ST_Latitude(@pt, 10)) |
  +---------------------------------+
  | POINT(10 90)                    |
  +---------------------------------+
  ```

- ST_Longitude(p [, new_longitude_val])

  使用代表具有地理空间参考系统 (SRS) 的有效 Point 对象 p 的单个参数，ST_Longitude() 以双精度数字形式返回 p 的经度值。

  使用代表有效经度值的可选第二个参数，ST_Longitude() 返回一个类似第一个参数的 Point 对象，其经度等于第二个参数。

  ST_Longitude() 按本节介绍中所述处理其参数，另外如果 Point 对象有效但没有地理 SRS，会发生 ER_SRS_NOT_GEOGRAPHIC 错误。

  ```
  mysql> SET @pt = ST_GeomFromText('POINT(45 90)', 4326);
  mysql> SELECT ST_Longitude(@pt);
  +-------------------+
  | ST_Longitude(@pt) |
  +-------------------+
  |                90 |
  +-------------------+
  mysql> SELECT ST_AsText(ST_Longitude(@pt, 10));
  +----------------------------------+
  | ST_AsText(ST_Longitude(@pt, 10)) |
  +----------------------------------+
  | POINT(45 10)                     |
  +----------------------------------+
  ```

- ST_X(p [, new_x_val])

  使用代表有效 Point 对象 p 的单个参数，ST_X() 以双精度数字形式返回 p 的 X 坐标值。X 坐标被认为是指 Point 空间参考系统 (SRS) 定义中首先出现的轴。

  使用可选的第二个参数，ST_X() 返回一个类似第一个参数的 Point 对象，其 X 坐标等于第二个参数。如果 Point 对象具有地理 SRS，第二个参数必须在经度或纬度值的适当范围内。

  ST_X() 按本节介绍中所述处理其参数。

  ```
  mysql> SELECT ST_X(Point(56.7, 53.34));
  +--------------------------+
  | ST_X(Point(56.7, 53.34)) |
  +--------------------------+
  |                     56.7 |
  +--------------------------+
  mysql> SELECT ST_AsText(ST_X(Point(56.7, 53.34), 10.5));
  +-------------------------------------------+
  | ST_AsText(ST_X(Point(56.7, 53.34), 10.5)) |
  +-------------------------------------------+
  | POINT(10.5 53.34)                         |
  +-------------------------------------------+
  ```

- ST_Y(p [, new_y_val])

  使用代表有效 Point 对象 p 的单个参数，ST_Y() 以双精度数字形式返回 p 的 Y 坐标值。Y 坐标被认为是指 Point 空间参考系统 (SRS) 定义中第二个出现的轴。

  使用可选的第二个参数，ST_Y() 返回一个类似第一个参数的 Point 对象，其 Y 坐标等于第二个参数。如果 Point 对象具有地理 SRS，第二个参数必须在经度或纬度值的适当范围内。

  ST_Y() 按本节介绍中所述处理其参数。

  ```
  mysql> SELECT ST_Y(Point(56.7, 53.34));
  +--------------------------+
  | ST_Y(Point(56.7, 53.34)) |
  +--------------------------+
  |                    53.34 |
  +--------------------------+
  mysql> SELECT ST_AsText(ST_Y(Point(56.7, 53.34), 10.5));
  +-------------------------------------------+
  | ST_AsText(ST_Y(Point(56.7, 53.34), 10.5)) |
  +-------------------------------------------+
  | POINT(56.7 10.5)                          |
  +-------------------------------------------+
  ```
