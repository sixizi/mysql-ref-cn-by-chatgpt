### 14.16.7.1 通用几何属性函数

本节列出的函数不限制其参数，接受任何类型的几何值。

除非另有说明，本节中的函数按以下方式处理其几何参数：

- 如果任何参数为 NULL，返回值为 NULL。

- 如果任何几何参数的语法格式不正确，会发生 ER_GIS_INVALID_DATA 错误。

- 如果任何几何参数的语法格式正确但位于未定义的空间参考系统 (SRS) 中，会发生 ER_SRS_NOT_FOUND 错误。

- 如果任何 SRID 参数不在 32 位无符号整数的范围内，会发生 ER_DATA_OUT_OF_RANGE 错误。

- 如果任何 SRID 参数引用未定义的 SRS，会发生 ER_SRS_NOT_FOUND 错误。

- 否则，返回值为非 NULL。

以下函数可用于获取几何属性：

- ST_Dimension(g)

  返回几何值 g 的固有维度。维度可以是 −1、0、1 或 2。这些值的含义在第 13.4.2.2 节"几何类"中给出。

  ST_Dimension() 按本节介绍中所述的方式处理其参数。

  ```
  mysql> SELECT ST_Dimension(ST_GeomFromText('LineString(1 1,2 2)'));
  +------------------------------------------------------+
  | ST_Dimension(ST_GeomFromText('LineString(1 1,2 2)')) |
  +------------------------------------------------------+
  |                                                    1 |
  +------------------------------------------------------+
  ```

- ST_Envelope(g)

  返回几何值 g 的最小边界矩形 (MBR)。结果作为由边界框的角点定义的 Polygon 值返回：

  ```
  POLYGON((MINX MINY, MAXX MINY, MAXX MAXY, MINX MAXY, MINX MINY))
  ```

  ```
  mysql> SELECT ST_AsText(ST_Envelope(ST_GeomFromText('LineString(1 1,2 2)')));
  +----------------------------------------------------------------+
  | ST_AsText(ST_Envelope(ST_GeomFromText('LineString(1 1,2 2)'))) |
  +----------------------------------------------------------------+
  | POLYGON((1 1,2 1,2 2,1 2,1 1))                                 |
  +----------------------------------------------------------------+
  ```

  如果参数是点或垂直或水平线段，ST_Envelope() 返回点或线段作为其 MBR，而不是返回无效的多边形：

  ```
  mysql> SELECT ST_AsText(ST_Envelope(ST_GeomFromText('LineString(1 1,1 2)')));
  +----------------------------------------------------------------+
  | ST_AsText(ST_Envelope(ST_GeomFromText('LineString(1 1,1 2)'))) |
  +----------------------------------------------------------------+
  | LINESTRING(1 1,1 2)                                            |
  +----------------------------------------------------------------+
  ```

  ST_Envelope() 按本节介绍中所述的方式处理其参数，但以下情况除外：

  - 如果几何具有地理空间参考系统 (SRS) 的 SRID 值，会发生 ER_NOT_IMPLEMENTED_FOR_GEOGRAPHIC_SRS 错误。

- ST_GeometryType(g)

  返回一个二进制字符串，指示几何实例 g 所属的几何类型的名称。该名称对应于可实例化的 Geometry 子类之一。

  ST_GeometryType() 按本节介绍中所述的方式处理其参数。

  ```
  mysql> SELECT ST_GeometryType(ST_GeomFromText('POINT(1 1)'));
  +------------------------------------------------+
  | ST_GeometryType(ST_GeomFromText('POINT(1 1)')) |
  +------------------------------------------------+
  | POINT                                          |
  +------------------------------------------------+
  ```

- ST_IsEmpty(g)

  此函数是一个占位符，对于空几何集合值返回 1，否则返回 0。

  唯一有效的空几何以空几何集合值的形式表示。MySQL 不支持 GIS EMPTY 值，如 POINT EMPTY。

  ST_IsEmpty() 按本节介绍中所述的方式处理其参数。

- ST_IsSimple(g)

  如果几何值 g 根据 ISO SQL/MM Part 3: Spatial 标准是简单的，返回 1。ST_IsSimple() 如果参数不是简单的，返回 0。

  第 13.4.2 节"OpenGIS 几何模型"下给出的可实例化几何类的描述包括导致类实例被分类为不简单的具体条件。

  ST_IsSimple() 按本节介绍中所述的方式处理其参数，但以下情况除外：

  - 如果几何具有地理 SRS，其经度或纬度超出范围，会发生错误：

    - 如果经度值不在范围 (−180, 180] 内，会发生 ER_GEOMETRY_PARAM_LONGITUDE_OUT_OF_RANGE 错误。

    - 如果纬度值不在范围 [−90, 90] 内，会发生 ER_GEOMETRY_PARAM_LATITUDE_OUT_OF_RANGE 错误。

  显示的范围以度为单位。由于浮点运算，确切的范围限制略有偏差。

- ST_SRID(g [, srid])

  使用表示有效几何对象 g 的单个参数，ST_SRID() 返回一个整数，指示与 g 关联的空间参考系统 (SRS) 的 ID。

  使用表示有效 SRID 值的可选第二个参数，ST_SRID() 返回一个与其第一个参数类型相同的对象，其 SRID 值等于第二个参数。这仅设置对象的 SRID 值；它不执行坐标值的任何转换。

  ST_SRID() 按本节介绍中所述的方式处理其参数，但以下情况除外：

  - 对于单参数语法，ST_SRID() 返回几何 SRID，即使它引用未定义的 SRS。不会发生 ER_SRS_NOT_FOUND 错误。

  ST_SRID(g, target_srid) 和 ST_Transform(g, target_srid) 的区别如下：

  - ST_SRID() 更改几何 SRID 值而不转换其坐标。

  - ST_Transform() 在更改其 SRID 值的同时转换几何坐标。

  ```
  mysql> SET @g = ST_GeomFromText('LineString(1 1,2 2)', 0);
  mysql> SELECT ST_SRID(@g);
  +-------------+
  | ST_SRID(@g) |
  +-------------+
  |           0 |
  +-------------+
  mysql> SET @g = ST_SRID(@g, 4326);
  mysql> SELECT ST_SRID(@g);
  +-------------+
  | ST_SRID(@g) |
  +-------------+
  |        4326 |
  +-------------+
  ```

  可以通过将 MySQL 特定函数之一创建空间值的结果与 SRID 值一起传递给 ST_SRID()，在特定 SRID 中创建几何。例如：

  ```
  SET @g1 = ST_SRID(Point(1, 1), 4326);
  ```

  但是，该方法在 SRID 0 中创建几何，然后将其转换为 SRID 4326 (WGS 84)。更好的替代方法是从一开始就使用正确的空间参考系统创建几何。例如：

  ```
  SET @g1 = ST_PointFromText('POINT(1 1)', 4326);
  ```

  ```
  SET @g1 = ST_GeomFromText('POINT(1 1)', 4326);
  ```

  ST_SRID() 的双参数形式对于纠正或更改具有不正确 SRID 的几何的 SRS 等任务很有用。
