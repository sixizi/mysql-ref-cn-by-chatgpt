### 14.16.5 创建几何值的 MySQL 特定函数

MySQL 提供了一组有用的非标准函数用于创建几何值。本节描述的函数是 MySQL 对 OpenGIS 规范的扩展。

这些函数从 WKB 值或几何对象作为参数生成几何对象。如果任何参数不是正确对象类型的正确 WKB 或几何表示，返回值为 NULL。

例如，你可以直接将 Point() 的几何返回值插入到 POINT 列中：
INSERT INTO t1 (pt_col) VALUES(Point(1,2));

- GeomCollection(g [, g] ...)

  从几何参数构造 GeomCollection 值。

  GeomCollection() 返回参数中包含的所有正确几何，即使存在不支持的几何也是如此。

  GeomCollection() 不带参数是允许的，作为创建空几何的一种方式。此外，诸如 ST_GeomFromText() 之类接受 WKT 几何集合参数的函数理解 OpenGIS 'GEOMETRYCOLLECTION EMPTY' 标准语法和 MySQL 'GEOMETRYCOLLECTION()' 非标准语法。

  GeomCollection() 和 GeometryCollection() 是同义词，GeomCollection() 是首选函数。

- GeometryCollection(g [, g] ...)

  从几何参数构造 GeomCollection 值。

  GeometryCollection() 返回参数中包含的所有正确几何，即使存在不支持的几何也是如此。

  GeometryCollection() 不带参数是允许的，作为创建空几何的一种方式。此外，诸如 ST_GeomFromText() 之类接受 WKT 几何集合参数的函数理解 OpenGIS 'GEOMETRYCOLLECTION EMPTY' 标准语法和 MySQL 'GEOMETRYCOLLECTION()' 非标准语法。

  GeomCollection() 和 GeometryCollection() 是同义词，GeomCollection() 是首选函数。

- LineString(pt [, pt] ...)

  从多个 Point 或 WKB Point 参数构造 LineString 值。如果参数数量少于两个，返回值为 NULL。

- MultiLineString(ls [, ls] ...)

  使用 LineString 或 WKB LineString 参数构造 MultiLineString 值。

- MultiPoint(pt [, pt2] ...)

  使用 Point 或 WKB Point 参数构造 MultiPoint 值。

- MultiPolygon(poly [, poly] ...)

  从一组 Polygon 或 WKB Polygon 参数构造 MultiPolygon 值。

- Point(x, y)

  使用其坐标构造 Point。

- Polygon(ls [, ls] ...)

  从多个 LineString 或 WKB LineString 参数构造 Polygon 值。如果任何参数不表示 LinearRing（即不是闭合且简单的 LineString），返回值为 NULL。
