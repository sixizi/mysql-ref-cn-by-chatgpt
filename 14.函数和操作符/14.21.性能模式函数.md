## 14.21 向量函数

MySQL 26.7 支持用于处理 VECTOR 值的 SQL 函数。本节介绍这些函数。

表 14.31 向量函数

| 名称 | 描述 |
|------|------|
| DISTANCE() | 根据指定的方法计算两个向量之间的距离 |
| STRING_TO_VECTOR() | 获取由符合条件的字符串表示的 VECTOR 列的二进制值 |
| VECTOR_DIM() | 获取向量的长度（即它包含的条目数） |
| VECTOR_TO_STRING() | 获取 VECTOR 列的字符串表示，给定其二进制字符串值 |

- DISTANCE(vector, vector, string)

  根据指定的计算方法计算两个向量之间的距离。它接受以下参数：

  - VECTOR 数据类型的列。

  - VECTOR 数据类型的输入查询。

  - 指定距离度量的字符串。支持的值为 COSINE、DOT 和 EUCLIDEAN。由于参数是字符串，必须加引号。

  VECTOR_DISTANCE 是此函数的同义词。

  示例：
  ```
  mysql> SELECT DISTANCE(STRING_TO_VECTOR("[1.01231, 2.0123123, 3.0123123, 4.01231231]"), STRING_TO_VEC
  +----------------------------------------------------------------------------------------------------
  | DISTANCE(STRING_TO_VECTOR("[1.01231, 2.0123123, 3.0123123, 4.01231231]"), STRING_TO_VECTOR("[1, 2,
  +----------------------------------------------------------------------------------------------------
  |                                                                                              0.0000
  +----------------------------------------------------------------------------------------------------
  ```

  注意

  DISTANCE() 仅适用于 MySQL HeatWave on OCI 和 MySQL AI 的用户；不包含在 MySQL Commercial 或 Community 发行版中。

- STRING_TO_VECTOR(string)

  将向量的字符串表示转换为二进制表示。字符串的预期格式包含一个或多个逗号分隔的浮点值列表，用方括号（[ ]）括起来。值可以用十进制或科学记数法表示。由于参数是字符串，必须加引号。

  TO_VECTOR() 是此函数的同义词。

  示例：
  ```
  mysql> SELECT STRING_TO_VECTOR("[1.05, -17.8, 32]");
  +---------------------------------------+
  | STRING_TO_VECTOR("[1.05, -17.8, 32]") |
  +---------------------------------------+
  | 0x6666863F66668EC100000042            |
  +---------------------------------------+
  1 row in set (0.00 sec)

  mysql> SELECT TO_VECTOR("[1.05, -17.8, 32, 123.456]");
  +-----------------------------------------+
  | TO_VECTOR("[1.05, -17.8, 32, 123.456]") |
  +-----------------------------------------+
  | 0x6666863F66668EC10000004279E9F642      |
  +-----------------------------------------+
  1 row in set (0.00 sec)
  ```

  VECTOR_TO_STRING() 是此函数的反函数：
  ```
  mysql> SELECT VECTOR_TO_STRING(STRING_TO_VECTOR("[1.05, -17.8, 32]"));
  +---------------------------------------------------------+
  | VECTOR_TO_STRING(STRING_TO_VECTOR("[1.05, -17.8, 32]")) |
  +---------------------------------------------------------+
  | [1.05000e+00,-1.78000e+01,3.20000e+01]                  |
  +---------------------------------------------------------+
  1 row in set (0.00 sec)
  ```

  这些值中的所有空白字符（数字后、方括号前后或这些的任意组合）在使用前都会被删除。

- VECTOR_DIM(vector)

  给定 VECTOR 列值，此函数返回向量包含的条目数。

  示例：
  ```
  mysql> SELECT VECTOR_DIM(0x0040004000800080);
  +--------------------------------+
  | VECTOR_DIM(0x0040004000800080) |
  +--------------------------------+
  |                              2 |
  +--------------------------------+
  1 row in set (0.00 sec)

  mysql> SELECT VECTOR_DIM(TO_VECTOR('[2, 3, 5]') );
  +-------------------------------------+
  | VECTOR_DIM(TO_VECTOR('[2, 3, 5]') ) |
  +-------------------------------------+
  |                                   3 |
  +-------------------------------------+
  1 row in set (0.00 sec)
  ```

  无法解析为向量值的此函数的参数会引发错误。

- VECTOR_TO_STRING(vector)

  给定 VECTOR 列值的二进制表示，此函数返回其字符串表示，格式与 STRING_TO_VECTOR() 函数的参数所述格式相同。

  FROM_VECTOR() 被接受为此函数的同义词。

  示例：
  ```
  mysql> SELECT VECTOR_TO_STRING(0x00000040000040400000A0400000E040);
  +------------------------------------------------------+
  | VECTOR_TO_STRING(0x00000040000040400000A0400000E040) |
  +------------------------------------------------------+
  | [2.00000e+00,3.00000e+00,5.00000e+00,7.00000e+00]    |
  +------------------------------------------------------+
  1 row in set (0.00 sec)

  mysql> SELECT FROM_VECTOR(0x00000040000040400000A040);
  +-----------------------------------------+
  | FROM_VECTOR(0x00000040000040400000A040) |
  +-----------------------------------------+
  | [2.00000e+00,3.00000e+00,5.00000e+00]   |
  +-----------------------------------------+
  1 row in set (0.00 sec)
  ```

  无法解析为向量值的此函数的参数会引发错误。

  此函数输出的最大大小为 262128（16 * 16383）字节。
