# 32.7 MySQL企业数据屏蔽与去标识概述

MySQL企业版5.7及更高版本包含MySQL企业数据屏蔽与去标识功能，它作为一个插件库实现，其中包括一个插件和若干可加载函数。数据屏蔽通过用替代值替换真实值来隐藏敏感信息。MySQL企业数据屏蔽与去标识函数支持使用多种方法屏蔽现有数据，例如混淆（移除可识别特征）、生成格式化随机数据，以及数据替换或替换式脱敏。

有关更多信息，请参见 [8.5 MySQL企业数据屏蔽与去标识](https://dev.mysql.com/doc/refman/8.0/en/mysql-enterprise-data-masking.html)。

官方英文版参见 [MySQL Enterprise Data Masking and De-Identification Overview](https://dev.mysql.com/doc/refman/8.0/en/mysql-enterprise-data-masking.html)。
