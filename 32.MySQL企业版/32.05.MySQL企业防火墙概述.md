# 32.5 MySQL企业防火墙概述

MySQL企业版包含MySQL企业防火墙。这是一个应用级防火墙，使数据库管理员能够基于已接受语句模式的允许列表匹配结果，允许或拒绝SQL语句的执行。这有助于增强MySQL服务器抵御攻击的能力，例如SQL注入，或在应用程序合法查询工作负载特征之外滥用应用程序的尝试。

防火墙中注册的每个MySQL账户都有自己的语句允许列表，因此保护策略可以按账户定制。对指定账户，防火墙可以运行在记录模式或保护模式下，用于训练已接受的语句模式，或防止不可接受的语句执行。

有关更多信息，请参见 [8.4.7 MySQL企业防火墙](../08.安全性/08.04.安全组件和插件/08.04.07.MySQL%20企业防火墙/08.04.07.00.MySQL%20企业防火墙.md)。

官方英文版参见 [MySQL Enterprise Firewall Overview](https://dev.mysql.com/doc/refman/8.0/en/mysql-enterprise-firewall.html)。
