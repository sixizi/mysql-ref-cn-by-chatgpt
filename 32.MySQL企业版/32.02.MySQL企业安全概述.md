# 32.2 MySQL企业安全概述

MySQL企业版提供了一组插件，利用外部服务实现安全功能：

- MySQL企业版包含一个身份验证插件，使MySQL服务器能够使用LDAP（轻量级目录访问协议）对MySQL用户进行身份验证。LDAP身份验证支持用户名和密码、SASL以及GSSAPI/Kerberos等访问LDAP服务的身份验证方法。有关更多信息，请参见 [8.4.1.7 LDAP可插拔身份验证](../08.安全性/08.04.安全组件和插件/08.04.01.认证插件/08.04.01.07.LDAP%20可插拔身份验证.md)。
- MySQL企业版包含一个身份验证插件，使MySQL服务器能够使用原生Kerberos，并通过用户的Kerberos主体对其访问进行身份验证。有关更多信息，请参见 [8.4.1.8 Kerberos可插拔身份验证](../08.安全性/08.04.安全组件和插件/08.04.01.认证插件/08.04.01.08.Kerberos%20可插拔身份验证.md)。
- MySQL企业版包含一个身份验证插件，使MySQL服务器能够使用PAM（可插拔身份验证模块）对MySQL用户进行身份验证。PAM使系统能够通过标准接口访问多种身份验证方法，例如Unix密码或LDAP目录。有关更多信息，请参见 [8.4.1.5 PAM可插拔身份验证](../08.安全性/08.04.安全组件和插件/08.04.01.认证插件/08.04.01.05.PAM%20可插拔身份验证.md)。
- MySQL企业版包含一个在Windows上执行外部身份验证的插件，使MySQL服务器能够使用原生Windows服务对客户端连接进行身份验证。已经登录Windows的用户可以从MySQL客户端程序连接到服务器，连接过程基于其环境中的信息完成，无需指定额外密码。有关更多信息，请参见 [8.4.1.6 Windows可插拔身份验证](../08.安全性/08.04.安全组件和插件/08.04.01.认证插件/08.04.01.06.Windows%20可插拔身份验证.md)。
- MySQL企业版包含一组屏蔽与去标识函数，可通过子集化、随机生成和字典替换，对字符串、数字、电话号码、电子邮件等信息进行去标识。这些函数支持使用混淆（移除可识别特征）、生成格式化随机数据、数据替换或替换/替换式脱敏等多种方法屏蔽现有数据。有关更多信息，请参见 [8.5 MySQL企业数据屏蔽与去标识](https://dev.mysql.com/doc/refman/8.0/en/mysql-enterprise-data-masking.html)。
- MySQL企业版包含一组基于OpenSSL库的加密函数，在SQL层面暴露OpenSSL能力。有关更多信息，请参见 [32.3 MySQL企业加密概述](./32.03.MySQL企业加密概述.md)。
- MySQL企业版5.7及更高版本包含一个密钥环插件，使用Oracle Key Vault作为密钥环存储后端。有关更多信息，请参见 [8.4.4 MySQL密钥环](../08.安全性/08.04.安全组件和插件/08.04.04.MySQL%20密钥环/08.04.04.00.MySQL%20密钥环.md)。
- MySQL透明数据加密（TDE）为MySQL服务器中所有可能包含敏感数据的文件提供静态加密。有关更多信息，请参见 [17.13 InnoDB数据静态加密](../17.InnoDB存储引擎/17.13.InnoDB数据静态加密.md)、[19.3.2 加密二进制日志文件和中继日志文件](../19.复制/19.03.复制安全/19.03.02.加密二进制日志文件和中继日志文件/19.03.02.00.加密二进制日志文件和中继日志文件.md)和[加密审计日志文件](../08.安全性/08.04.安全组件和插件/08.04.05.MySQL%20企业审计/08.04.05.05.配置审计日志记录特性.md)。

有关其他相关企业安全功能，请参见 [32.3 MySQL企业加密概述](./32.03.MySQL企业加密概述.md)。

官方英文版参见 [MySQL Enterprise Security Overview](https://dev.mysql.com/doc/refman/8.0/en/mysql-enterprise-security.html)。
