# 32.8 MySQL Telemetry

MySQL Telemetry组件基于OpenTelemetry（OTel）项目。OpenTelemetry是一个开源、供应商中立的可观测性框架，提供通用的可观测性标准。它使用户能够对应用程序进行插桩，从而导出可观测性数据：跟踪、指标和日志，并为调试和测试提供更高的粒度。

有关更多信息，请参见 [Telemetry](https://dev.mysql.com/doc/refman/8.0/en/telemetry.html)。

官方英文版参见 [MySQL Telemetry](https://dev.mysql.com/doc/refman/8.0/en/mysql-enterprise-telemetry.html)。
