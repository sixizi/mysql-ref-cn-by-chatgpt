### 32.1 MySQL Enterprise Backup 概述

MySQL Enterprise Backup 为 MySQL 数据库执行热备份操作。该产品的架构设计用于高效可靠地备份由 InnoDB 存储引擎创建的表。为了完整性，它也可以备份来自 MyISAM 和其他存储引擎的表。

以下讨论简要总结了 MySQL Enterprise Backup。有关更多信息，请参阅 MySQL Enterprise Backup 手册，可在 https://dev.mysql.com/doc/mysql-enterprise-backup/en/ 获取。

热备份在数据库运行且应用程序正在读写时执行。这种类型的备份不会阻止正常的数据库操作，并且它捕获备份过程中发生的所有更改。由于这些原因，当您的数据库"成长"时，热备份是理想的选择——当数据足够大以至于备份需要花费大量时间，以及当您的数据对业务足够重要以至于您必须捕获每一个更改，而不能让您的应用程序、网站或网络服务离线时。

MySQL Enterprise Backup 对所有使用 InnoDB 存储引擎的表执行热备份。对于使用 MyISAM 或其他非 InnoDB 存储引擎的表，它执行"温"备份，其中数据库继续运行，但这些表在备份时无法修改。为了高效的备份操作，您可以将 InnoDB 指定为新表的默认存储引擎，或将现有表转换为使用 InnoDB 存储引擎。
