# 32.1 MySQL企业备份概述

MySQL企业备份为MySQL数据库执行热备份操作。该产品专为高效、可靠地备份由InnoDB存储引擎创建的表而设计。为保持完整性，它也可以备份MyISAM和其他存储引擎创建的表。

热备份是在数据库运行、应用程序持续读写数据库时执行的备份。这种备份不会阻塞正常的数据库操作，并且能够捕获备份进行期间发生的变化。因此，当数据库规模增长到备份需要较长时间，以及数据对业务足够重要、必须在不停机应用程序、网站或Web服务的情况下捕获每一次变化时，热备份非常有价值。

MySQL企业备份对使用InnoDB存储引擎的所有表执行热备份。对使用MyISAM或其他非InnoDB存储引擎的表，它执行的是“温”备份：数据库继续运行，但这些表在备份期间不能被修改。为了提高备份效率，可以将InnoDB指定为新表的默认存储引擎，或将现有表转换为InnoDB存储引擎。

有关MySQL企业备份的更多信息，请参见 [MySQL企业备份手册](https://dev.mysql.com/doc/mysql-enterprise-backup/en/)。

官方英文版参见 [MySQL Enterprise Backup Overview](https://dev.mysql.com/doc/refman/8.0/en/mysql-enterprise-backup.html)。
