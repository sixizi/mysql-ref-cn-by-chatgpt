# 32.3 MySQL企业加密概述

MySQL企业版包含一组基于OpenSSL库的加密函数，在SQL层面暴露OpenSSL能力。这些函数使企业应用能够执行以下操作：

- 使用公钥非对称加密算法实现额外的数据保护
- 创建公钥、私钥和数字签名
- 执行非对称加密和解密
- 使用加密哈希进行数字签名，以及数据验证和校验

有关更多信息，请参见 [8.6 MySQL企业加密](../08.安全性/08.06.MySQL企业加密/08.06.00.MySQL企业加密.md)。

有关其他相关企业安全功能，请参见 [32.2 MySQL企业安全概述](./32.02.MySQL企业安全概述.md)。

官方英文版参见 [MySQL Enterprise Encryption Overview](https://dev.mysql.com/doc/refman/8.0/en/mysql-enterprise-encryption.html)。
