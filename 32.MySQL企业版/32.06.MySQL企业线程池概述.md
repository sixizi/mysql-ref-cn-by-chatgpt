# 32.6 MySQL企业线程池概述

MySQL企业版包含MySQL企业线程池，它以服务器插件的形式实现。MySQL服务器的默认线程处理模型为每个客户端连接使用一个线程执行语句。随着连接到服务器并执行语句的客户端增多，整体性能会下降。在MySQL企业版中，线程池插件提供另一种线程处理模型，旨在降低开销并提升性能。该插件实现了一个线程池，通过高效管理大量客户端连接的语句执行线程，提高服务器性能。

有关更多信息，请参见 [7.6.3 MySQL企业线程池](https://dev.mysql.com/doc/refman/8.0/en/mysql-enterprise-thread-pool.html)。

官方英文版参见 [MySQL Enterprise Thread Pool Overview](https://dev.mysql.com/doc/refman/8.0/en/mysql-enterprise-thread-pool.html)。
