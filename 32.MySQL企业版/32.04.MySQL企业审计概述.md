# 32.4 MySQL企业审计概述

MySQL企业版包含MySQL企业审计，它通过服务器插件实现。MySQL企业审计使用开放的MySQL审计API，对特定MySQL服务器上执行的连接和查询活动进行标准化、基于策略的监控和日志记录。MySQL企业审计按照Oracle审计规范设计，为受内部和外部监管准则约束的应用提供了开箱即用、易于使用的审计与合规解决方案。

安装审计插件后，MySQL服务器可以生成包含服务器活动审计记录的日志文件。日志内容包括客户端何时连接和断开，以及它们在连接期间执行了哪些操作，例如访问了哪些数据库和表。

有关更多信息，请参见 [8.4.5 MySQL企业审计](../08.安全性/08.04.安全组件和插件/08.04.05.MySQL%20企业审计/08.04.05.00.MySQL%20企业审计.md)。
