## 服务器配置状态变量

本节描述与日志记录器相关的状态变量。

- Telemetry_logs_supported：显示服务器是否使用遥测日志支持进行编译。

- Performance_schema_logger_lost：显示未能创建的日志记录器工具数量。

## 服务器配置命令行

本节描述与日志记录器相关的命令行配置选项。

- performance-schema-logger：定义日志记录器的默认值。可以多次定义，类似于 --performance-schema-instrument。

  在以下示例中，所有日志记录器都配置为错误级别 ERROR，除了 foo 和 bar 分别配置为错误级别 INFO 和 WARNING：

  ```
  --performance-schema-logger = 'logger/% = Level:ERROR' --performance-schema-logger = 'logger/foo/% = Level:INFO'
  --performance-schema-logger = 'logger/bar/% = Level:WARNING'
  ```

  要查看已配置的日志记录器，请运行以下命令：

  ```
  select * from performance_schema.setup_loggers;
  +------------------------+-------+-------------------------+
  | NAME                   | LEVEL | DESCRIPTION             |
  +------------------------+-------+-------------------------+
  | logger/sql/error_log   | info | MySQL error logger       |
  | logger/sql/slow_log    | info | MySQL slow query logger |
  | logger/sql/general_log | info | MySQL general logger     |
  +------------------------+-------+-------------------------+
  ```

  此示例显示默认的 MySQL 错误日志记录器。可以将其设置为以下值之一：

  - none

  - error

  - warn

  - info

  - debug

  以下示例将错误日志级别更改为 WARNING：

  ```
  mysql> UPDATE performance_schema.setup_loggers
         SET LEVEL='WARN'
  ```

- performance_schema_max_logger_classes：此系统变量也可以从命令行设置。例如：

  ```
  --performance_schema_max_logger_classes=100
  ```

  编辑此值需要服务器重启。
