### 35.1 安装 OpenTelemetry 支持

本节描述服务器和客户端 OpenTelemetry 支持的安装。

- 安装服务器组件

- 安装客户端插件

#### 安装服务器组件

要安装服务器组件，运行以下命令：

```
install component 'file://component_telemetry';
```

要确认该组件存在于您的服务器中，运行以下查询：

```
mysql> select * from mysql.component;
+--------------+--------------------+---------------------------------+
| component_id | component_group_id | component_urn                   |
+--------------+--------------------+---------------------------------+
|            1 |                  1 | file://component_telemetry      |
|            3 |                  3 | file://component_option_tracker |
|            4 |                  4 | file://component_mle            |
+--------------+--------------------+---------------------------------+
```

如果 component_telemetry 出现在 component_urn 列中，则该组件已安装。

#### 安装客户端插件

MySQL 客户端的遥测插件可以通过命令行开关 `--telemetry_client` 启用，或通过在配置文件的 `[mysql]` 部分中定义的配置选项 `telemetry-client=ON|OFF` 启用。
