## 29.12.19.2 clone_progress 表

clone_progress 表仅显示当前或最后执行的克隆操作的进度信息。

克隆操作的阶段包括 DROP DATA、FILE COPY、PAGE_COPY、REDO_COPY、FILE_SYNC、RESTART 和 RECOVERY。克隆操作为每个阶段生成一条记录。因此该表最多只包含七行数据，或者为空。

clone_progress 表具有以下列：

- ID

  当前 MySQL 服务器实例中的唯一克隆操作标识符。

- STAGE

  当前克隆阶段的名称。阶段包括 DROP DATA、FILE COPY、PAGE_COPY、REDO_COPY、FILE_SYNC、RESTART 和 RECOVERY。

- STATE

  克隆阶段的当前状态。状态包括 Not Started、In Progress 和 Completed。

- BEGIN_TIME

  格式为 'YYYY-MM-DD hh:mm:ss[.fraction]' 的时间戳，显示克隆阶段何时开始。如果阶段尚未开始，则报告 NULL。

- END_TIME

  格式为 'YYYY-MM-DD hh:mm:ss[.fraction]' 的时间戳，显示克隆阶段何时完成。如果阶段尚未结束，则报告 NULL。

- THREADS

  该阶段使用的并发线程数。

- ESTIMATE

  当前阶段的估计数据量，单位为字节。

- DATA

  当前状态下传输的数据量，单位为字节。

- NETWORK

  当前状态下传输的网络数据量，单位为字节。

- DATA_SPEED

  当前实际数据传输速度，单位为字节/秒。此值可能与由 clone_max_data_bandwidth 定义的请求最大数据传输速率不同。

- NETWORK_SPEED

  当前网络传输速度，单位为字节/秒。

clone_progress 表是只读的。不允许 DDL 操作，包括 TRUNCATE TABLE。
