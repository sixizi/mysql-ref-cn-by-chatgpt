### 29.12.3.5 socket_instances 表

socket_instances 表提供了到 MySQL 服务器的活跃连接的实时快照。该表为每个 TCP/IP 或 Unix 套接字文件连接包含一行。此表中可用的信息提供了到服务器的活跃连接的实时快照。（套接字汇总表中提供了其他信息，包括网络活动，如套接字操作和传输/接收的字节数；参见第 29.12.20.9 节"套接字汇总表"）。

```
mysql> SELECT * FROM performance_schema.socket_instances\G
*************************** 1. row ***************************
           EVENT_NAME: wait/io/socket/sql/server_unix_socket
OBJECT_INSTANCE_BEGIN: 4316619408
                THREAD_ID: 1
                SOCKET_ID: 16
                       IP:
                     PORT: 0
                    STATE: ACTIVE
*************************** 2. row ***************************
           EVENT_NAME: wait/io/socket/sql/client_connection
OBJECT_INSTANCE_BEGIN: 4316644608
                THREAD_ID: 21
                SOCKET_ID: 39
                       IP: 127.0.0.1
                     PORT: 55233
                    STATE: ACTIVE
*************************** 3. row ***************************
           EVENT_NAME: wait/io/socket/sql/server_tcpip_socket
OBJECT_INSTANCE_BEGIN: 4316699040
                THREAD_ID: 1
                SOCKET_ID: 14
                       IP: 0.0.0.0
                     PORT: 50603
                    STATE: ACTIVE
```

套接字工具的名称形式为 wait/io/socket/sql/socket_type，使用方式如下：

1. 服务器为其支持的每个网络协议都有一个监听套接字。与 TCP/IP 或 Unix 套接字文件连接的监听套接字关联的工具分别具有 server_tcpip_socket 或 server_unix_socket 的 socket_type 值。

2. 当监听套接字检测到连接时，服务器将连接转移到由单独线程管理的新套接字。新连接线程的工具具有 client_connection 的 socket_type 值。

3. 当连接终止时，socket_instances 中对应的行被删除。

socket_instances 表具有以下列：

- EVENT_NAME

  生成事件的 wait/io/socket/* 工具的名称。这是来自 setup_instruments 表的 NAME 值。工具名称可能有多个部分并形成层次结构，如第 29.6 节"Performance Schema 工具命名约定"中所讨论的。

- OBJECT_INSTANCE_BEGIN

  此列唯一标识套接字。该值是内存中对象的地址。

- THREAD_ID

  由服务器分配的内部线程标识符。每个套接字由单个线程管理，因此每个套接字可以映射到一个线程，该线程可以映射到服务器进程。

- SOCKET_ID

  分配给套接字的内部文件句柄。

- IP

  客户端 IP 地址。该值可以是 IPv4 或 IPv6 地址，或为空以表示 Unix 套接字文件连接。

- PORT

  TCP/IP 端口号，范围从 0 到 65535。

- STATE

  套接字状态，为 IDLE 或 ACTIVE。活跃套接字的等待时间使用相应的套接字工具进行跟踪。空闲套接字的等待时间使用空闲工具进行跟踪。

  套接字处于空闲状态是指它正在等待来自客户端的请求。当套接字变为空闲时，socket_instances 中跟踪该套接字的事件行从 ACTIVE 状态切换到 IDLE。EVENT_NAME 值保持为 wait/io/socket/*，但工具的计时被暂停。相反，在 events_waits_current 表中生成一个 EVENT_NAME 值为 idle 的事件。

  当接收到下一个请求时，空闲事件终止，套接字实例从 IDLE 切换到 ACTIVE，套接字工具的计时恢复。

socket_instances 表具有以下索引：

- (OBJECT_INSTANCE_BEGIN) 上的主键

- (THREAD_ID) 上的索引

- (SOCKET_ID) 上的索引

- (IP, PORT) 上的索引

socket_instances 表不允许 TRUNCATE TABLE。

IP:PORT 列组合值标识连接。此组合值在 events_waits_xxx 表的 OBJECT_NAME 列中使用，以标识套接字事件来自的连接：

- 对于 Unix 域监听套接字 (server_unix_socket)，端口为 0，IP 为 ''。

- 对于通过 Unix 域监听器的客户端连接 (client_connection)，端口为 0，IP 为 ''。

- 对于 TCP/IP 服务器监听套接字 (server_tcpip_socket)，端口始终为主端口（例如 3306），IP 始终为 0.0.0.0。

- 对于通过 TCP/IP 监听器的客户端连接 (client_connection)，端口是服务器分配的任何值，但永远不为 0。IP 是源主机的 IP（本地主机为 127.0.0.1 或 ::1）
