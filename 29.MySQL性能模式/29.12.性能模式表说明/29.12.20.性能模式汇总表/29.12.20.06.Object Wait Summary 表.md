### 29.12.20.6 对象等待汇总表

Performance Schema 维护 objects_summary_global_by_type 表用于聚合对象等待事件。

对象等待事件汇总信息示例：

```
mysql> SELECT * FROM performance_schema.objects_summary_global_by_type\G
...
*************************** 3. row ***************************
    OBJECT_TYPE: TABLE
 OBJECT_SCHEMA: test
    OBJECT_NAME: t
     COUNT_STAR: 3
SUM_TIMER_WAIT: 263126976
MIN_TIMER_WAIT: 1522272
AVG_TIMER_WAIT: 87708678
MAX_TIMER_WAIT: 258428280
...
*************************** 10. row ***************************
    OBJECT_TYPE: TABLE
 OBJECT_SCHEMA: mysql
    OBJECT_NAME: user
     COUNT_STAR: 14
SUM_TIMER_WAIT: 365567592
MIN_TIMER_WAIT: 1141704
AVG_TIMER_WAIT: 26111769
MAX_TIMER_WAIT: 334783032
...
```

objects_summary_global_by_type 表具有以下分组列，用于指示表如何聚合事件：OBJECT_TYPE、OBJECT_SCHEMA 和 OBJECT_NAME。每一行汇总给定对象的事件。

objects_summary_global_by_type 具有与 events_waits_summary_by_xxx 表相同的汇总列。参见第 29.12.20.1 节"等待事件汇总表"。

objects_summary_global_by_type 表具有以下索引：

- (OBJECT_TYPE, OBJECT_SCHEMA, OBJECT_NAME) 上的主键

对象汇总表允许使用 TRUNCATE TABLE。它将汇总列重置为零，而不是删除行。
