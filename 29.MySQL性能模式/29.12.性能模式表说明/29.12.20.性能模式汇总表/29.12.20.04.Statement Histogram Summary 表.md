### 29.12.20.4 语句直方图摘要表

Performance Schema 维护语句事件摘要表，其中包含有关最小、最大和平均语句延迟的信息（参见第 29.12.20.3 节"语句摘要表"）。这些表允许对系统性能进行高级评估。为了允许在更细粒度级别进行评估，Performance Schema 还收集语句延迟的直方图数据。这些直方图提供了对延迟分布的额外洞察。

第 29.12.6 节"Performance Schema 语句事件表"描述了语句摘要所基于的事件。请参阅该讨论以了解语句事件的内容、当前和历史语句事件表，以及如何控制语句事件收集（默认情况下部分禁用）。

每个语句直方图摘要表都有一个或多个分组列来指示表如何聚合事件：

- events_statements_histogram_by_digest 具有 SCHEMA_NAME、DIGEST 和 BUCKET_NUMBER 列：

  - SCHEMA_NAME 和 DIGEST 列标识 events_statements_summary_by_digest 表中的语句摘要行。

  - events_statements_histogram_by_digest 行具有相同的 SCHEMA_NAME 和 DIGEST 值，组成该 schema/digest 组合的直方图。

  - 在给定的直方图中，BUCKET_NUMBER 列指示桶号。

- events_statements_histogram_global 具有 BUCKET_NUMBER 列。此表使用单个直方图在 schema 名称和摘要值之间全局汇总延迟。BUCKET_NUMBER 列指示此全局直方图中的桶号。

直方图由 N 个桶组成，其中每一行代表一个桶，桶号由 BUCKET_NUMBER 列指示。桶号从 0 开始。

每个语句直方图摘要表都有这些包含聚合值的摘要列：

- BUCKET_TIMER_LOW、BUCKET_TIMER_HIGH

  桶计算具有延迟的语句，以皮秒为单位，在 BUCKET_TIMER_LOW 和 BUCKET_TIMER_HIGH 之间测量：

  - 第一个桶（BUCKET_NUMBER = 0）的 BUCKET_TIMER_LOW 值为 0。

  - 桶（BUCKET_NUMBER = k）的 BUCKET_TIMER_LOW 值与前一个桶（BUCKET_NUMBER = k−1）的 BUCKET_TIMER_HIGH 相同。

  - 最后一个桶是一个包罗万象的桶，用于延迟超过直方图中前面桶的语句。

- COUNT_BUCKET

  延迟在 BUCKET_TIMER_LOW 到 BUCKET_TIMER_HIGH（不包括）区间内测量的语句数。

- COUNT_BUCKET_AND_LOWER

  延迟在 0 到 BUCKET_TIMER_HIGH（不包括）区间内测量的语句数。

- BUCKET_QUANTILE

  落入此桶或更低桶的语句比例。此比例根据定义对应于 COUNT_BUCKET_AND_LOWER / SUM(COUNT_BUCKET)，作为便利列显示。

语句直方图摘要表具有这些索引：

- events_statements_histogram_by_digest：

  - (SCHEMA_NAME, DIGEST, BUCKET_NUMBER) 上的唯一索引

- events_statements_histogram_global：

  - (BUCKET_NUMBER) 上的主键

语句直方图摘要表允许 TRUNCATE TABLE。截断将 COUNT_BUCKET 和 COUNT_BUCKET_AND_LOWER 列设置为 0。

此外，截断 events_statements_summary_by_digest 隐式截断 events_statements_histogram_by_digest，截断 events_statements_summary_global_by_event_name 隐式截断 events_statements_histogram_global。
