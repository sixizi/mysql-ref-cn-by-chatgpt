### 29.12.12.1 ndb_sync_pending_objects 表

此表提供有关 NDB 数据库对象的信息，这些对象已检测到不匹配，并且正在等待在 NDB 字典和 MySQL 数据字典之间进行同步。

等待同步的 NDB 数据库对象的示例信息：

```
mysql> SELECT * FROM performance_schema.ndb_sync_pending_objects;
+-------------+------+----------------+
| SCHEMA_NAME | NAME | TYPE           |
+-------------+------+----------------+
| NULL        | lg1 | LOGFILE GROUP |
| NULL        | ts1 | TABLESPACE      |
| db1         | NULL | SCHEMA         |
| test        | t1   | TABLE          |
| test        | t2   | TABLE          |
| test        | t3   | TABLE          |
+-------------+------+----------------+
```

ndb_sync_pending_objects 表具有以下列：

- SCHEMA_NAME：等待同步的对象所在的模式（数据库）的名称；对于表空间和日志文件组，此值为 NULL

- NAME：等待同步的对象的名称；如果对象是模式，则此值为 NULL

- TYPE：等待同步的对象的类型；这是 LOGFILE GROUP、TABLESPACE、SCHEMA 或 TABLE 之一
