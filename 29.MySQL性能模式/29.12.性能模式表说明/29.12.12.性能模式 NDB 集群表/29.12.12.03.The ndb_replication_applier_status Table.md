### 29.12.12.3 ndb_replication_applier_status 表

NDBCLUSTER 通过全局状态变量（如 Ndb_replica_max_replicated_epoch 和 Ndb_api_trans_start_count_replica）公开其内部复制应用程序状态以供观察，但这些值仅反映默认复制通道的状态。ndb_replication_applier_status 提供相同的信息，但基于每个通道；除了 CHANNEL_NAME 外，此表中的每一列都对应一个服务器状态变量；在适用的情况下，此信息包含在本节后面提供的列描述中。

此表是对 replication_applier_status 表的 NDB 特定扩展。

ndb_replication_applier_status 表具有以下列表中所示和描述的列：

- CHANNEL_NAME：

  复制通道的名称。默认值为空字符串 ("")。

- MAX_REPLICATED_EPOCH：

  此副本上最近提交的 NDB epoch。Ndb_replica_max_replicated_epoch 显示默认复制通道的此值。

- API_WAIT_EXEC_COMPLETE_COUNT：

  此线程在等待此 SQL 节点的操作完成时被阻止的次数。Ndb_api_wait_exec_complete_count_replica 显示默认复制通道的此值。

- API_WAIT_SCAN_RESULT_COUNT：

  此线程在等待此 SQL 节点的基于扫描的信号时被阻止的次数。Ndb_api_wait_scan_result_count_replica 显示默认复制通道的此值。

- API_WAIT_META_REQUEST_COUNT：

  此线程在等待此 SQL 节点的基于元数据的信号时被阻止的次数。Ndb_api_wait_meta_request_count_replica 显示默认复制通道的此值。

- API_WAIT_NANOS_COUNT：

  此 SQL 节点在等待来自数据节点的某种类型信号时花费的累积时间（以纳秒为单位）。Ndb_api_wait_nanos_count_replica 显示默认复制通道的此值。

- API_BYTES_SENT_COUNT：

  此 SQL 节点发送到数据节点的字节数。Ndb_api_bytes_sent_count_replica 显示默认复制通道的此值。

- API_BYTES_RECEIVED_COUNT：

  此 SQL 节点从数据节点接收的字节数。Ndb_api_bytes_received_count_replica 显示默认复制通道的此值。

- API_TRANS_START_COUNT：

  此 SQL 节点启动的事务数。Ndb_api_trans_start_count_replica 显示默认复制通道的此值。

- API_TRANS_COMMIT_COUNT：

  此 SQL 节点提交的事务数。Ndb_api_trans_commit_count_replica 显示默认复制通道的此值。

- API_TRANS_ABORT_COUNT：

  此 SQL 节点中止的事务数。Ndb_api_trans_abort_count_replica 显示默认复制通道的此值。

- API_TRANS_CLOSE_COUNT：

  此 SQL 节点已关闭的事务数；此值可能大于 API_TRANS_COMMIT_COUNT 和 API_TRANS_ABORT_COUNT 的总和。Ndb_api_trans_close_count_replica 显示默认复制通道的此值。

- API_PK_OP_COUNT：

  此 SQL 节点执行的主键操作数。Ndb_api_pk_op_count_replica 显示默认复制通道的此值。

- API_UK_OP_COUNT：

  此 SQL 节点执行的唯一键操作数。Ndb_api_uk_op_count_replica 显示默认复制通道的此值。

- API_TABLE_SCAN_COUNT：

  此 SQL 节点启动的表扫描数。这包括内部表的扫描。Ndb_api_table_scan_count_replica 显示默认复制通道的此值。

- API_RANGE_SCAN_COUNT：

  此 SQL 节点启动的范围扫描数。Ndb_api_range_scan_count_replica 显示默认复制通道的此值。

- API_PRUNED_SCAN_COUNT：

  此 SQL 节点已修剪为单个分区的扫描数。Ndb_api_pruned_scan_count_replica 显示默认复制通道的此值。

- API_SCAN_BATCH_COUNT：

  此 SQL 节点接收的行批次数。Ndb_api_scan_batch_count_replica 显示默认复制通道的此值。

- API_READ_ROW_COUNT：

  此 SQL 节点读取的总行数。Ndb_api_read_row_count_replica 显示默认复制通道的此值。

- API_TRANS_LOCAL_READ_ROW_COUNT：

  此 SQL 节点本地读取的总行数。Ndb_api_trans_local_read_row_count_replica 显示默认复制通道的此值。

- API_ADAPTIVE_SEND_FORCED_COUNT：

  此 SQL 节点使用强制发送发送的自适应发送数。Ndb_api_adaptive_send_forced_count_replica 显示默认复制通道的此值。

- API_ADAPTIVE_SEND_UNFORCED_COUNT：

  此 SQL 节点在不使用强制发送的情况下发送的自适应发送数。Ndb_api_adaptive_send_unforced_count_replica 显示默认复制通道的此值。

- API_ADAPTIVE_SEND_DEFERRED_COUNT：

  此 SQL 节点未实际发送的自适应发送数。Ndb_api_adaptive_send_deferred_count_replica 显示默认复制通道的此值。

- CONFLICT_FN_MAX：

  NDB 复制"较新时间戳获胜"冲突解决已应用于更新和删除操作的次数。Ndb_conflict_fn_max 显示默认复制通道的此值。

- CONFLICT_FN_OLD：

  NDB 复制"相同时间戳获胜"冲突解决已应用的次数。Ndb_conflict_fn_old 显示默认复制通道的此值。

- CONFLICT_FN_MAX_DEL_WIN：

  基于 NDB$MAX_DELETE_WIN() 结果的 NDB 复制冲突解决已应用于更新和删除操作的次数。Ndb_conflict_fn_max_del_win 显示默认复制通道的此值。

- CONFLICT_FN_MAX_INS：

  NDB 复制"较新时间戳获胜"冲突解决已应用于插入操作的次数。Ndb_conflict_fn_max_ins 显示默认复制通道的此值。

- CONFLICT_FN_MAX_DEL_WIN_INS：

  基于 NDB$MAX_DELETE_WIN_INS() 结果的 NDB 复制冲突解决已应用于更新和删除操作的次数。Ndb_conflict_fn_max_del_win_ins 显示默认复制通道的此值。

- CONFLICT_FN_EPOCH：

  NDB$EPOCH() NDB 复制冲突检测函数发现冲突的行数。Ndb_conflict_fn_epoch 显示默认复制通道的此值。

- CONFLICT_FN_EPOCH_TRANS：

  NDB$EPOCH_TRANS() NDB 复制冲突检测函数发现冲突的行数。Ndb_conflict_fn_epoch_trans 显示默认复制通道的此值。

- CONFLICT_FN_EPOCH2：

  NDB$EPOCH2() NDB 复制冲突检测函数发现冲突的行数。Ndb_conflict_fn_epoch2 显示默认复制通道的此值。

- CONFLICT_FN_EPOCH2_TRANS：

  NDB$EPOCH2_TRANS() NDB 复制冲突检测函数发现冲突的行数。Ndb_conflict_fn_epoch2_trans 显示默认复制通道的此值。

- CONFLICT_TRANS_ROW_CONFLICT_COUNT：

  被事务冲突函数发现处于冲突中的行数，包括包含在或依赖于冲突事务中的任何行。Ndb_conflict_trans_row_conflict_count 显示默认复制通道的此值。

- CONFLICT_TRANS_ROW_REJECT_COUNT：

  被事务冲突函数发现处于冲突中后已重新对齐的总行数，包括 CONFLICT_TRANS_ROW_CONFLICT_COUNT 以及包含在或依赖于冲突事务中的任何行。Ndb_conflict_trans_row_reject_count 显示默认复制通道的此值。

- CONFLICT_TRANS_REJECT_COUNT：

  被事务冲突函数发现处于冲突中后已拒绝的事务数。Ndb_conflict_trans_reject_count 显示默认复制通道的此值。

- CONFLICT_TRANS_DETECT_ITER_COUNT：

  提交 epoch 事务所需的内部迭代数。此值通常应略大于或等于 CONFLICT_TRANS_CONFLICT_COMMIT_COUNT 的值。Ndb_conflict_trans_detect_iter_count 显示默认复制通道的此值。

- CONFLICT_TRANS_CONFLICT_COMMIT_COUNT：

  在需要事务冲突处理后已提交的 epoch 事务数。Ndb_conflict_trans_conflict_commit_count 显示默认复制通道的此值。

- CONFLICT_EPOCH_DELETE_DELETE_COUNT：

  检测到的删除-删除冲突数。删除-删除冲突发生在应用删除操作但行不存在时。Ndb_epoch_delete_delete_count 显示默认复制通道的此值。

- CONFLICT_REFLECTED_OP_PREPARE_COUNT：

  已接收并准备执行的反射操作数。Ndb_conflict_reflected_op_prepare_count 显示默认复制通道的此值。

- CONFLICT_REFLECTED_OP_DISCARD_COUNT：

  由于执行期间的错误而未应用的反射操作数。Ndb_conflict_reflected_op_discard_count 显示默认复制通道的此值。

- CONFLICT_REFRESH_OP_COUNT：

  已准备的刷新操作数。Ndb_conflict_refresh_op_count 显示默认复制通道的此值。

- CONFLICT_LAST_CONFLICT_EPOCH：

  此副本上检测到冲突的最近 NDB epoch。Ndb_conflict_last_conflict_epoch 显示默认复制通道的此值。

- CONFLICT_LAST_STABLE_EPOCH：

  未检测到冲突的最近 NDB epoch。Ndb_conflict_last_stable_epoch 显示默认复制通道的此值。

有关更多信息，请参阅指示的服务器状态变量的描述，以及第 25.7 节"NDB Cluster 复制"。
