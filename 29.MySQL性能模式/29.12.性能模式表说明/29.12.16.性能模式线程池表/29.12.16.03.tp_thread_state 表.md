### 29.12.16.4 tp_thread_state 表

tp_thread_state 表为线程池创建的每个用于处理连接的线程各有一行。

tp_thread_state 表包含以下列：

- TP_GROUP_ID

  线程组 ID。

- TP_THREAD_NUMBER

  线程在其线程组内的 ID。TP_GROUP_ID 和 TP_THREAD_NUMBER 一起在表中提供唯一键。

- PROCESS_COUNT

  使用此线程的语句当前执行所在的 10ms 间隔。0 表示没有语句执行，1 表示在第一个 10ms 内，以此类推。

- WAIT_TYPE

  线程的等待类型。NULL 表示线程未被阻塞。否则，线程被 thd_wait_begin() 调用阻塞，该值指定等待的类型。tp_thread_group_stats 表的 xxx_WAIT 列累积每种等待类型的计数。

  WAIT_TYPE 值是描述等待类型的字符串，如下表所示。

  表 29.4 tp_thread_state 表 WAIT_TYPE 值
  | 等待类型 | 含义 |
  | --- | --- |
  | THD_WAIT_SLEEP | 等待睡眠 |
  | THD_WAIT_DISKIO | 等待磁盘 IO |
  | THD_WAIT_ROW_LOCK | 等待行锁 |
  | THD_WAIT_GLOBAL_LOCK | 等待全局锁 |
  | THD_WAIT_META_DATA_LOCK | 等待元数据锁 |
  | THD_WAIT_TABLE_LOCK | 等待表锁 |
  | THD_WAIT_USER_LOCK | 等待用户锁 |
  | THD_WAIT_BINLOG | 等待 binlog |
  | THD_WAIT_GROUP_COMMIT | 等待组提交 |
  | THD_WAIT_SYNC | 等待 fsync |

- TP_THREAD_TYPE

  线程的类型。此列显示的值为 CONNECTION_HANDLER_WORKER_THREAD、LISTENER_WORKER_THREAD、QUERY_WORKER_THREAD 或 TIMER_WORKER_THREAD 之一。

- THREAD_ID

  此线程的唯一标识符。该值与 Performance Schema threads 表的 THREAD_ID 列中使用的值相同。

- TIME_OF_ATTACH

  显示线程何时被附加的时间戳，如果附加到连接则显示时间戳；否则为 NULL。

- MARKED_STALLED

  如果此线程已被停滞检查器线程标记为停滞，则为 True。

- STATE

  可能的值取决于线程的类型，如 TP_THREAD_TYPE 列所示：

  - 对于工作线程（QUERY_WORKER_THREAD），这是 Managing、Polling、Processing Direct、Processing Queued、Sleeping Consumer 或 Sleeping Reserve 之一。

  - 对于连接处理程序线程（CONNECTION_HANDLER_WORKER_THREAD），这是 CH Processing、CH Sleeping Timed 或 CH Sleeping Indefinite 之一。

  - 对于停滞检查器线程（TIMER_WORKER_THREAD），这是 SC Checking、SC Sleeping Short 或 SC Sleeping Long 之一。

- EVENT_COUNT

  此线程处理的事件的累积数量。

- ACCUMULATED_EVENT_TIME

  处理事件所花费的挂钟时间。

- EXEC_COUNT

  传递给服务器执行的查询（语句）的累积数量。

- ACCUMULATED_EXEC_TIME

  服务器处理查询所花费的挂钟时间。

tp_thread_state 表有一个索引；这是 TP_GROUP_ID 和 TP_THREAD_NUMBER 列上的唯一索引。

不允许对 tp_thread_state 表执行 TRUNCATE TABLE。
