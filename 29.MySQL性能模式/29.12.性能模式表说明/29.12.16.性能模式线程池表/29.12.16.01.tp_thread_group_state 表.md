## 29.12.16.1 tp_connections 表

tp_connections 表包含由 Thread Pool 插件管理的每个连接一行。每行提供有关线程池连接当前状态的信息。

tp_connections 表包含以下列：

- CONNECTION_ID

  由 SELECT CONNECTION_ID() 报告的连接 ID。

- TP_GROUP_ID

  全局数组中线程组的索引。此列和 TP_PROCESSING_THREAD_NUMBER 充当 tp_thread_state 表的外键。

- TP_PROCESSING_THREAD_NUMBER

  如果当前没有线程附加到连接，则可能为 NULL。

- THREAD_ID

  Performance Schema 线程 ID。

- STATE

  连接状态；为以下之一：Established、Armed、Queued、Waiting for Credit、Attached、Expired 或 Killed。

- ACTIVE_FLAG

  当此值为 0 时，连接未附加到任何工作线程。

- KILLED_STATE

  报告杀死连接过程中的当前阶段。

- CLEANUP_STATE

  报告关闭连接时清理过程中的当前阶段。

- TIME_OF_LAST_EVENT_COMPLETION

  显示连接最后处理请求时的时间戳。

- TIME_OF_EXPIRY

  显示空闲连接将过期的时间戳（如果在此之前没有新请求到达）；当线程当前正在处理请求时为 NULL。

- TIME_OF_ADD

  显示连接添加到线程池连接请求队列时的时间戳。

- TIME_OF_POP

  显示连接由连接处理程序线程从队列中出队（弹出）时的时间戳。

- TIME_OF_ARM

  显示连接文件描述符最后一次添加到由 poll() 或 epoll() 监控的集合时的时间戳。

- CONNECT_HANDLER_INDEX

  处理连接请求的组中连接处理程序线程的索引；数字越大表示连接负载已触发创建额外的连接处理程序线程。

- TYPE

  连接类型；为以下之一：User、Admin_interface 或 Admin_privilege；Admin_privilege 表示此连接一直在使用普通接口，但由于用户具有 TP_CONNECTION_ADMIN 权限而被放入管理组。

- DIRECT_QUERY_EVENTS

  此连接直接执行的查询数。

- QUEUED_QUERY_EVENTS

  此连接执行的排队查询数。

- TIME_OF_EVENT_ARRIVAL

  显示 poll_wait() 为连接返回事件时的时间戳；此值需要用于计算 MANAGEMENT_TIME。

- MANAGEMENT_TIME

  等待文件描述符返回之间累积的时间；这包括排队等待未直接执行的查询所花费的时间。
