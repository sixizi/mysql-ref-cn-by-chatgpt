## 29.12.18.1 keyring_component_status 表

keyring_component_status 表提供关于正在使用的 keyring 组件属性的状态信息（如果已安装）。如果未安装 keyring 组件（例如，未使用 keyring，或配置为使用 keyring 插件而非 keyring 组件来管理密钥库），则该表为空。

没有固定的属性集。每个 keyring 组件都可以自由定义自己的属性集。

keyring_component_status 内容示例：

Performance Schema Clone 表

```
mysql> SELECT * FROM performance_schema.keyring_component_status;
+---------------------+-------------------------------------------------+
| STATUS_KEY          | STATUS_VALUE                                    |
+---------------------+-------------------------------------------------+
| Component_name      | component_keyring_file                          |
| Author              | Oracle Corporation                              |
| License             | GPL                                             |
| Implementation_name | component_keyring_file                          |
| Version             | 1.0                                             |
| Component_status    | Active                                          |
| Data_file           | /usr/local/mysql/keyring/component_keyring_file |
| Read_only           | No                                              |
+---------------------+-------------------------------------------------+
```

keyring_component_status 表包含以下列：

- STATUS_KEY

  状态项名称。

- STATUS_VALUE

  状态项值。

keyring_component_status 表没有索引。

不允许对 keyring_component_status 表执行 TRUNCATE TABLE。
