### 29.12.11.13 replication_connection_status 表

此表显示处理副本与源连接的 I/O 线程的当前状态、中继日志中最后一个排队事务的信息，以及当前在中继日志中排队的事务的信息。

与 replication_connection_configuration 表相比，replication_connection_status 变化更频繁。它包含在连接期间变化的值，而 replication_connection_configuration 包含定义副本如何连接到源且在连接期间保持不变的值。

replication_connection_status 表具有以下列：

- CHANNEL_NAME

  此行显示的复制通道。始终存在一个默认复制通道，可以添加更多复制通道。有关更多信息，请参见第 19.2.2 节"复制通道"。

- GROUP_NAME

  如果此服务器是组的成员，显示该服务器所属组的名称。

- SOURCE_UUID

  源中的 server_uuid 值。

- THREAD_ID

  I/O 线程 ID。

- SERVICE_STATE

  ON（线程存在且处于活动或空闲状态）、OFF（线程不再存在）或 CONNECTING（线程存在且正在连接到源）。

- RECEIVED_TRANSACTION_SET

  与此副本接收的所有事务对应的全局事务 ID (GTID) 集合。如果未使用 GTID，则为空。有关更多信息，请参见 GTID 集合。

- LAST_ERROR_NUMBER、LAST_ERROR_MESSAGE

  导致 I/O 线程停止的最近错误的错误号和错误消息。错误号为 0 且消息为空字符串表示"无错误"。如果 LAST_ERROR_MESSAGE 值不为空，错误值也会出现在副本的错误日志中。

  发出 RESET BINARY LOGS AND GTIDS 或 RESET REPLICA 会重置这些列中显示的值。

- LAST_ERROR_TIMESTAMP

  格式为 'YYYY-MM-DD hh:mm:ss[.fraction]' 的时间戳，显示最近的 I/O 错误发生的时间。

- LAST_HEARTBEAT_TIMESTAMP

  格式为 'YYYY-MM-DD hh:mm:ss[.fraction]' 的时间戳，显示副本接收到最近心跳信号的时间。

- COUNT_RECEIVED_HEARTBEATS

  副本自上次重启或重置以来接收的心跳信号总数，或发出 CHANGE REPLICATION SOURCE TO 语句以来的总数。

- LAST_QUEUED_TRANSACTION

  排队到中继日志的最后一个事务的全局事务 ID (GTID)。

- LAST_QUEUED_TRANSACTION_ORIGINAL_COMMIT_TIMESTAMP

  格式为 'YYYY-MM-DD hh:mm:ss[.fraction]' 的时间戳，显示排队到中继日志的最后一个事务在原始源上提交的时间。

- LAST_QUEUED_TRANSACTION_IMMEDIATE_COMMIT_TIMESTAMP

  格式为 'YYYY-MM-DD hh:mm:ss[.fraction]' 的时间戳，显示排队到中继日志的最后一个事务在直接源上提交的时间。

- LAST_QUEUED_TRANSACTION_START_QUEUE_TIMESTAMP

  格式为 'YYYY-MM-DD hh:mm:ss[.fraction]' 的时间戳，显示最后一个事务由此 I/O 线程放入中继日志队列的时间。

- LAST_QUEUED_TRANSACTION_END_QUEUE_TIMESTAMP

  格式为 'YYYY-MM-DD hh:mm:ss[.fraction]' 的时间戳，显示最后一个事务排队到中继日志文件的时间。

- QUEUEING_TRANSACTION

  当前在中继日志中排队的事务的全局事务 ID (GTID)。

- QUEUEING_TRANSACTION_ORIGINAL_COMMIT_TIMESTAMP

  格式为 'YYYY-MM-DD hh:mm:ss[.fraction]' 的时间戳，显示当前排队的事务在原始源上提交的时间。

- QUEUEING_TRANSACTION_IMMEDIATE_COMMIT_TIMESTAMP

  格式为 'YYYY-MM-DD hh:mm:ss[.fraction]' 的时间戳，显示当前排队的事务在直接源上提交的时间。

- QUEUEING_TRANSACTION_START_QUEUE_TIMESTAMP

  格式为 'YYYY-MM-DD hh:mm:ss[.fraction]' 的时间戳，显示当前排队事务的第一个事件由此 I/O 线程写入中继日志的时间。

当 Performance Schema 被禁用时，不收集本地计时信息，因此显示排队事务的开始和结束时间戳的字段为零。

replication_connection_status 表具有以下索引：

- (CHANNEL_NAME) 上的主键

- (THREAD_ID) 上的索引

下表显示了 replication_connection_status 列与 SHOW REPLICA STATUS 列之间的对应关系。

| replication_connection_status 列 | SHOW REPLICA STATUS 列 |
|---|---|
| SOURCE_UUID | Master_UUID |
| THREAD_ID | None |
| SERVICE_STATE | Replica_IO_Running |
| RECEIVED_TRANSACTION_SET | Retrieved_Gtid_Set |
| LAST_ERROR_NUMBER | Last_IO_Errno |
| LAST_ERROR_MESSAGE | Last_IO_Error |
| LAST_ERROR_TIMESTAMP | Last_IO_Error_Timestamp |
