### 29.12.21.1 setup_loggers 表

setup_loggers 表列出已注册的日志记录器及其日志级别：

```
mysql> select * from performance_schema.setup_loggers;
+------------------------+-------+-------------------------+
| NAME                   | LEVEL | DESCRIPTION             |
+------------------------+-------+-------------------------+
| logger/sql/error_log   | info | MySQL error logger       |
| logger/sql/slow_log    | info | MySQL slow query logger |
| logger/sql/general_log | info | MySQL general logger     |
+------------------------+-------+-------------------------+
```

- NAME：日志记录器的名称。

  可以是以下之一：

  - logger/sql/error_log

  - logger/sql/general_log

    常规日志没有日志级别。所有日志都使用 INFO 进行检测。它也独立于现有配置。例如，如果禁用了 log_output 或 general_log，常规 OpenTelemetry 日志记录仍会继续。

  - logger/sql/slow_log

    慢查询日志没有日志级别。所有日志都使用 WARN 进行检测。它也独立于现有配置。例如，如果禁用了 log_output 或 slow_query_log，慢查询 OpenTelemetry 日志记录仍会继续。同样，在副本上，如果禁用了 log_slow_replica_statements，慢查询 OpenTelemetry 日志记录仍会在副本上继续。

- LEVEL：日志级别。可以设置为以下值之一：

  - none

  - error

  - warn

  - info

  - debug

- DESCRIPTION：日志记录器的文本描述。
