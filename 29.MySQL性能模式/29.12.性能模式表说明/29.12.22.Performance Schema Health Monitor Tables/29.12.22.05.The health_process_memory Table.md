### 29.12.22.5 health_process_memory 表

MySQL 进程的内存使用信息。

```
mysql> select * from performance_schema.health_process_memory\G
*************************** 1. row ***************************
   TIMESTAMP: 2026-09-30 10:10:34
PROCESS_NAME: mysqld
         PID: 2505
      VM_RSS: 513454080
     VM_DATA: 944553984
     VM_SWAP: 0
 PAGE_FAULTS: 153
*************************** 2. row ***************************
   TIMESTAMP: 2026-09-30 10:11:34
PROCESS_NAME: mysqld
         PID: 2505
      VM_RSS: 513458176
     VM_DATA: 944553984
     VM_SWAP: 0
 PAGE_FAULTS: 153
*************************** 3. row ***************************
   TIMESTAMP: 2026-09-30 10:12:34
PROCESS_NAME: mysqld
         PID: 2505
      VM_RSS: 513458176
     VM_DATA: 944553984
     VM_SWAP: 0
 PAGE_FAULTS: 153
*************************** 4. row ***************************
....
```

health_process_memory 表包含以下列：

- TIMESTAMP：此行中数据样本的收集时间。

- PROCESS_NAME：MySQL Server 进程的名称和路径。

- PID：MySQL 服务器进程的系统标识符。

- VM_RSS：MySQL 服务器进程的常驻内存大小，单位为字节。

- VM_DATA：MySQL 服务器进程数据段的大小，单位为字节。

- VM_SWAP：MySQL 服务器进程交换段的大小，单位为字节。

- PAGE_FAULTS：需要磁盘 I/O 的页面错误数。
