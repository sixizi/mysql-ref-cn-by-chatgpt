### 29.12.22.11 system_memory_stats 表

系统内存统计信息。

```
mysql> select * from performance_schema.system_memory_stats\G
*************************** 1. row ***************************
       TIMESTAMP: 2026-10-01 09:52:33
     TOTAL_BYTES: 8022503424
      FREE_BYTES: 840933376
      USED_BYTES: 4688453632
 AVAILABLE_BYTES: 2804424704
   BUFFERS_BYTES: 4489216
    CACHED_BYTES: 2066862080
      SLAB_BYTES: 421765120
  SWAP_TOTAL_BYTES: 4236242944
   SWAP_FREE_BYTES: 4006621184
   SWAP_USED_BYTES: 229621760
           SWAP_IN: 4808998912
          SWAP_OUT: 2948497408
1 row in set (0.001 sec)
```

system_memory_stats 表包含以下列：

- TIMESTAMP：测量时间。

- TOTAL_BYTES：系统可用内存总量，单位为字节。

- FREE_BYTES：未使用的内存。

- USED_BYTES：已使用的内存。计算方式为 TOTAL_BYTES - FREE_BYTES - CACHED_BYTES - BUFFERS_BYTES - SLAB_BYTES。

- AVAILABLE_BYTES：可用于启动新应用程序的估计内存量，单位为字节。

- BUFFERS_BYTES：原始磁盘块的临时存储。

- CACHED_BYTES：从磁盘读取的文件的内存缓存（页面缓存）。

- SLAB_BYTES：内核数据结构缓存。

- SWAP_TOTAL_BYTES：可用交换空间的总量。

- SWAP_FREE_BYTES：从 RAM 中驱逐并临时存储在磁盘上的内存总量。

- SWAP_USED_BYTES：已使用的交换空间。计算方式为 SWAP_TOTAL_BYTES - SWAP_FREE_BYTES。

- SWAP_IN：从磁盘交换进入的内存量，单位为 kB/s。

- SWAP_OUT：交换到磁盘的内存量，单位为 kB/s。
