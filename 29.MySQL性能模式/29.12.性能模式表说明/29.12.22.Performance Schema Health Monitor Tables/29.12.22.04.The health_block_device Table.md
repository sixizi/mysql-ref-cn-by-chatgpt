### 29.12.22.4 health_block_device 表

此表显示 df 工具的等效输出，每 health_monitor.disk_sample_rate 秒执行一次，针对在 health_monitor.disk_monitored 中定义的磁盘。

```
mysql> select * from performance_schema.health_block_device \G
*************************** 1. row ***************************
         DEVICE: /dev/mapper/ok-root
      TIMESTAMP: 2026-09-30 10:10:34
    TOTAL_BYTES: 75125227520
AVAILABLE_BYTES: 59197743104
    USE_PERCENT: 21.20
    MOUNT_POINT: /
*************************** 2. row ***************************
         DEVICE: /dev/mapper/ok-root
      TIMESTAMP: 2026-09-30 10:11:34
    TOTAL_BYTES: 75125227520
AVAILABLE_BYTES: 59197485056
    USE_PERCENT: 21.20
    MOUNT_POINT: /
*************************** 3. row ***************************
         DEVICE: /dev/mapper/ok-root
      TIMESTAMP: 2026-09-30 10:12:34
    TOTAL_BYTES: 75125227520
AVAILABLE_BYTES: 59197337600
    USE_PERCENT: 21.20
    MOUNT_POINT: /
*************************** 4. row ***************************
...
```

health_block_device 表具有以下列：

- DEVICE：设备名称。
- TIMESTAMP：收集此行中数据样本的时间。
- TOTAL_BYTES：设备上的总存储量，以字节为单位。
- AVAILABLE_BYTES：设备上的可用存储量，以字节为单位。
- USE_PERCENT：磁盘空间使用百分比。
- MOUNT_POINT：设备挂载点。
