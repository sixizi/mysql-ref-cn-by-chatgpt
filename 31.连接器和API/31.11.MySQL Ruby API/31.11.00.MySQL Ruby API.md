`mysql2` Ruby gem提供连接MySQL、执行查询并遍历结果的API，目标是支持MySQL 5.7和MySQL 8.0。有关更多信息，请参见 [RubyGems上的mysql2页面](https://rubygems.org/gems/mysql2/)或[项目GitHub页面](https://github.com/brianmario/mysql2)。

有关Ruby语言的背景和语法信息，请参见 [Ruby Programming Language](https://www.ruby-lang.org/)。

官方英文版参见 [MySQL Ruby APIs](https://dev.mysql.com/doc/refman/8.0/en/apis-ruby.html)。
