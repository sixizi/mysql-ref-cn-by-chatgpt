MySQL连接器为客户端程序提供到MySQL服务器的连接能力。API则通过经典MySQL协议或X协议提供对MySQL资源的低层访问。连接器和API都支持从其他语言或环境连接并执行MySQL语句，包括ODBC、Java（JDBC）、C++、Python、Node.js、PHP、Perl、Ruby和C。

## MySQL连接器

Oracle开发了多个连接器：

- Connector/C++ 使 C++ 应用程序能够连接到MySQL。
- Connector/J 为Java应用程序使用标准JDBC API连接MySQL提供驱动支持。
- Connector/NET 使开发人员能够创建连接到MySQL的.NET应用程序。Connector/NET实现了功能完整的ADO.NET接口，并支持与ADO.NET感知工具配合使用。使用Connector/NET的应用程序可以使用任何受支持的.NET语言编写。
- Connector/ODBC 为使用ODBC API连接MySQL提供驱动支持。Windows、Unix和macOS平台均支持ODBC连接。
- Connector/Python 为Python应用程序使用符合Python DB API 2.0的API连接MySQL提供驱动支持，不需要额外的Python模块或MySQL客户端库。
- Connector/Node.js 为Node.js应用程序使用X Protocol连接MySQL提供异步API。Connector/Node.js支持管理数据库会话和模式，使用MySQL文档存储集合，以及执行原始SQL语句。

## MySQL C API

若要在C应用程序中原生、直接地访问MySQL，C API通过 `libmysqlclient` 客户端库提供对MySQL客户端/服务器协议的低层访问。这是连接MySQL服务器实例的主要方法，既被MySQL命令行客户端使用，也被本节介绍的许多MySQL连接器以及第三方API使用。

`libmysqlclient` 包含在MySQL发行版中。若要从C应用程序访问MySQL，或为本章连接器和API不支持的语言构建MySQL接口，可以从C API开始。许多程序员实用工具可以帮助完成该过程；参见 [6.7 程序开发实用工具](https://dev.mysql.com/doc/refman/8.0/en/program-development-utilities.html)。

## 第三方MySQL API

本章其余API为特定应用语言提供MySQL接口。这些第三方解决方案不由Oracle开发或支持。此处仅提供其用法和能力的 基本信息，供参考。

所有第三方语言API都基于以下两种方法之一开发：使用 `libmysqlclient`，或实现原生驱动。两种方案各有优势：

- 使用 `libmysqlclient` 与MySQL完全兼容，因为它使用与MySQL客户端应用相同的库。不过，功能集限于通过 `libmysqlclient` 及其接口暴露的实现，而且由于数据会在原生语言和MySQL API组件之间复制，性能可能较低。
- 原生驱动是在宿主语言或环境内完整实现MySQL网络协议的驱动。原生驱动速度更快，因为组件之间复制的数据更少，并且可以提供标准MySQL API中不具备的高级功能。构建和部署原生驱动组件不需要MySQL客户端库副本，因此对终端用户也更容易。
