# 31.10 MySQL Python API

MySQLdb是一个第三方驱动，为Python提供MySQL支持，符合Python DB API 2.0。它可在 [SourceForge的MySQLdb项目](https://sourceforge.net/projects/mysql-python/)获取。

新的MySQL Connector/Python组件提供同一Python API的接口，内置于MySQL服务器并由Oracle支持。有关Connector、Python应用编码指南和示例Python代码的详细信息，请参见 [MySQL Connector/Python Developer Guide](https://dev.mysql.com/doc/connector-python/en/)。

官方英文版参见 [MySQL Python API](https://dev.mysql.com/doc/refman/8.0/en/apis-python.html)。
