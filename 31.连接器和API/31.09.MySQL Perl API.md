# 31.9 MySQL Perl API

Perl DBI模块提供通用的数据库访问接口。你可以编写一个无需修改即可在许多不同数据库引擎上工作的DBI脚本。要在MySQL中使用DBI，请安装：

1. DBI模块。
2. `DBD::mysql`模块。这是Perl的数据库驱动（DBD）模块。
3. 可选地，安装你要访问的其他类型数据库服务器的DBD模块。

Perl DBI是推荐的Perl接口。它取代了旧接口mysqlperl；旧接口应视为已废弃。

- 有关从选项文件读取选项的示例，参见 [7.8.4 Using Client Programs in a Multiple-Server Environment](https://dev.mysql.com/doc/refman/8.0/en/multiple-server-client-program.html)。
- 有关安全编码提示，参见 [8.1.1 Security Guidelines](https://dev.mysql.com/doc/refman/8.0/en/general-security-guidelines.html)。
- 有关调试提示，参见 [7.9.1.4 Debugging mysqld under gdb](https://dev.mysql.com/doc/refman/8.0/en/debugging-mysqld.html)。
- 有关Perl特定环境变量，参见 [6.9 Environment Variables](https://dev.mysql.com/doc/refman/8.0/en/environment-variables.html)。
- 有关macOS上的运行注意事项，参见 [2.4 Installing MySQL on macOS](https://dev.mysql.com/doc/refman/8.0/en/macos-installation.html)。
- 有关字符串字面量引用方式，参见 [11.1.1 String Literals](https://dev.mysql.com/doc/refman/8.0/en/string-literals.html)。

DBI信息可通过命令行、在线和印刷文档获取：

安装DBI和 `DBD::mysql` 模块后，可在命令行使用 `perldoc` 命令查看相关信息：

```text
perldoc DBI
perldoc DBI::FAQ
perldoc DBD::mysql
```

也可以使用 `pod2man`、`pod2html`等工具将这些信息转换为其他格式。在线信息请访问 [DBI网站](https://dbi.perl.org/)，该网站还提供通用DBI邮件列表。印刷资料方面，官方DBI书籍为《Programming the Perl DBI》（Alligator Descartes与Tim Bunce，O'Reilly & Associates，2000），可在DBI网站查看相关信息。

官方英文版参见 [MySQL Perl API](https://dev.mysql.com/doc/refman/8.0/en/apis-perl.html)。
