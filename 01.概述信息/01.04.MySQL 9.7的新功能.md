### MySQL 26.10 中添加或更改的功能

以下功能已添加到 MySQL 26.10：

- **四部分精确发布标识。** MySQL Server 现在以 MAJOR.MINOR.PATCH.UPDATE 形式公开精确发布标识，以便可以区分同一补丁线上单独交付的更新。更新组件始终存在于更新感知接口上，包括其值为 0 时。使用 VERSION_WITH_UPDATE()、version_with_update 系统变量或 mysqld --version-with-update 来获取完整值。现有接口（如 VERSION()、version 和 mysqld --version）继续返回三部分兼容性版本。mysql_upgrade_history 审计文件在嵌套的 update_history 数组中记录精确发布转换，不改变兼容性检查。

  有关更多信息，请参见 mysql_upgrade_history 文件。

- **JSON 二元性视图的粒度并发和更新控制。** JSON_DUALITY_OBJECT() 现在支持表和列级别的 CHECK 和 NO CHECK 注解，以及列级别的 UPDATE 和 NO UPDATE 注解。这些注解确定哪些投影列参与 ETAG 计算以及哪些字段可以通过视图修改。列设置从其表继承，除非显式覆盖。JSON_DUALITY_VIEW_COLUMNS 信息架构表使用 ALLOW_CHECK 和 ALLOW_UPDATE 公开有效设置。

### MySQL 26.10 中弃用的功能

以下功能在 MySQL 26.10 中已弃用，可能在未来版本中删除。如果显示了替代方案，应更新应用程序以使用它们。

对于使用在 MySQL 26.10 中弃用但在更高版本 MySQL 中已删除的功能的应用程序，从 MySQL 26.10 源复制到运行更高版本的副本时，语句可能会失败，或者可能对源和副本产生不同的影响。为避免此类问题，应修改使用在 26.10 中弃用的功能的应用程序以避免使用它们，并在可能的情况下使用替代方案。

- **SCRAM-SHA-1 身份验证。** SASL LDAP 身份验证的 SCRAM-SHA-1 身份验证方法自 MySQL 9.5.0 起已弃用。改用 SCRAM-SHA-256；这现在也是 authentication_ldap_sasl_auth_method_name 的默认值。

  有关更多信息，请参见第 8.4.1.6 节"LDAP 可插拔身份验证"。

### MySQL 26.10 中删除的功能

以下项目已过时，已在 MySQL 26.10 中删除。如果显示了替代方案，应更新应用程序以使用它们。

对于使用在 MySQL 26.10 中删除的功能的 MySQL 9.7 应用程序，从 MySQL 9.7 源复制到 MySQL 26.10 副本时，语句可能会失败，或者可能对源和副本产生不同的影响。为避免此类问题，应修改使用在 MySQL 26.10 中删除的功能的应用程序以避免使用它们，并在可能的情况下使用替代方案。

- **删除的服务器系统和状态变量。** MySQL 26.10 中删除的服务器系统和状态变量如下所示：

  - group_replication_allow_local_lower_version_join

  - replica_parallel_type

本节列出在 MySQL 26.10 中首次添加、已弃用或已删除的服务器变量、状态变量和选项。

### MySQL 26.10 中引入的选项和变量

以下系统变量、状态变量和服务器选项已在 MySQL 26.10 中添加。

- **disk_forecaster_run_mode：** 当前磁盘预测器模式。在 MySQL 26.10.0 中添加。

- **disk_forecaster_test_state：** 磁盘预测测试或模拟的当前状态。在 MySQL 26.10.0 中添加。

- **health_monitor.disk_fallback_enable：** 启用磁盘收集。在 MySQL 26.10.0 中添加。

- **health_monitor.disk_fallback_force：** 允许在隔离期间终止阻塞的前台会话。在 MySQL 26.10.0 中添加。

- **health_monitor.disk_forecast_report_interval：** 磁盘预测指标间隔（秒）。在 MySQL 26.10.0 中添加。

- **health_monitor.disk_forecast_run_mode：** 磁盘预测器操作模式。在 MySQL 26.10.0 中添加。

- **health_monitor.disk_forecast_running：** 启用磁盘指标收集和预测。在 MySQL 26.10.0 中添加。

- **health_monitor.disk_forecast_sample_interval：** 磁盘预测指标间隔（秒）。在 MySQL 26.10.0 中添加。

- **health_monitor.disk_forecast_test_filename：** 为 TEST 模式选择的输入文件。在 MySQL 26.10.0 中添加。

- **health_monitor.disk_low_space_critical_level：** 启用隔离时立即隔离的关键低空间阈值（MiB）。在 MySQL 26.10.0 中添加。

- **health_monitor.disk_low_space_duration：** 低于低空间阈值的秒数，然后隔离。在 MySQL 26.10.0 中添加。

- **health_monitor.disk_low_space_level：** 低于低空间阈值的秒数，然后隔离。在 MySQL 26.10.0 中添加。

- **health_monitor.disk_low_space_percent：** 低空间阈值，占文件系统容量的百分比，与固定阈值一起使用。在 MySQL 26.10.0 中添加。
