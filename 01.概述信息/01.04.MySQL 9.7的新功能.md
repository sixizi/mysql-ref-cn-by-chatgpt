### MySQL 26.7 中添加或更改的功能

以下功能已添加到 MySQL 26.7：

- **基于日历的版本控制和兼容性系统验证。** MySQL 26.7.0 是第一个使用 YY.M.P 日历版本格式的版本。服务器现在在数据字典中持久化内部兼容性系统元数据，并在验证后续直接升级时使用它。MySQL 26.7.x LTS 是唯一可以进入第一个日历版本系统的旧版本线。创新版本可以在系统内升级，但不能跨越系统边界，而 LTS 版本可以进入紧随其后的系统。直接降级策略仍限于同一 LTS YY.M 版本线内的合格补丁降级。请参见第 1.3 节"MySQL 版本：创新版和 LTS 版"、第 3.2 节"升级路径"和第 4 章"降级 MySQL"。

- **日历版本发布的克隆版本兼容性。** 克隆插件允许在同一 MySQL 服务器系列内的补丁版本之间进行克隆。在不同系列之间，仅允许从 LTS 供体克隆到紧随其后的 LTS 接收方。不支持涉及创新版本的跨系列克隆、克隆到较旧的 LTS 系列以及跳过 LTS 系列的克隆。请参见第 7.6.6.3 节"克隆远程数据"。

- **InnoDB AUTO_INCREMENT 计数器持久化。** InnoDB 现在以批处理方式持久化 AUTO_INCREMENT 计数器。新的全局动态系统变量 innodb_autoinc_preallocate 控制在持久化计数器时预留多少额外值。默认值为 50。这减少了持久化元数据更新，但意外的服务器退出可能导致未使用的预留值被跳过。将变量设置为 0 会禁用额外的预分配。正常关闭会持久化实际计数器值，不会引入预分配间隙。

- **崩溃安全的撤销表空间创建和截断。** InnoDB 不再为 CREATE UNDO TABLESPACE 或撤销表空间截断操作创建本地 undo_space_number_trunc.log 标记文件。相反，它在撤销表空间文件头中记录进行中的状态，并使用重做和 DDL 日志来恢复中断的操作。启动时，受影响的撤销表空间会根据需要删除或重新创建。为了向后兼容，早期服务器版本留下的标记文件继续被识别，但不会创建新的标记文件。在数据字典中记录但在已知目录中未发现的撤销表空间会自动重新创建。初始化后必须至少保留一个活跃的撤销表空间；如果未找到撤销表空间，服务器启动无法继续。请参见第 17.6.3.4 节"撤销表空间"。

- **TLS 的后量子密码学。** 对于使用 OpenSSL 3.5 或更高版本的构建，MySQL TLSv1.3 连接支持混合和纯后量子密钥交换组以及 ML-DSA TLS 握手签名算法。PQC 密钥交换默认优先使用经典回退，可以为主、管理、异步复制、Group Replication 和 X Plugin 连接通道独立要求。新的客户端选项和状态变量提供配置和监控支持。请参见第 8.3.6 节"后量子密码学"。

- **变更流应用器。** 变更流应用器（CSA）是一个可选的复制应用器，旨在改进并行事务应用和可扩展性。CSA 使用 APPLIER_VERSION = 2 按通道选择。APPLIER_WORKER_COUNT 和 APPLIER_EVENT_MEMORY_LIMIT 选项提供按通道的工作线程和事件内存配置。CSA 需要基于行的复制和 GTID。请参见第 19.2.4 节"变更流应用器"。

### MySQL 26.7 中弃用的功能

以下功能在 MySQL 26.7 中已弃用，可能在未来版本中删除。如果显示了替代方案，应更新应用程序以使用它们。

对于使用在 MySQL 26.7 中弃用但在更高版本 MySQL 中已删除的功能的应用程序，从 MySQL 26.7 源复制到运行更高版本的副本时，语句可能会失败，或者可能对源和副本产生不同的影响。为避免此类问题，应修改使用 26.7 中弃用功能的应用程序以避免使用它们，并在可能的情况下使用替代方案。

- **SCRAM-SHA-1 身份验证。** SASL LDAP 身份验证的 SCRAM-SHA-1 身份验证方法自 MySQL 9.5.0 起已弃用。改用 SCRAM-SHA-256；这现在也是 authentication_ldap_sasl_auth_method_name 的默认值。

  请参见第 8.4.1.6 节"LDAP 可插拔身份验证"以获取更多信息。

### MySQL 26.7 中删除的功能

以下项目已过时，已在 MySQL 26.7 中删除。如果显示了替代方案，应更新应用程序以使用它们。

对于使用在 MySQL 26.7 中删除的功能的 MySQL 26.7 应用程序，从 MySQL 26.7 源复制到 MySQL 26.7 副本时，语句可能会失败，或者可能对源和副本产生不同的影响。为避免此类问题，应修改使用在 MySQL 26.7 中删除的功能的应用程序以避免使用它们，并在可能的情况下使用替代方案。

- **删除的服务器系统和状态变量。** MySQL 26.7 中删除的服务器系统和状态变量如下所示：

  - group_replication_allow_local_lower_version_join

  - replica_parallel_type
