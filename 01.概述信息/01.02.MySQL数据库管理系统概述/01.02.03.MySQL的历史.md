### 1.2.3 MySQL 的历史

我们最初的目的是使用 mSQL 数据库系统来连接我们的表，并使用我们自己的快速低级（ISAM）例程。然而，经过一些测试后，我们得出结论，mSQL 对我们的需求来说既不够快也不够灵活。这导致我们为数据库创建了一个新的 SQL 接口，但其 API 接口与 mSQL 几乎相同。这个 API 的设计目的是使为 mSQL 编写的第三方代码能够轻松移植到 MySQL 中使用。

MySQL 是以联合创始人 Monty Widenius 的女儿 My 的名字命名的。

MySQL 海豚（我们的标志）的名字是"Sakila"，这是从用户在我们的"给海豚命名"竞赛中建议的大量名字中选出来的。获胜的名字由来自埃斯瓦蒂尼（原斯威士兰）非洲的开源软件开发者 Ambrose Twebaze 提交。根据 Ambrose 的说法，女性名字 Sakila 的根源在于埃斯瓦蒂尼的当地语言 SiSwati。Sakila 也是坦桑尼亚阿鲁沙的一个城镇的名字，靠近 Ambrose 的祖国乌干达。
