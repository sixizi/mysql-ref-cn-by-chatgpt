# 1.5 MySQL 26.7 中新增、弃用或移除的服务器和状态变量及选项

- Options and Variables Introduced in MySQL 26.7
- Options and Variables Deprecated in MySQL 26.7
- Options and Variables Removed in MySQL 26.7

本节列出了在 MySQL 26.7 中首次添加、已弃用或已移除的服务器变量、状态变量和选项。

## MySQL 26.7 中引入的选项和变量

以下系统变量、状态变量和服务器选项已在 MySQL 26.7 中添加。

- Audit_log_file_count：审计日志插件生成的审计日志文件数。在 MySQL 26.7.0 中添加。

- Mysqlx_force_pqc：应用于当前 X Plugin TLS 通道的有效配置值。在 MySQL 26.7.0 中添加。

- Mysqlx_tls_kex：应用于当前 X Plugin TLS 通道的有效配置值。在 MySQL 26.7.0 中添加。

- Mysqlx_use_pqc_sign：应用于当前 X Plugin TLS 通道的有效配置值。在 MySQL 26.7.0 中添加。

- Tls_key_exchange_algorithm：该值表示为当前 TLS 连接协商的 TLS 密钥交换组。如果连接未使用 TLS、TLS 会话已恢复或 TLS 库版本未公开协商的密钥交换组，则该值为空。在 MySQL 26.7.0 中添加。

- Tls_sign_algorithm：该值表示为当前 TLS 连接协商的 TLS 握手签名算法。如果连接未使用 TLS、TLS 会话已恢复或 TLS 库版本未公开协商的签名算法，则该值为空。在 MySQL 26.7.0 中添加。

- admin_force_pqc：是否接受使用 PQC 兼容密钥交换组协商的管理员 TLS 连接。在 MySQL 26.7.0 中添加。

- admin_tls_kex：用于管理员连接通道的 TLS 密钥交换组的冒号分隔列表。在 MySQL 26.7.0 中添加。

- admin_use_pqc_sign：如果为 OFF，仅在管理员连接通道上通告经典 TLS 握手签名算法。在 MySQL 26.7.0 中添加。

- audit_log.file_count：审计日志组件生成的审计日志文件数。在 MySQL 26.7.0 中添加。

- force_pqc：是否接受使用 PQC 兼容密钥交换组协商的主 TLS 连接。在 MySQL 26.7.0 中添加。

- group_replication_force_pqc：是否要求 Group Replication 恢复 TLS 连接使用 PQC 兼容密钥交换组。在 MySQL 26.7.0 中添加。

- group_replication_tls_kex：用于 Group Replication 恢复 TLS 连接的 TLS 密钥交换组的冒号分隔列表。在 MySQL 26.7.0 中添加。

- group_replication_use_pqc_sign：如果为 OFF，仅在 Group Replication 恢复 TLS 连接上通告经典 TLS 握手签名算法。在 MySQL 26.7.0 中添加。

- innodb_autoinc_preallocate：当在数据字典中持久化表的自增计数器时，InnoDB 预留的额外 AUTO_INCREMENT 值数量。在 MySQL 26.7.0 中添加。

- mysqlx_force_pqc：是否仅接受使用 PQC 兼容密钥交换组协商的 X Plugin TLS 连接。在 MySQL 26.7.0 中添加。

- mysqlx_tls_kex：用于 X Plugin TLS 连接的 TLS 密钥交换组的冒号分隔列表。在 MySQL 26.7.0 中添加。

- mysqlx_use_pqc_sign：如果为 OFF，仅在 Group Replication 恢复 TLS 连接上通告经典 TLS 握手签名算法。在 MySQL 26.7.0 中添加。

- replication_force_pqc：是否要求异步复制 TLS 连接使用 PQC 兼容密钥交换组。在 MySQL 26.7.0 中添加。

- replication_tls_kex：用于异步复制 TLS 连接的 TLS 密钥交换组的冒号分隔列表。在 MySQL 26.7.0 中添加。

- replication_use_pqc_sign：如果为 OFF，仅在异步复制 TLS 连接上通告经典 TLS 握手签名算法。在 MySQL 26.7.0 中添加。

- tls_kex：用于主连接通道的 TLS 密钥交换组的冒号分隔列表。在 MySQL 26.7.0 中添加。

- use_pqc_sign：如果为 OFF，仅在主连接通道上通告经典 TLS 握手签名算法。在 MySQL 26.7.0 中添加。

## MySQL 26.7 中弃用的选项和变量

以下系统变量、状态变量和选项已在 MySQL 26.7 中弃用。

- group_replication_communication_stack：指定应使用哪个通信堆栈（XCom 或 MySQL）来建立成员之间的组通信连接。在 MySQL 26.7.0 中弃用。

## MySQL 26.7 中移除的选项和变量

MySQL 26.7 中未移除任何系统变量、状态变量或选项。
