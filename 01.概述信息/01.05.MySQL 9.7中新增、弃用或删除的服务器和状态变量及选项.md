# 1.5 MySQL 9.7 中新增、弃用或删除的服务器和状态变量及选项

本节列出在 MySQL 9.7 中首次添加、已弃用或已删除的服务器系统变量、状态变量和服务器选项。

## MySQL 9.7 中新增的选项和变量

以下系统变量、状态变量和服务器选项已在 MySQL 9.7 中新增。

- `Audit_log_file_count`：审计日志插件生成的审计日志文件数量。在 MySQL 9.7.0 中新增。
- `audit_log.file_count`：审计日志组件生成的审计日志文件数量。在 MySQL 9.7.0 中新增。
- `audit_log.filter_recovery_mode`：当 `mysql_log_filter` 配置不正确时，控制服务器的恢复模式。在 MySQL 9.7.0 中新增。
- `audit_log.rotate_on_time`：根据当前文件创建以来经过的时间关闭并重新打开审计日志文件。在 MySQL 9.7.0 中新增。
- `audit_log_filter_recovery_mode`：当 `mysql_log_filter` 配置不正确时，控制服务器的恢复模式。在 MySQL 9.7.0 中新增。
- `caching_sha2_password_enforce_storage_format`：强制指定 `caching_sha2_password_storage_format` 的存储格式。在 MySQL 9.7.0 中新增。
- `caching_sha2_password_storage_format`：`caching_sha2_password` 的存储格式。在 MySQL 9.7.0 中新增。
- `enable_cascade_triggers`：指定由服务器运行时还是 InnoDB 引擎处理外键。在 MySQL 9.7.0 中新增。
- `object_policy_flush_interval_seconds`：启用从库和副本的对象策略缓存刷新。在 MySQL 9.7.0 中新增。
- `replica_allow_higher_version_source`：控制是否允许异步复制来自更高版本源服务器。在 MySQL 9.7.0 中新增。
- `version_with_update`：返回表示四段式 MySQL 服务器版本号的字符串。在 MySQL 9.7.4 中新增。

## MySQL 9.7 中弃用的选项和变量

以下系统变量、状态变量和服务器选项已在 MySQL 9.7 中弃用。

- `enable_cascade_triggers`：指定由服务器运行时还是 InnoDB 引擎处理外键。在 MySQL 9.7.0 中弃用。
- `group_replication_communication_stack`：指定成员之间建立组通信连接时使用的通信栈（`XCom` 或 `MySQL`）。在 MySQL 9.7.2 中弃用。

## MySQL 9.7 中删除的选项和变量

MySQL 9.7 中没有删除任何系统变量、状态变量或服务器选项。

官方英文版参见 [Server and Status Variables and Options Added, Deprecated, or Removed in MySQL 9.7](https://dev.mysql.com/doc/refman/9.7/en/added-deprecated-removed.html)。
