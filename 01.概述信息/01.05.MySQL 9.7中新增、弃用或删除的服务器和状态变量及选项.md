# 1.5 MySQL 26.10 中新增、弃用或移除的服务器和状态变量及选项

- Options and Variables Introduced in MySQL 26.10

- Options and Variables Deprecated in MySQL 26.10

- Options and Variables Removed in MySQL 26.10

本节列出了在 MySQL 26.10 中首次添加、已弃用或已移除的服务器变量、状态变量和选项。

## MySQL 26.10 中引入的选项和变量

以下系统变量、状态变量和服务器选项已在 MySQL 26.10 中添加。

- disk_forecaster_run_mode: 当前磁盘预测器模式。在 MySQL 26.10.0 中添加。

- disk_forecaster_test_state: 磁盘预测测试或模拟的当前状态。在 MySQL 26.10.0 中添加。

- health_monitor.disk_fallback_enable: 启用磁盘收集。在 MySQL 26.10.0 中添加。

- health_monitor.disk_fallback_force: 允许在隔离期间终止阻塞的前台会话。在 MySQL 26.10.0 中添加。

- health_monitor.disk_forecast_report_interval: 磁盘预测指标间隔（秒）。在 MySQL 26.10.0 中添加。

- health_monitor.disk_forecast_run_mode: 磁盘预测器运行模式。在 MySQL 26.10.0 中添加。

- health_monitor.disk_forecast_running: 启用磁盘指标收集和预测。在 MySQL 26.10.0 中添加。

- health_monitor.disk_forecast_sample_interval: 磁盘预测指标间隔（秒）。在 MySQL 26.10.0 中添加。

- health_monitor.disk_forecast_test_filename: 为 TEST 模式选择的输入文件。在 MySQL 26.10.0 中添加。

- health_monitor.disk_low_space_critical_level: 启用隔离时立即隔离的关键低空间阈值（MiB）。在 MySQL 26.10.0 中添加。

- health_monitor.disk_low_space_duration: 低于低空间阈值后进行隔离的秒数。在 MySQL 26.10.0 中添加。

- health_monitor.disk_low_space_level: 低于低空间阈值后进行隔离的秒数。在 MySQL 26.10.0 中添加。

- health_monitor.disk_low_space_percent: 低空间阈值，表示为文件系统容量的百分比，与固定阈值一起使用。在 MySQL 26.10.0 中添加。

- health_monitor.disk_monitored: 文件系统上要监视的路径。空值选择数据目录文件系统。在 MySQL 26.10.0 中添加。

- health_monitor.disk_recovery_enable: 启用从健康监视器隔离的自动恢复。在 MySQL 26.10.0 中添加。

- health_monitor.disk_recovery_increment: 每个恢复周期后添加的延迟（秒）。在 MySQL 26.10.0 中添加。

- health_monitor.disk_recovery_level: 开始恢复所需的保留空间上方的可用空间百分比。在 MySQL 26.10.0 中添加。

- health_monitor.disk_recovery_max_cycles: 恢复窗口内自动恢复周期的最大数量。在 MySQL 26.10.0 中添加。

- health_monitor.disk_recovery_time_1: 恢复级别上方的秒数，在此之后清除健康监视器拥有的 OFFLINE_MODE。在 MySQL 26.10.0 中添加。

- health_monitor.disk_recovery_time_2: 恢复级别上方的额外秒数，在此之后清除健康监视器拥有的 SUPER_READ_ONLY。在 MySQL 26.10.0 中添加。

- health_monitor.disk_recovery_window: 用于重置恢复周期计数的窗口（秒）。在 MySQL 26.10.0 中添加。

- health_monitor.disk_retention: 磁盘样本保留时间（秒）。在 MySQL 26.10.0 中添加。

- health_monitor.disk_running: 启用磁盘收集。在 MySQL 26.10.0 中添加。

- health_monitor.disk_sample_rate: 磁盘样本间隔（秒）。在 MySQL 26.10.0 中添加。

- health_monitor.disk_usage_warning_level_1: 第一个警告级别，表示为保留可用空间上方的百分比。在 MySQL 26.10.0 中添加。

- health_monitor.disk_usage_warning_level_2: 第二个警告级别，表示为保留可用空间上方的百分比。在 MySQL 26.10.0 中添加。

- health_monitor.disk_usage_warning_level_3: 第三个警告级别，表示为保留可用空间上方的百分比。在 MySQL 26.10.0 中添加。

- health_monitor.memory_report_definition: 有效的报告定义，最多 65,535 字节。保留供将来开发使用。在 MySQL 26.10.0 中添加。

- health_monitor.memory_reporting: 启用触发的内存报告。在 MySQL 26.10.0 中添加。

- health_monitor.memory_retention: 内存样本保留时间（秒）。在 MySQL 26.10.0 中添加。

- health_monitor.memory_running: 启用主机和 MySQL 进程内存收集。在 MySQL 26.10.0 中添加。

- health_monitor.memory_sample_rate: 内存样本间隔（秒）。在 MySQL 26.10.0 中添加。

- health_monitor.memory_usage_warning_level_1: 第一个内存警告级别（MiB）。在 MySQL 26.10.0 中添加。

- health_monitor.memory_usage_warning_level_2: 第二个内存警告级别（MiB）。在 MySQL 26.10.0 中添加。

- health_monitor.memory_usage_warning_level_3: 第三个内存警告级别（MiB）。在 MySQL 26.10.0 中添加。

- health_monitor.periodic_report_definition: 有效的报告定义，最多 65,535 字节。保留供将来开发使用。在 MySQL 26.10.0 中添加。

- health_monitor.periodic_reporting: 有效的报告定义，最多 65,535 字节。保留供将来开发使用。在 MySQL 26.10.0 中添加。

- health_monitor.status_interval: 共享状态消息间隔，以每个收集器的样本间隔的倍数表示。在 MySQL 26.10.0 中添加。

- health_monitor.system_cpu_stats_history: 启用 CPU 历史行。在 MySQL 26.10.0 中添加。

- health_monitor.system_disk_stats_history: 当磁盘统计信息可用时启用磁盘历史行。在 MySQL 26.10.0 中添加。

- health_monitor.system_memory_stats_history: 启用系统内存历史行。在 MySQL 26.10.0 中添加。

- health_monitor.system_process_stats_history: 启用 MySQL 进程历史行。在 MySQL 26.10.0 中添加。

- health_monitor.system_retention: 系统统计信息保留时间（秒）。在 MySQL 26.10.0 中添加。

- health_monitor.system_running: 启用 CPU、磁盘、内存和 MySQL 进程统计信息收集。在 MySQL 26.10.0 中添加。

- health_monitor.system_sample_rate: 系统统计信息样本间隔（秒）。在 MySQL 26.10.0 中添加。

- mysql_rest_service.current_http_port: 活动 HTTP 侦听器绑定的端口。在 MySQL 26.10.0 中添加。

- mysql_rest_service.current_io_worker_threads: 已解析的活动 IO 工作线程计数。在 MySQL 26.10.0 中添加。

- mysql_rest_service.current_tls_cert: 活动 TLS 上下文加载的证书路径。在 MySQL 26.10.0 中添加。

- mysql_rest_service.current_tls_cipher: 活动 TLS 1.2 密码列表策略。在 MySQL 26.10.0 中添加。

- mysql_rest_service.current_tls_key: 活动 TLS 上下文加载的密钥路径。在 MySQL 26.10.0 中添加。

- mysql_rest_service.http_max_connections: HTTP 连接限制。在 MySQL 26.10.0 中添加。

- mysql_rest_service.http_max_request_body_size: 请求体大小限制。在 MySQL 26.10.0 中添加。

- mysql_rest_service.http_max_response_body_size: 响应体大小限制。在 MySQL 26.10.0 中添加。

- mysql_rest_service.http_port: 活动 HTTP 侦听器绑定的 HTTPS 端口。在 MySQL 26.10.0 中添加。

- mysql_rest_service.io_worker_threads: I/O 工作线程计数。在 MySQL 26.10.0 中添加。

- mysql_rest_service.ssl_cert: 指定公钥证书文件的路径。在 MySQL 26.10.0 中添加。

- mysql_rest_service.ssl_cipher: SSL 加密的允许密码。在 MySQL 26.10.0 中添加。

- mysql_rest_service.ssl_key: 指定私钥文件的路径。在 MySQL 26.10.0 中添加。

- mysql_rest_service.state: MRS 堆栈的状态。在 MySQL 26.10.0 中添加。

- offline_mode_disk_full: 如果健康监视器因磁盘空间不足而设置 OFFLINE_MODE=ON，则为 ON。在 MySQL 26.10.0 中添加。

- option_tracker_usage: 健康监视器：健康监视器表被 SQL 查询访问的总次数。仅限 MySQL Enterprise Edition。在 MySQL 26.10.0 中添加。

- recovery_cycles: 活动恢复窗口中的隔离和恢复周期数。在 MySQL 26.10.0 中添加。

- super_read_only_disk_full: 如果健康监视器因磁盘空间不足而设置 SUPER_READ_ONLY=ON，则为 ON。在 MySQL 26.10.0 中添加。

- version_with_update: 返回指示四部分 MySQL 服务器版本的字符串。在 MySQL 26.10.0 中添加。

## MySQL 26.10 中弃用的选项和变量

在 MySQL 26.10 中没有系统变量、状态变量或服务器选项被弃用。

## MySQL 26.10 中移除的选项和变量

在 MySQL 26.10 中没有系统变量、状态变量或选项被移除。
