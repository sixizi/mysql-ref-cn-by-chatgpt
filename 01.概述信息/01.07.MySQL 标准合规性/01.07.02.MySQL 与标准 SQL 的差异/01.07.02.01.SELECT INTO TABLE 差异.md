### 1.7.2.1 SELECT INTO TABLE 差异

MySQL Server 不支持 SELECT ... INTO TABLE Sybase SQL 扩展。相反，MySQL Server 支持 INSERT INTO ... SELECT 标准 SQL 语法，两者基本相同。参见 Section 15.2.7.1，"INSERT ... SELECT Statement"。例如：

```
INSERT INTO tbl_temp2 (fld_id)
    SELECT tbl_temp1.fld_order_id
    FROM tbl_temp1 WHERE tbl_temp1.fld_order_id > 100;
```

或者，你可以使用 SELECT ... INTO OUTFILE 或 CREATE TABLE ... SELECT。

你可以将 SELECT ... INTO 与用户定义的变量一起使用。相同的语法也可以在存储例程中使用游标和局部变量。参见 Section 15.2.13.1，"SELECT ... INTO Statement"。
