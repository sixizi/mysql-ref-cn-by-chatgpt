### 1.7.2.1 SELECT INTO TABLE 差异

MySQL Server 不支持 Sybase SQL 扩展的 SELECT ... INTO TABLE 语法。相反，MySQL Server 支持标准 SQL 语法 INSERT INTO ... SELECT，两者基本功能相同。参见 Section 15.2.7.1，"INSERT ... SELECT Statement"。例如：

```
INSERT INTO tbl_temp2 (fld_id)
    SELECT tbl_temp1.fld_order_id
    FROM tbl_temp1 WHERE tbl_temp1.fld_order_id > 100;
```

或者，你可以使用 SELECT ... INTO OUTFILE 或 CREATE TABLE ... SELECT。

你可以使用 SELECT ... INTO 与用户定义的变量。相同的语法也可以在存储例程中使用游标和局部变量。参见 Section 15.2.13.1，"SELECT ... INTO Statement"。
