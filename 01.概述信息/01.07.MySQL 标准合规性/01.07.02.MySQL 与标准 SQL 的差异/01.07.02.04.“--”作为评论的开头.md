### 1.7.2.4 '--' 作为注释的开始

标准 SQL 使用 C 语法 `/* this is a comment */` 来表示注释，MySQL Server 也支持这种语法。MySQL 还支持对这种语法的扩展，允许将 MySQL 特定的 SQL 嵌入到注释中；参见第 11.7 节"注释"。

MySQL Server 也使用 `#` 作为注释开始字符。这是非标准的。

标准 SQL 也使用 `--` 作为注释开始序列。MySQL Server 支持 `--` 注释风格的变体；`--` 注释开始序列被接受，但必须后跟空格或换行符等空白字符。这个空格的目的是防止生成的 SQL 查询出现问题，例如以下构造，用于更新余额以反映一笔费用：

```
UPDATE account SET balance=balance-charge
WHERE account_id=user_id
```

考虑当 charge 具有负值（例如 -1）时会发生什么，这可能是在向账户记入金额时的情况。在这种情况下，生成的语句如下所示：

```
UPDATE account SET balance=balance--1
WHERE account_id=5752;
```

`balance--1` 是有效的标准 SQL，但 `--` 被解释为注释的开始，表达式的一部分被丢弃。结果是一个含义完全不同的语句：

```
UPDATE account SET balance=balance
WHERE account_id=5752;
```

此语句根本不会改变任何值。为了防止这种情况发生，MySQL 要求 `--` 后面必须有空白字符才能在 MySQL Server 中被识别为注释开始序列，因此 `balance--1` 这样的表达式总是安全的。
