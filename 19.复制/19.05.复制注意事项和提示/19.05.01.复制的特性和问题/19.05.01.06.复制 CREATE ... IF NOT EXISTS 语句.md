### 19.5.1.6 CREATE ... IF NOT EXISTS 语句的复制

MySQL 在复制各种 CREATE ... IF NOT EXISTS 语句时应用以下规则：

- 每个 CREATE DATABASE IF NOT EXISTS 语句都会被复制，无论源上是否已存在该数据库。

- 类似地，每个不带 SELECT 的 CREATE TABLE IF NOT EXISTS 语句都会被复制，无论源上是否已存在该表。这包括 CREATE TABLE IF NOT EXISTS ... LIKE。CREATE TABLE IF NOT EXISTS ... SELECT 的复制遵循略有不同的规则；有关更多信息，请参见第 19.5.1.7 节"CREATE TABLE ... SELECT 语句的复制"。

- CREATE EVENT IF NOT EXISTS 总是被复制，无论源上是否已存在该语句中命名的事件。

- CREATE USER 仅在成功时才写入二进制日志。如果语句包含 IF NOT EXISTS，则认为它成功，只要创建了语句中命名的至少一个用户，就会记录该语句；在这种情况下，语句按原样记录；这包括对未创建的现有用户的引用。有关更多信息，请参见 CREATE USER 二进制日志记录。

- CREATE PROCEDURE IF NOT EXISTS、CREATE FUNCTION IF NOT EXISTS 或 CREATE TRIGGER IF NOT EXISTS，如果成功，会完整地写入二进制日志（包括 IF NOT EXISTS 子句），无论该语句是否因对象（过程、函数或触发器）已存在而引发警告。
