### 19.5.1.17 JSON 文档的复制

在 MySQL 26.7 中，可以记录对 JSON 文档的部分更新（参见 JSON 值的部分更新）。日志记录行为取决于所使用的格式，如下所述：

- **基于语句的复制。** JSON 部分更新始终作为部分更新进行记录。使用基于语句的日志记录时无法禁用此功能。

- **基于行的复制。** 默认情况下，JSON 部分更新不作为部分更新进行记录，而是作为完整文档进行记录。要启用部分更新的日志记录，请设置 binlog_row_value_options=PARTIAL_JSON。如果复制源设置了此变量，从该源接收的部分更新将由副本处理和应用，无论副本自身对该变量的设置如何。
