### 19.5.1.16 调用功能的复制

调用功能（如可加载函数和存储程序（存储过程和函数、触发器和事件））的复制提供以下特性：

- 功能的效果始终被复制。

- 以下语句使用基于语句的复制进行复制：

  - CREATE EVENT

  - ALTER EVENT

  - DROP EVENT

  - CREATE PROCEDURE

  - DROP PROCEDURE

  - CREATE FUNCTION

  - DROP FUNCTION

  - CREATE TRIGGER

  - DROP TRIGGER

  但是，使用这些语句创建、修改或删除的功能的效果使用基于行的复制进行复制。

  注意

  尝试使用基于语句的复制复制调用功能会产生警告 Statement is not safe to log in statement format。例如，尝试使用基于语句的复制复制可加载函数会生成此警告，因为 MySQL 服务器目前无法确定该函数是否是确定性的。如果您完全确定调用功能的效果是确定性的，可以安全地忽略此类警告。

- 在 CREATE EVENT 和 ALTER EVENT 的情况下：

  - 事件的状态在副本上被设置为 REPLICA_SIDE_DISABLED，无论指定的状态如何（这不适用于 DROP EVENT）。

  - 创建事件的源在副本上由其服务器 ID 标识。INFORMATION_SCHEMA.EVENTS 中的 ORIGINATOR 列存储此信息。有关更多信息，请参见第 15.7.7.21 节"SHOW EVENTS 语句"。

- 功能实现在副本上以可更新状态驻留，以便在源失败时，副本可以用作源而不会丢失事件处理。

要确定 MySQL 服务器上是否存在在不同服务器（充当源）上创建的任何计划事件，请以类似于此处所示的方式查询信息架构 EVENTS 表：

```
SELECT EVENT_SCHEMA, EVENT_NAME
    FROM INFORMATION_SCHEMA.EVENTS
    WHERE STATUS = 'REPLICA_SIDE_DISABLED';
```

或者，您可以使用 SHOW EVENTS 语句，如下所示：

```
SHOW EVENTS
    WHERE STATUS = 'REPLICA_SIDE_DISABLED';
```

将具有此类事件的副本提升为源时，必须使用 ALTER EVENT event_name ENABLE 启用每个事件，其中 event_name 是事件的名称。

如果多个源涉及在此副本上创建事件，并且您希望识别仅在具有服务器 ID source_id 的给定源上创建的事件，请修改 EVENTS 表上的前一个查询以包含 ORIGINATOR 列，如下所示：

```
SELECT EVENT_SCHEMA, EVENT_NAME, ORIGINATOR
    FROM INFORMATION_SCHEMA.EVENTS
    WHERE STATUS = 'REPLICA_SIDE_DISABLED'
    AND   ORIGINATOR = 'source_id'
```

您可以以类似的方式将 ORIGINATOR 与 SHOW EVENTS 语句一起使用：

```
SHOW EVENTS
    WHERE STATUS = 'REPLICA_SIDE_DISABLED'
    AND   ORIGINATOR = 'source_id'
```

注意

REPLICA_SIDE_DISABLED 替代已弃用的 SLAVESIDE_DISABLED。

在启用从源复制的事件之前，应在副本上禁用 MySQL 事件调度程序（使用诸如 SET GLOBAL event_scheduler = OFF; 之类的语句），运行任何必要的 ALTER EVENT 语句，重启服务器，然后之后在副本上重新启用事件调度程序（使用诸如 SET GLOBAL event_scheduler = ON; 之类的语句）。

如果您稍后将新源降级回副本，必须手动禁用由 ALTER EVENT 语句启用的所有事件。您可以通过将前面所示的 SELECT 语句中的事件名称存储在单独的表中，或使用 ALTER EVENT 语句将事件重命名为公共前缀（如 replicated_）来标识它们。

如果您重命名事件，则在将此服务器降级回副本时，可以通过查询 EVENTS 表来标识事件，如下所示：

```
SELECT CONCAT(EVENT_SCHEMA, '.', EVENT_NAME) AS 'Db.Event'
      FROM INFORMATION_SCHEMA.EVENTS
      WHERE INSTR(EVENT_NAME, 'replicated_') = 1;
```
