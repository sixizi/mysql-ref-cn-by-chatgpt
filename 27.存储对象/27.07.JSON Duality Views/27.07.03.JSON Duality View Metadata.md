### 27.7.3 JSON Duality View 元数据

您可以从以下信息架构表中获取有关现有 JSON Duality View 的信息，这些表已在本版本中实现：

- JSON_DUALITY_VIEWS：提供关于 JSON Duality View 的每个视图信息。

- JSON_DUALITY_VIEW_COLUMNS：提供在 JSON Duality View 中定义的列的信息。

- JSON_DUALITY_VIEW_LINKS：描述 JSON Duality View 与其基表之间的父子关系。

- JSON_DUALITY_VIEW_TABLES：提供关于 JSON Duality View 引用的表的信息。

有关更多信息，请参阅各个表的描述。

JSON Duality View 也作为一项功能由 Option Tracker 组件支持，该组件公开状态变量 option_tracker_usage:JSON Duality View；此变量存储服务器打开任何 JSON Duality View 的次数。
