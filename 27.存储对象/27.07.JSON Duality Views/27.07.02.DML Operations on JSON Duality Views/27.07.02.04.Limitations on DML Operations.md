### 27.7.2.4 DML 操作的限制

以下限制或限制适用于 JSON 二元视图上的所有数据修改操作（INSERT、UPDATE 和 DELETE 语句）：

- 不支持对 JSON 文档的多个 INSERT、UPDATE 和 DELETE 操作。

- 不支持 EXPLAIN 语句。

- 不支持 REPLACE 语句。

- 不支持 LOAD DATA 和 LOAD XML。

- 不支持 INSERT ... FROM SELECT。

- 不允许多表 UPDATE 和 DELETE 语句。

- 不允许 INSERT ... ON DUPLICATE KEY UPDATE。

- 不支持 LOW_PRIORITY 和 IGNORE 子句。

JSON 二元视图元数据

- 不支持对通过 JSON 二元视图定义的 SQL 视图进行数据修改操作。

- 不支持多个对象的更新。更新需要一个 WHERE 子句来标识单个行。
