### 27.5.4 视图 WITH CHECK OPTION 子句

可以为可更新视图指定 `WITH CHECK OPTION` 子句，以防止插入不满足 `select_statement` 中 `WHERE` 子句的行。它还会阻止对满足 `WHERE` 子句的行进行更新，如果更新会导致其不再满足该子句（换句话说，它阻止可见行被更新为不可见行）。

在可更新视图的 `WITH CHECK OPTION` 子句中，`LOCAL` 和 `CASCADED` 关键字决定当视图基于另一个视图定义时检查测试的范围。两个关键字都未给出时，默认为 `CASCADED`。

`WITH CHECK OPTION` 测试符合标准：

- 使用 `LOCAL` 时，检查视图的 `WHERE` 子句，然后递归检查基础视图并应用相同规则。
- 使用 `CASCADED` 时，检查视图的 `WHERE` 子句，然后递归检查基础视图，为它们添加 `WITH CASCADED CHECK OPTION`（仅用于检查目的，其定义保持不变），并应用相同规则。
- 没有检查选项时，不检查视图的 `WHERE` 子句，然后递归检查基础视图并应用相同规则。

考虑以下表和视图集合的定义：

```mysql
CREATE TABLE t1 (a INT);
CREATE VIEW v1 AS SELECT * FROM t1 WHERE a < 2
WITH CHECK OPTION;
CREATE VIEW v2 AS SELECT * FROM v1 WHERE a > 0
WITH LOCAL CHECK OPTION;
CREATE VIEW v3 AS SELECT * FROM v1 WHERE a > 0
WITH CASCADED CHECK OPTION;
```

这里 `v2` 和 `v3` 基于另一个视图 `v1` 定义。

对 `v2` 的插入会先根据其 `LOCAL` 检查选项检查，然后递归到 `v1` 并再次应用规则。`v1` 的规则会导致检查失败。`v3` 的检查也会失败：

```mysql
mysql> INSERT INTO v2 VALUES (2);
ERROR 1369 (HY000): CHECK OPTION failed 'test.v2'
mysql> INSERT INTO v3 VALUES (2);
ERROR 1369 (HY000): CHECK OPTION failed 'test.v3'
```
