### 27.5.1 视图语法

`CREATE VIEW` 语句用于创建新视图（参见 [15.1.23，CREATE VIEW Statement](#)）。要修改视图定义或删除视图，使用 `ALTER VIEW`（参见 [15.1.11，ALTER VIEW Statement](#)）或 `DROP VIEW`（参见 [15.1.35，DROP VIEW Statement](#)）。

视图可以由多种 `SELECT` 语句创建。它可以引用基础表或其他视图，可以使用连接、`UNION` 和子查询。`SELECT` 甚至不必引用任何表。下面的示例定义了一个视图，它从另一张表选择两列，并计算这两列得到的一个表达式：

```mysql
mysql> CREATE TABLE t (qty INT, price INT);
mysql> INSERT INTO t VALUES(3, 50), (5, 60);
mysql> CREATE VIEW v AS SELECT qty, price, qty*price AS value FROM t;
mysql> SELECT * FROM v;
+------+-------+-------+
| qty  | price | value |
+------+-------+-------+
|    3 |    50 |   150 |
|    5 |    60 |   300 |
+------+-------+-------+
mysql> SELECT * FROM v WHERE qty = 5;
+------+-------+-------+
| qty  | price | value |
+------+-------+-------+
|    5 |    60 |   300 |
+------+-------+-------+
```
