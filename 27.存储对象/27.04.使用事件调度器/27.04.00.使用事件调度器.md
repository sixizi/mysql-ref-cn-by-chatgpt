MySQL **事件调度器**（`Event Scheduler`）负责管理和执行**事件**（`event`），即按照计划运行的任务。本节讨论事件调度器，内容分为以下几个部分：

- [27.4.1 事件调度器概述](./27.04.01.事件调度器概述.md)：介绍 MySQL 事件并给出概念性概述。
- [27.4.3 事件语法](./27.04.03.事件语法.md)：讨论创建、修改和删除 MySQL 事件的 SQL 语句。
- [27.4.4 事件元数据](./27.04.04.事件元数据.md)：说明如何获取事件信息，以及 MySQL 服务器如何存储这些信息。
- [27.4.6 事件调度器与 MySQL 权限](./27.04.06.事件调度器与 MySQL 权限.md)：讨论使用事件所需的权限，以及事件在执行时与权限相关的影响。

存储对象需要 `mysql` 系统数据库中的 `events` 数据字典表。该表在 MySQL 8.0 安装过程中创建。如果从早期版本升级到 MySQL 8.0，务必执行升级过程，以确保系统数据库是最新的。参见 [2.10，升级 MySQL](#)。
