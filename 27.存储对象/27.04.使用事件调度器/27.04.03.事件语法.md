### 27.4.3 事件语法

MySQL 提供以下 SQL 语句来处理调度事件：

- 新事件使用 `CREATE EVENT` 语句定义。参见 [15.1.13，CREATE EVENT Statement](#)。
- 现有事件的定义可以通过 `ALTER EVENT` 语句修改。参见 [15.1.3，ALTER EVENT Statement](#)。
- 当不再需要某个调度事件时，其定义者可以使用 `DROP EVENT` 语句把它从服务器删除。参见 [15.1.25，DROP EVENT Statement](#)。事件是否在其计划结束后继续存在，也取决于它的 `ON COMPLETION` 子句（如果存在）。参见 [15.1.13，CREATE EVENT Statement](#)。

任何对事件所在数据库具有 `EVENT` 权限的用户都可以删除该事件。参见 [27.4.6 事件调度器与 MySQL 权限](./27.04.06.事件调度器与 MySQL 权限.md)。
