### 27.3.2 触发器元数据

获取触发器元数据可以通过以下方式：

- 查询 `INFORMATION_SCHEMA` 数据库中的 `TRIGGERS` 表。

  参见 [28.3.45，The INFORMATION_SCHEMA TRIGGERS Table](#)。

- 使用 `SHOW CREATE TRIGGER` 语句查看触发器的**定义**。

  参见 [15.7.7.11，SHOW CREATE TRIGGER Statement](#)。

- 使用 `SHOW TRIGGERS` 语句查看触发器信息。

  参见 [15.7.7.40，SHOW TRIGGERS Statement](#)。
