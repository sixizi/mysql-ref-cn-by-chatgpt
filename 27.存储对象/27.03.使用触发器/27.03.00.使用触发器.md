## 27.3 使用触发器

- [27.3.1 触发器语法和示例](./27.03.01.触发器语法和示例.md)
- [27.3.2 触发器元数据](./27.03.02.触发器元数据.md)

**触发器**（`trigger`）是一个与表关联的命名数据库对象，当表中发生特定事件时被激活。触发器的用途包括检查插入表中的值，以及对更新操作涉及的值进行计算。

触发器被定义为在语句向关联表中插入、更新或删除行时激活。这些行操作就是**触发器事件**（trigger event）。例如，行可以通过 `INSERT` 或 `LOAD DATA` 语句插入，此时插入触发器会为每个被插入的行激活一次。触发器可以设置为在触发器事件**之前**（`BEFORE`）或**之后**（`AFTER`）激活。例如，你可以让触发器在向表中插入每一行之前激活，或在更新每一行之后激活。

> **重要**
>
> MySQL 触发器只对通过 SQL 语句对表所做的更改激活。这也包括可更新视图所基于的基础表上的更改。对于不向 MySQL 服务器发送 SQL 语句的 API 所做的表更改，触发器不会激活。这意味着，使用 NDB API 所做的更新不会激活触发器。
>
> `INFORMATION_SCHEMA` 或 `performance_schema` 表中的变化也不会激活触发器。这些表实际上是视图，而视图上不允许创建触发器。

接下来的小节介绍创建和删除触发器的语法，给出一些使用示例，并说明如何获取触发器元数据。
