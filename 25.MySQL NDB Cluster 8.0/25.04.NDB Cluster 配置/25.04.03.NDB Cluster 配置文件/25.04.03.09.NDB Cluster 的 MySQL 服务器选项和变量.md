##### 使用要点

- `--ndbcluster` 启用 NDBCLUSTER 存储引擎；`--ndb-connectstring` 指定管理服务器地址。
- `--ndb-cluster-connection-pool` 大于 1 时，每个连接都需要配置文件中独立的 `[api]` 或 `[mysqld]` 节。
- BLOB 批处理、事务批大小和发送缓冲区参数影响 NDB API 性能；`0` 通常表示禁用对应批处理。
- 冲突检测状态变量用于评估 NDB 复制中的写入冲突和被拒绝操作。

官方英文版参见 [MySQL Server Options and Variables for NDB Cluster](https://dev.mysql.com/doc/refman/8.0/en/mysql-cluster-options-variables.html)。
