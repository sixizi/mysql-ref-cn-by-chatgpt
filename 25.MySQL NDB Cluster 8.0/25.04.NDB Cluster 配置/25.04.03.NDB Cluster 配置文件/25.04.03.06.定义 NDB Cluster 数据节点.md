#### 25.4.3.6 定义 NDB Cluster 数据节点

本节说明 `[ndbd]` 与 `[ndbd default]` 配置段中的数据节点参数。`[ndbd]` 针对单个节点，`[ndbd default]` 为所有未显式覆盖的数据节点提供默认值。

数据节点参数大致覆盖节点标识与存储位置、内存与事务资源、扫描和缓冲、日志检查点、元对象容量、布尔行为、超时与心跳、实时性以及调试特性。修改重启类型后，必须按对应方式重启节点或整个集群。

##### 重启与容量要点

- **节点重启**：滚动重启数据节点即可生效。
- **初始节点重启**：滚动重启，且节点必须使用 `--initial` 启动。
- **系统重启**：完整停止并重启集群。
- **初始系统重启**：需要完整关闭集群，清理并从备份恢复集群文件系统，再重启。
- `DataMemory`、`IndexMemory`、`MaxNoOfConcurrentTransactions` 等容量参数必须结合负载评估；配置过小会导致启动或运行失败。

官方英文版参见 [Defining NDB Cluster Data Nodes](https://dev.mysql.com/doc/refman/8.0/en/mysql-cluster-ndbd-definition.html)。
