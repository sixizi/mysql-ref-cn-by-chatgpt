### 25.6.8.4 NDB Cluster 备份故障排除

如果在发出备份请求时返回错误代码，最可能的原因是内存或磁盘空间不足。您应该检查是否为备份分配了足够的内存。

> **重要**
>
> 如果您设置了 BackupDataBufferSize 和 BackupLogBufferSize，且它们的总和大于 4MB，那么您还必须设置 BackupMemory。

导入数据到 MySQL Cluster

您还应该确保备份目标的硬盘分区有足够的空间。

NDB 不支持可重复读，这可能会导致恢复过程出现问题。虽然备份过程是"热"的，但从备份恢复 NDB Cluster 并不是 100% 的"热"过程。这是因为在恢复过程的持续时间内，运行中的事务会从恢复的数据中获得不可重复的读。这意味着在恢复进行期间，数据的状态是不一致的。
