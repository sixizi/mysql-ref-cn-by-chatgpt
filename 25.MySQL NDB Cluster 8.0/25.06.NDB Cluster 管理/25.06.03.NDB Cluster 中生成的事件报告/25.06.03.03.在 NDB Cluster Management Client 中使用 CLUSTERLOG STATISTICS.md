# 在 NDB Cluster Management Client 中使用 CLUSTERLOG STATISTICS

NDB 管理客户端的 CLUSTERLOG STATISTICS 命令可以在其输出中提供许多有用的统计信息。提供有关集群状态信息的计数器由事务协调器 (TC) 和本地查询处理程序 (LQH) 以 5 秒报告间隔更新，并写入集群日志。

官方英文版参见 [Using CLUSTERLOG STATISTICS in the NDB Cluster Management Client](https://dev.mysql.com/doc/refman/8.0/en/mysql-cluster-log-statistics.html)。
