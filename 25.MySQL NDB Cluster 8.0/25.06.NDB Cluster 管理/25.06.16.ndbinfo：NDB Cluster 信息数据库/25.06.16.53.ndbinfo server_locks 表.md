# ndbinfo server_locks 表

server_locks 表在结构上与 cluster_locks 表类似，并提供后一个表中找到的信息的子集，但特定于其所在的 SQL 节点（MySQL 服务器）。 （cluster_locks 表提供有关集群中所有锁的信息。）更准确地说，server_locks 包含有关属于当前 mysqld 实例的线程请求的锁的信息，并充当 server_operations 的伴随表。

官方英文版参见 [The ndbinfo server_locks Table](https://dev.mysql.com/doc/refman/8.0/en/mysql-cluster-ndbinfo-server-locks.html)。
