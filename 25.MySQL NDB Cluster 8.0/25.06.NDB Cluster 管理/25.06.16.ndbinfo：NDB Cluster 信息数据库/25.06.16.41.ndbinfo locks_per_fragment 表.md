# ndbinfo locks_per_fragment 表

locks_per_fragment 表提供有关锁声明请求计数的信息，以及基于每个片段的这些请求的结果，充当 Operations_per_fragment 和 memory_per_fragment 的配套表。此表还显示自片段或表创建或自最近重新启动以来等待成功和不成功锁定所花费的总时间。

官方英文版参见 [The ndbinfo locks_per_fragment Table](https://dev.mysql.com/doc/refman/8.0/en/mysql-cluster-ndbinfo-locks-per-fragment.html)。
