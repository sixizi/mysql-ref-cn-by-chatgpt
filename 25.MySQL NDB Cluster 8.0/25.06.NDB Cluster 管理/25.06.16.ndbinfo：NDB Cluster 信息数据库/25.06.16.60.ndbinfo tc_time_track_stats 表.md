# ndbinfo tc_time_track_stats 表

tc_time_track_stats 表提供从数据节点中的 DBTC 块（TC）实例获得的时间跟踪信息，通过 API 节点访问 NDB。每个 TC 实例都会跟踪它代表 API 节点或其他数据节点进行的一组活动的延迟；这些活动包括事务、事务错误、键读取、键写入、唯一索引操作、任何类型的失败键操作、扫描、失败扫描、片段扫描和失败片段扫描。

官方英文版参见 [The ndbinfo tc_time_track_stats Table](https://dev.mysql.com/doc/refman/8.0/en/mysql-cluster-ndbinfo-tc-time-track-stats.html)。
