### 25.3.1.2 从 RPM 安装 NDB Cluster

本节介绍使用 Oracle 提供的 RPM 包为每种类型的 NDB Cluster 节点安装正确可执行文件所需的步骤。

作为本节所述方法的替代方案，Oracle 为 NDB Cluster 提供了与许多常见 Linux 发行版兼容的 MySQL 存储库。以下两个存储库可用于基于 RPM 的发行版：

- 对于使用 yum 或 dnf 的发行版，可以使用 MySQL Yum Repository for NDB Cluster。有关说明和其他信息，请参见使用 Yum 存储库安装 MySQL NDB Cluster。

- 对于 SLES，可以使用 MySQL SLES Repository for NDB Cluster。有关说明和其他信息，请参见使用 SLES 存储库安装 MySQL NDB Cluster。

RPM 可用于 32 位和 64 位 Linux 平台。这些 RPM 的文件名遵循以下模式：

```
mysql-cluster-community-data-node-26.10.0-1.el8.x86_64.rpm

mysql-cluster-license-component-ver-rev.distro.arch.rpm

    license:= {commercial | community}

    component: {management-server | data-node | server | client | other—see text}

    ver: major.minor.release

    rev: major[.minor]

    distro: {el8 | el9 | | el10 | sles15}

    arch: {i686 | x86_64}
```

license 表示 RPM 是 NDB Cluster 的商业版本还是社区版本。在本节的其余部分中，我们假设示例中安装的是社区版本。

component 的可能值及其描述可在下表中找到：

注意

nodejs 包（以前包含用于 Node.js 设置的文件）已被删除。

还提供了给定平台和架构的所有 NDB Cluster RPM 的单个捆绑包 (.tar 文件)。此文件的名称遵循以下模式：

```
mysql-cluster-license-ver-rev.distro.arch.rpm-bundle.tar
```

可以使用 tar 或首选的存档提取工具从此文件中提取各个 RPM 文件。

安装三种主要类型的 NDB Cluster 节点所需的组件在以下列表中给出：

Linux 上的 NDB Cluster 安装

- 管理节点：management-server

- 数据节点：data-node

- SQL 节点：server 和 common

此外，应在至少一个管理节点上安装 client RPM 以提供 ndb_mgm 管理客户端。您可能还希望在 SQL 节点上安装它，以便在这些节点上提供 mysql 和其他 MySQL 客户端程序。本节稍后将讨论按类型安装节点的内容。

ver 表示 9.x.x 格式的三部分 NDB 存储引擎版本号，在示例中显示为 26.10.0。rev 提供 major.minor 格式的 RPM 修订号。在本节所示的示例中，我们为此值使用 1.1。

distro (Linux 发行版) 是 el8 (Oracle Linux 8、Red Hat Enterprise Linux 8)、el9 (Oracle Linux 9、Red Hat Enterprise Linux 9)、el10 (Oracle Linux 10、Red Hat Enterprise Linux 10) 或 sles15 (SUSE Enterprise Linux 15) 之一。对于本节中的示例，我们假设主机运行 Oracle Linux 8、Red Hat Enterprise Linux 8 或等效版本 (el8)。

arch 对于 32 位 RPM 是 i686，对于 64 位版本是 x86_64。在此处显示的示例中，我们假设 64 位平台。

RPM 文件名中的 NDB Cluster 版本号 (此处显示为 26.10.0) 可能因您实际使用的版本而异。所有要安装的 Cluster RPM 具有相同版本号非常重要。架构也应该适合安装 RPM 的机器；特别是，您应该记住 64 位 RPM (x86_64) 不能与 32 位操作系统一起使用 (对于后者使用 i686)。

数据节点。在将托管 NDB Cluster 数据节点的计算机上，只需安装 data-node RPM。为此，请将此 RPM 复制到数据节点主机，并以系统 root 用户身份运行以下命令，根据需要替换为从 MySQL 网站下载的 RPM 的名称：

```
$> rpm -Uhv mysql-cluster-community-data-node-26.10.0-1.el8.x86_64.rpm
```

这会在 /usr/sbin 中安装 ndbd 和 ndbmtd 数据节点二进制文件。其中任何一个都可以用于在此主机上运行数据节点进程。

SQL 节点。将 server 和 common RPM 复制到每台将用于托管 NDB Cluster SQL 节点的机器 (server 需要 common)。通过以系统 root 用户身份执行以下命令来安装 server RPM，根据需要替换为从 MySQL 网站下载的 RPM 的名称：

```
$> rpm -Uhv mysql-cluster-community-server-26.10.0-1.el8.x86_64.rpm
```

这会在 /usr/sbin 目录中安装 MySQL 服务器二进制文件 (mysqld)，具有 NDB 存储引擎支持。它还安装所有需要的 MySQL Server 支持文件和有用的 MySQL 服务器程序，包括 mysql.server 和 mysqld_safe 启动脚本 (分别在 /usr/share/mysql 和 /usr/bin 中)。RPM 安装程序应该自动处理常规配置问题 (例如创建 mysql 用户和组，如果需要)。

重要

您必须使用为 NDB Cluster 发布的这些 RPM 版本；为标准 MySQL 服务器发布的版本不提供 NDB 存储引擎支持。

要管理 SQL 节点 (MySQL 服务器)，您还应该安装 client RPM，如下所示：

```
$> rpm -Uhv mysql-cluster-community-client-26.10.0-1.el8.x86_64.rpm
```

这会将 mysql 客户端和其他 MySQL 客户端程序 (例如 mysqladmin 和 mysqldump) 安装到 /usr/bin。

管理节点。要安装 NDB Cluster 管理服务器，只需使用 management-server RPM。将此 RPM 复制到打算托管管理节点的计算机，然后通过以系统 root 用户身份运行以下命令来安装它 (根据需要替换为从 MySQL 网站下载的 management-server RPM 的名称)：

```
$> rpm -Uhv mysql-cluster-community-management-server-26.10.0-1.el8.x86_64.rpm
```

此 RPM 在 /usr/sbin 目录中安装管理服务器二进制文件 ndb_mgmd。虽然这是运行管理节点实际需要的唯一程序，但最好也有 ndb_mgm NDB Cluster 管理客户端可用。您可以通过安装之前描述的 client RPM 来获得此程序，以及其他 NDB 客户端程序 (例如 ndb_desc 和 ndb_config)。

有关使用 Oracle 提供的 RPM 安装 MySQL 的常规信息，请参见第 2.5.4 节"在 Linux 上使用 Oracle 的 RPM 包安装 MySQL"。

从 RPM 安装后，您仍需要配置集群；有关相关信息，请参见第 25.3.3 节"NDB Cluster 的初始配置"。

所有要安装的 Cluster RPM 具有相同版本号非常重要。架构指定也应该适合安装 RPM 的机器；特别是，您应该记住 64 位 RPM 不能与 32 位操作系统一起使用。

数据节点。在将托管集群数据节点的计算机上，只需安装 server RPM。为此，请将此 RPM 复制到数据节点主机，并以系统 root 用户身份运行以下命令，根据需要替换为从 MySQL 网站下载的 RPM 的名称：

```
$> rpm -Uhv MySQL-Cluster-server-gpl-26.10.0-1.sles11.i386.rpm
```

虽然这会安装所有 NDB Cluster 二进制文件，但只有程序 ndbd 或 ndbmtd (都在 /usr/sbin 中) 实际需要运行 NDB Cluster 数据节点。

SQL 节点。在每台将用于托管集群 SQL 节点的机器上，通过以系统 root 用户身份执行以下命令来安装 server RPM，根据需要替换为从 MySQL 网站下载的 RPM 的名称：

```
$> rpm -Uhv MySQL-Cluster-server-gpl-26.10.0-1.sles11.i386.rpm
```

这会在 /usr/sbin 目录中安装 MySQL 服务器二进制文件 (mysqld)，具有 NDB 存储引擎支持，以及所有需要的 MySQL Server 支持文件。它还安装 mysql.server 和 mysqld_safe 启动脚本 (分别在 /usr/share/mysql 和 /usr/bin 中)。RPM 安装程序应该自动处理常规配置问题 (例如创建 mysql 用户和组，如果需要)。

要管理 SQL 节点 (MySQL 服务器)，您还应该安装 client RPM，如下所示：

```
$> rpm -Uhv MySQL-Cluster-client-gpl-26.10.0-1.sles11.i386.rpm
```

这会安装 mysql 客户端程序。

管理节点。要安装 NDB Cluster 管理服务器，只需使用 server RPM。将此 RPM 复制到打算托管管理节点的计算机，然后通过以系统 root 用户身份运行以下命令来安装它 (根据需要替换为从 MySQL 网站下载的 server RPM 的名称)：

```
$> rpm -Uhv MySQL-Cluster-server-gpl-26.10.0-1.sles11.i386.rpm
```

虽然此 RPM 安装许多其他文件，但只有管理服务器二进制文件 ndb_mgmd (在 /usr/sbin 目录中) 实际需要运行管理节点。server RPM 还安装 ndb_mgm (NDB 管理客户端)。

有关使用 Oracle 提供的 RPM 安装 MySQL 的常规信息，请参见第 2.5.4 节"在 Linux 上使用 Oracle 的 RPM 包安装 MySQL"。有关所需的安装后配置信息，请参见第 25.3.3 节"NDB Cluster 的初始配置"。
