### 25.2.6.2 NDB 和 InnoDB 工作负载

NDB Cluster 具有一系列独特的属性，使其非常适合为需要高可用性、快速故障转移、高吞吐量和低延迟的应用程序提供服务。由于其分布式架构和多节点实现，NDB Cluster 也有特定的约束，可能会导致某些工作负载性能不佳。NDB 和 InnoDB 存储引擎在某些常见类型的数据库驱动应用程序工作负载方面存在许多主要行为差异，如下表所示：

表 25.2 InnoDB 和 NDB 存储引擎之间的差异，常见的数据驱动应用程序工作负载类型。

| 工作负载 | InnoDB | NDB Cluster (NDB) |
|---------|--------|------------------|
| 高容量 OLTP 应用程序 | 是 | 是 |
| DSS 应用程序（数据集市、分析） | 是 | 受限（跨 OLTP 数据集的联接操作不超过 3TB） |
| 自定义应用程序 | 是 | 是 |
| 打包应用程序 | 是 | 受限（应主要为主键访问）；NDB Cluster 26.7 支持外键 |
| 网络电信应用程序（HLR、HSS、SDP） | 否 | 是 |
| 会话管理和缓存 | 是 | 是 |
| 电子商务应用程序 | 是 | 是 |
| 用户配置文件管理、AAA 协议 | 是 | 是 |
