### 25.2.6.3 NDB 和 InnoDB 功能使用总结

在将应用程序功能需求与 InnoDB 和 NDB 的功能进行比较时，某些功能显然与一个存储引擎的兼容性更好。

下表根据每个功能通常更适合的存储引擎列出了支持的应用程序功能。

表 25.3 根据每个功能通常更适合的存储引擎列出的支持应用程序功能

| InnoDB 的首选应用需求 | NDB 的首选应用需求 |
|---|---|
| - 外键 | - 写入扩展性 |
| | - 99.999% 正常运行时间 |
| | - 在线添加节点和在线模式操作 |
| - 全表扫描 | - 多个 SQL 和 NoSQL API（参见 NDB Cluster APIs: Overview and Concepts） |
| - 非常大的数据库、行或事务 | - 实时性能 |
| - READ COMMITTED 以外的事务 | - BLOB 列的有限使用 |
| | - 支持外键，尽管在高吞吐量下使用可能会对性能产生影响 |

注意

NDB Cluster 26.10 支持外键
