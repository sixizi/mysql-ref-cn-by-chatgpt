# ndb_blob_tool — 检查并修复 NDB Cluster 的 BLOB 和 TEXT 列 表格

此工具可用于检查和删除 NDB 表中的孤立 BLOB 列部分，以及生成列出所有孤立部分的文件。它有时在诊断和修复包含 BLOB 或 TEXT 列的损坏或损坏的 NDB 表时很有用。





官方英文版参见 [ndb_blob_tool — Check and Repair BLOB and TEXT columns of NDB Cluster Tables](https://dev.mysql.com/doc/refman/8.0/en/mysql-cluster-programs-ndb-blob-tool.html)。
