# ndbxfrm — 压缩、解压缩、加密和解密 NDB Cluster 创建的文件

NDB 8.0.22 中引入的 ndbxfrm 实用程序可用于解压缩、解密和输出有关 NDB Cluster 创建的压缩、加密或两者的文件的信息。它还可用于压缩或加密文件。





官方英文版参见 [ndbxfrm — Compress, Decompress, Encrypt, and Decrypt Files Created by NDB Cluster](https://dev.mysql.com/doc/refman/8.0/en/mysql-cluster-programs-ndbxfrm.html)。
