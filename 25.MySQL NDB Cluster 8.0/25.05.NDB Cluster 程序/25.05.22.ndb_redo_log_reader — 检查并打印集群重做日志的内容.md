# ndb_redo_log_reader — 检查并打印集群重做日志的内容

读取重做日志文件，检查其是否有错误，以人类可读的格式打印其内容，或两者兼而有之。 ndb_redo_log_reader 主要供 NDB Cluster 开发人员和支持人员调试和诊断问题时使用。

官方英文版参见 [ndb_redo_log_reader — Check and Print Content of Cluster Redo Log](https://dev.mysql.com/doc/refman/8.0/en/mysql-cluster-programs-ndb-redo-log-reader.html)。
