# ndb_config — 提取 NDB 集群配置信息

该工具从多个源之一提取数据节点、SQL 节点和 API 节点的当前配置信息：NDB Cluster 管理节点或其 config.ini 或 my.cnf 文件。默认情况下，管理节点是配置数据的来源；要覆盖默认值，请使用 --config-file 或 --mycnf 选项执行 ndb_config。

官方英文版参见 [ndb_config — Extract NDB Cluster Configuration Information](https://dev.mysql.com/doc/refman/8.0/en/mysql-cluster-programs-ndb-config.html)。
