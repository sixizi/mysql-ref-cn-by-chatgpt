# ndb_waiter — 等待 NDB Cluster 达到给定状态

ndb_waiter 重复（每 100 毫秒）打印出所有集群数据节点的状态，直到集群达到给定状态或超过 --timeout 限制，然后退出。默认情况下，它等待集群达到 STARTED 状态，此时所有节点都已启动并连接到集群。

官方英文版参见 [ndb_waiter — Wait for NDB Cluster to Reach a Given Status](https://dev.mysql.com/doc/refman/8.0/en/mysql-cluster-programs-ndb-waiter.html)。
