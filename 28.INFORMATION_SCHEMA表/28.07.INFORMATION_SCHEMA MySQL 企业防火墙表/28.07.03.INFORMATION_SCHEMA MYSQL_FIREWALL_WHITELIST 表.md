# INFORMATION_SCHEMA MYSQL_FIREWALL_WHITELIST 表

MYSQL_FIREWALL_WHITELIST 表提供了 MySQL Enterprise Firewall 内存中数据缓存的视图。它列出了已注册防火墙帐户配置文件的白名单规则。

官方英文版参见 [The INFORMATION_SCHEMA MYSQL_FIREWALL_WHITELIST Table](https://dev.mysql.com/doc/refman/8.0/en/information-schema-mysql-firewall-whitelist-table.html)。
