# INFORMATION_SCHEMA COLLATION_CHARACTER_SET_APPLICABILITY 表

COLLATION_CHARACTER_SET_APPLICABILITY 表指示什么字符集适用于什么排序规则。

官方英文版参见 [The INFORMATION_SCHEMA COLLATION_CHARACTER_SET_APPLICABILITY Table](https://dev.mysql.com/doc/refman/8.0/en/information-schema-collation-character-set-applicability-table.html)。
