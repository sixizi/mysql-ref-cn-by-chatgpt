### 28.3.21 INFORMATION_SCHEMA JSON_DUALITY_VIEW_TABLES 表

JSON_DUALITY_VIEW_TABLES 表显示当前用户可访问的任何 JSON 对偶视图所引用的所有表的信息。此表每个表引用包含一行。

JSON_DUALITY_VIEW_TABLES 表包含以下列：

- TABLE_CATALOG

  视图目录；始终为 def。

- TABLE_SCHEMA

  视图模式。

- TABLE_NAME

  视图名称。

- REFERENCED_TABLE_CATALOG

  表目录；始终为 def。

- REFERENCED_TABLE_SCHEMA

  表模式。

- REFERENCED_TABLE_NAME

  表的名称。

- WHERE_CLAUSE

  WHERE 子句中使用的表达式。

- ALLOW_INSERT

  如果允许插入，则为 1，否则为 0。

- ALLOW_UPDATE

  如果允许更新，则为 1，否则为 0。

- ALLOW_DELETE

  如果允许删除，则为 1，否则为 0。

- READ_ONLY

  如果不允许插入、更新或删除，则为 1，否则为 0。（换句话说，仅当 ALLOW_INSERT、ALLOW_UPDATE 和 ALLOW_DELETE 都为 0 时，此值才为 1。）

- IS_ROOT_TABLE

  如果这是根表，则为 1，否则为 0。

- REFERENCED_TABLE_ID

  此视图内的唯一表 ID。

- REFERENCED_TABLE_PARENT_ID

  父表的 ID。

- REFERENCED_TABLE_PARENT_RELATIONSHIP

  nested（数组）或 singleton（其他情况）之一。
