## 28.3.20 INFORMATION_SCHEMA JSON_DUALITY_VIEW_LINKS 表

JSON_DUALITY_VIEW_LINKS 表显示当前用户可访问的所有视图的父表和子表之间的关系信息。每个视图对应一行。

JSON_DUALITY_VIEW_LINKS 表包含以下列：

- TABLE_CATALOG

  视图目录；始终为 def。

- TABLE_SCHEMA

  视图模式。

- TABLE_NAME

  视图名称。

- PARENT_TABLE_CATALOG

  父表目录；始终为 def。

- PARENT_TABLE_SCHEMA

  父表模式。

- PARENT_TABLE_NAME

  父表。

- CHILD_TABLE_CATALOG

  子表目录；始终为 def。

- CHILD_TABLE_SCHEMA

  子表模式。

- CHILD_TABLE_NAME

  子表。

- PARENT_TABLE_COLUMN_NAME

  父表列名。

- CHILD_TABLE_COLUMN_NAME

  子表列名。

- JOIN_TYPE

  NESTED 或 OUTER 之一。

- JSON_KEY_NAME

  适用的 JSON 键名称（如果有）。
