### 28.3.19 INFORMATION_SCHEMA JSON_DUALITY_VIEW_COLUMNS 表

INFORMATION_SCHEMA JSON_DUALITY_VIEW_COLUMNS 表显示当前用户可访问的任何 JSON 对偶视图所引用的所有列的信息。每个表引用对应一行。

JSON_DUALITY_VIEW_COLUMNS 表包含以下列：

- TABLE_CATALOG

  视图目录；始终为 def。

- TABLE_SCHEMA

  视图模式。

- TABLE_NAME

  视图名称。

- REFERENCED_TABLE_CATALOG

  表目录；始终为 def。

- REFERENCED_TABLE_SCHEMA

  表模式。

- REFERENCED_TABLE_NAME

  表名称。

- IS_ROOT_TABLE

  如果这是根表，则为 1，否则为 0。

- REFERENCED_TABLE_ID

  此视图内的唯一表 ID。

- REFERENCED_TABLE_COLUMN_NAME

  列名称。

- JSON_KEY_NAME

  JSON 键名称。

- ALLOW_INSERT

  如果允许插入，则为 1，否则为 0。

- ALLOW_UPDATE

  如果列的有效注解为 UPDATE，则为 1。如果其有效注解为 NO UPDATE，则为 0。有效值包括从表继承的值和任何列级覆盖。

- ALLOW_CHECK

  如果列的有效注解为 CHECK，则为 1。如果其有效注解为 NO CHECK，则为 0。默认值为 1。有效值包括从表继承的值和任何列级覆盖。

- ALLOW_DELETE

  如果允许删除，则为 1，否则为 0。

- READ_ONLY

  如果不允许插入、更新或删除，则为 1，否则为 0。（换句话说，仅当 ALLOW_INSERT、ALLOW_UPDATE 和 ALLOW_DELETE 都为 0 时，此值才为 1。）
