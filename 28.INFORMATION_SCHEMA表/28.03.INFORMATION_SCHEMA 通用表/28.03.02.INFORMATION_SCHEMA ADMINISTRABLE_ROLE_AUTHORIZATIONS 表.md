# INFORMATION_SCHEMA ADMINISTRABLE_ROLE_AUTHORIZATIONS 表

ADMINISTRABLE_ROLE_AUTHORIZATIONS 表（从 MySQL 8.0.19 开始提供）提供有关可以将哪些适用于当前用户或角色的角色授予其他用户或角色的信息。

官方英文版参见 [The INFORMATION_SCHEMA ADMINISTRABLE_ROLE_AUTHORIZATIONS Table](https://dev.mysql.com/doc/refman/8.0/en/information-schema-administrable-role-authorizations-table.html)。
