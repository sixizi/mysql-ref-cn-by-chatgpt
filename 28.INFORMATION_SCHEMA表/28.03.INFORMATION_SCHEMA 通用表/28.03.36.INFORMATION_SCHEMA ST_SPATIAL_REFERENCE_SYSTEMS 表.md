# INFORMATION_SCHEMA ST_SPATIAL_REFERENCE_SYSTEMS 表

ST_SPATIAL_REFERENCE_SYSTEMS 表提供有关空间数据的可用空间参考系统 (SRS) 的信息。该表基于 SQL/MM (ISO/IEC 13249-3) 标准。

官方英文版参见 [The INFORMATION_SCHEMA ST_SPATIAL_REFERENCE_SYSTEMS Table](https://dev.mysql.com/doc/refman/8.0/en/information-schema-st-spatial-reference-systems-table.html)。
