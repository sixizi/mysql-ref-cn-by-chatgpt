# INFORMATION_SCHEMA TABLE_CONSTRAINTS_EXTENSIONS 表

TABLE_CONSTRAINTS_EXTENSIONS 表（从 MySQL 8.0.21 开始提供）提供有关为主存储引擎和辅助存储引擎定义的表约束属性的信息。

官方英文版参见 [The INFORMATION_SCHEMA TABLE_CONSTRAINTS_EXTENSIONS Table](https://dev.mysql.com/doc/refman/8.0/en/information-schema-table-constraints-extensions-table.html)。
