### 26.6.3 与函数相关的分区限制

本节讨论 MySQL 分区中与分区表达式中使用的函数相关的限制。

分区表达式中只允许使用以下列表中显示的 MySQL 函数：

- ABS()

- CEILING()（参见 CEILING() 和 FLOOR()）

- DATEDIFF()

- DAY()

- DAYOFMONTH()

- DAYOFWEEK()

- DAYOFYEAR()

- EXTRACT()（参见 EXTRACT() 函数与 WEEK 说明符）

- FLOOR()（参见 CEILING() 和 FLOOR()）

- HOUR()

- MICROSECOND()

- MINUTE()

- MOD()

- MONTH()

- QUARTER()

- SECOND()

- TIME_TO_SEC()

- TO_DAYS()

- TO_SECONDS()

- UNIX_TIMESTAMP()（用于 TIMESTAMP 列）

- WEEKDAY()

- YEAR()

- YEARWEEK()

在 MySQL 26.7 中，分区修剪支持 TO_DAYS()、TO_SECONDS()、YEAR() 和 UNIX_TIMESTAMP() 函数。有关更多信息，请参见第 26.4 节"分区修剪"。

**CEILING() 和 FLOOR()。** 这些函数中的每一个仅当传递精确数值类型（如 INT 类型或 DECIMAL）的参数时才返回整数。这意味着，例如，以下 CREATE TABLE 语句会失败并显示错误，如下所示：

```
mysql> CREATE TABLE t (c FLOAT) PARTITION BY LIST( FLOOR(c) )(
    ->     PARTITION p0 VALUES IN (1,3,5),
    ->     PARTITION p1 VALUES IN (2,4,6)
    -> );
ERROR 1490 (HY000): The PARTITION function returns the wrong type
```

**EXTRACT() 函数与 WEEK 说明符。** EXTRACT() 函数返回的值（当用作 EXTRACT(WEEK FROM col) 时）取决于 default_week_format 系统变量的值。因此，当 EXTRACT() 指定单位为 WEEK 时，不允许将其用作分区函数。（Bug #54483）

有关这些函数的返回类型的更多信息，请参见第 14.6.2 节"数学函数"以及第 13.1 节"数值数据类型"。
