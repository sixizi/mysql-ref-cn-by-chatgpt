# 11.2.3 标识符大小写敏感性

在 MySQL 中，数据库和表名的大小写敏感性取决于操作系统对文件名大小写的处理方式，以及 `lower_case_table_names` 系统变量的设置。列名、索引名、存储程序名、事件名、触发器名和分区名始终不区分大小写。

`lower_case_table_names` 的常见取值：

- `0`：表名按指定形式存储，比较区分大小写。适用于 Unix/Linux 等大小写敏感文件系统。
- `1`：表名以小写存储，比较不区分大小写。Windows 和 macOS 默认采用此行为。
- `2`：表名按指定形式存储，但比较时不区分大小写。适用于大小写不敏感文件系统。

最佳实践是始终在同一个查询中使用一致的大小写，避免依赖平台行为。在复制或迁移到不同操作系统前，应确认 `lower_case_table_names` 的设置是否兼容。
