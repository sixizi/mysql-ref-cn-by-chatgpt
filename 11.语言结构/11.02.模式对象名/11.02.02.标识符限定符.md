# 11.2.2 标识符限定符

对象名可以是非限定名，也可以是包含一个或多个限定符的限定名。限定符用句点分隔，用于明确对象所属的数据库或表：

```sql
CREATE TABLE t1 (i INT);
CREATE TABLE db1.t1 (i INT);
```

第一条语句在没有默认数据库时会失败；第二条语句显式指定数据库，不受默认数据库影响。

限定名具有以下特点：

- 多部分名称的各组成部分必须分别加引号，例如 `` `my-table`.`my-column` ``。
- 句点是独立记号，`tbl_name.col_name` 与 `tbl_name . col_name` 等价。
- 句点后的保留字在该位置必须是标识符，因此不需要加引号。
- 列名可用表名限定，表名又可用数据库名限定，例如 `db_name.tbl_name.col_name`。

当未限定引用有歧义时必须使用限定符。例如两个表中都有列 `c`，则应写作 `t1.c` 或 `t2.c`。表别名可以让限定列名更简洁，例如：

```sql
SELECT t1.c, t2.c FROM very_long_table_name AS t1
  JOIN another_long_table_name AS t2;
```
