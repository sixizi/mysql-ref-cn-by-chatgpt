# 11.2.1 标识符长度限制

MySQL 以字符而不是字节来计算标识符长度。常见标识符的最大长度如下：

| 标识符类型 | 最大长度（字符） |
|---|---:|
| 数据库 | 64 |
| 表 | 64 |
| 列 | 64 |
| 索引 | 64 |
| 约束 | 64 |
| 存储程序 | 64 |
| 视图 | 64 |
| 表空间 | 64 |
| 服务器 | 64 |
| 日志文件组 | 64 |
| 别名 | 256 |
| 复合语句标签 | 16 |
| 用户定义变量 | 64 |
| 资源组 | 64 |

`CREATE VIEW` 中列别名的最大长度按列名的 64 字符限制检查，而不是普通别名的 256 字符限制。未显式命名的约束会由服务器根据表名和后缀生成内部名称；如果表名接近 64 字符限制，生成的约束名可能超出长度限制并导致错误。
