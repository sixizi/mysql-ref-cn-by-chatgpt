# 11.2.4 标识符到文件名的映射

每个数据库对应一个目录，每个表、触发器等对象对应文件系统中的文件。为了提升跨平台可移植性，MySQL 会对数据目录和表目录名中的特殊字符进行编码。

编码规则包括：

- ASCII 数字、加号、斜杠和下划线等安全字符保持不变。
- 不区分大小写文件系统上的大小写差异也会编码。
- 有大小写映射的字母按特定 `@` 序列编码。
- 非字母字符以及无大小写映射的字母使用 `@xxxx` 形式的十六进制编码。
- Windows 保留名如 `NUL`、`PRN`、`AUX`、`COM1` 到 `COM9`、`LPT1` 到 `LPT9` 会追加 `@@@`。
- 名称中的 `$` 会编码为 `@0024`，因此 `CLOCK$` 写入文件系统时为 `CLOCK@0024`。

这些编码通常由服务器自动处理。使用备份、文件系统工具或第三方复制方案时，应避免手工重命名数据目录或表文件。
