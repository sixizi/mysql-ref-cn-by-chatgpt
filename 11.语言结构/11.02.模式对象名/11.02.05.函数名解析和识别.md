# 11.2.5 函数名解析和识别

内置函数名与用户自定义标识符可能相同，例如把 `count` 用作表名或列名。默认情况下，函数名后跟括号且中间没有空白时会被解析为函数调用；否则按非函数上下文解析。

启用 `IGNORE_SPACE` SQL 模式后，解析器允许内置函数名与 `(` 之间有空白，代价是这些函数名会被视为保留字。此时在非表达式上下文中使用这些名称必须加引号：

```sql
CREATE TABLE count(i INT);        -- 启用 IGNORE_SPACE 后失败
CREATE TABLE `count`(i INT);     -- 正确
```

函数名解析遵循以下规则：

- 不能创建与内置函数同名的可加载函数。
- 存储函数可以与内置函数同名，但调用时必须用模式名限定，例如 `test.PI()`。
- 存储函数和可加载函数可以同名，但未限定名称会解析为可加载函数，存储函数必须用模式名限定。
- 升级后如果新版本引入同名内置函数，应重命名冲突的自定义函数，或为存储函数调用添加模式限定符。
