# 11.6 查询属性

从 MySQL 8.0.23 开始，客户端可以在发送下一条 SQL 语句前为该语句定义查询属性。查询属性在语句执行结束前可被服务器端访问，执行结束后属性集会被清除。

查询属性适合传递与语句文本相关的元数据，例如：

- Web 应用记录生成某条查询的页面 URL。
- 应用为审计插件或查询重写插件传递附加处理信息。

使用 MySQL C API 的应用程序通过 `mysql_bind_param()` 定义查询属性；其他连接器也可能提供相应支持。服务器端可通过 `mysql_query_attribute_string()` 等可加载函数读取属性。

使用查询属性前需要满足以下条件：

- 服务器启用查询属性支持。
- 安装 `mysql_query_attributes` 组件。
- 客户端和连接器支持查询属性。
