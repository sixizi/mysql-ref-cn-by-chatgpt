# 11.4 用户定义变量

用户定义变量写作 `@var_name`，可以在一条语句中赋值，并在后续语句中引用，用于在语句之间传递值。

变量名通常由字母、数字、`.`、`_` 和 `$` 组成。包含其他字符时，可用字符串或标识符引号括起来，例如 `@'my-var'`、`@"my-var"` 或 `` @`my-var` ``。用户变量名不区分大小写，最大长度为 64 个字符。

```sql
SET @var_name = expr [, @var_name = expr] ...;
```

在 `SET` 语句中，`=` 和 `:=` 都可用作赋值运算符。在其他语句中赋值时必须使用 `:=`，因为 `=` 会被解释为比较运算符。

用户变量是会话级的：一个客户端不能看到另一个客户端的变量，客户端退出时其变量自动释放。变量可保存整数、十进制数、浮点数、二进制或非二进制字符串以及 `NULL`。十进制和实数的精度与小数位数在赋值时不会保留；时间、空间和 JSON 等其他类型会转换为允许的类型。

使用时需注意：

- 未初始化变量的值为 `NULL`，类型为字符串。
- 表达式求值顺序未定义，不要在同一条语句中同时读取和赋值同一变量。
- 变量不能直接用作表名、列名或 SQL 标识符；需要动态标识符时应构造预处理语句字符串。
- 变量不能用于要求字面值的位置，例如 `SELECT ... LIMIT` 或 `LOAD DATA ... IGNORE N LINES`。
