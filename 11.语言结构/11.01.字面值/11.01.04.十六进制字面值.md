# 11.1.4 十六进制字面值

MySQL 支持两种十六进制字面值语法：

```sql
X'hexdigits'
0x'hexdigits'
0X'hexdigits'
```

使用 `X'...'` 时，引号内必须是偶数个十六进制数字，每个字节由两位表示，例如 `X'41'` 和 `x'4D53514C'`。`0x` 或 `0X` 语法允许奇数个数字，并将其视为前面补零的偶数位值，例如 `0x41` 等同于 `X'041'`。

十六进制字面值默认表示二进制字符串。在数字上下文中，它会被解释为整数：

```sql
SELECT X'41', X'41' + 0;
```

其中 `X'41'` 作为二进制字符串显示为 `A`，而 `X'41' + 0` 是整数 `65`。
