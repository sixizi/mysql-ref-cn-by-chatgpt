# 11.1.1 字符串字面值

字符串是由字节或字符组成的序列，可以用单引号或双引号括起来：

```sql
'a string'
"another string"
```

相邻的带引号字符串会拼接为一个字符串。例如，以下两行等价：

```sql
'a string'
'a' ' ' 'string'
```

启用 `ANSI_QUOTES` SQL 模式后，双引号内容会被解释为标识符，因此字符串字面值必须使用单引号。

## 字符集与排序规则

二进制字符串是字节序列，其字符集和排序规则均为 `binary`。非二进制字符串是字符序列，使用 `binary` 以外的字符集和兼容的排序规则。比较基于字符串单元的数值：二进制字符串按字节值比较，非二进制字符串按字符代码值和排序规则比较。

字符串字面值可指定字符集引入符和 `COLLATE` 子句：

```sql
[_charset_name]'string' [COLLATE collation_name]
```

示例：

```sql
SELECT _latin1'string';
SELECT _binary'string';
SELECT _utf8mb4'string' COLLATE utf8mb4_danish_ci;
```

## 转义序列

除非启用 `NO_BACKSLASH_ESCAPES`，以反斜杠开头的特殊序列具有指定含义：

| 转义序列 | 表示的字符 |
|---|---|
| `\0` | ASCII NUL 字符 |
| `\'` | 单引号 |
| `\"` | 双引号 |
| `\b` | 退格字符 |
| `\n` | 换行符 |
| `\r` | 回车符 |
| `\t` | 制表符 |
| `\Z` | ASCII 26，即 Control+Z |

转义序列区分大小写。未知转义序列中的反斜杠会被忽略，例如 `\x` 等同于 `x`。也可以通过重复引号来转义引号，例如 `'Can''t'`。
