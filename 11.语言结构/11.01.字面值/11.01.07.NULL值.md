# 11.1.7 NULL 值

`NULL` 表示“没有数据”，可以写作大写或小写。它与数字 `0`、空字符串、字符串 `'NULL'` 都不同。

`NULL` 参与算术、比较和大多数函数运算时，结果通常是 `NULL`。判断一个值是否为 `NULL` 必须使用 `IS NULL` 或 `IS NOT NULL`，不能使用 `= NULL` 或 `<> NULL`。

```sql
SELECT NULL IS NULL, NULL = NULL;
```

结果分别为 `1` 和 `NULL`。
