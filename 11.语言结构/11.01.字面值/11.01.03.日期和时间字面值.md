# 11.1.3 日期和时间字面值

日期和时间值可以用带引号的字符串或数字表示。例如，在 MySQL 期望日期的上下文中，`'2015-07-21'`、`'20150721'` 和 `20150721` 都会被解释为同一个日期。

## 标准 SQL 与 ODBC 语法

标准 SQL 要求使用类型关键字和字符串：

```sql
DATE 'str'
TIME 'str'
TIMESTAMP 'str'
```

MySQL 识别但不强制要求类型关键字。为了保持标准兼容，应用程序应包含类型关键字。MySQL 还识别 ODBC 语法：

```sql
{ d 'str' }
{ t 'str' }
{ ts 'str' }
```

`DATE`、`TIME` 和 `TIMESTAMP` 语法分别产生 `DATE`、`TIME` 和 `DATETIME` 值。`TIMESTAMP` 在 MySQL 中产生 `DATETIME`，因为标准 SQL `TIMESTAMP` 的年份范围更接近 MySQL `DATETIME`。

## 字符串和数字形式

`DATE` 可写作 `'YYYY-MM-DD'`、`'YY-MM-DD'`、`'YYYYMMDD'`、`'YYMMDD'`，或对应的数字形式。`DATETIME` 和 `TIMESTAMP` 可写作 `'YYYY-MM-DD hh:mm:ss'`、`'YY-MM-DD hh:mm:ss'`，或无分隔符字符串和数字形式。

MySQL 允许一些宽松分隔符语法，但从 MySQL 8.0.29 起已弃用，并会产生警告。建议日期部分使用 `-`，时间部分使用 `:`。日期和时间部分可用 `T` 分隔，例如 `'2012-12-31T11:30:45'`。小数秒只能用小数点与前一部分分隔。
