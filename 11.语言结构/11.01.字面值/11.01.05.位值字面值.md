# 11.1.5 位值字面值

位值字面值使用 `b` 或 `0b` 前缀书写，后跟二进制数字 `0` 或 `1`：

```sql
b'101'
B'101'
0b101
```

位值字面值默认是二进制字符串。在数字上下文中，它会被解释为整数，例如 `b'101' + 0` 的结果是 `5`。

十六进制字面值和位值字面值都可以用于插入二进制数据或参与数值计算，但需要通过上下文或显式转换明确预期类型。
