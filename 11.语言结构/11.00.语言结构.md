本章描述 MySQL SQL 语言的基础构成：字面值如何书写，模式对象名有哪些语法和长度限制，哪些字是关键字或保留字，用户定义变量的行为，表达式的语法规则，客户端如何附加查询属性，以及 MySQL 支持的注释形式。

这些规则会影响 SQL 语句的解析结果。例如，启用 `ANSI_QUOTES` 后，双引号字符串会被解释为标识符；保留字用作表名或列名时必须加反引号；同一个表达式中读取和赋值同一个用户变量时，求值顺序未定义。
