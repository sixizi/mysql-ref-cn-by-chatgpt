### 11.3 关键字和保留字

关键字是在 SQL 中具有特殊意义的词。某些关键字（如 SELECT、DELETE 或 BIGINT）是保留的，当用作标识符（如表名和列名）时需要特殊处理。内置函数的名称也可能如此。

大多数非保留关键字可以不加引号地用作标识符。某些通常被认为是非保留的关键字被限制用作角色、存储程序标签的不带引号的标识符，或在某些情况下两者都限制。有关这些关键字的列表，请参见 MySQL 26.7 受限关键字。

保留字如果按照第 11.2 节"模式对象名称"中所述进行引用，则可以用作标识符：

```
mysql> CREATE TABLE interval (begin INT, end INT);
ERROR 1064 (42000): You have an error in your SQL syntax ...
near 'interval (begin INT, end INT)'
```

BEGIN 和 END 是关键字但不是保留字，因此将其用作标识符不需要引用。INTERVAL 是保留关键字，必须加引号才能用作标识符：

```
mysql> CREATE TABLE `interval` (begin INT, end INT);
Query OK, 0 rows affected (0.01 sec)
```

例外：在限定名称中跟在句点后面的词必须是标识符，因此即使它是保留字也不需要引用：

```
mysql> CREATE TABLE mydb.interval (begin INT, end INT);
Query OK, 0 rows affected (0.01 sec)
```

内置函数的名称可以用作标识符，但使用时可能需要小心。例如，COUNT 可以作为列名。但是，默认情况下，在函数调用中函数名和后面的 ( 字符之间不允许有空格。此要求使解析器能够区分该名称是用于函数调用还是用于非函数上下文。有关函数名识别的更多详细信息，请参见第 11.2.5 节"函数名解析和解析"。

INFORMATION_SCHEMA.KEYWORDS 表列出了 MySQL 认为的关键字，并指示它们是否是保留的。请参见第 28.3.17 节"INFORMATION_SCHEMA KEYWORDS 表"。
