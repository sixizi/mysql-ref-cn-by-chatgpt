# 11.3 关键字和保留字

关键字是在 SQL 中具有特殊含义的词。部分关键字是保留字，例如 `SELECT`、`DELETE` 和 `BIGINT`，用作表名、列名等标识符时必须加反引号。

```sql
CREATE TABLE interval (begin INT, end INT);     -- 失败，INTERVAL 是保留字
CREATE TABLE `interval` (begin INT, end INT);   -- 成功
```

例外规则是：限定名中句点后的保留字在该位置必然是标识符，因此可以不加引号。例如 `mydb.interval` 中的 `interval` 不需要引号。

大多数非保留关键字可以用作未加引号的标识符，但某些关键字在角色名、存储程序标签等上下文中仍受限制。MySQL 8.0 的完整关键字列表、新增和移除关键字以及受限关键字可在官方英文页面查看。

`INFORMATION_SCHEMA.KEYWORDS` 表列出 MySQL 认为是关键字的词，并标明它们是否保留。
