# 11.7 注释

MySQL 支持三种注释形式：

- `#` 到行尾。
- `--` 到行尾。第二个短横线后必须至少有一个空白或控制字符。
- `/* ... */`，可跨越多行。

示例：

```sql
SELECT 1+1; # 行尾注释
SELECT 1+1; -- 行尾注释
SELECT 1 /* 行内注释 */ + 1;
SELECT 1+
/*
多行注释
*/
1;
```

嵌套注释不受支持且已弃用，应避免使用。

MySQL 还支持一种可执行注释语法，用于编写包含 MySQL 扩展但仍保持可移植性的 SQL：

```sql
/*! MySQL-specific code */
/*!80000 MySQL 8.0 or later only */
```

普通 `/* ... */` 注释会被其他数据库系统忽略；`/*! ... */` 中的内容会被 MySQL 服务器执行。带版本号的可执行注释只在服务器版本大于或等于指定版本时执行。
