# 11.5 表达式

表达式由字面值、列引用、变量、函数调用、运算符、子查询和其他表达式元素组成。本节概述 MySQL 表达式语法的主要类别。

常见表达式包括：

- 逻辑表达式：`AND`、`OR`、`XOR`、`NOT`。
- 比较表达式：`=`、`<=>`、`<>`、`<`、`>`、`IS NULL`、`IS NOT NULL`。
- 谓词：`BETWEEN ... AND ...`、`IN (...)`、`LIKE`、`REGEXP`、`MEMBER OF (...)`。
- 算术表达式：`+`、`-`、`*`、`/`、`DIV`、`MOD`。
- 区间表达式：`INTERVAL expr unit`，用于日期和时间计算。
- 位表达式：`&`、`|`、`^`、`<<`、`>>`。
- 结构化值：行构造器 `(expr, expr, ...)`、JSON 值。

`INTERVAL` 表达式可用于日期加减，例如：

```sql
SELECT NOW() + INTERVAL 1 DAY;
SELECT DATE_ADD('2026-01-31', INTERVAL 1 MONTH);
```

表达式中的 `NULL` 会按三值逻辑传播，`AND`、`OR` 和比较运算的结果可能是真、假或未知。
